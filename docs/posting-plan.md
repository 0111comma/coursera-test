# 投稿計画とチャンネル設定ガイド

作成: 2026-08-13(deep-loops ㉛)。4本の並列調査(投稿頻度/立ち上げ戦略/メタデータ/チャンネル整備)に基づく。
手動アップロード用の実務ドキュメント。各動画のコピペ素材は `uploads/S00X_投稿キット.txt`、字幕は `uploads/S00X.srt`。

## 1. 投稿頻度の結論(調査要点)

- **頻度はランキング要因ではない**(YouTube成長チームが公式に明言。「頻度ペナルティ」「投稿しないと下がる」は俗説)
- ただし相関データでは**月12本以上(週3)** のチャンネルが最も伸びる(vidIQ 508万ch分析: 月1本未満比で再生8倍)
- **1日1本まで**が実務コンセンサス(登録者への通知は1日3本まで/同日連投はフィードで共食い)。同日に出すなら4〜6時間以上あける
- **時刻は19:00〜21:00 JST**(Buffer 180万本分析: Shortsは夜が最強。社会人向け金融は特に)
- 燃え尽きるペースにしない。**週3を90日継続**>毎日投稿を2週間
- 予約投稿は公開時刻の**1時間以上前にアップロード完了**(処理遅延対策)

## 3. アップロード時の設定(全本共通)

| 設定 | 値 | 根拠 |
|---|---|---|
| 公開設定 | 予約投稿(上表) | — |
| 子ども向け | **いいえ** | 「はい」だとコメント欄が完全無効=固定コメント戦略が全滅 |
| Altered content(AI開示) | **いいえ** | 開示義務は実在人物の模倣・実際の出来事の誤認誘導のみ。ずんだもん=架空キャラ+明示的な合成音声は対象外(判断根拠をこの行に記録) |
| 言語 | 日本語 | 字幕・検索インデックスの前提 |
| 字幕 | `uploads/S00X.srt` をアップロード | 手動字幕は別途インデックスされ、金融用語の誤認識を防ぐ |
| サムネイル | フレーム選択で**冒頭のカバーフレーム**を指定 | Shortsのカスタム画像はYPP後に解放。冒頭カバー=サムネ設計なのでフレーム選択で意図通りになる |
| 関連動画リンク | キット記載の1本を設定 | Shortsで唯一クリック可能な公式導線(説明欄・コメントのURLはクリック不可)。「上級者向け機能」の有効化が必要 |
| 有料プロモーション | チェックしない | — |

## 6. 投稿後の運用(各本共通)

1. 公開直後: 固定コメント(キット記載)を投稿して固定。**URLは貼らない**(コメントのURLもクリック不可+スパム判定)
2. 1〜3時間: コメント返信を最優先(初動のエンゲージメント)
3. 48時間後: Studioで「視聴者がスワイプして続行した割合」(目標60%以上)と平均再生率(ループで100%超なら理想)を記録
4. 週次: 検索流入が多かった動画のタイトル型・キーワードを次の企画に反映(1回に変えるのは1要素)

## 7. メタデータチェックリスト(投稿前に各本照合)

- [ ] タイトル28字以内・主要検索語が先頭15字以内・#なし
- [ ] タイトル型が直近と同型ばかりになっていない(疑問形/数式型/逆説型の分散)
- [ ] 説明欄1行目に検索語が自然な文で入っている
- [ ] 説明欄に「クリックしてね」等のURL誘導がない(出典表記としてのURLはOK)
- [ ] ハッシュタグは日本語3個(先頭3つが表示される。#shortsは不要)
- [ ] 検索タグ欄にキット記載の8〜12個(表記ゆれ: ニーサ/イデコ等)
- [ ] SRT字幕アップロード済み・言語=日本語
- [ ] 子ども向け=いいえ/Altered content=いいえ/有料プロモーション=なし
- [ ] 関連動画リンク設定済み
- [ ] 再生リストに追加済み
- [ ] 固定コメント設置済み(URLなし)
