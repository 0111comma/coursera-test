# チャンネル戦略: お金・金融リテラシー

最終更新: 2026-08-12 / テーマ選定の経緯と市場調査は [research/theme-candidates.md](research/theme-candidates.md) を参照。

## 1. コンセプト

**「数字で見るお金の教科書」— すべての主張に出典と計算根拠がある、日本一検証可能なマネー教育チャンネル**

競合大手(リベ大、中田大学など)は「経験談・意見・生き方」型。本チャンネルは真逆の
**「公的データ + 実計算シミュレーション」型**で差別化する。

- 動画内の数字はすべて Claude Code が実際に計算・検証したもの(複利、手取り、税額、年金…)
- グラフ・図表はすべて公的統計(金融庁、国税庁、厚労省、総務省、日銀)から独自生成
- この「毎回オリジナルの計算とチャートを含む」構造自体が、YouTubeの量産型コンテンツ規制への防御になる

## 2. ターゲット視聴者

**主: 20〜35歳の社会人。「NISAやiDeCoって聞くけど、実は仕組みを分かっていない」層**

- お金の不安はあるが、何から学べばいいか分からない
- 長い動画・難しい本は続かない → Shortsで「1つの数字」から入ってもらう
- 特定の商品を売り込まれるのは警戒している → 「制度と数字の解説だけ、勧誘なし」が刺さる

## 3. 提供価値と差別化

| | 競合大手(意見・経験談型) | 本チャンネル(データ・計算型) |
|---|---|---|
| 根拠 | 個人の経験・思想 | 公的統計と実計算(全て出典明記) |
| スタンス | 「こうすべき」 | 「制度はこうなっている。計算するとこうなる」 |
| 検証可能性 | 低い | 全ての数字が再計算可能 |
| 商品への言及 | 特定サービス紹介あり | 個別商品・銘柄には一切言及しない |

## 4. コンテンツピラー(4本柱)

1. **制度解説** — NISA、iDeCo、ふるさと納税、社会保険、税金の仕組み(事実ベースで正確性を担保しやすい主戦場)
2. **シミュレーション** — 「月1万円を20年積み立てたら?」「年収400万の手取りは?」(Claude Codeの計算力が最も活きる)
3. **統計で見る日本のお金** — 平均貯蓄額、年金の実態、物価の推移(公的統計の独自可視化)
4. **制度改正ニュース** — 税制改正、制度変更の速報解説(ネタの自動供給源、Shorts向き)

## 5. フォーマット定義

### ショート動画(毎日1本、〜60秒)
- **型: 「1動画 = 1つの数字」**。冒頭2秒で数字を見せる(例:「411万円。月1万円を20年積み立てた結果です」)
- 構成: フック(数字の提示) → 種明かし(計算・制度の説明) → 意外性の一押し → 解説動画への誘導
- 画面: 数字とグラフ中心 + 合成音声ナレーション + 字幕

### 解説動画(週1本、5〜15分)
- **型: 「教科書の1章」**。その週のShortsで反応が良かったトピックを深掘りする
- 構成: 結論先出し → 制度の仕組み → シミュレーション(複数パターン) → 落とし穴・注意点 → まとめ
- Shorts が集客、解説動画が再生時間(収益化条件の4,000時間)を稼ぐ役割分担

## 6. コンプライアンスルール(全動画で厳守)

YMYL領域 × AI制作の組み合わせは炎上・規制リスクが高い。以下を企画テンプレートのチェックリストに組み込み、例外なく適用する。

1. **投資助言をしない**: 個別銘柄・特定の金融商品・特定の証券会社を推奨しない(金融商品取引法上、投資助言は登録業者のみ可能)
2. **断定しない**: 「儲かる」「必ず」「〜すべき」を使わない。利回りは常に「仮定」と明示(例:「年利5%と仮定した場合」)
3. **出典必須**: 動画内のすべての数字・制度説明に出典(官公庁の一次資料を優先)を付け、概要欄に記載する
4. **計算検証必須**: 動画内の計算はすべてコードで再計算し、検証スクリプトを企画に添付する
5. **制度の時点を明示**: 「2026年8月時点の制度です」を必ず入れる(税制・制度は毎年変わる)
6. **免責を入れる**: 概要欄に「本動画は情報提供を目的としており、投資助言ではありません」を常設

## 7. 収益化ロードマップとKPI

| フェーズ | 目標 | 主要KPI |
|---|---|---|
| 0〜3ヶ月 | フォーマット検証 | Shorts視聴維持率50%以上の「型」を見つける / 週次で企画→投稿サイクルが回る |
| 3〜6ヶ月 | 登録者1,000人 | 登録者数、解説動画の平均視聴時間 |
| 6〜12ヶ月 | 収益化達成 | 総再生4,000時間(解説動画ルート優先。Shortsの1,000万回/90日は狙わない) |

- 収益化は**長尺ルート(登録者1,000人+4,000時間)を本線**とする。Shortsは集客装置と割り切る
- 初期3ヶ月は数字を追わず、「1動画=1つの数字」フォーマットの改善に集中する

## 8. 量産型コンテンツ規制への対策(再掲・最重要)

収益化審査・維持で「独自性なし」と判定されないため、全動画に以下の**いずれか2つ以上**を含める:

- [ ] 独自に計算したシミュレーション結果(検証コード付き)
- [ ] 公的統計から独自生成したグラフ・図表
- [ ] 制度の原文(法令・官公庁資料)に基づく独自の噛み砕き解説
- [ ] 複数パターンの比較(年収別・年齢別など、視聴者が自分事にできる切り口)

「AI音声 + ストック画像 + どこかで見た話」の組み合わせだけの動画は**作らない**。
