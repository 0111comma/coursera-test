# 視聴者ペルソナ(ループ㊹。ユーザー指摘「誰に向けて作ってるの?ペルソナなさすぎる」)

企画書(plan.md)なしで render.py を書いたことが原因で、
「誰が、なぜこの動画で指を止めるのか」を定義しないまま作っていた。以後、この文書を起点にする。

## P-A: 投資シリーズのペルソナ(主戦場・10本中7〜8本)

**「つみたてはしているが、投資の言葉が分からない人」**

| 項目 | 内容 |
|---|---|
| 年齢・状況 | 28〜40歳の会社員。NISAで月1〜3万円、インデックス投信を積立中 |
| 投資歴 | 1〜3年。**個別株はやっていない。信用取引の口座も持っていない** |
| 知識 | 「長期・分散・積立」は知っている。**用語の意味は説明できない** |
| 困りごと | ニュースやSNSで「空売り」「金利上昇」「織り込み済み」と出てくるが、意味が分からない。調べると難しい言葉で返ってきて閉じる |
| 動機 | やり方を知りたいのではない。**言葉の意味が分かるようになりたい。自分の積立に関係あるのか知りたい** |
| 恐れ | 損すること。難しい話で置いていかれること |

### この人が指を止める理由(=フックの設計条件)

**この人は、まだその名詞を知らない。だから名詞を含む数字では止まらない。**

| フックの型 | 例 | 判定 |
|---|---|---|
| 名詞を知らないと意味がない数字 | 「100万円の空売りで、損が200万円」 | **不可**。空売りを知らないし、持ってもいない |
| 名詞なしで分かる矛盾 | 「株が下がると、もうかる人がいる」 | 可。意味が分かり、直ちに「どうやって?」が立つ |
| 自分の資産への影響 | 「金利が上がった日、あなたの投信も動いている」 | 可 |
| 既知の名詞+数字 | 「月7万608円。老後にもらえる年金の額」 | 可(年金は誰でも知っている名詞) |

→ **数字フック(B1)は、視聴者がその名詞をすでに理解している時にだけ機能する。**
用語解説の動画では、名詞を知らなくても分かる矛盾・現象で開き、名詞は2文目で与える。

### この人が動画を見終わって得るもの(=ペイオフの設計条件)

1. **ニュースのその言葉が分かるようになる**(第一の価値)
2. 自分の積立に関係あるか/ないかが分かる
3. やらない理由が分かる(空売り・レバレッジ等は、まねさせない)

やり方の指南はしない。この人は実行しないし、するべきでもない(戦略§6)。

## P-B: 生活・制度シリーズのペルソナ(10本中1〜2本)

**「金融リテラシーが低い社会人」**(従来のペルソナ。S010〜S021で使用)

- 会社員/元会社員のフリーランス。制度の言葉に不慣れ
- 「控除」「標準報酬月額」などの業界語は、初出の同じ画面で日常語に言い換える(D30)
- 検証方法: 1文ずつ聞かせて「?」が浮かんだ箇所を潰すペルソナ通読(ループ㊵)

## 企画書に必ず書く4行(plan.md の先頭)

```
- 想定視聴者: P-A / P-B のどちら + 具体的な状況
- 指を止める理由: この人はフィードで何を見て、何が気になって止まるのか
- 視聴後に得るもの: この人は何が分かるようになるのか
- 視聴者の予想 → この動画の結論: (ネタ選定ゲートF1)
```

**この4行を書かずに render.py を書かない。** 書けないなら、その企画は成立していない。

## P-0: ショートは「選ばれない」(ループ56)

ユーザー指摘:「shortフィードに色んな動画が出てきて、選んで動画をみてるんじゃない。
ただただ関係のないその人にお勧めするアルゴリズムが選んだ動画がたくさん出てくるだけ。
前提知識も何もない人間が見て満足する、その分野に興味がない人が見ても満足する、
そんな動画・プロットを作らないといけない」

**これまでのペルソナ設計が根本から誤っていた。**
P-A(NISAで積立中の会社員)は「自分で選んで見に来る人」の像であり、
**押し付けられる媒体に、引き寄せられる人の像を当てていた**。
だから債券・PER・レバレッジ・配当落ち・為替が全部外れた。
どれも「投資に興味がある人」でないと1秒目で止まらない。

### 実際の視聴者(P-0)

- この動画を**選んでいない**。アルゴリズムが押し込んだ
- この分野に**興味がない**。お金の勉強をしようとしてスマホを開いたわけではない
- 前提知識は**ゼロ**。NISAも投資信託も、名前を聞いたことがある程度
- 1秒で判定する。「自分に関係ある」と思わなければ、指が動く

P-A/P-Bは**動画の中身を書くときの想定読者**として残す。
だが**題材とフックを決めるのはP-0**。順番を間違えない。

### P-0が満足する条件

1. **入口が日常語**: 1文目に出る名詞は、興味がない人でも日常で知っている物
   (給料・税金・銀行・家・保険・宝くじ・学費・年金・スマホ代)
2. **専門語は入口にしない**: NISA・債券・PER・投資信託・為替は、
   **中で教える対象**であって、掴みに使う言葉ではない
3. **見終わって得した気分**: 自分の生活の金額が分かる / 知らないと損する /
   誰かに言いたくなる。そのどれかが無ければ、興味のない人には何も残らない
