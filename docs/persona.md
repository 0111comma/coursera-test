# 新金融チャンネルの視聴者仮説（2026-09-08更新）

チャンネル名はユーザー指定の「やけに金融リテラシーの高いずんだもん」。
現行の企画基準は [チャンネル設計](strategy.md) と [人物仕様](brand/character-spec.md) にまとめる。

既存の主対象「35歳前後の会社員。損はしたくないが、金融を勉強として見る気にはなりにくい人」を初期仮説として残す。
NISAを始めた・検討している人が、日常の判断を通じて理解できる内容にする。
家族構成、特定の性別や年収を全動画の前提にしない。新しいキャラクターでの反応は、公開後に検証する。

以前の調査値・詳細ペルソナは [旧資料](archive/2026-09-08-female-fp/persona.md) に保存した。
旧チャンネルの視聴傾向と、新チャンネルの検証結果を混同しない。
