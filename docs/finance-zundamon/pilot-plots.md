## FZ-P01｜NISAの枠が余っているのに、平然としているずんだもん

### 企画

- 場面：年末。投資で得た利益などが非課税になるNISAの、その年に買える枠が余っている。
- 欲求：将来のために投資したい。同時に、翌春の引っ越し代は確保したい。
- 気になる行動：お金は預金にあるのに、残りの投資枠を埋めない。
- 「やけに」：期限だけで動かず、そのお金を使う時期と照合する。
- 一つの持ち帰り：枠を埋めることより、お金を使う予定に合わせて投資額を決める。
- 目安：45〜60秒。お金がない人物を笑う話にしない。

### 流れと仮セリフ

| 場面 | 画面・動作 | ずんだもんの仮セリフ |
|---|---|---|
| 気になる判断 | カレンダーは12月。架空のNISA画面「今年の投資枠：残りあり」。ずんだもんが落ち着いて閉じる | 「今年のNISA、枠が余ってる。……でも、埋めないのだ。」 |
| お金の置き場所 | 預金のメモに「来春の引っ越し代」。ずんだもんが指で押さえる | 「投資の利益などが非課税になる制度、NISA。預金を回せば、もっと買える。でも、このお金は春の引っ越し代なのだ。」 |
| 期限の条件 | 「今年の未使用枠 → 来年へ上乗せ ×」を短く表示 | 「余った年の枠は、翌年には繰り越せない。それは分かってる。」 |
| 判断の理由 | 引っ越しのカレンダーと、上下する値動きの模式図。下落も描く | 「でも、投資には値下がりもある。春に使うお金を、春までに戻るか分からない所へ入れるつもりはないのだ。」 |
| 決着 | 引っ越し代のメモを残す。内訳の最終行「カーテン」までチェックしてスマホを閉じる | 「枠は上限。ノルマじゃないのだ。……新居のカーテン代も、ここに入ってる。」 |

### 制作時の注意

- 「埋めないほうが必ず得」「誰も上限まで投資すべきでない」と言わない。この人物の、使用予定があるお金についての判断。
- 未使用の年間投資枠を翌年に加算できないことと、非課税保有限度額の消滅を混同しない。
- NISAなら元本が守られるとは言わない。具体的な投資商品、利回り、必要な預金額はこの話では指定しない。
- 「今年」は物語内の12月を指す。年末企画なので、年末以外に公開する場合は冒頭から「年末」と明示するか公開順を変える。
- これは制度の機会を無価値と断定する話ではなく、期限と使途がぶつかったときの選択。

## FZ-P02｜投資信託3本。ずんだもんは中身を並べ始めた

### 企画

- 場面：NISAで購入する投資信託の候補を選んでいる。
- 欲求：投資先を偏らせすぎたくない。
- 気になる行動：商品を3本に増やす前に、商品ごとの中身を同じ場所へ並べ直す。
- 「やけに」：商品名ではなく、実際の投資先がどれだけ重なるかを見る。
- 一つの持ち帰り：商品の本数だけでは、投資先が分散したか分からない。
- 目安：45〜60秒。初心者の買い方を馬鹿にしない。

### 流れと仮セリフ

| 場面 | 画面・動作 | ずんだもんの仮セリフ |
|---|---|---|
| 気になる判断 | 投資信託の候補3枚。「NISAで買う候補」と表示。ずんだもんが裏面を見始める | 「投資信託を3本買えば、分散？ ボクは、まず中身を見るのだ。」 |
| 何の中身か | 「投資家のお金 → いろいろな投資先」の短い図。候補の組入情報へ寄る | 「投資信託は、お金をまとめて運用する商品。別の商品でも、投資先が重なることはある。」 |
| 比べられる例 | 候補画面から明確に切り替えて「架空の単純化例」。3つの箱すべてにX半分・Y半分。実商品名は出さない | 「中身が同じ場合を、簡単な例で見るのだ。この3つは、どれも投資先Xが半分、Yが半分。」 |
| 並べ直す | 各箱から同じ量を出し、X同士・Y同士で集める。合計の円グラフは50%ずつ | 「同じ金額ずつ買って、全部合わせても、Xが半分、Yが半分。商品は3つでも、投資先の割合は変わっていないのだ。」 |
| 決着 | 候補画面へ戻り、「本数」のメモを「投資先・割合」へ書き換える | 「だから、買う前に月次レポートの投資先と割合を見る。袋を3つに分けても、中身まで別物にはならないのだ。」 |

### 制作時の注意

- X・Yの例は重なりを説明する架空のモデル。実在する2銘柄だけの投資信託や、NISA対象商品の実例として見せない。
- 各箱を同額で買う条件は音声でも言う。X・Yの割合は全て50%。数値確認は fact-check.md に記載。
- 複数本の保有が常に無意味とは言わない。一本でも中身が広く分散した商品はあり、本数だけでは決められない。
- 上位銘柄だけで完全な重複率を判定できるとは言わない。実際の商品比較では投資対象・地域・配分等も確認する。
- 最初の場面にNISAは出るが、学びはNISA固有の制度ではなく、投資信託の中身の見方。制度概要をここへ追加して話を分けない。

## FZ-P03｜NISAで値上がり。ずんだもんが見るのは昔の購入額

### 企画

- 場面：NISA口座の、値上がりした保有商品の残高を見ている。
- 欲求：非課税で保有できる総枠を、どれだけ使っているか確認したい。
- 気になる行動：現在の残高が大きく表示される画面を横へ寄せて、購入額を確認する。
- 「やけに」：目立つ数字と、いまの判断に必要な数字を分ける。
- 一つの持ち帰り：NISAの非課税保有限度額は購入額で管理され、値上がり分が追加で総枠を使うわけではない。
- 目安：40〜55秒。投資成果を誇る動画にしない。

### 流れと仮セリフ

| 場面 | 画面・動作 | ずんだもんの仮セリフ |
|---|---|---|
| 目立つ数字 | 架空の口座画面。「仮の例：100万円で買い、200万円に値上がり」。現在残高を大きく表示 | 「NISAで100万円で買った商品が、200万円になったとする。非課税で持てる総枠も、200万円使ったことになる？」 |
| 意外な確認 | ずんだもんが現在残高を脇へ寄せ、「購入額100万円」を中央へ出す | 「ここで見るのは、買ったときの金額なのだ。」 |
| 制度と数字 | 「NISA＝投資の利益などが非課税になる制度」「総枠の管理：購入額」を順に表示 | 「投資の利益などが非課税になるNISA。その総枠は、今の値段じゃなくて、購入額で管理する。」 |
| 対応を見せる | 「現在の価値200万円」と「この商品の総枠使用額100万円」を別の列に置く | 「この商品が使っている総枠は、100万円のまま。値上がりした100万円まで、追加で枠を使うわけではないのだ。」 |
| 決着 | 「現在の価値」と「枠の確認」の二つの付箋を対応する数字へ。ずんだもんが購入額の欄をチェック | 「残高は200万円。枠の確認は100万円。増えた分まで、ボクが払ったことにしないでほしいのだ。」 |

### 制作時の注意

- 仮の値上がり例。期間、期待利回り、再現性は示さない。実績や将来予測に見せない。
- 同じ商品を保有し続け、追加購入・売却・分配金再投資はない例。比較条件を図のそばに表示する。
- 年間投資枠の話と混ぜず、「非課税で保有できる総枠」を対象にする。
- 含み益が現金として確定しているとは言わない。
- 売却後の枠の再利用は別の論点なので、今回は説明しない。
- 「値上がりしても絶対売らない」という売買指示にはしない。残高と総枠の使用額の区別を描く。

## 3本を並べたときの役割

P01は「使う時期を優先する」、P02は「中身を比較する」、P03は「必要な数字を選ぶ」。
知識の読み上げを3回繰り返すのではなく、同じ人物の異なる判断を見せる。
P01を年末以外に公開するなら、P02→P03→P01の順でも成立する。前後の視聴を必要条件にしない。

## 初稿の自己点検と残る作業

- 旧女性FPの挨拶や講義構成を引き継がず、3本とも冒頭の判断へ戻る流れにした。
- 3本とも主な学びを一つに絞った。制度解説を全て盛り込まない。
- P02の架空例と、P03の仮の値上がりを実績と混同しない表示を指定した。
- 仮セリフには、まだ声にすると硬い箇所があり得る。VOICEVOXで読み、息継ぎ・尺・オチの間を調整する。
- P01とP03のオチは控えめ。実際の表情と間で成立するかを見る。成立しなければ末尾の単語交換だけで済ませず、場面から書き直す。
- 外部視聴者による初見レビュー、批評、音声確認、映像の品質検証は未実施。合格済みとは扱わない。
