## P03の数値確認

条件：取得金額100万円の商品を継続保有。仮に時価が200万円。追加購入・売却・分配金再投資なし。
- 時価と取得金額の差：200万円 - 100万円 = 100万円
- この商品の非課税保有限度額の使用額：取得金額の100万円
- 値上がりのみを理由とした追加使用額：0円

値上がりは仮定。100万円が200万円になる確率、期間、推奨商品を示すものではない。
口座に他の商品がある場合の総使用額とは区別し、画面には「この商品」と表示する。
