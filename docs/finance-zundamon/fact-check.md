P01の引っ越し代を投資しない判断は、主人公の設定上の選択。誰にでも同じ預金額・投資額を勧めるものではない。
P02の月次レポートは投資先を確認する入口。上位銘柄だけで全資産の重複を厳密に計算できるとはしない。

## P02の数値確認

条件：架空の商品A・B・Cの各々が、投資先Xを50%、Yを50%保有する。同額ずつ購入。費用や価格変動は省略。
これは投資対象の重なりだけを示す模式例であり、実在商品やNISA対象商品を再現していない。

各商品の購入額を1単位とすると：
- 合計購入額：1 + 1 + 1 = 3単位
- X：0.5 + 0.5 + 0.5 = 1.5単位
- Y：0.5 + 0.5 + 0.5 = 1.5単位
- 全体の配分：X = 1.5 / 3 = 50%、Y = 1.5 / 3 = 50%

結論は「本数だけで投資先の分散を判断できない」。複数商品が必ず無意味、という一般化はしない。

## P03の数値確認

条件：取得金額100万円の商品を継続保有。仮に時価が200万円。追加購入・売却・分配金再投資なし。
- 時価と取得金額の差：200万円 - 100万円 = 100万円
- この商品の非課税保有限度額の使用額：取得金額の100万円
- 値上がりのみを理由とした追加使用額：0円

値上がりは仮定。100万円が200万円になる確率、期間、推奨商品を示すものではない。
口座に他の商品がある場合の総使用額とは区別し、画面には「この商品」と表示する。
