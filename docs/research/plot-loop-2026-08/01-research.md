# フェーズ1: 調査 — なぜプロットが「意味わかんなく」なるのか

着手前の仮説(PROGRAM.md):
> プロットの分かりにくさは「独立した話の数」で説明できる。

この仮説を、認知科学の側から裏づけられるか調べた。結論から言うと**裏づけられた**。
しかも「数が多いとダメ」ではなく、**「因果の鎖に載っていない事実がダメ」**という、
より使える形になった。

## 1. 物語の理解は、因果の鎖をたどる作業である

物語理解の研究(Trabasso ら、causal network theory)で繰り返し確認されていること:

- **因果的につながっている出来事ほど、多く思い出され、先に思い出される。**
  読み手は現在の出来事を理解するとき、**因果的に関係のある過去の出来事を検索して統合する**
- 出来事の「重要さ」の判定を予測するのは次の2つ:
  1. **直接の因果的つながりの数**
  2. **その出来事が、冒頭から結末までの因果の鎖の上に載っているかどうか**
- 因果的に一貫した3部構成の順序は、断片的な出来事の順序よりよく覚えられる。
  一貫した刺激の細部の再生は、断片的な系列の細部の再生より優れる
- 「提示された順に思い出して」と指示しても、**人は因果の順に思い出してしまう**。
  理解の過程で走る推論は、課題の指示を上書きするほど強い

→ **視聴者は、こちらが並べた順ではなく「因果の鎖」で記憶している。**
鎖に載っていない事実は、正しくても落ちる。落ちるだけならまだよくて、
**鎖を探して失敗するあいだ、次の文が入ってこない。** これが「意味わかんなくなる」の正体。

## 2. 作業記憶には上限がある(認知負荷理論)

- Sweller の認知負荷理論: 人の作業記憶には限りがあり、
  一度に処理できる量を超えると理解と学習が落ちる
- 動画の速度を上げると単位時間あたりに流れ込む情報が増え、
  **作業記憶の容量を超えた時点で学習が阻害される**
- 情報密度の急上昇(information density spikes)がある動画で、
  深刻な作業記憶の過負荷が観察されている

→ 本チャンネルは話速を1.3倍にしている(ループ58)。**速度を上げたぶん、
情報の密度は下げないと釣り合わない。** 速くして、かつ詰め込んだのが今のS013。

## 3. 自チャンネルの実測と照合する

「初出の数値」を数えると(scratchpad/count_nums.py):

| 本 | ユニット | 初出の数値 | 独立した話 | ユーザー判定 |
|---|---|---|---|---|
| S011 年金 | 19 | 14 | **1** | **「素晴らしい。このクオリティと面白さなら良いよ」** |
| S010 空売り | 14 | 6 | 1 | 合格 |
| S015 住民税 | 18 | 7 | 1 | 「良いね」 |
| S012 社会保険料 | 18 | 9 | 1 | (未評価) |
| S014 銀行の手数料 | 18 | 12 | 2 | 「内容がおもろいからいい」(日本語は要修正) |
| **S013 変動と固定** | **21** | **17** | **6** | **「もっと意味わかんなくなってる」** |

**数値の個数だけでは分かれない**(S011は14個もあるのに合格)。
分かれるのは**独立した話の数**である。S011の14個は全部1本の計算でつながっている:

```
1万7920円 ×12ヶ月 ×40年 = 860万円 ┐
7万608円 ×12ヶ月 = 85万円         ┘→ 860÷85 = 10年 → 65+10 = 75歳
                                      → 81歳−75歳 = 6年ぶん = 525万円
```

種になる数字は**2つだけ**(保険料と年金額)。あとは全部そこから導かれる。
冒頭の問い「元が取れるのか」から結末「75歳」まで、**1本の鎖**になっている。
これは上の研究1の「冒頭から結末までの因果の鎖」そのものである。

S013(現行)はこうなっている:

```
[鎖1] 3000万円/35年 → 3571万円 / 4948万円 → 差1377万円
[単発] 75%が変動
[単発] 昔8.5%だった
[単発] 2024年から上がりはじめた
[鎖2] 1%上がると → 毎月1万4728円
[鎖3] 5年後3.83% → 固定と並ぶ
```

**3つの鎖と3つの単発。**どれも事実で、どれも「変動と固定」の話ではあるが、
**互いに導かれない。** 視聴者は鎖1を組み立て終わった所で、鎖のない事実を3つ投げられ、
また別の鎖を2本組まされる。5回リセットされている。

## 4. なぜこうなったか(制作プロセスの問題)

S013 は**フィードバックのたびに足して、引かなかった**:

| 回 | 指摘 | 私がしたこと |
|---|---|---|
| ループ60 | 「変わらない金利もある、から分からない」 | 変動/固定の説明を**2ユニット追加** |
| ループ62 | 「どっちが得なのかまで落とし込みたい」 | 75% / 8.5% / 2024年 / 1万4728円 / 3.83% を**追加** |

どちらの指摘も正しく、追加した内容も正しい。**間違っていたのは、足すときに引かなかったこと。**
55.5秒という尺は変わらないのに、話だけが増えた。増えた分は文の骨格を削って捻出した
(それがループ63の「助詞と動詞を削るな」につながっている)。

**指摘に応えることと、1本の鎖を保つことは、両立させなければならない。**
両立できないなら、それは**2本の動画**である。

## 5. この調査から作る基準(フェーズ2で機械化する)

**L1. 1本 = 1つの鎖。** 冒頭の問いから結末まで、数字が導出でつながっていること。
   種になる数字(外から持ってくる値)は**3つまで**。

**L2. 鎖に載らない事実は入れない。** 面白くても、正しくても、
   その動画の問いの答えに寄与しないなら別の動画にする。

**L3. 指摘に応えて足すときは、同じ量を引く。** 引けないなら2本に割る。

**L4. 速度を上げたぶん、密度は下げる。** 1.3倍にしたのだから、
   1秒あたりに投げる新情報はむしろ減らす。
