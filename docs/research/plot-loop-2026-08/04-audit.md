# フェーズ4: 未公開の残り3本を同じ物差しで点検する

対象: S012(社会保険料)・S014(銀行の手数料)・S015(住民税)。
S013 はフェーズ3で作り直し済み。

## 1. 機械ゲート(check_ikko.py)

3本とも上限内。**直しが必要なものは無かった。**

| 本 | 鎖 | 判定 |
|---|---|---|
| S012 社会保険料 | 1本 | OK |
| S014 銀行の手数料 | 1本 | OK |
| S015 住民税 | 1本 | OK |
| (参考)S013 作り直し後 | 2本 | OK |
| (参考)S013 作り直し前 | **4本** | NG |

## 2. チェッカーの改良(この点検の副産物)

点検中に、S014 の `20.315%` が「どの計算にも繋がらない数値」に出るのを見つけた。
実際には `4000円 × 20.315% = 813円` で繋がっているはずである。

原因は実装だった。**最初に見つかった導出だけで縁を張って打ち切っていた。**
`813円` は「4000 × 20.315%」でも「4000 − 3187」でも導ける。後者が先に当たると、
`20.315%` との縁が張られないまま次に進んでしまう。

**見つかった導出を全部つなぐ**ように直した。効果:

| 本 | 改良前 | 改良後 |
|---|---|---|
| S013 作り直し前(壊れていた版) | 鎖4本/単発5個 | **鎖4本/単発5個**(変わらず = 見逃さない) |
| S013 作り直し後 | 鎖2本/単発6個 | 鎖2本/単発6個 |
| S010 合格 | 鎖1本/単発0個 | 鎖1本/単発0個 |
| **S011 合格** | 鎖2本/単発2個 | **鎖1本/単発1個** |
| S012 | 鎖1本/単発0個 | 鎖1本/単発0個 |
| **S014** | 鎖2本/単発2個 | **鎖1本/単発0個** |
| S015 合格 | 鎖1本/単発5個 | 鎖1本/単発5個 |

**合格作がすべて鎖1本になり、壊れていた版は4本のまま。** 分離がはっきりした。
閾値(上限2本)は据え置き。作り直した S013 の2本は「総額の差」と「それが並ぶ金利」で、
同じ問いの表と裏なので許容する。

## 3. 目視の監査 — 機械が見られない部分

check_ikko は「数字が繋がっているか」しか見ない。
**「全ビートが1つの問いに奉仕しているか」は目で見るしかない。** 3本を読んだ結果:

### S012 社会保険料 — 問いに奉仕していないビートが2つ

問い「その保険料、誰が払っているのか」→ 答え「会社も同じ額。年収400万の人に460万円」。

| # | ビート | 判定 |
|---|---|---|
| 4 | その中身は、年金と健康保険なのだ。 | **問いに奉仕していない**(内訳の説明) |
| 5 | これは、病気や老後にそなえるお金。 | **問いに奉仕していない**(制度の目的) |
| 6-7 | 月33万円 → 毎月4万9千円 | 同じ59万円の言い換え。生活翻訳(P2)としての役割はある |

**直さない。** 理由: (a) 鎖は1本で繋がっており、視聴者が迷子になる形ではない
(b) ユーザーから指摘を受けていない本を、指摘のないまま作り替えるのは
リスクのほうが大きい (c) 今夜のレンダリング枠は S013 に使うべき。
ただし**次に S012 を触るときは #4 と #5 を削る**候補として記録しておく。

### S014 銀行の手数料 — 問題なし

問い「銀行に預けたら増えるのか」→ 答え「手数料のほうが多い」+ 減らし方3つ。
18ビート全部が問いか行動に奉仕している。#13「金利は選べない」は行動への転換点。

### S015 住民税 — 問題なし(ほぼ)

問い「住民税はいつの所得で決まるのか」→ 答え「去年。辞めた翌年も来る」。
#6「その住民税とは、住む街に払う税金」だけが定義の寄り道だが、
初出の語の言い換え(W7)としての役割があるので残してよい。

## 4. この点検から持ち帰るもの

**A1. 機械ゲートを通ることと、1つの問いに奉仕していることは別。**
鎖が1本でも、問いに関係ないビートは混ざる。plan.md の
「この動画が答える問い(1つだけ)」と全ビートを並べて読む工程を、
レンダリング前に必ず入れる。

**A2. 指摘を受けていない本を、指摘のないまま作り替えない。**
S012 に改善余地はあるが、いま触ると新しい不具合を入れるリスクのほうが大きい。
**見つけた改善余地は記録し、次にその本を触るときに適用する。**
(これは S013 で「足すだけで引かなかった」のと同じ失敗を、
別の形で繰り返さないための歯止めでもある)
