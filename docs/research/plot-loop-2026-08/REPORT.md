## 何が起きていたのか

ご指摘は「金利の話のやつ、もっと意味わかんなくなってる、プロットが」でした。
測ってみると、そのとおりの形で壊れていました。

```
作り直す前の S013
  鎖1: 1377万円 → 3571万円 → 4948万円
  鎖2: 2 → 1 → 5年
  鎖3: 8万5036円 → 9万9764円 → 1万4728円
  鎖4: 3.14% → 3.83%
  単発: 3000万円、1.025%、35年、75%、8.5%
```

**3つの鎖と3つの単発。** 視聴者は鎖1を組み立て終わった所で鎖のない事実を3つ投げられ、
また別の鎖を2本組まされます。**5回リセットされていました。**

対して、合格をいただいた S011(年金)はこうでした:

```
1万7920円 ×12ヶ月 ×40年 = 860万円 ┐
7万608円 ×12ヶ月 = 85万円         ┘→ 860÷85 = 10年 → 65+10 = 75歳
                                     → 81歳−75歳 = 6年ぶん = 525万円
```

**種になる数字は2つだけで、あとは全部そこから導かれる。1本の鎖。**

### なぜそうなったか

私がループ60とループ62のご指摘に応えるとき、**足すだけで引かなかった**からです。

| 回 | ご指摘 | 私がしたこと |
|---|---|---|
| ループ60 | 「変わらない金利もある、から分からない」 | 変動/固定の説明を2ユニット**追加** |
| ループ62 | 「どっちが得なのかまで落とし込みたい」 | 75% / 8.5% / 2024年 / 1万4728円 / 3.83% を**追加** |

どちらのご指摘も正しく、足した内容も事実として正しい。
**間違っていたのは、尺が変わらないのに話だけ増やしたことです。**
増えた分は文の骨格を削って捻出していて、それが「助詞と動詞が抜けている」
(ループ63のご指摘)にもつながっていました。**同じ根から出た2つの症状**でした。

## 調べたこと

物語理解の研究で繰り返し確認されているのは、**人は提示された順ではなく
「因果の鎖」で記憶する**ということでした。「提示順に思い出して」と指示しても
因果順で思い出してしまうほど強い。出来事の重要さを予測するのは
(1)直接の因果的つながりの数 (2)冒頭から結末までの鎖の上に載っているか、の2つ。

つまり**鎖に載っていない事実は、落ちるだけでなく、
鎖を探して失敗するあいだ次の文が入ってこない。** これが「意味わかんない」の正体です。

あわせて認知負荷理論から、**話速を上げたぶん情報密度は下げないと釣り合わない**
ことも確認しました。1.3倍にした(ループ58)のに詰め込んだのが、今回の S013 でした。

詳細は [01-research.md](01-research.md)。

## 作ったもの

### `production/check_ikko.py` — 6つ目のゲート

字幕の数値を出現順に並べ、**前に出た数値から四則演算で導けるか**を試して
鎖にまとめ(union-find)、残った鎖の本数を数えます。上限は2本。

較正でひとつ**指標を捨てました**。「宙に浮いた数字の個数」は、合格判定をいただいた
S015(住民税)に5個も出てしまいます。画面の丸めのせいです
(「年17万円」と言っても実額は176,700円なので、そこから「毎月1万4700円」を導くと
3.8%ずれる)。許容誤差を緩めると今度は S013 を見逃すので、
**誤爆と見逃しを同時に避けられる閾値が存在しない指標は、閾値にしませんでした。**

詳細は [02-calibration.md](02-calibration.md)。

## 持ち帰った規則

**L1. 1本 = 1つの鎖。** 冒頭の問いから結末まで、数字が導出でつながっていること。

**L2. 鎖に載らない事実は入れない。** 面白くても正しくても、
その動画の問いの答えに寄与しないなら別の動画にする。

**L3. 指摘に応えて足すときは、同じ量を引く。** 引けないなら2本に割る。

**L4. 速度を上げたぶん、密度は下げる。**

**A1. 機械ゲートを通ることと、1つの問いに奉仕していることは別。**
鎖が1本でも、問いに関係ないビートは混ざる。
plan.md の「この動画が答える問い」と全ビートを並べて読む工程を必ず入れる。

**A2. 指摘を受けていない本を、指摘のないまま作り替えない。**
見つけた改善余地は記録し、次にその本を触るときに適用する。
(ただしゲート落ちは別。出せない状態なので直す)
