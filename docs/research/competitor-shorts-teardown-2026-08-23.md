# 競合ショートの分解(@bankacademy 2本・計51コマ)

ユーザーが送ってくれたスクリーンショットから、**進捗バーの長さを測って時間軸を復元**し、
2本を突き合わせた。動画は再生できない環境なので、**測れたことだけを書く**。

- 1本目: 【保存版】50代・60代の新NISA、9割の人はこれでOK(いいね6086 / コメント73)— 24コマ
- 2本目: 【50代・60代向け】退職金を受け取ったらまずこれやれ!(いいね219 / コメント3)— 26コマ

---

## 1. 構成が完全にテンプレート化されている

進捗バーで測った位置を2本で並べる:

| | 動画1(NISA) | 動画2(退職金) |
|---|---|---|
| カバー(タイトル) | 〜3.7% | 〜4.1% |
| 本編の開始 | 5.6% | 6.7% |
| 結論 | 73.2% | 73.5% |
| **ロゴのカット** | **75.8%** | **75.8%** |
| 「〜シェアしますので」 | 80.2% | 78.6% |
| 「ぜひチャンネル登録・フォローをお願いします!」 | 82.9% | 83.8% |

**ロゴのカットが両方とも 75.8%。偶然ではない。**

つまり尺の配分が固定されている:

```
0〜5%    カバー(タイトルを段階的に積む)
5〜73%   本編
73〜76%  結論
76〜100% CTA(定型文4カット)
```

**CTAは全体の1/4。**しかも文言まで同じテンプレート:

> バンクアカデミーでは今後も、[ターゲット]に[価値]をシェアしますので、
> ぜひチャンネル登録・フォローをお願いします!

## 3. 本編の型は2つある(タイトルが決める)

| | タイトル | 結論の位置 | 本編の流れ |
|---|---|---|---|
| 動画1 | 「9割はこれで**OK**!」= 安心の約束 | **73%** | 状況と感情(数字なし)→ 前提 → グラフと数字 → 出口 → 結論 |
| 動画2 | 「まず**これやれ**!」= 命令 | **8.7%** | **命令を即出し** → NG行動 → 表で配分 → 計算 → 結論の再確認 |

**タイトルの語尾が本編の構成を決めている。**

## 4. 数字の鎖(動画2)— 検算したら全部合う

```
26.3%  例えば年金に加えて 月5万 あれば        ← 目標を先に置く
33〜45% 表(2,000万の内訳を4行、赤枠が1行ずつ動く)
47.3%  国債(年1.8%)に 500万
49.7%  高配当株(年3%)に 300万
52.7%  利息や配当で 毎月約1.5万 もらえます
58.0%  残り 約3.5万 を新NISAから取り崩せば
65.7%  毎月5万を年金にプラスできます!         ← 26.3%に着地
```

検算:

```
500万 × 1.80% ÷ 12 = 7,500円/月
300万 × 3.00% ÷ 12 = 7,500円/月  → 合計 1.5万  ✓ 一致
5万 − 1.5万 = 3.5万                            ✓ 一致
600+500+600+300 = 2,000万                      ✓ 一致
```

**冒頭に置いた数字へ着地する構成**で、うちの `check_ikko`(鎖は1本)と同じ思想。
**構成の考え方は近い。**

### 向こうが言っていないこと(うちの隙間)

新NISA 600万を月3.5万ずつ取り崩すと:

| | 尽きるまで | 65歳開始なら |
|---|---|---|
| 運用益ゼロ | 14.3年 | 79歳 |
| 年3% | 18.8年 | 83歳 |
| 年5% | 25.2年 | 90歳 |

動画は「毎月5万を年金にプラスできます!」で終わり、**いつまで続くかを言っていない**。
**「その5万、何歳まで続くのか」はうちが得意な問い**であり、
YouTube の言う「独自の価値」の条件にも合う。

## 5. 画面(実測)

| | @bankacademy | うち |
|---|---|---|
| 画面の平均の明るさ | **0.771**(9枚とも0.736以上) | **0.141** |
| 背景色 | #f0d8c0(クリーム)+ ドット | #1a1a19(ほぼ黒) |

**滞在時間そのものは大差ない。違うのは「そのあいだ画面が変わるか」だけ。**

### 図の使い方

- **グラフは1本目に1回だけ**(金融庁のスクショを引用)。しかも同じ絵を2文またぎ
- **表は2本目に1回**。4行 × [金額・アイコン・説明]。赤枠が1行ずつ下りる
- それ以外はすべて**人物やモノのイラスト**。感情(困り顔・笑顔・ガッツポーズ)を出している
- **吹き出しで視聴者の心の声を代弁**してから否定する(「年齢的に無理かなぁ...」)

### 素材

- 1本あたり**約25点**。ただし**チャンネル横断で使い回し**(動画2の老夫婦は動画1と同じ絵)
- マスコット(ペンギン)が表情・ポーズ違いで頻出。**素材の半分近くがマスコット**

## 6. うちに足りないもの(結論)

| # | 差 | いまの道具で足りるか |
|---|---|---|
| 1 | **画面が明るい** | 色定数を変えるだけ。**足りる** |

| 3 | **図の滞在中に画面が変わる** | `table(highlight=)` `barsN(highlight=)` が既にある。**足りる** |
| 4 | **上部にタイトル帯を固定** | 未実装。簡単 |
| 5 | **CTAブロック(定型4カット)** | 未実装。簡単 |

**1〜6はコードの問題で、今日中に手が動く。7だけが調達の問題。**

### 7をどうするか

| 案 | 実現性 | 懸念 |
|---|---|---|
| A. ずんだもんの表情・ポーズ差分を増やす | すぐできる(既に5表情) | 人物の場面(老夫婦・スーツの女性)は作れない |
| B. フリー素材(いらすとや等)を使う | ライセンス要確認 | いらすとやは**1制作物に20点以上で有償**。1本25点なら該当しうる |
| C. **ローカルのSDXLでイラストを生成**(RTX 4070) | **十分動く**(SDXLは8GBで快適、4070は12GB) | AIポリシー。ただし**人物ペルソナではなく素材**なので該当しにくい |
| D. matplotlib で図形だけで作る | いまの延長 | 感情が出せない。**これが今の限界そのもの** |

**Cが本命。**前回「ローカルAIは動画生成に使う」と考えたが、それは筋が悪かった。
**イラスト素材の生成に使うのが正しい。**動画生成(1本30〜75分)と違い、
SDXL の画像1枚は数秒〜十数秒。25点なら数分で、しかも**一度作れば使い回せる**。

ただし **Claude Code をユーザーのPCで動かす必要がある**(いまはクラウドでGPUが無い)。
