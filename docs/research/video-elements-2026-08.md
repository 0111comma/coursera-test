# 動画の全構成要素の分解と最適解 — Deep Research(2026-08-21)

ユーザー指摘「背景はなぜこのまま? 全ての要素において仕事をサボっているように思える。
要素を全て詳細に分類して、その最適解は何かDeep researchをかけて、方針が決まってから作成」への回答。

確度: A=一次資料/実測 B=独立複数ソース一致 C=単一ソース・自チャンネル判断(実測で検証する)

## 調査の要点(ソースの一致点)

1. **定番の画面は「背景+テロップ背景(字幕帯)+素材表示部分の枠」の3点セット**(確度B)。
   ずんだもん/ゆっくり解説のテンプレはこの3つを最初に決める。**現状のL001はこの3つが全部無い。**
2. **画面は常にどこかが動いているとキャラが止まっていても間が持つ**(確度B)。
   背景がゆっくり流れる・効果背景が動く、が定石。
3. 配色は**4色以内**(無彩色2+テーマ色+強調色)。フォントは太ゴシック2〜3種まで。
   縁取りで背景との分離を確保。装飾は「足す」より「ノイズを削る」(確度B)。
4. 音量は**BGMは声より約-20dB**(ゆっくり系は-25〜-35dBと更に控えめ推奨)。SEは強調と転換だけ(確度B)。
5. サムネは**キャラの顔+大文字+派手背景+素材**の4点構成(確度B)。
6. 立ち絵は口パク・目パチ・登場退場エフェクト。場面転換にはアイキャッチとSE(確度B)。
