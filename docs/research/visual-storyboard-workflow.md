# 金融ショートのプロット・画面設計・検証（U28）

2026-09-08。企画→プロット作成→描画という流れを維持し、工程間で落ちていた画面の意味を明示する。

## 1. 企画

一つのメッセージ、視聴者が持ちやすい疑問、見終えたときに得る理解を定める。例の変更では主題を変えない（U27）。FZ002の主題は商品数だけでは分散を判断できず、投資先と割合を見ること。

## 2. プロット作成に絵コンテを含める

各場面について以下を埋める。台詞だけ決まっても画面設計完了とはしない。

| 項目 | 決める内容 |
|---|---|
| 伝える一点 | この場面で何を理解してもらうか |
| 必要な情報 | 実物・名称・データ・関係のうち何が根拠になるか |
| 図の意味 | 比較、包含、重なり、変化、順序など何を形にするか |
| 視聴者の読み取り | 実際の画面から何が読み取れるか。台詞だけが結論を運んでいないか |
| 見せる順番 | 最初に見せる要素と、次に現れる要素。前後で何を発見するか |
| 削除する要素 | 同じ意味の繰り返し、根拠のない箱、装飾だけの矢印など |

問いかけの画面には答えを先に全部置く必要はないが、何についての問いかは具体的に分かるようにする。

FZ002の検討例：購入候補の商品を示して「3本なら分散？」という疑問を置き、続く画面で同じ商品の保有企業を開く。同じ企業を一貫した表示で追えるようにし、「商品名は別でも投資先が重なる」を読み取れるようにする。実在商品の中身が全部同じであるような図や、比率の裏付けがない面積表現にはしない。これは画面設計の方向の例であり、完成した絵コンテ・改善済み映像ではない。

## 3. 描画

絵コンテの意味と見せる順番を実装する。カード枚数や既存テンプレートの都合から画面内容を逆算しない。意味の異なる場面を同じ図で済ませない。重要度に応じたサイズ、整列、関係の一貫性、読める情報量を確認する。

## 検証の区別

- 正確性：図と台詞が資料に裏付けられ、誤った包含・同一性・量を暗示しない。
- 意味：図から意図した比較や関係が読み取れる。見出しを読むだけの画面になっていない。
- 見やすさ：どこを見るかが明確で、冗長な情報がなく、短時間でも対象を区別できる。
- 技術：文字境界、下側余白、右側専用余白なし、音声話者、解像度、全デコードを確認。

技術検査だけで上の3項目を合格扱いしない。まず主要画面の静止画を自分で確認し、その後に動画として台詞・図の出現順とタイミングを確認する。ユーザーに工程上の確認作業を当然の負担として転嫁しない。納品は独立したMP4リンクを必須とする（U26）。
