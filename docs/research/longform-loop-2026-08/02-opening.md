# フェーズ2: 冒頭 — 30〜60秒に何を置くか

フェーズ1で「60秒で55%以上が離脱する」ことは分かった。
このフェーズは、**その60秒に何を置くのか**を決める。

## 調べたこと

### 冒頭は3段構えになっている

実務側で共通して出てくる形。

| 区間 | 役目 | 具体 |
|---|---|---|
| **0〜5秒** | パターン割り込み | 予想を外す。挨拶もチャンネル紹介も置かない |
| **5〜15秒** | **具体的な約束** | 何が手に入るのかを**数字か固有の言葉**で言う |
| **15〜30秒** | コミットの引っかけ | 「ただし条件が3つある」で開いたループを閉じさせない |

(確度**B**。複数の実務ソースで区間の切り方と役目が一致。ただし実験データではない)

### 最も急な離脱は10〜20秒。変化点は15秒あたり

(確度**C**。単一系列のソース。ただしフェーズ1の「15秒の価値提案で18%改善」と方向が一致)

### 30秒時点で50%以上残っていれば良い方

YouTubeの視聴者維持レポートは「最初の30秒を過ぎた視聴者の割合」を出す。
ここが50%を超えると平均より上とされる。(確度**B**)

### やってはいけないこと(実務側で共通して挙がる4つ)

1. 一般的な挨拶で始める
2. 焦らすだけで、急ぐ理由を作らない
3. **価値の約束より先に前提を置く**
4. どの動画も同じ形の冒頭にする

### 冒頭は静止画にしない

冒頭30秒に動きのない画が続くと離脱率が上がる。
言っていることを補強する動く画があると維持率が上がる。(確度**B**)

### 冒頭で上げたエネルギーを、本題で落とさない

強い冒頭のあとに崖を作らない。**冒頭の勢いを本題に橋渡しする**。
リセットしてはいけない。(確度**B**)

## L001 のどこが、それに反しているか

`production/timeline_long.py`(このフェーズで作った測定ツール)の出力より。

```
  秒     型            字幕
   0.0  文字 hero        NISA口座が、マイナスになっているとする。
   2.6  文字 hero        そのマイナスは、税金の足しにならないのか。
   5.3  文字 card        でもその損は、税金では無かったことになる。
   8.1  文字 card        でも課税口座なら、そうではないのだ。
  10.3  文字 card        その課税口座とは、NISAではない普通の口座のこと。 ← 定義
  13.7  文字 card        その課税口座の損は、同じ年の利益から引けるのだ。   ← 前提
  17.1  文字 card        だからNISAのほうが、不利になる場合があるのだ。
  19.9  図   compare2    たとえば、こういう年を考えてみるのだ。          ← 図はここが最初
  22.3  図   compare2    その年は、NISAで20万円の損、課税口座で20万円の利益。← 数値はここが最初
  30.3  図   compare2    でもNISAを使っていると、40630円かかるのだ。      ← 答えはここ
```

| 研究の言うこと | L001の実測 | 判定 |
|---|---|---|
| 0〜5秒でパターン割り込み | 場面の提示と問い。予想は外していない | **弱い** |
| 5〜15秒で**具体的な約束**を数字で | 5.3〜17.1秒は**全部が前提と定義**。数値ゼロ | **反している** |
| 数値は15秒以内 | **22.3秒** | **反している** |
| 冒頭30秒に動く画 | **0〜19.9秒はすべて文字カード**(hero 2枚 + card 5枚) | **反している** |
| 15〜30秒で引っかけ | 例の設定に使っている。条件の予告は37.5秒 | **遅い** |
| 冒頭の勢いを本題に橋渡し | **53.0秒に「では第1章」**。しかも中身は損の話ではない | **反している** |

**やってはいけないことの3番(価値の約束より先に前提を置く)を、そのままやっている。**
10.3秒の「その課税口座とは、NISAではない普通の口座のこと」は、
定義としては正しいが、**約束の前に置く必要がない**。

**そして最悪なのは 53.0秒。** 冒頭で 40,630円 まで出して勢いを作ったのに、
離脱の山のど真ん中で「では第1章。NISAは、お金を増やしてくれるのか」と
**別のテーマにリセット**している。研究が「やるな」と言っている崖そのもの。

## 何を変えるか

### 冒頭の型を決める(これをテンプレにする)

```
0〜5秒    数字で割り込む。答えの金額を先に出す
          例:「NISAで20万円損した。でも税金は40630円ふえた」
5〜15秒   具体的な約束。何が手に入るか
          例:「この差がどこから出るのか、自分の場合の出し方まで出す」
15〜30秒  引っかけ。ただし条件がある
          例:「ただし、これが起きるのは条件がそろった年だけ」
30〜60秒  **本題に入る。ここで別テーマに移らない**
```

| # | 変えるもの | どう変えるか |
|---|---|---|
| 1 | **台本(0〜15秒)** | 答えの40,630円を**5秒以内**に出す。#5「課税口座とは」の定義は第2章へ移す |
| 2 | **台本(0〜20秒)** | 冒頭に**図を置く**。いまは19.9秒まで文字カードだけ。compare2 を10秒台に上げる |
| 3 | **台本(章の順序)** | **第1章「NISAは増やす仕組みではない」を削るか後ろへ。** 60秒の山を越えるまで本題から離れない |
| 4 | **台本(章の切れ目)** | 45〜75秒に章の切れ目を置かない。第1章相当は80秒以降 |
| 5 | **`timeline_long.py`**(作成済み) | 冒頭の3つ(図が出る秒/数値が出る秒/45〜75秒の切れ目)を自動で判定する |
| 6 | **`check_long.py`**(フェーズ11) | 5の判定を機械ゲートにする。いまは目で見る道具まで |

1〜4 はフェーズ12(適用)で台本に反映する。
**5は今フェーズで作った。** ユニット単位のゲートは8つあったのに、
「30秒時点で何が出ているか」を測る道具が1つも無かったのが、この問題を見逃した原因である。
