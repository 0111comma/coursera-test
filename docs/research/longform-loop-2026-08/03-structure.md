# フェーズ3: 構成 — 章の数・長さ・順序・継ぎ目

フェーズ1で「尺は8分に根拠が無い」、フェーズ2で「冒頭60秒に何を置くか」が決まった。
このフェーズは**その先の8分をどう割るか**を決める。

## 調べたこと

### YouTubeのチャプター仕様(一次資料)

- 章は**3つ以上**。各章**10秒以上**。**昇順**で、最初は必ず `0:00`
- 概要欄の時刻リストがこの形になっていないとチャプターとして認識されない

(確度**A**。YouTube公式ヘルプ「Video Chapters」)

### チャプターを切ると維持率が上がる

章に区切った長尺は、区切らない場合より維持率が**12〜18%高い**、
平均視聴時間が**18〜22%増**という報告がある。
理由は「見たい所に飛べるので、離脱ではなくスキップになる」。

(確度**C**。実務ソースの数値で、出所の実験が確認できない。
方向としては複数ソースで一致するので**B**として扱い、数値は使わない)

### 章の数は尺に比例させる。ただし増やしすぎない

- 10分の動画で**5章**という例示が複数ある
- 「章を作りすぎると視聴者が圧倒される」という注意が並記される
- 2時間のドキュメンタリーでは主要な幕が8〜12分 — **これは9分の動画には使えない**

(確度**C**。「5章」に根拠データが無い。ただし後述の実測と合うので採用する)

### 継ぎ目は「閉じてから開く」のではなく「開いてから閉じる」

台本の実務側で共通する言い方:

> 節を移るときは、**いま話していることを閉じる前に次を予告する**(open loop)。
> 各節は自己完結した「小さなフック + 答え」を持ち、
> **閉じた問いがすぐ次の問いに置き換わるから、視聴者が残る。**

(確度**B**。複数の台本ソースで表現も手順も一致)

### 60〜90秒ごとの拍は、章の切れ目とは別物

5部構成の型として挙がるのは
「フック → 約束 → 節(open loopで繋ぐ) → **60〜90秒ごとのパターン割り込み** → CTA」。
つまり**60〜90秒ごとに拍を打つ**のは章の切れ目とは別に、**章の中に**置く。

(確度**B**。フェーズ2で調べた「25〜35秒のリフック」と同じ系統の考え方)

**ここが `longform-design.md` の「章 = ショート1本」の間違い。**
60〜90秒の拍を**章の長さそのものにしてしまった**ので、
章の切れ目(=話題のリセット)が90秒ごとに6回起きている。
拍は章の中に置くもので、章を刻む理由にはならない。

## L001 のどこが、それに反しているか

`production/timeline_long.py`(このフェーズで章の判定を追加)の出力。

```
  冒頭        0.0s →   53.0s  尺  53.0s   17ユニット  図 24%  ← 短い ← 図が4割未満
  ch1      53.0s →   97.0s  尺  44.0s   14ユニット  図 21%  ← 短い ← 図が4割未満
  ch2      97.0s →  180.8s  尺  83.8s   25ユニット  図 36%           ← 図が4割未満
  ch3     180.8s →  239.0s  尺  58.2s   19ユニット  図 21%  ← 短い ← 図が4割未満
  ch4     239.0s →  312.2s  尺  73.3s   23ユニット  図 61%
  ch5     312.2s →  385.5s  尺  73.3s   22ユニット  図 55%
  ch6     385.5s →  505.2s  尺 119.7s   37ユニット  図 54%
  章の数(冒頭を除く): 6   ← 9分なら4〜5
```

### 1. 章が6つあり、長さが2.7倍ばらついている

最短 ch1 44.0秒、最長 ch6 119.7秒。**同じ「章」と呼んでいるが別物**。
ch6 は37ユニットで、中にチェック5項目・枠が戻る図・一覧表・自分で出す式・締めが
**5話題ぶん**入っている。逆に ch1 は44秒で1話題も完結していない。

### 2. 章の切れ目が計画と一致していない

`plan.md` の構成表は **6ブロック**(冒頭60 / 120 / 130 / 130 / 140 / 締め50)。
実物は **8ブロック**で、対応が崩れている。

| plan.md | 実物 | ずれ |
|---|---|---|
| 冒頭 60s | 冒頭 53.0s | ほぼ一致 |
| — | **ch1 44.0s「NISAは増やしてくれるのか」** | **計画に無い章が入っている** |
| 章1 税金の決まり方 120s | ch2 83.8s | −36s |
| 章2 引けない 130s | ch3 58.2s | **−72s** |
| 章3 来年も引けない 130s | ch4 73.3s | −57s |
| 章4 いくらまで 140s | ch5 73.3s | **−67s** |
| 章5 締め 50s | **ch6 119.7s に締めが埋まっている** | **締めが独立していない** |

計画では各章120〜140秒だったのに、実物は44〜84秒。
**書きながら章を増やしたので、1章あたりが半分になった。**

### 3. 継ぎ目で同じ問いを2回言っている(28.5秒 = 全体の6%)

これがこのフェーズで見つけた最大の無駄。

```
  ch5    重なり 100%
         出口: では、この不利はいくらまで効くのだろうか。
         章札: では第5章。この不利は、いくらまで効くのか。
  ch4    重なり  90%
         出口: では、来年の利益からも引けないのだろうか。
         章札: では第4章。来年の利益からは、引けるのか。
```

6つの継ぎ目のうち**5つが重なり60%以上**、2つは**90%・100%**。
前章の出口で open loop を正しく開いているのに、
**次の章札がその同じ問いをそのまま読み直している。**
研究の言う「開いてから閉じる」を、「開いて、開き直す」にしている。

**合計28.5秒(6%)を、何も進まない繰り返しに使っている。**

### 4. 図の偏りが前半と後半で3倍ちがう

前半(冒頭・ch1・ch2・ch3)は図 21〜36%、後半(ch4・ch5・ch6)は 54〜61%。
**離脱が起きる前半のほうが図が少ない。** 順番が逆。

### 5. 本題でない章を、離脱の山に置いている

ch1(53.0〜97.0秒)は「NISAは、お金を増やしてくれるのか」で、
**この動画の問い(損は引けるのか)ではない**。
フェーズ2で指摘した崖と同じ場所で、しかも中身が寄り道。
本題の ch3 に入るのは **180.8秒**。3分待たせている。

### 6. L002 も同じ形で書いてある(まだ焼いていない)

```
  ch5    重なり 67%  出口: では、繰り上げて返すとどうなるのだろうか。
                     章札: では第5章。繰り上げて返すと、分かれ目は動くのか。
  ch4    重なり 27%  出口: だからこれは目安であって、予測ではないのだ。   ← ループを開いていない
```

L002 も6章。継ぎ目3つが重なり50%以上で、**ch4 の継ぎ目は逆に問いを開いていない**。
フェーズ0で L002 のレンダリングを止めた判断は正しかった。

## 何を変えるか

### 構成の型(これを longform-design.md の§2と差し替える)

```
冒頭     0〜45s    答えを出し切る(フェーズ2の3段構え)。章にしない
章1     45〜165s   本題の第1問。120秒。中に60〜90秒でリフックを1回
章2    165〜285s   次の問い。120秒
章3    285〜405s   次の問い。120秒
章4    405〜495s   自分の場合の出し方。90秒
締め   495〜525s   30秒。章に含めない。表 + 時点表記 + 免責
```

- **章は4つ。9分で5つ以上に割らない**(4章 + 冒頭 + 締めで概要欄チャプター6行)
- **1章は100〜130秒**。60秒未満の章は前後に吸収し、150秒超は2つに割る
- **拍(リフック)は章の中に置く。章を刻んで拍を作らない**
- **締めは独立ブロック**。章の中に埋めない
- **図は各章40%以上。前半を後半より薄くしない**

### 継ぎ目の書き方(2回言わない)

| | いま | これから |
|---|---|---|
| 前章の出口 | では、来年の利益からも引けないのだろうか。 | では、来年の利益からも引けないのだろうか。 |
| 章札 | では第4章。来年の利益からは、引けるのか。 | 第4章。**ここで差が2倍になる。** |

**前章の出口が問いを開く。章札は問いを繰り返さず、答えの側を予告する。**
章札が引っかけになるので、28.5秒が無駄から仕掛けに変わる。

### L001 の章の組み替え(フェーズ12で実行)

| 新 | 中身 | 旧 | 尺 |
|---|---|---|---|
| 冒頭 | 40,630円まで。定義は入れない | 冒頭 −定義2文 | 45s |
| 章1 | **NISAの損は引けるのか**(本題を最初に) | ch3 + ch2の税率だけ | 125s |
| 章2 | 来年の利益からも引けないのか | ch4 | 120s |
| 章3 | いくらまで効くのか | ch5 | 115s |
| 章4 | 自分の場合はどう出すのか | ch6の後半 + 8,126円の例 | 95s |
| 締め | 表・時点表記・免責 | ch6の末尾を切り出す | 30s |

- **ch1「NISAは増やす仕組みではない」は削る。** 本題でなく、離脱の山に置いてある
- **ch6 の5話題は割る。** チェック5項目は章4に3項目まで、枠の話は概要欄へ
- **ch2 の税率の説明は章1に最小限だけ残す。** 独立した章にしない

## 出典

- 章は3つ以上・各10秒以上・昇順・最初は0:00 — YouTube公式ヘルプ「Video Chapters」(確度A)
- チャプターと維持率12〜18% / 平均視聴時間18〜22% —
  instantviews / clickyapps / usevisuals(**確度C。数値は使わない**)
- 10分で5章 / 作りすぎると圧倒される — gyre / speechify / tubebuddy(確度C)
- 継ぎ目は open loop、閉じる前に次を予告する / 各節が小さなフックと答えを持つ —
  sumera「5-Part Retention Structure」/ humbleandbrag / learn.tubeai(確度B)
- 60〜90秒ごとのパターン割り込み — humbleandbrag / air.io(確度B)
