# フェーズ9: 立ち絵 — 8分間、出ずっぱりでよいのか

自己診断 H6「立ち絵が8分間同じ。位置・大きさ・出番が一定。いる意味が薄い」を潰す。

**H6 の「いる意味が薄い」は間違いだった。** 立ち絵には測れる効果がある。
ただし**効くものと損なうものが別**で、L001 は損なう側を8分間やり続けていた。

## 調べたこと

### 講師が映っている動画の効果 — メタ分析

| 何に対して | 効果 |
|---|---|
| **保持**(覚えているか) | **小さいが有意にプラス**(35研究のメタ分析) |
| **転移**(応用できるか) | 有意な効果なし |
| **社会的存在感・情動・動機づけ** | **有意にプラス** |
| **認知的負荷** | **有意に増える** |

(確度**A**。メタ分析2件(20研究 / 35研究)と系統的レビュー1件。
Education and Information Technologies / Educational Research Review /
Computers and Education Open に掲載)

### そして、図から目を奪う(視線計測)

> 立ち絵があると、**関連する視覚情報への注視時間が減る**。
> 画面上の講師が、鍵になる視覚情報から学習者の注意をそらしている可能性がある。
> 認知負荷理論の懸念どおり、**講師の顔と身振りに常時アクセスできる状態は
> 限られた注意を学習内容から逸らし、講師と教材の間で注意が分裂する。**
> **講師と学習内容を頻繁に行き来することも負荷になる。**

(確度**A**。視線計測の研究。Brain Sciences 12(7):946)

### まとめると

**立ち絵は「人がいる感じ」を作るのには効き、「図を読ませる」のには害がある。**
どちらも確度Aで、方向が逆。だから**出しっぱなしにするか消すかの二択ではなく、
場面で切り替えるもの**である。

## L001 のどこが、それに反しているか

### 1. **157ユニット全部・505.2秒すべてで立ち絵が出ている**

```
chara の分布: {'bl': 157}
立ち絵が出ているユニット: 157/157 = 100%
立ち絵の出ている時間: 505.2s / 505.2s = 100%
chara=none のユニット: []
```

**8分25秒、1秒も引いていない。** 位置も `bl`(左下)のまま一度も動かない。

### 2. **図が主役の66ユニットすべてに立ち絵が乗っている**

```
立ち絵の判定:
  図の上に立ち絵がいる: 66/66本(100%)   ← 図が主役のときは引く(注視時間を奪う)
```

視線計測が「図への注視時間を奪う」と言っているところで、
**66回すべて立ち絵を置いている。**
フェーズ6で「数字は図の上で言う」と決めたが、
**その図の隣にずっと立ち絵がいると、そこを見てもらえない。**

### 3. 立ち絵が図の描画域に食い込んでいる

- 横型の立ち絵の枠: **x 0.010〜0.202 / y 0.200〜0.591**(左下)
- `scenes_long` の図の描画域: **PLOT_L = 0.055 〜 PLOT_R = 0.775**

**x 0.055〜0.202 が重なっている。**
`barsN` `band` `table` は横99%まで使うので、**左端が立ち絵の裏に来る**。
`check_overlap` は通っている(各図が実際にはその隅を避けて描いている)が、
**図の使える幅が、立ち絵のぶんだけ狭められている**のは事実。

### 4. 表情がほぼ動かない — `normal` が136/157(87%)

```
face の分布: {'normal': 136, 'troubled': 8, 'surprised': 5, 'happy': 4, 'smug': 4}
表情を変えている回数: 40回
```

研究が言う**立ち絵の効き所は「社会的存在感・動機づけ」**で、
それを作るのは表情と視線である。ところが**87%が同じ顔**。
つまり **L001 は、立ち絵の害(図への注意をそらす)だけを8分間受け取り、
効き(人がいる感じ)はほとんど受け取っていない。**

### 5. フェーズ6の測定を訂正した

この立ち絵の位置(x 0.010〜0.202)を確認したことで、
**フェーズ6の面積測定に立ち絵が入り込んでいた**ことが分かった。
`06-screen.md` を訂正した。

- 結論(**文字カードと図で面積はほぼ同じ・空白の問題ではない**)は変わらない。
  むしろ訂正後は文字のほうがインクが多い(0.107 対 0.092)
- ただし**縦の使用率は66%ではなく22〜53%**だった。余りは書いたより大きい
- `timeline` の弱さも、インク0.074→**0.031**、横64%→**54%** と、さらに悪かった

## 何を変えるか

### 1. 立ち絵の判定を `timeline_long.py` に入れた(**実装済み**)

```
立ち絵の判定(09-character.md):
  図の上に立ち絵がいる: 66/66本(100%)   ← 図が主役のときは引く(注視時間を奪う)
  表情の偏り          : normal が 136/157(87%)   ← 判定のところで表情を変える
```

| 判定 | 基準 | 決め方 |
|---|---|---|
| 図の上に立ち絵がいる割合 | **5割以下** | 視線計測(確度A)。図が主役の回では引く |
| 同じ表情の割合 | **8割以下** | 立ち絵の効き所は社会的存在感なので、顔が動かないと効きが出ない |

### 2. 図のユニットでは立ち絵を引く(台本の手順)

```
文字カードのユニット  → 立ち絵を出す(社会的存在感・動機づけ。確度A)
図が主役のユニット    → 立ち絵を消す(chara="none")。図に注視させる
章の出口の判定        → 立ち絵を出し、表情を変える(いちばん人に言わせたい1文)
```

- **`shortlib` の変更は要らない。** `Unit.chara="none"` は既に対応している
- フェーズ4の「図は3〜5ユニット持たせる」と組み合わせると、
  **図が出ている間は立ち絵が消え、文字に戻ると立ち絵が返ってくる**。
  H6 が欲しかった「立ち絵の出番の変化」は、これで**根拠つきに**手に入る

### 3. 判定のところで表情を変える

- 章の出口の判定(4章 → 4箇所)で `troubled` / `smug` などに変える
- **表情を増やすのではなく、置き所を決める。** いま40回変えているが場所が散っている

### 4. 立ち絵を消した回は、図の幅を左に広げられる

立ち絵が消えるユニットでは **x 0.010〜0.202 が空く**。
`scenes_long` の図を、立ち絵の有無で `PLOT_L` を変えられるようにする
(いまは 0.055 固定で、実質 0.202 から描き始めている図もある)。
これはフェーズ12で実装する。

### 変えるファイル

| # | 何を | どう | いつ |
|---|---|---|---|
| 1 | `timeline_long.py` | 図の上の立ち絵率・表情の偏りを判定 | **済** |
| 2 | `06-screen.md` | 立ち絵を含めて測っていた表を訂正 | **済** |
| 3 | `check_long.py` | 1を機械ゲートにする | フェーズ11 |
| 4 | `L001 / L002 の render.py` | 図のユニットは `chara="none"`。判定で表情を変える | フェーズ12 |
| 5 | `scenes_long.py` | 立ち絵が無い回は図を左に広げる | フェーズ12 |
| 6 | `docs/research/longform-design.md` | 立ち絵の出し入れを節にする | フェーズ14 |

**ショートには当てはめない。** 55秒の縦型は画面が狭く、
立ち絵が「話している人」として機能している。公開済み11本はそれで通っている。

### 仮説として記録(確度Cなので行動を変えない)

- **立ち絵を消す割合の最適値**は分からない。「図の回は消す」で結果的に約4割になるが、
  これは研究から出た数ではなく設計上の帰結。長尺3本で維持率と突き合わせる
- **位置を動かす(左下 ⇄ 右下)**のが効くかは分からない。
  研究は位置ではなく**存在の有無**を測っている。動かさない
- **性別による効き方の違い**を扱った研究があるが、出し分けられないので使えない
