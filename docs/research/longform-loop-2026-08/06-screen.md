# フェーズ6: 画面 — 横型で1画面に何を置くか

自己診断 H3「画面が文字カード中心。図のあるユニットは4割強で、残りは語を大きく出しているだけ」を潰す。

**仮説の半分は外れた。** 文字カードは横幅を使っていなかったのではなく、
**そもそも図が無い時間が長い**のが問題だった。

## 調べたこと

### 冗長性の原則 — 基本形は「図 + 語り」

> 人は**図と語り**から学ぶほうが、**図と語りと画面の文字**からよりよく学ぶ。
> 語りのついた図に画面の文字を足すと、同時に処理する情報が増えて認知の負荷が上がる。

(確度**A**。Mayer の12原則の1つとして、複数の大学・教育機関の教材で一致)

### ただし境界条件がある — **短い語句なら、図の中に重ねたほうが良い**

雷の発生・車のブレーキを説明した実験で、
**図の中に短い重複語句を置いた群のほうが、置かない群より保持テストで良かった**
(**d = 0.47 と 0.70**)。転移テストでは差が出ていない。

さらに:

- **図が無い場合**は、画面の文字が学習を助けることがある
- 語りと画面の文字に**わずかな差**があると、作業記憶の中で
  意味を作る処理が働いて学習が進む。**差が大きすぎると負荷で潰れる**

(確度**A**。効果量つきの実験。ただし対象は静止スライド教材で、動画ではない)

**これは自分のゲートの検証になった。**
`check_figure` の「冗長」ルールは**10字以上**の図中テキストが
字幕と6割以上重なったときに落とす。つまり**短い語句は最初から除外している**。
研究が「短い重複語句は d=0.47〜0.70 で効く」と言っているところと、閾値がほぼ一致していた。
**これは偶然で、当時この研究を読んでいなかった。**
「図に文を貼るな、語は貼ってよい」は結果的に正しい線だったと確認できた。

### 一方で「差が大きすぎると潰れる」に自分は寄りすぎている可能性がある

フェーズ2で `chapter()` が問いを**まったく描かない**ようにした。
研究の言う「わずかな差」を通り越して「差が最大」にしている疑い。
ただし**動画での検証ではない**ので、ここは変えない(仮説として記録)。

## L001 のどこが、それに反しているか

### 1. 図が42%しかなく、58%は図の無い画面

```
文 card        56( 36%)
文 hero        28( 18%)
図 compare2    18( 11%)
図 timeline    17( 11%)
図 barsN       13(  8%)
図 checklist   10(  6%)
文 chapter      7(  4%)
図 band         4(  3%)
図 table        4(  3%)

図のユニット 66/157 = 42% / 文字だけ 91 = 58%
```

8分25秒のうち**およそ290秒が、図の無い画面**。
Mayer の基本形(図 + 語り)ではなく、**語り + 画面の文字**で通している。

### 2. 数字を65回言っていて、そのうち16回は図が無い(60.3秒)

**これがこのフェーズで見つけた一番痛いところ。**

```
#11  hero  その差の40630円が、今日の答えなのだ。          ← 動画の答え
#25  hero  その差の40630円が、非課税の中身なのだ。
#33  card  その株や投資信託の利益には、20.315%かかるのだ。  ← 種になる数字
#67  hero  でも全部が課税口座なら0円だったので、差は40630円。 ← 第3章の判定
#68  hero  その40630円が、損を引けないことの値段なのだ。
#87  hero  つまり課税口座なら0円だったので、差は81260円。   ← 第4章の判定
#116 hero  つまり合わせると、3年で121890円になるのだ。
```

**この動画の答え(40,630円)を、図の無い画面で言っている**(#11、34.8秒地点)。
章の判定(#67 / #68 / #87)も同じ。
**一番覚えてほしい数字ほど、図が付いていない。**

フェーズ2で見つけた「0〜19.9秒が全部文字カード」は、この癖の1例だった。

### 4. 外れた仮説: 文字カードは横幅を使っていた

レンダリング済みのフレームで、内容エリア
(ブランド行の下〜字幕帯の上、立ち絵の左)の使い方を測った。

| 型 | インク率 | 横の列を使った率 | 縦の行を使った率 |
|---|---|---|---|
| 文 card | 0.138 | 69% | 67% |
| 文 hero | 0.173 | 83% | 67% |
| 図 compare2 | 0.169 | 71% | 71% |
| 図 barsN | 0.182 | **99%** | 66% |
| 図 timeline | **0.074** | **64%** | 61% |
| **文字 まとめ** | **0.148** | **73%** | 66% |
| **図 まとめ** | **0.145** | **78%** | 66% |

**文字カードと図で、使っている面積はほぼ同じ**(インク率0.148 対 0.145)。
「語を大きく出しているだけで横幅が空いている」という自己診断は**外れ**だった。
問題は空白ではなく、**図が無いこと**そのもの。

ついでに分かったこと:

- **`timeline` が一番弱い**(インク0.074・横64%)。年をまたぐ図なのに横幅を使えていない
- **縦は全型で66%しか使っていない**。1080pxの3分の1が余っている

## 何を変えるか

### 1. 画面の判定を `timeline_long.py` に入れた(**実装済み**)

```
画面の判定(06-screen.md):
  図のあるユニット   : 66/157(42%)   ← 6割以上にする
  数字を図なしで言う : 16/65本(25%) 計60.3秒   ← 数字は図の上で言う
      #11 / #14 / #25 / #33 / #64 / #67 / #68 / #78 / #87 / #99 ...
  図が出ない最長区間 : 36.6秒(#67〜#78)   ← 25秒を超えたら図を割りこませる
      25秒超の区間は5箇所: 37s / 35s / 32s / 30s / 30s
```

| 判定 | 基準 | 決め方 |
|---|---|---|
| 図のあるユニット | **6割以上** | Mayer の基本形が「図 + 語り」なので、図の無い画面を少数派にする |
| 数字を図なしで言う | **1割以下** | 数字はこのチャンネルの中身そのもの。図に載せない理由が無い |
| 図が出ない連続 | **25秒以下** | 30秒級の窓が5つあったので、その下に引いた |

**ショートには当てはめない。** 55秒では文字カードで数字を言っても通っている
(S012が合格)。`timeline_long.py` は長尺専用なので、そこで判定する。

### 2. 数字を言うユニットは、図の上に置く(台本の手順)

- **答えの金額・章の判定は、必ず図の上で言う。**
  #11 の 40,630円は `compare2` の差分の上で、#67/#68 は比較の図の上で言う
- 新しい図を作るのではなく、**直前の図を持たせたまま数字を足す**(フェーズ4の「図は3〜5ユニット持たせる」と同じ手)

### 3. `timeline` を作り直す(横幅を使う)

インク0.074・横64%で、6つの図型の中で最も弱い。
年をまたぐ図なのに、1920pxの3分の1しか使っていない。
**年の帯を左端から右端まで伸ばし、繰越の矢印を長く架ける。**

### 4. 縦の余りを使う(注記の置き場)

全型で縦66%しか使っていない。余った3分の1に
**出典・時点・仮定のバッジ**を置く(いまは右下の1箇所に小さく出しているだけ)。
研究の「短い重複語句は効く(d=0.47〜0.70)」に沿って、
**短い語句なら図の中に置いてよい**。

### 仮説として記録(確度Cなので行動を変えない)

- **`chapter()` が問いを一切描かないのは、差が大きすぎるかもしれない。**
  研究は「わずかな差が良く、差が大きすぎると潰れる」と言っており、
  短い重複語句は d=0.47〜0.70 で効いている。
  ただし**静止スライドの実験で、動画ではない**。
  章札に短い語句を戻すかどうかは、長尺が3本たまってから比べる
- **`check_figure` の10字という閾値**が研究の境界と一致していたのは偶然。
  次に閾値を動かすときは、この研究を根拠に置く
