# フェーズ1: 尺 — 8分に根拠はあるのか

## 調べたこと

### 8分という数字の出どころ

**8分はミッドロール広告(動画の途中に入る広告)を入れられる条件である。**
YouTubeヘルプに明記されており、8分未満の動画にはミッドロールを設定できない。
つまり **8分は収益側の閾値であって、視聴者の体験のための数字ではない。**(確度**A**)

### 長さと視聴維持率

- **5〜10分の動画が平均維持率でいちばん高い(約31.5%)。** 短ければ良いという通説に反する
  (確度**B**。実務レポート複数で近い数値だが、ジャンル横断の平均で自チャンネルの値ではない)
- 5分未満は「視聴された割合」50〜70%、30分超は25〜35%が目安
  (確度**B**。母集団が示されないレポートが多い)

### 離脱がどこで起きるか

- **長さに関係なく、最初の60秒で55%以上が離脱する。**(確度**B**。複数の実務レポートで一致)
- 1分を超えた視聴者が65%以上いる動画は、その後の平均視聴時間が58%高い(確度**C**。相関のみ)
- 最初の15秒で価値提案が明確な動画は、1分時点の維持率が18%高い(確度**C**。単一ソース)

### まとめると

尺は「8分を超えること」ではなく、**最初の60秒を生き残ること**で決まる。
5〜10分は悪くない選択だが、それは**中身が5〜10分ぶんあるとき**の話である。

## L001 のどこが、それに反しているか

L001(総尺 505.2秒)の実測タイムライン。

### (1) 答えの金額が出るのが **30.3秒**。15秒以内に価値が出ていない

```
 0.0s #1  NISA口座が、マイナスになっているとする。      ← 場面。良い
 2.6s #2  そのマイナスは、税金の足しにならないのか。      ← 問い。良い
 5.3s #3  でもその損は、税金では無かったことになる。
 8.1s #4  でも課税口座なら、そうではないのだ。
10.3s #5  その課税口座とは、NISAではない普通の口座のこと。 ← **用語の定義**
13.7s #6  その課税口座の損は、同じ年の利益から引けるのだ。
...
30.3s #11 でもNISAを使っていると、40630円かかるのだ。    ← **答えがここ**
```

**15秒までの6文のうち、2文が用語の定義に使われている。** 答えの金額は30秒後。
「いくら損するのか」を見に来た人に、30秒間金額を出していない。

### (2) **53.0秒に章の切れ目を置いている**。離脱の山のど真ん中

第1章の開始が 53.0秒。**55%以上が離脱する60秒地点に、
「では第1章」という事務的な区切りを重ねている。**

しかも第1章の中身は「NISAは、お金を増やしてくれるのか」で、
**損の話ではない**。損の話を聞きに来た人が、いちばん離脱しやすい瞬間に
別の話へ連れて行かれる。損の本題(第3章)が始まるのは **180.8秒**。

### (3) 章の長さが設計とずれている

| 章 | 実測 | 設計(plan.md) |
|---|---|---|
| 冒頭 | 53s | 60s |
| 第1章 | 44s | — |
| 第2章 | 84s | 120s |
| 第3章 | 58s | 130s |
| 第4章 | 73s | 130s |
| 第5章 | 73s | 140s |
| 第6章 | 52s | — |
| まとめ | 67s | 50s |

**設計では120〜140秒の章だったが、実測は44〜84秒。** 章が細かく割れている。

### (4) いちばん悪いこと: **8分に届かせるために内容を足した**

L002 を作るときの記録が残っている。66ユニット(3.65分)で書き終えたあと、
**「8分に足りない」という理由で +89ユニット足した。** L001 も同じ経緯である。

これは順序が逆で、**答えを出し切った結果が8分を超えるべき**だった。
`check_video.py` に「推定尺 8分以上」を**不合格条件として**入れたのが、
その圧力を作った。**自分で作ったゲートに、自分で内容を薄められた。**

## 何を変えるか

| # | 変えるもの | どう変えるか |
|---|---|---|
| 1 | **台本(冒頭)** | 答えの金額を**15秒以内**に出す。用語の定義(#5「課税口座とは」)は答えの後ろへ移す |
| 2 | **台本(章立て)** | **60秒付近に章の切れ目を置かない。** 40〜50秒か、80秒以降にずらす |
| 3 | **台本(章の順序)** | 第1章「NISAは増やす仕組みではない」を本題の後ろへ移すか落とす。**60秒の山を越えるまで、本題から離れない** |
| 4 | **check_video.py** | 「推定尺 8分以上」を**不合格からWARNに落とす**。尺を下限で縛ると内容を薄める圧力になる |
| 5 | **check_yokkyu.py または新ゲート** | 尺の判定を**企画の段階**に移す。「この問いは8分ぶんの中身があるか」を plan.md で問う |
| 6 | **longform-design.md** | 「8分を超えること」を目標に書いていた箇所を、「最初の60秒を生き残ること」に書き換える(フェーズ14) |

4 と 5 はこのフェーズで実装する。1〜3 はフェーズ12(適用)で台本に反映する。
