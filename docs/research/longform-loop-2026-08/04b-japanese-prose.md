## 調べたこと

### 本多勝一『日本語の作文技術』 — 修飾の順序と読点は原則で決まる

**修飾の順序(4原則)**

1. **節を先に、句をあとに**
2. **長い修飾語ほど先に、短いほどあとに**
3. **大状況・重要内容ほど先に**
4. 親和度(なじみ)の強弱による配置転換

**読点の打ち方(2原則)**

- **第一原則: 長い修飾語が2つ以上あるとき、その境界に打つ**
- **第二原則: 原則的語順が逆順のときに打つ**

(確度**A**。書籍の原則そのもので、独立した複数の要約で内容が一致)

**そして「主語のあとに機械的に打つ」は、この2原則のどちらでもない。**

### 木下是雄『理科系の作文技術』 — 説明する文の原則

- **文は短く、主語をはっきりさせる**
- 読者の予備知識に合わせて言葉を選び、必要なら用語を解説する
- **なくても済む言葉は一つも書かない**
- **受動態ではなく能動態で書く**

(確度**A**。書籍の原則。複数の大学の講義要約で内容が一致)

### プロットの型: 起承転結は説明に向かない

- **PREP法**(結論 → 理由 → 具体例 → 結論)は**実用文向け**。
  先に結論を言うので、伝えたいことがすぐ明確になる
- **起承転結**が向くのは小説・エッセイ・スピーチなど「読ませる」文章。
  **伝えたいことを最後に置く**ことで意外性と余韻を作る型なので、
  **長文・説明には構成上向かない**
- **序破急**は起承転結より1つ区切りが少なく、テンポよく運ぶ型

(確度**B**。国語・ビジネス文書の解説で一致。実験データではない)

**この動画の設計(冒頭で答えを出し切る)は PREP と同じ向き。**
ところが**章の中は起承転結のまま**になっている(次節)。

## L001 のどこが、それに反しているか

### 1. 読点の78%が主題・主語の直後(本多勝一のどちらの原則でもない)

```
読点の数: 0個:12本(7%) 1個:153本(91%) 2個:3本(2%)
読点のある156文のうち121文(78%)が主題・主語の直後
   直前の語: は46 / では17 / が15 / も13 / とは10
```

**91%の文が読点をちょうど1個持っている。** 構造から出た読点ではなく、
**位置が決まっている飾り**になっている。

```
#0  NISA口座が、マイナスになっているとする
#1  そのマイナスは、税金の足しにならないのか
#2  でもその損は、税金では【無かったこと】になる
#5  その課税口座の損は、同じ年の利益から引けるのだ
#6  だからNISAのほうが、不利になる場合があるのだ
```

読点1個の文のうち**50%(76本)は、先頭の接続詞・指示語の直後**に打っている。
つまり読点の予算1個を接続詞に使い切っていて、
**修飾の境界(第一原則の打ち所)には一度も回っていない。**

**原因は自分で作ったゲートだった。** `check_flow` が
「各文の頭に接続語を置く」ことを要求しているので、
`接続語 + 読点 + 本文` が最も安い通し方になり、それを157回使った。
フェーズ1の「8分ゲートが内容を薄めた」と同じ形。

### 2. 「その」で始まる文が4連続している

```
#32 その投資信託とは、お金をまとめて運用する商品のこと。
#33 その株や投資信託の利益には、20.315%かかるのだ。
#34 その内訳は、所得税と住民税と、復興特別所得税なのだ。
#35 その所得税が、15%なのだ。
```

`#41〜#43` にも3連続がある。**「その」で始まる文は157本中57本(36%)。**

### 3. 章の中が起承転結のまま(判定が章の最後にしかない)

章の中で金額が出るのは早い(ch2で9%地点、ch5で4%地点)。
ところが**損得の判定は章の出口にしか無い**。

| 章 | 章の出口の判定 | 判定が出る位置 |
|---|---|---|
| ch1 | #29「そのNISAは、増やす仕組みではないのだ」 | 章の**末尾** |
| ch3 | #73「その裏側で、引けるはずだった損が消えているのだ」 | 章の**末尾** |
| ch5 | #118「だからその年は、小さいほうの額の20.315%を余分に払う」 | 章の**末尾** |

**PREP なら章の頭でも判定を言う。**
いまは「前提 → 説明 → 判定」の3段で、**判定を最後に置く起承転結型**。
90秒待たないと、その章に付き合った意味が返ってこない。

フェーズ3で「章札は問いを繰り返さず答えの側を予告する」と決めたが、
**それは PREP の最初の P(結論)を置くことと同じ**だった。
思いつきの修正ではなく、実用文の型そのものだと分かったので、そのまま採用する。

### 4. 合否を分けなかったもの(ゲートにしない)

正直に書く。日本語の指標をいくつも測ったが、**多くはユーザーの合否と一致しなかった**。

| 指標 | L001(**ゴミ**) | S012(**OK**) | 分けられるか |
|---|---|---|---|
| 文末「のだ/なのだ」の割合 | 54% | **72%** | **逆。ずんだもんの口調なので直さない** |
| 「その」始まりの割合 | 36% | 33% | 分けられない |
| 1文の字数 | 平均22.6 | 平均19.2 | 分けられない |
| 受動態の割合 | 2% | 0% | どちらも十分低い |
| 冗長表現 | ほぼ無し | 無し | 分けられない |
| **「その」始まりの最長連続** | **4** | **2** | **分けられる** |
| 読点が主題直後の割合 | **78%** | 50% | 差はあるがn=2 |

**「のだ」を直そうとしていたら、ユーザーが合格させたものを壊していた。**
比率で測れるものは、ほとんど合否を分けない。分けるのは**連続の回数**である。
フェーズ4で出た結論(比率ではなく回数が効く)と同じ形が、文の側でも出た。

### 2. 読点は修飾の境界に打つ(書き方の手順。ゲートにしない)

- **接続語のあとに読点を打たない。** 「でもその損は、〜」→「でもその損は〜」
  接続語は1〜3字なので、区切る必要が無い
- **読点は長い修飾語が2つ以上あるときの境界に回す**(本多勝一 第一原則)
- **読点ゼロの短い文を混ぜる。** いまは93%の文が読点を持っている
- `check_flow` の接続語要件を「読点付きの接続語」で満たすのをやめる

### 3. 章の中を PREP にする

```
章札      結論を先に言う(答えの側)。「第2章。ここで差が2倍になる」
本文前半  理由(なぜそうなるのか)
本文後半  具体例(金額で1つ)
章の出口  結論をもう一度。**12字以下で言い切る**(フェーズ4)
```

起承転結(前提 → 説明 → 判定)をやめる。**章の頭と出口の両方に判定を置く。**

### 4. 修飾の順序を、台本を書くときに1回見る

- 節を先に、句をあとに / 長い修飾語を先に、短いものをあとに
- ナレーションは音で流れるので、**逆順は聞き直せない**。
  逆順にするなら読点を打つ(本多勝一 第二原則)
