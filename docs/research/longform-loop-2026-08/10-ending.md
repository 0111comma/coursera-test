# フェーズ10: 締めと回遊 — 終わり方・チャプター・概要欄・次の動画

長尺だけが持つ機能(終了画面・チャプター・カード)を、L001 は1つも使っていない。

## 調べたこと

### 終了画面は最後の5〜20秒。ただし「10〜15秒」が目安

- YouTube の仕様: **終了画面は動画の最後の5〜20秒に表示できる**(公式ヘルプ。確度**A**)
- 実務側の目安: **最後の10〜15秒が、注意と行動のバランスが最もよい**
- 動画の終わりの **15〜20秒前**から締めに入り、終了画面の要素のための余白を作る

(確度**B**。実務ソース複数で区間の切り方が一致)

### 終了画面の20秒を「待合室」にしない

> 作り手は20秒をクリック要素のために取っておくのに、
> **その20秒で有益なことを何も言わなくなる。**
> 「以上です」「これで終わりです」「ありがとうございました」といった**退出の言葉が、
> 「もう価値は来ない」と脳に伝える。**
> 10秒で足りるなら10秒にする。**短くて能動的な終了画面のほうが、20秒の待合室よりよい。**

(確度**B**。実務ソース複数で一致)

### 言葉のCTAを必ず添える。名前を言う

> **どれをクリックするのか、なぜクリックするのかを言葉で言う。**
> 最後の15〜20秒で、リンクしている動画を**指し、名前を言い、
> 視聴者が何を得るのかを説明する。**

(確度**B**)

### 参考にしない数値

- 終了画面のクリック率の健全な目安は3〜7%、シリーズ物で8〜10%
- 終了画面に到達する視聴者が30%未満なら、まず維持率の問題

(どちらも確度**C**。一次資料が確認できない。**行動を変えない**)

## L001 のどこが、それに反しているか

### 1. 最後の20秒のうち、3ユニットが免責

```
締めの判定:
  最後の20秒        : 6ユニット(#151〜#156)
  そこに免責・時点表記: 3本 ['#151', '#152', '#153']   ← 終了画面の枠を免責で埋めない
  次に見るものの名指し: 0本   ← 名前を言って、見ると何が分かるかを言う
```

終わりの30秒を並べるとこうなっている。

```
475.1s #148 hero  だから余分に払うのは、8126円になるのだ。        ← 最後の数字
478.7s #149 card  ちなみにこの動画の金額は、すべて今の制度で計算したのだ。 ┐
482.7s #150 card  その計算に使ったのは、税率と足し算と掛け算だけ。      │ 免責
486.4s #151 card  ただし制度は、毎年変わるのだ。                │ 16.8秒
488.5s #152 card  その制度は、2026年8月時点の内容なのだ。          │
491.9s #153 card  だから使うときには、そのときの制度を確かめてほしいのだ。 ┘
495.5s #154 hero  つまりNISAで売っても、税金の話は動かないのだ。
498.9s #155 hero  だから売るかどうかは、税金と切り離して決める。
502.0s #156 hero  その判断に、税金を持ちこまなくていいのだ。
```

**478.7秒から495.5秒までの16.8秒が、まるごと免責。**
終了画面が出る枠(485.2秒〜505.2秒)のうち、**10.3秒が免責で埋まっている。**
研究が「退出の言葉を置くな」と言っているところに、
**「制度は毎年変わる」「そのときの制度を確かめてほしい」を置いている。**

### 2. 次に見るものを一度も名指ししていない

157ユニット全部を調べて、
**「次の動画」「関連」「概要欄」「チャンネル」に当たる言及はゼロ。**
終了画面に動画を置いても、**何をクリックすべきか声で言っていない。**

### 3. 最後の30秒に図が1枚も無い

`#148〜#156`(475.1s〜505.2s、30.1秒)は**全部が文字カードと hero**。
フェーズ6で見つけた「図なし30秒級の窓」5つのうちの1つが、まさに締めだった。

### 4. 長尺の投稿キットが存在しなかった

- `production/make_upload_kit.py` は **`videos/S0*` しか見ていない。**
  L001・L002 は生成対象に入っていなかった
- `uploads/` に L001 の概要欄・タグ・再生リストが**1つも無い**
- `chapters.txt` は生成されているが、**概要欄に入れる工程が無い**

### 5. チャプターは合格していた

```
0:00 NISAで損したら、いくら損するのか
0:53 第1章 NISAは、お金を増やしてくれるのか
1:37 第2章 そもそも株の税金は、どう決まるのか
...
7:17 まとめ 3つの場合と、自分の場合の出し方
```

- **8個で、0:00 から始まっている**(仕様を満たす。確度A)
- **目次ではなく問いになっている**(CLAUDE.md の決めごとを満たす)
- ただしフェーズ3で第1章を削るので、作り直しが必要

## 何を変えるか

### 1. 締めの判定を `timeline_long.py` に入れた(**実装済み**)

| 判定 | 基準 |
|---|---|
| 最後の20秒に免責・時点表記 | **0本**。免責は最後の数字の直後か、画面のバッジに置く |
| 次に見るものの名指し | **1本以上**。名前を言い、見ると何が分かるかを言う |

### 2. 長尺の投稿キットを作った(**実装済み**)

`production/make_upload_kit.py` に長尺の分岐を足した。
ショートと違う4点だけを別テンプレにしている。

```
■ 概要欄(コピペ。**チャプターを先頭に置く**)
0:00 NISAで損したら、いくら損するのか
0:53 第1章 ...
(以下、chapters.txt をそのまま差し込む)

■ 終了画面(長尺のみ。Shortsには無い)
  置くもの: 動画1枚 + チャンネル登録
  次の動画: S017(NISAの損益通算・同じ話の1分版)
  出す長さ: 10〜15秒(上限は20秒だが、埋めるだけの20秒は逆効果)

■ 設定チェック
- [ ] チャプターが概要欄の先頭にあり、0:00 から始まっているか
- [ ] 終了画面を設置したか(最後の10〜15秒)
- [ ] 48時間後に記録: 平均視聴率 / 平均視聴時間 / 30秒地点の残存率 /
      チャプター別の維持率 / 終了画面のクリック率
```

**指標をショートの「スワイプ継続率」から差し替えた。** 長尺で見るものが違う。
`uploads/L001_投稿キット.txt` `uploads/L002_投稿キット.txt` を生成して確認した。

### 3. 締めの並べ替え(台本。フェーズ12で実行)

```
いま:  最後の数字 → 免責16.8秒 → 結論9.7秒 → 終わり
これから:
  最後の数字(図の上)
  免責を1文に圧縮 + **画面のバッジに寄せる**
  結論(判定を12字以下で言い切る)
  **次に見るものを名指し(10〜15秒)** ← 終了画面の枠
```

- **免責を消すのではなく、位置を変えて短くする**(戦略§6の要件なので削れない)。
  「2026年8月時点の制度」は**画面のバッジで担保**し、ナレーションは1文にする
- 最後の10〜15秒は「S017 では、この話を1分で見られる」型の名指しにする
- **「以上です」「ありがとう」型を使わない**

### 4. 締めに図を置く

締めの30秒が図なしなので、**3つの場合の表(`table`)を締めに置いたまま持たせる**。
フェーズ6の「図が無い連続は25秒以下」と同じ手当てで解決する。

### 5. チャプターを作り直す(フェーズ12)

フェーズ3で章を4つにするので、チャプターは **冒頭 + 4章 + まとめ = 6行**になる。
問いの形は維持する。
