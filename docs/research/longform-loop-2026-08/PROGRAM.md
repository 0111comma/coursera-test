# 長尺動画の改善プログラム(2026-08-17)

ユーザー指示:
> ゴミ。長尺動画をどう作ったらいいのか、前行ったみたいに要素に分解して
> 一つずつリサーチを行なって。改善ループを立ち上げて。

## 何が起きたか(言い訳なしの事実)

L001(NISA・8分25秒)を出したが、判定は「ゴミ」だった。

**私がやったのは、ショートの作り方を155ユニットぶん並べただけ**である。
`docs/research/longform-design.md` は書いたが、中身は
「ショートのルールを持ち込む」「章=ショート1本」という**引き伸ばしの設計**で、
**長尺そのものを要素に分けて調べていない**。

ショートで通用した8ゲートをそのまま横型に通したので、
1文1画面・同じ話速・同じ立ち絵・同じBGMが8分続く。
1本ずつの文は基準を満たすのに、**通して見ると単調**になる。
これは各ユニットの品質の問題ではなく、**長尺という形式を調べていない**問題である。

## 着手前の自己診断(仮説。各フェーズで潰す)

L001 を自分で通して見て、疑わしい所を先に列挙する。

| # | 疑い | なぜそう思うか |
|---|---|---|
| H1 | **リズムが一定すぎる** | 155ユニットすべて「1文=1画面」。8分間ずっと同じ拍 |
| H2 | **話速がショートのまま** | SPEED_SCALE=1.3。押し付けられるショート用の速度で8分は疲れる |
| H3 | **画面が文字カード中心** | 図のあるユニットは4割強。残りは語を大きく出しているだけ |
| H4 | **章の切れ目が機械的** | 「では第N章」で6回。切れ目に演出も間もない |
| H5 | **進んでいる感じがない** | 40,630円が何度も出るが、どこまで来たかが分からない |
| H6 | **立ち絵が8分間同じ** | 位置・大きさ・出番が一定。いる意味が薄い |
| H7 | **BGMが1本で通し** | 章が変わっても音が変わらない |
| H8 | **間(ま)が無い** | ショートの詰め方のまま。8分ぶん息継ぎが無い |
| H9 | **長尺用の機械ゲートが無い** | ショート用の8ゲートを流用しているだけ。通しの単調さを誰も見ていない |

**このプログラムは、H1〜H9 を1つずつ調べて潰す。**

## 進め方の約束(前回のプログラムと同じ形)

- **1フェーズずつ**。トリガーが発火したら、下の表で状態が「未」の一番上を**1つだけ**実行する
- 各フェーズは**成果物のファイルを1つ以上残す**。残っていなければ未完了
- 各フェーズの終わりに、この表を更新してコミット・プッシュする
- **1フェーズでトークンを使い切らない。** 調べることを絞る
- 判断が要る所は決めて、理由を「判断ログ」に書く
- **調査は `docs/research/research-standards.md` に従う。**
  行動を変える主張は独立ソース5本以上+一次資料1本以上。確度A/B/Cを必ず付ける
- **確度Cで行動を変えない。** 自チャンネルで検証する仮説として記録する

## 各フェーズで必ず答えること

調べっぱなしにしない。どのフェーズも、最後にこの3つを書く。

1. **何が分かったか**(確度つき)
2. **L001 のどこが、それに反しているか**(具体的なユニット番号・秒数で)
3. **何を変えるか**(コード・台本・ドキュメントのどれを、どう)

3が書けない調査は、調べ方が悪い。やり直す。

## 判断ログ

### フェーズ10(2026-08-17 17時台)

- **長尺だけが持つ機能(終了画面・チャプター・カード)を1つも使っていなかった。**
  そして **`make_upload_kit.py` は `videos/S0*` しか見ておらず、長尺は生成対象に入っていなかった。**
  `uploads/` に L001 の概要欄・タグ・再生リストが1つも無い状態だった。
  → **長尺の分岐を実装した。** ショートと違う4点(チャプターを概要欄の先頭に置く /
  終了画面 / サムネの扱い / 見る指標)だけを別テンプレにし、
  `uploads/L001_投稿キット.txt` `L002_...` を生成して確認した。
  **指標をショートの「スワイプ継続率」から、平均視聴率・30秒地点の残存率・
  チャプター別の維持率・終了画面のクリック率に差し替えた。**
- **終了画面の枠を免責で埋めていた。**
  終了画面は最後の5〜20秒に出る(確度A・公式)。L001 は
  **478.7秒〜495.5秒の16.8秒がまるごと免責**で、終了画面の枠(485.2〜505.2秒)のうち
  **10.3秒が免責**。研究が「退出の言葉は『もう価値が無い』と伝える」と言う場所
  (確度B)に「制度は毎年変わる」「確かめてほしい」を置いていた。
  → **免責は消さず(戦略§6の要件)、1文に圧縮して画面のバッジに寄せる。**
- **次に見るものを一度も名指ししていない。** 157ユニット中、
  「次の動画」「関連」「概要欄」「チャンネル」への言及が**ゼロ**。
  → 最後の10〜15秒で**動画の名前と、見ると何が分かるか**を言う。
  「以上です」「ありがとう」型は使わない。
- **締めの30秒(#148〜#156)に図が1枚も無い。**
  フェーズ6で見つけた「図なし30秒級の窓」5つのうちの1つが、まさに締めだった。
  → 3つの場合の表を締めに置いたまま持たせる。
- **チャプターは合格していた。** 8個・0:00から・目次ではなく問い(CLAUDE.mdの決めごと)。
  ただしフェーズ3で章を4つにするので **冒頭+4章+まとめ=6行**に作り直す。
- **確度Cを2つ却下した。** 終了画面のクリック率3〜7%・到達率30%
  (どちらも一次資料が無い)。自チャンネルの実測で目安を作る。

### フェーズ9(2026-08-17 16時台)

- **H6 の「いる意味が薄い」は間違いだった。立ち絵には測れる効果がある。**
  メタ分析2件+系統的レビュー(確度A): 保持に**小さくプラス**、転移は有意差なし、
  **社会的存在感・情動・動機づけにプラス**、**認知的負荷は増える**。
  そして視線計測(確度A)は **立ち絵があると図への注視時間が減る** と言っている。
  **効くものと損なうものが別で、方向が逆。** だから出しっぱなしか消すかの二択ではなく、
  **場面で切り替えるもの**だった。
- **L001 は損なう側だけを8分間受け取っていた。**
  **157ユニット全部・505.2秒すべてで立ち絵が出ている**(1秒も引いていない)。
  **図が主役の66ユニットすべてに立ち絵が乗っている**(66/66 = 100%)。
  一方で**表情は `normal` が136/157(87%)**で、効き所である社会的存在感は出ていない。
  → **図のユニットは `chara="none"`、文字カードでは出す、章の出口の判定で表情を変える。**
  `shortlib` の変更は不要(`chara="none"` は既に対応)。
  H6 が欲しかった「立ち絵の出番の変化」が、これで**根拠つきに**手に入る。
- **立ち絵が図の描画域に食い込んでいた。**
  立ち絵の枠 x 0.010〜0.202 に対し `scenes_long` の `PLOT_L = 0.055`。
  `check_overlap` は通っているが、**図の使える幅が立ち絵のぶん狭められている**。
  立ち絵を消す回は図を左に広げられる(フェーズ12)。
- **フェーズ6の測定を訂正した。** 立ち絵の位置を確認したことで、
  **面積測定の範囲(x 0.03〜0.78)に立ち絵が入っていた**ことが分かった。
  結論(**文字カードと図で面積はほぼ同じ・空白の問題ではない**)は変わらず、
  訂正後は文字のほうがインクが多い(0.107 対 0.092)。ただし
  **縦の使用率は66%ではなく22〜53%**、`timeline` はインク0.074→**0.031**・横64%→**54%**
  とさらに悪かった。`06-screen.md` を直した。
- **ショートには当てはめない。** 55秒の縦型は画面が狭く、立ち絵が「話している人」として
  機能しており、公開済み11本はそれで通っている。
- **確度Cを2つ却下した。** 立ち絵の位置を動かす(研究は位置ではなく存在の有無を測っている)/
  性別による効き方の違い(出し分けられない)。

### フェーズ8(2026-08-17 15時台)

- **H7 は方向が逆だった。** 「章が変わってもBGMが変わらない」を欠点に挙げていたが、
  一貫性の原則は「**余分な音は除く**」と言っており、
  Moreno & Mayer (2000) では **BGM+環境音で保持・転移が悪化、効果量1.66**(確度A)。
  → **章ごとにBGMを変えるのはやめる。** 章の切れ目は音を足すのではなく
  **抜くこと(止め)**で作る。SEも9%から増やさない。
- **フェーズ4の「0.6秒の止め」は、そのまま入れたら逆効果になるところだった。**
  ダッキングの `release=300ms` なので、0.6秒黙ると**その間にBGMが戻って盛り上がる**。
  同じフィルタ構成で実測したら、止めの最中のBGMは**声より4.6dB下**しかなかった
  (-21.0 対 -25.6 dBFS)。「黙って聞かせる0.6秒」が
  「**BGMだけが急に大きくなる0.6秒**」になる。
  → `LONG_STOP_PAD = 0.5` を新設し、**止めの区間はBGMを0にする**実装を入れた。
  実測で無音になることを確認。`pad < 0.5` の動画は区間が空になり
  **従来とまったく同じミックス**なので、公開済み11本に影響しない。
  **いまの L001 は pad が 0.15秒(release より短い)なので起きていない。
  フェーズ4の変更を入れた瞬間に起きる不具合だった。**
- **BGMを外すことはしない。理由を残す。** 研究(確度A)は「BGMなしが最良」だが、
  ①測っているのは**テストの点**で、要るのは**視聴時間** ②**公開済み11本はすべてBGM入りで
  ユーザーは一度も指摘していない** ③実測でBGMは**声より26.9dB下**でダッキングも効いている。
  → 外さない。ただし**長尺2本でBGMあり/なしを比べる**ことをフェーズ13で提案する。
- **実測で分かったこと**: `L001.mp4` は声 -14.7 dBFS / pad -41.7 dBFS。
  **8分25秒に完全な無音が1箇所も無い**(157個の pad すべてでBGMが鳴っている)。

### フェーズ5(2026-08-17 12時台)

- **長尺のほうがショートより速かった。順序が逆。**
  L001 は **398字/分**(声だけ)で、ユーザーが「OK」と言った S012 は **352字/分**。
  **8分の動画を、55秒のショートより13%速く読んでいた。**
  日本語の目安は ゆっくり200〜250 / 標準300〜350 / **速め400〜**(確度B)で、
  L001 は「速め」= TikTok・ショート向けの帯に入っていた。
  ショートは押し付けられるので速さで指を止める必要があるが、長尺は選ばれて再生される。
  → **`LONG_SPEED_SCALE = 1.15` を新設し、`use_landscape()` が差し替える。**
  20ユニットを合成し直して実測 **346字/分**。標準の上限に入った。
  **ショートの 1.3 は触らない**(ループ58でユーザーが「もうちょっと早く」と言った結果)。
- **VOICEVOX の speed と字/分の対応を実測して表にした**(確度A。再現可能)。
  実効1.25 = 340字/分、1.45 = 395字/分、1.56 = 427字/分。
- **間の秒数は研究に書かれていなかった。** 「重要な部分の前後に間を作ると強調される」
  は確度Bで一致するが、**秒数はどのソースにも無い**。
  → 章の出口の判定の直前 0.6s / 判定のあと 0.4s / 章札の直前 0.5s を**自分で決めた**。
  根拠が無い値だと明記し、フェーズ13で実際に聞いて調整する。
- **話速がユニット単位でばらついているだけで、塊になっていなかった。**
  1文の速さの変化率0.12。→ 章の前半は `speed=1.0`、判定は `speed=1.15` と塊で変える。
- **不具合を見つけて直した。署名に `SPEED_SCALE` が入っていなかった。**
