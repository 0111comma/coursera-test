# フェーズ4: リズム — 1文1画面以外の拍の作り方

自己診断 H1「155ユニットすべて1文=1画面。8分間ずっと同じ拍」を潰す。

**このフェーズの結論は、当初の見込みと逆になった。**
「ばらつきが足りない」を機械で測れると思って測ったら、
**ユーザーの合否と一致しなかった**。そこは仮説に落とし、別のものをゲートにした。

## 調べたこと

### 同じ長さの拍が続くと単調になる

編集側の言い方:

> **持続時間のばらつきがリズムを作り、持続時間が一定だと単調になる。**
> 一定のペースは単調になるので、変化が視聴者を引きつける。
> **本当の勢いは対比から生まれる。** 速いカットの連続のあとの
> **不意の止め・長回し**が、速い部分をさらに速く感じさせる。

(確度**B**。編集の実務ソース複数で、表現も手順も一致)

### 単調なカット間隔は、フックが良くても中盤で落ちる原因の上位

「monotone cut rate は、冒頭がうまくいった動画でも中盤の離脱を招く上位の原因」
という指摘がある。(確度**C**。単一系列。方向はBの内容と一致)

### 文の長さも同じ

`100 Ways to Improve Your Writing`(Gary Provost)の有名な一節。原文の趣旨:

> 5語の文はそれでいい。**だが何本も続くと単調になる。**
> 音がうなり、レコードが引っかかったようになる。耳は変化を求める。
> **文の長さを変えると、そこに音楽が生まれる。**
> 短い文を使う。中くらいの文も使う。そして読者が休めたと確信したときに、
> 長い文で引きこむ。

大学のライティングセンター(CUNY / SUNY系)も独立に同じことを教えている。
(確度**B**。書籍の原文 + 系統の異なる複数ソースで一致。ただし実験データではない)

### 「音の変化幅 ÷ 平均」で単調な語りを判別できる

発表動画の学術的な計測で、
**エネルギーの変化幅と平均の比が、単調な語りと表情のある語りを分ける**指標として
使われている。(確度**B**。査読前論文だが、指標の定義が明示されている)

→ **これを字数とユニット尺に当てはめて測ってみた。結果は次節。**

## L001 のどこが、それに反しているか

### 測った(`production/timeline_long.py` に追加)

```
  ユニットの尺   : 平均3.22s 最短1.54s 最長5.39s 変化率0.21
  字幕の字数     : 平均22.6 最短9 最長30 変化率0.14
  12字以下の短文 : 1本(1%)
  絵の持続       : 平均6.0s 最長13.6s 変化率0.44
  2ユニット以下で切る絵: 65枚(77%)
  間(pad)の種類 : [0.15, 0.2]
  止め(pad≥0.5s): 0箇所
```

- **157ユニットのうち127本(81%)が2.5〜3.5秒**に入る。標準偏差0.67秒
- **字幕は95%が18〜28字**。標準偏差3.2字
- **12字以下の短文は157本で1本だけ**(#57「答えは、引けない。」)
- **絵は77%が2ユニット以下で切り替わる**。5ユニット以上持たせた絵はゼロ
- **8分25秒で、無音の止めが1箇所も無い**(pad は 0.15 と 0.2 の2値だけ)

### ばらつきの比率は、ユーザーの合否と一致しなかった

これが今フェーズでいちばん大事な結果。

| | 字数の変化率 | 同じ長さ帯(±3字)の最長連続 | 12字以下 | **ユーザーの判定** |
|---|---|---|---|---|
| S012(ショート・18ユニット) | 0.13 | 7 | 0本 | **「S12OK」** |
| L001(長尺・157ユニット) | 0.14 | 7 | 1本 | **「ゴミ」** |
| L002(長尺・155ユニット) | 0.11 | 12 | 0本 | 未提出 |

**同じ値で、判定が正反対。** 変化率も連続の長さも、合否を分けていない。

**だから変化率をゲートにしない。**(ループ51の約束「人の合否と一致しない機械判定は入れない」)
Provost の言うことは正しいだろうが、**それが効くのは繰り返しの回数が多いときだけ**で、
18回では単調として知覚されず、157回では知覚される。
比率ではなく**回数の絶対値**が効いているので、比率を閾値にしても分けられない。

### では L001 の何が測れるのか — 「対比」がゼロ

研究が言っているのは「ばらつき」ではなく **「対比」**
(速いカットの連続のあとの不意の止め)である。そこはゼロか否かで判定できる。

**L001 は8分25秒・157ユニットで、止め(無音の間)が0箇所。**
ユニット番号でいうと、**#0 から #156 まで全部が pad 0.15〜0.2 秒**。
章の出口の判定(#29「そのNISAは、増やす仕組みではないのだ」、
#73「その裏側で、引けるはずだった損が消えているのだ」、
#118「だからその年は、小さいほうの額の20.315%を余分に払う」)の直前にも間が無い。

**判定の一番大事な1文が、その他の156文と同じ速度・同じ間・同じ字数で流れていく。**
これが H1 の正体で、対比の不在は数えられる。

## 何を変えるか

### 1. 判定の直前に止めを置く(ゲートにする)

- **長尺は pad ≥ 0.5秒 の止めを最低3箇所持つ。ゼロは不合格**
- 置く場所は決め打ちにする: **各章の出口の判定の直前**(4章なら4箇所)
- ショートには適用しない(55秒に止めは要らない。S012がOKだった通り)
- 実装済み: `timeline_long.py` が `止め(pad≥0.5s)` を数えて判定する。
  フェーズ11で `check_long.py` に移す

### 2. 図は持たせ、文字は切る

いまは77%の絵が2ユニット以下で切り替わる。ここに緩急が作れる。

- **図(barsN / compare2 / curve / table 等)は3〜5ユニット持たせる。**
  絵を差し替えるのではなく、**同じ図の上で数字を1つずつ足す**(`step` 引数を使う)
- **文字カードは1〜2ユニットで切る**
- 結果として絵の持続が「長い / 短い」の2山になり、対比が出る

### 3. 判定の1文は短く言い切る

12字以下が157本で1本しか無い。**章の出口の判定は12字以下**にする。
`#57「答えは、引けない。」`(9字)が唯一の例で、これが正しい形。

例: `#118「だからその年は、小さいほうの額の20.315%を余分に払う。」`(28字)
→ `「余分に払うのは、小さいほうの2割。」`(18字)+ `「それだけ。」`(6字)

**これはゲートにしない**(上の表の通り、字数は合否と一致しないため)。
台本を書くときの手順として `write-script` スキルに入れる。

### 4. 話速はブロックで変える(数値はフェーズ5)

`speed` は 1.0〜1.15 の4値が**ユニット単位でばらついているだけ**で、
「速いブロック / 遅いブロック」という塊になっていない。
**章の前提部分は遅く、判定は速く**という塊にする。秒数はフェーズ5で詰める。

- **字数の変化率0.25以上・12字以下の短文を1割** — 長尺の維持率と相関するか。
  いまの2件(S012 OK / L001 ゴミ)では分けられていない。
  長尺が3本たまった時点で、自チャンネルの維持率グラフと突き合わせる
