# フェーズ7: 進行感 — どこまで来たかを見せる

自己診断 H5「進んでいる感じがない。40,630円が何度も出るが、どこまで来たかが分からない」を潰す。

## 調べたこと

### 分割の原則 — 区切りがあるほうが学べる

> 連続した1本ではなく、**受け手のペースで進める区切り**に分けたほうがよく学べる。
> 区切りが効くのは、**初学者のとき・内容が複雑なとき・提示が速いとき**。

(確度**A**。Mayer の分割の原則。Cambridge の『Multimedia Learning』第9章 /
CBE—Life Sciences Education / UCSD の教材で一致)

**この動画の視聴者はまさに3条件に当たる**(初学者 / 税制は複雑 / 話速380字/分)。

### 合図の原則 — 構造を示す手がかりが効く

> **鍵になる情報と構造を強調する手がかり**を足すと学習が進む。
> 手がかりは注意を向けさせ、作業記憶で処理すべき要素を絞るので、
> 何が重要かを判断する余分な負荷を減らす。

(確度**A**。Mayer の合図の原則。同上のソースで一致)

区切りは**構造の知識**を組み立てるのに効き、合図は**事実の統合**に効くと整理されている。

### ロードマップ(冒頭の予告)

> 長い動画の冒頭で、これから何を扱うかを短く言う。
> 「まずXを、次にYを、最後にZを渡す」。
> **この見取り図が不安を減らし、各節を通して見てもらえる確率を上げる。**

(確度**B**。実務ソース複数で一致)

### 節は3〜5分。区切りが精神的なチェックポイントになる

> 動画を3〜5分の自然な節に分ける。**小さい単位が視聴者に精神的なチェックポイントを与え**、
> 中盤の急な落ち込みを減らす。

(確度**C**。単一系列で、しかもフェーズ3で決めた「1章100〜130秒」と食い違う。
**行動を変えない。** フェーズ3の判断を維持する)

## L001 のどこが、それに反しているか

### 1. 章の出口に判定が無い章が4つある

```
進行感の判定:
  章の出口に判定が無い章: 4章   ← 章の出口は損得で言い切る
      冒頭     # 16 その2つとは、NISAと課税口座のことなのだ。
      ch1    # 30 では、その税金はどう決まるのだろうか。
      ch2    # 55 では、NISAの損はどうなるのだろうか。
      ch6    #156 その判断に、税金を持ちこまなくていいのだ。
```

`plan.md` には**「各章の出口に損得の判定を1文置く」**と書いてある。
実物は **7ブロックのうち4つに判定が無い**。

- **ch2**(97.0s〜180.8s、83.8秒)は税率の説明で終わり、
  出口が **#55「では、NISAの損はどうなるのだろうか」= 問いだけ**。
  84秒付き合って、返ってくるのが次の問いだけ
- **ch1** も同じ形(#30 が問いだけ)
- **ch4**(239.0s〜312.2s)には `ch4_out` というシーンが存在しない。
  `ch1_out` `ch3_out` `ch5_out` `ch6_out` はあるのに、**ch2 と ch4 は作り忘れている**

### 2. 積み上がる数字は1回しか出ないのに、動かない数字は12回出る

| 数字 | 回数 | 出る秒 |
|---|---|---|
| **40,630円**(1年ぶん。動かない) | **12回** | 30 / 34 / 79 / 123 / 211 / 215 / 219 / 362 / 367 / 443 / 446 / 450 |
| 81,260円(2年ぶん。積み上がった) | **2回** | 272 / 277 |
| **121,890円**(3年ぶん。積み上がった) | **1回** | 371 |

**進行感を出せる数字が121,890円で、それは1回しか出ない。**
一方、進行を示さない40,630円が12回出る。しかも
**211/215/219秒と443/446/450秒で3連続**しており、同じ額を固めて繰り返している。

H5 の「40,630円が何度も出るが、どこまで来たかが分からない」は正しかった。
**理由は、繰り返しているのが「動かない数字」だから。**

### 3. 画面に「全体のうちのどこか」が出ていない

- ナレーションでは **#13(40.6秒)「その条件を、6つの章で確かめていくのだ」** と予告している。
  ロードマップの原則(確度B)は満たしている
- ところが**章札は「第N章」だけで、「N/6」の分母が画面に無い**。
  render.py に「第N章」の表示は31箇所あるが、全体量を画面に出す仕掛けはゼロ
- **40.6秒に一度言ったあとは、8分間どこにも6という数字が出ない**

## 何を変えるか

### 1. 進行感の判定を `timeline_long.py` に入れた(**実装済み**)

| 判定 | 基準 |
|---|---|
| 章の出口に判定があるか | 章の最後の2ユニットに、**数字か損得の語**が出ていること |
| 全体量の予告 | 冒頭60秒までに「何章あるか」を言っていること |

**問いの形は判定として数えない。**
最初は「損」「差」などの語だけで見ていたが、
**#55「では、NISAの損はどうなるのだろうか」が「損」を含むだけで通ってしまった。**
「〜のか / 〜だろうか」で終わる文を除いたら、ch2 が正しく落ちた。

### 2. 章札に分母を出す(`scenes_long.py`)

```
いま:  第3章
これから: 第3章 / 全4章        ← 右上に小さく。合図の原則(確度A)
```

- フェーズ3で章を**4つ**にすると決めたので分母は4
- 「短い語句を図の中に置くのは効く」(フェーズ6、d=0.47〜0.70)に沿って、
  文ではなく**分数だけ**を置く

### 3. 繰り返すのは「積み上がる数字」に変える

- **40,630円を12回言うのをやめる。** 章の判定に必要な回数だけにする(4〜5回)
- 代わりに **40,630 → 81,260 → 121,890 の階段を、同じ図の上で積み上げる**。
  フェーズ4の「図は3〜5ユニット持たせる」・
  フェーズ6の「数字は図の上で言う」と同じ手で実装できる
- **同じ額を3連続で言うのをやめる**(211/215/219 と 443/446/450)

### 4. 章の出口の判定を、全章に置く

- `ch2_out` と `ch4_out` を作る(いま存在しない)
- 出口の1文は**12字以下で言い切る**(フェーズ4)
- 出口の直前に **pad 0.6秒の止め**(フェーズ4)
- 出口は問いではなく**判定**。問いは判定のあとに1文だけ置く

### 仮説として記録(確度Cなので行動を変えない)

- **「節は3〜5分」**という記述を見つけたが、単一系列で、
  フェーズ3で決めた「1章100〜130秒」と食い違う。**フェーズ3の判断を維持する。**
  長尺が3本たまった時点で、章の長さとチャプター別の維持率を突き合わせる
- **画面の進捗表示が維持率に効くか**は分からない。YouTube 自体が進捗バーを持っているので、
  重複する可能性がある。合図の原則(確度A)を根拠に「分母を出す」ところまでにして、
  バーやゲージは作らない
