# 調査の合格基準(ループ共通ルール)

制定: 2026-08-13(ユーザーレビュー第5弾: 「文献1、2つだと圧倒的な不合格」を受けて)。
以後のすべてのリサーチ→検証→改善ループに適用する。

## 1. ソース数の下限(主張単位で数える)

「1要素あたり」ではなく**個別の主張(claim)単位**で数える。

| 主張の重み | 下限 | 内訳の条件 |
|---|---|---|
| 行動を変える主張(コード・台本・設定を変更する根拠) | **独立5本以上** | うち一次資料1本以上(公式ヘルプ/公式ブログ/官公庁/査読論文) |
| 方針に影響する主張(ルール化・プレイブック追記) | 独立3本以上 | うち一次資料または大規模データ1本以上 |
| 参考情報(記録のみ・行動なし) | 2本以上 | 確度ラベル付きで記録 |

## 2. 「独立」の定義

- 同一の数値・言い回しを使い回しているベンダーブログ群は**まとめて1本**と数える(相互コピペ検出: 出典を遡って同じ一次データに行き着くものは同一ソース)
- 同一企業・同一著者の複数記事は1本
- 翻訳・転載は元記事と合わせて1本

## 3. ソースの格付け(優先順)

1. **一次資料**: プラットフォーム公式(YouTubeヘルプ/blog.youtube/Creator Insider)、官公庁、法令原文
2. **査読研究・大規模データ**: 学術論文、方法論を公開している10万本級の分析
3. **独立した複数の実務家**: 顔と実績のある運用者・専門家(相互に独立していること)
4. **ベンダー・ツール会社のブログ**: 自社データなら格上げ可。出典なしの断言は最下位
5. 匿名まとめ・AI生成疑いのある記事: カウントしない

## 4. 確度ラベル(記録に必須)

- **確度A**: 一次資料+独立ソース5本以上が一致。行動変更に使ってよい
- **確度B**: 独立3〜4本一致、または一次資料はあるが実務検証が薄い。小さい行動変更まで
- **確度C**: 1〜2本。行動変更に使わない。自チャンネルのアナリティクスでA/B検証する仮説として扱う

## 5. 運用

- 各ループの記録(deep-loops.md)には主張ごとに「独立ソース数・確度ラベル」を明記する
- 確度C の主張で行動を変えていた場合は、裏取りラウンドを回して A/B に昇格させるか、変更を差し戻す
- 反証検索を必須にする: 主張を支持する検索だけでなく「主張 反論」「claim criticism」でも1回引く
- 絶対値(◯%・◯秒)はすべて「自チャンネルのアナリティクスで再検証する」前提で扱う(外部データの絶対値は環境が違う)
