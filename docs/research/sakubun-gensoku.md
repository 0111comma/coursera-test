ユーザー指示「どうすれば上手に作文できるのか検索して、自分なりに整理して、
このプロジェクトに落とし込んで」への回答。

調べた出どころ: 本多勝一『日本語の作文技術』/ 木下是雄『理科系の作文技術』/
放送原稿(ニュース原稿)の書き方 / 認知負荷とワーキングメモリの文章論 /
YouTube台本の実務論。**それに加えて、この2週間にユーザーが却下した実例**。
確度: 書籍2冊は一次資料に近い定番(A)。放送原稿・認知負荷は複数の独立解説で一致(B)。
却下ログはこのチャンネル自身の一次データ(A)。

## 0. いちばん大きい発見 — 下手だったのは「文」ではなく「書く順序」

2週間の却下を並べると、個々の文法ミスではなく**同じ製造工程の欠陥**から出ている。

> ゲートに落ちる → その1行だけ差し替える → 貼った接続語や指示語が嘘になる →
> 「でも」「つまり」「ある名前」「その」の連続 → 読むとバカっぽい

つまり **検査工程(ゲート)を作文工程として使っていた**。
Goodhartの法則そのもので、指標を目標にした瞬間に指標が壊れた。
機械ゲートが5回、欠陥の生産装置になった記録が残っている
(check_video の尺 / check_flow の接続語×2 / check_teinei の入口規制 / check_ikko の鎖)。

**だから最大の対策は原則の暗記ではなく、工程の固定である(§2)。**

## 1. 原則 — 却下ログと文章術が一致した10箇条

各条に (出どころ) と、実際に食らった却下を添える。**全部、防げた却下だった。**

### 書く前

1. **聞き手はひとり。その人が「見る前と後で何が変わるか」を先に言えること**
   (木下: 読者の想定 / このリポジトリの欲求マップ)。
   却下例: 「だから何って思う。これはどの欲求に訴求している動画なの?」(旧S016)
2. **事実と仮定を分けて言う**(木下: 事実と意見の区別)。
   利回りは「仮定」、制度は「いまの制度で」。
   却下例: 「株が増えるわけなくない? 株価が上がってるんだろ?」— 事実として誤った描写
3. **話題の道具(語)は最初に名乗る。勿体ぶらない**(放送原稿: 聞き手は戻れない)。
   タイトルに出した語・金額は、本編の頭でそれが何かを言う。
   却下例: 「普通に何の話か分からん」(S020 — 2000円の正体を言っていなかった)
   却下例: 「ある名前が増えたって何?」(S022 — ぼかし語)

### 文を書くとき

4. **一文一義。耳で聞く文は40字を超えない**(放送原稿 / 認知負荷:
   ワーキングメモリは文の後半で前半を忘れる)。このチャンネルは1文25字目安。
5. **前の文の名詞を受けて次の文を作る。接続語で貼らない**(木下: 文と文の連結)。
   接続語は関係の宣言であり、**宣言した関係が成り立たない接続語は嘘**。
   却下例: 「急に『でも』って言われるのムカつく」「つまりって何?w」
6. **指示語は1本の動画で数回まで。名詞をもう一度言うほうが速い**(認知負荷:
   指示語の解決は聞き手に計算をさせる)。
   却下例: 「1分の動画で指示語が20回30回出てるのって普通に考えるとおかしいじゃん」
7. **同じ意味を2回言わない。なくても済む語は書かない**(木下: 「必要なことは
   洩れなく、必要でないことは一つも書かない」)。
   却下例: 「お礼に返礼品が届く — 頭痛が痛いみたいな感じ」
8. **名詞の圧縮をほどく。動作は動詞で言う**(認知負荷: 抽象名詞句は解凍コストを払わせる)。
   「出したお金の差」より「積みそこねた1年ぶんの36万円」。
   却下例: 「『出したお金の差』は日本語として分かりずらい」
9. **修飾語は長いものを先に、読点は修飾の境界に打つ**(本多の二大原則)。
   主題の直後に読点を打つ癖(「その額は、〜」)はこの原則の裏返しで、
   check_bunsho が比率でWARNしている。
10. **正式な名前を一度は言い、意味を渡してから使う。略さない**(放送原稿:
    同音・省略は耳で判別できない)。
    却下例: 「枠って一般的な用語じゃないだろ? 省略してんじゃん」
    却下例: 「信託報酬ってなんのために払うのか1行で言ってあげたほうがいい」

## 2. 工程 — 台本は次の順でしか書かない

**ゲートは検収。作文の道具ではない。** これを工程で固定する。

```
A. 鎖を書く      plan.md の計算の鎖(1本)を先に完成させる。文はまだ書かない
B. 口で通す      その鎖を、聞き手ひとりに向かって声に出して説明するつもりで、
                 一気に最後まで書き下ろす。途中でゲートを見ない
C. 縦読み        全文を縦に並べて通しで読む(check_bunsho --tate が印字する)。
                 「これを人前で音読して恥ずかしくないか」で自分が先に落とす
D. 検収          ゲート一式(check_all)。不合格が出たら——
E. 段落ごと書き直す  ★1行だけの差し替えは禁止。落ちた文を含む段落(同じシーンの
                 ユニット群)を、Bのやり方で書き直す。語の入れ替えで通そうとしない
```

Eが2週間ぶんの教訓の核心。1行パッチは局所最適で、全体の日本語を壊す。

| 4 一文一義・短文 | check_video(文長・字幕幅) | — |
| 5 名詞の鎖・嘘の接続語 | check_flow(共通語必須・逆接/まとめの検査) | 接続語が「気持ちとして」合うか |
| 6 指示語の総数 | check_bunsho D3(4回まで) | — |

## 4. 確度と限界

- 原則1〜10は複数の独立した文章術と、自チャンネルの却下ログの両方に現れた(確度A〜B)
- ただし「原則を守った台本が伸びる」かはまだ実測していない(確度C)。
  アナリティクスの平均視聴率で検証する
