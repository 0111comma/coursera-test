| C 拍 = 止め と定義 | 章が90秒を超えたら中に止めを1つ以上 | 実測(確度A): 90秒超は ch1 のみで、#41 に止めがある | 現状を落とさずに床を作る。BGMも切れるので聴覚的にも拍になる | 効きの根拠は無い(止めが維持率を上げる証拠は自チャンネルに無い) |
| D 拍 = 前向きの引き と定義 | 90秒ごとに数値か固有名を含む引き | 検索3件一致(確度B)+ 実測で200秒間隔(確度A) | **いま本当に足りていないのはこれ**(C1-6と同じ結論) | 台本の書き直しが要る |

- **比較**: B は測ったら**既に達成済み**だったので、規定する価値がない
  (「7.29秒間隔のものに90秒の上限をつける」のは何も縛らない)。
  C は現状追認だが、**規定が無かったものを明文化する**価値がある
  (ch4本体は止め0回で、90秒を超えていたら抜けていた)。
  D が実質の不足。C1-6 と同じ変更なので重複させない。

- **決定**: **変更**。「拍」の定義を文書で分ける:
  - **視覚の拍 = 場面替わり**。実測7.29秒間隔で達成済み。**規定しない**(測っても情報が無い)。
  - **聴覚の拍 = 止め(pad≥0.5)**。「章が90秒を超えるとき、その中に止めを1つ以上」を追加。
  - **言葉の拍 = 前向きの引き**。C1-6 の規定に統合。**C1-6 が WARN に降格したので、こちらも WARN。**

  > **検証の注(締めの切り方で中身が変わる)**: この規則を当てても L001 はどちらの切り方でも落ちない。
  > - **#103基準**: ch4本体 = #82〜#102・**77.2秒・止め0回** → 90秒未満なので規則の対象外。
  > - **#109基準**: ch4本体 = #82〜#108・**100.3秒・止め1回**(#106 pad=0.6)→ 90秒超だが合格。
  >
  > つまり本文書の「ch4本体は止め0回で、90秒を超えていたら抜けていた」は **#103 で切ったときの話**。
  > 第1ラウンド確定の #109 で切ると、ch4 は 90秒を超えたうえで止めも持っている。
  > **床としては正しいが、L001 で作動する場面は無い**(=現状追認の明文化)。

- **根拠**: 実測で「60〜90秒ごとの拍」が、読み方によって
  **8倍達成しているとも、2.7倍不足しているとも言える**状態だった。
  同じ文が両方を指しているせいで、どちらも検証できていなかった。分けたことが変更の中身。

- **確度**: **A**(3種類の間隔をすべて実測)/ 60〜90秒という**値**の根拠は **B**(検索3件一致)

  「設計文書が既に要求していることを満たしていない」か「算数が合わない」のどちらかであって、
  **維持率が上がるという主張ではない**。

  競合の長尺の章の秒数・冒頭の秒数を**フレーム単位で測ることはできなかった**。
  外部の数値はすべて検索スニペット由来で、最良でも確度B。
- **「冒頭40秒」「1章100〜130秒」という設計値そのものの根拠は、自チャンネルには無い。**
  実測はこの値からのズレを出せるが、**この値が正しいかは検証できていない**。
- **L002 は実測できない**(`output/work/` が空。署名も無い)。
  上の実測はすべて L001 1本だけで、**n=1** である。

- **「答えの数値を先に出すと維持率が上がるか」は、この文書のどの決定でも証明されていない。**
  C1-1 の初版が変更を決めていたのは、まさにこの未証明の効果に対してだった。
