## この文書の証拠の出どころ(先に宣言する)

第1ラウンドは「一次資料を読んだ」と書いて検証員に却下された。同じことをしないために、
**この文書で使った証拠を3種類に分けて明示する。**

| 記号 | 何か | この文書での扱い |
|---|---|---|
| 【測】 | **このコンテナで自分が走らせた測定**。スクリプトと再現手順を各項目に書いた | 確度A |
| 【索】 | **WebSearch の検索結果スニペットのみ**。本文は1本も開いていない | 独立3件以上一致で確度B、それ未満はC |
| 【内】 | このリポジトリ内の文書・コードの記述 | 出典としては内部規則。確度は元文書の申告に従う |

**外部サイトの本文は1本も読めていない。** note.com・jstage・wdc-jp・ousar 等は
この環境から到達できない(第1ラウンドで実測済み)。したがって以下で URL を挙げているものは
**すべて「検索結果に出た URL とスニペット」であり、本文の確認はしていない。**
査読論文(花村博司・山根智恵)も**要旨スニペットしか見ていない**。数値の引用は
スニペットに書かれていた文字列そのままで、原典での定義・条件は確認できていない。

## C3-1 役割分担(現状 めたん=解説 / ずんだもん=聞き手)

- **現状(測定値)**:
  - 【測】**数字を含む台詞の割合は、めたん 45/72 = 62%、ずんだもん 25/41 = 61%。ほぼ同じ。**
    (正規表現 `[0-9０-９]` を字幕文に当てて数えた)
  - 【測】**「初出の数値」を運んでいるずんだもんの台詞は 41本中7本**(u1/19/20/22/30/99/100)。
    例: 「そして住民税が、5%なのだ。」「さらに残りの0.315%が、復興特別所得税なのだ。」
    20.315% の内訳の一部が聞き手側に置かれている。
  - 【測】制度語(損益通算・繰越控除・源泉徴収・投資枠など10語)の**初出をずんだもんが担った回数は0**。
    定義文「〜とは」4本のうち、めたん3本・ずんだもん1本(u45、ただし疑問形)。
  - 【測】章の出口の**判定**(pad=0.6 の止めの次のユニット)5箇所のうち、
    **めたんが言ったのは3箇所、ずんだもんが言ったのは2箇所**(u11・u81)。
    `duo-skit-2026-08.md` の「判定はめたんが言う」は **3/5 = 60% しか守られていない**。
- **選択肢**:

| 案 | 内容 | 根拠・採用例 | 長所 | 短所 |
|---|---|---|---|---|
| a 現状(名目は解説/聞き手、実体は共同解説) | 数字も定義も両者が運ぶ | 実測がこうなっている | 情報を詰められる。尺が短くて済む | **役が耳で判別できない**。実測で数字保有率が 62% vs 61% |
| b 純粋な解説/聞き手 | 数字・定義・判定はすべて解説役。聞き手は問い・驚き・言い換えのみ | 【索】「説明する側、説明される側などキャラクターの性格を意識した台本」([movis](https://movis.jp/youtube-yukkuri-kaisetu/))、「片方を視聴者の代弁者とし想定質問をさせる」([Wondershare](https://dc.wondershare.jp/editing-tips/how-to-make-yukkuri-explanation-video.html))、「霊夢は聞き役で視聴者目線で質問やツッコミ」([YukkuriGen](https://yukkurigen.com/blog/yukkuri-kaisetsu-script-guide)) | 役が耳で分かる。ラジオテストに強い | 移す台詞が7本。**めたんの連続台詞が最大10まで伸びる**(下の実測) |
| c 役を章ごとに入れ替える | 章1・3は めたんが解説、章2・4は ずんだもんが解説 | 実在の型としては確認できなかった | 単調さが減る | キャラの性格と矛盾する。学習者が混乱する |
| d 対立型(賛成役/反対役) | 一方が「得だ」と言い、他方が反論する | 【索】脚本の掛け合い論([かかねば](https://kakaneba.com/scenario-serif/)) | 争点が立つ | **戦略§6(投資助言をしない・断定しない)と正面衝突する。この案は使えない** |

- **比較**【測】: 案bを機械的にシミュレートした(初出数値を運ぶ7本を めたん側に移す)。
  結果は **めたん79 : ずんだもん34**、めたんの連続台詞の分布が
  `[1×13, 2×7, 3×9, 7×1, 8×1, 10×1]` になり、**7・8・10連続の塊が3つできる**。
  現行の「連続3まで」を守るには**相槌を7本追加で挟む必要がある**。
  移動対象の7本の実測秒は 26.7s(ずんだもん全体 148.9s の 18%)。
- **決定**: **変更(案b)。ただし C3-3・C3-4 と同時に入れる。**
  具体値: (1) **初出の数値・制度語の説明は解説役(めたん)だけが言う**。
  (2) 章の出口の**判定は必ずめたん**(現状3/5 → 5/5)。
  (3) 聞き手は問い・驚き・言い換え・要約の4種のみ。
  実装は `check_long.py` に **WARN** として足す(不合格にはしない。理由は下の確度)。
- **根拠**: 役割分担が守られていないことは実測で確定している(62% vs 61%、判定3/5)。
  外部側も「解説役/聞き役」で一致するが、**すべてゆっくり解説の制作ブログのスニペットで
  一次資料ではない**。だから「役を分けるべき」までは B、
  「分けると視聴維持率が上がる」は**どこにも根拠が無い**。
- **確度**: **A**(役割が実測で崩れているという事実)/ **B**(役を分ける型が慣行として存在すること。
  独立4サイトのスニペット一致。ただし全部ベンダー・アフィリエイト系ブログで、
  research-standards の格付けでは4等級)/ **C**(それが数字を良くするかどうか。証拠ゼロ)。

## C3-3 連続台詞の上限(現状 めたん3まで)

- **現状(測定値)**:
  - 【測】**めたんの連続台詞の分布 = 1連続15回 / 2連続6回 / 3連続15回。最大3。違反0。**
    ずんだもんは 1連続33回 / 2連続4回。最大2。
  - **上限の3が最頻値と並んでいる**(36ターン中15ターン=42%がちょうど3)。
    規則が「上限」ではなく「既定値」として働いている。
  - 【測】ターンの字数は平均35.1字・最大80字。
    【索】花村博司の要旨スニペットにある「長いターン=話者ごとの1回のターンにおける
    平均文字数の3倍以上」を当てると閾値は105.3字で、**L001に該当するターンは0個**。
    同スニペットの「長いターンの出現割合は約20ターンに1回」を73ターンに当てると
    期待値は3.6個。**L001 は自然会話の研究が報告する『長いターン』を1つも持っていない。**
- **選択肢**:

| 案 | 内容 | 根拠・採用例 | 長所 | 短所 |
|---|---|---|---|---|
| a 3まで(現状) | 4本目までに聞き手を挟む | 【内】`duo-skit-2026-08.md`(自己申告で確度C) | テンポが一定 | **一定すぎる。42%がちょうど3。長いターンが0個** |

  d を入れると L001 は**即不合格**(4連続以上が0本)。

  具体値: **章の中は連続5まで / 冒頭40秒と各章の最後3ユニットは連続2まで /

  実装は `check_long.py` の WARN。
- **根拠**: 「上限3が最頻値」という実測【測】は、規則が型を作ってしまっている状態で、
  `sakubun-gensoku.md` §0 が警告する「検査工程を作文工程として使う」形と同じ。
  上限を開ける方向は慣行(3〜5)の範囲内【索】。
  下限を置く根拠は花村スニペットの「20ターンに1回」だが、**原典を読めていないので
  この数値をそのまま基準にはできない**。だから「最低1回」という弱い形にした。
- **確度**: **A**(分布が上限に張り付いている事実)/ **C**(5・2・「最低1回」という具体値)。
  確度Cなので**この変更は L003 で試して比較する扱い**にし、既存本の作り直しはしない。

## 自チャンネルのデータでは何も判定できなかった、という結論

公開済みショート13本(視聴率が分かるもの)に対して、
C4 の全指標と視聴率の関係を**完全並べ替え検定**で調べた【測】。

| 指標 | ρ または群間差 | p |
|---|---|---|
| 質問文の割合 | ρ = -0.506 | 0.081 |
| 指示語の総数 | ρ = +0.474 | 0.104 |
| 1文の平均字数 | ρ = +0.435 | 0.140 |
| 同語尾の最大連続 | ρ = -0.214 | 0.474 |
| 同語尾6連続以上 | -20.0pt (n=2/11) | 0.115 |
| 指示語5回以上 | +12.9pt (n=5/8) | 0.195 |
| 質問文2つ以上 | -8.7pt (n=8/5) | 0.392 |

**有意なものは1つもない。** しかも「指示語が多いほど視聴率が高い」(ρ=+0.474)という、
現行ゲートと逆向きの結果が出ている。これは
(a) n=13 で検出力が無い、(b) 題材の差が支配的(`demand-2026-08.md` が「いまやっていること」で
40pt の差を報告)、(c) 公開時期と台本世代が交絡している(上位3本 S015/S011/S012 は
すべて 2026-08-16 の新型)、のいずれか、あるいは全部である。

**したがって C4 の閾値を「視聴率のデータで決めた」と書けるものは1つも無い。**
本文で「変更」と書いたものは、すべて**内部の一貫性(規定と実装の乖離、
ゲートを当てたときの落ち件数)**だけを根拠にしている。

2. **外部の本文は1行も読めていない。** note.com・jstage・wdc-jp・ousar・

   **基準として採用はせず「最低1回」という弱い形に落とした**のはそのためである。
3. **ゆっくり解説の制作ブログ群が互いに独立か確かめられない。**
   「解説役3〜5回に1回」という同じ数値が複数サイトに出るが、
   出典を遡れない(本文が読めない)。research-standards の定義では
   **安全側では1本と数えるべき**で、だから C3-2 は確度Cにした。
4. **視聴率13本のデータは、台本世代・公開時期・題材と交絡している。**
   上位3本がすべて同じ日(2026-08-16)の新型なので、

5. **「面白い掛け合い」を測る指標を作れなかった。** 交替頻度・字数・語尾は測れるが、
   それが面白さかどうかは測っていない。ここは測定では埋まらない。
6. **CLAUDE.md は長尺を「8分以上」と定義しているが、L001 は 6.8分である。**
   本文の尺の計算はこの事実の上に乗っている。この不一致自体は
