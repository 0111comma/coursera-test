## PR-1 ゲートの実行順と、走らせ忘れの検出

### 現状(測定値と測り方)

**(1) ゲートの本数が合っていない。**

```
ls production/check_*.py | wc -l          → 17(うち check_all.py 本体を除くと 16)
check_all.py の COMMON(13) + LONG_ONLY(1) → 14
差分 → align, yougo
```

`check_yougo.py` は**HEAD のコミット `aad4d8f`(2026-08-22)で新設された**。
そのコミットは L001 の見逃し2件を直したが、**`check_all.py` の COMMON に `yougo` を足していない**。
`check_all.py` の docstring は「ゲートを1本ずつ手で叩いていて、この2本だけ叩き忘れていた」
という S017/S018 の事故を書いているのに、**その事故と同じことが、その事故を記録した
ファイルの上で起きている**。

`check_align.py` は「合否を出すゲートではなく照合表を読ませる道具」と自称しているが、
docstring 自身が「Unit が存在しないシーン名を指していたら不合格(これは常にバグ)」と書いており、
**非ゼロ終了する経路を持つ**。それが自動では一度も走らない。

**(2) 実行順は速いゲートが後ろにいる。** S031 で1本ずつ計測(確度A):

第3ラウンドの表(合計27.2秒・video 4.4・align 2.7)を同じ手順で測り直した値である。
順位は変わらないが **video は 4.4 ではなく 3.0 秒**だった。再現コマンド:
`for g in …; do time python3 production/check_$g.py videos/S031-iryohi-kojo; done`

上位4本で 19.9秒 = **全体の77%**。いまの `COMMON` の並びは
`toi, hold, teinei, flow, figure, overlap, ...` で、5番目に重い figure が来る。
安いゲートを先に置けば、典型的な不合格は **26.0秒待たずに約6秒**で返る(安い11本の合計6.1秒)。

### 選択肢

| 案 | 中身 | 漏れの起きる余地 | 追加コスト |
|---|---|---|---|
| 1 現状維持 | `COMMON` に手で書き足す | **新設ゲートを足し忘れると黙って通る**(実績2回) | 0 |
| 2 自動列挙 | `production/check_*.py` を glob し、明示的な `EXCLUDE` に無いものを全部走らせる。EXCLUDE にも無く走ってもいないゲートを見つけたら**不合格** | 0(足し忘れは新設時に落ちる) | 0秒(列挙のみ) |
| 3 登録テスト | `check_all` の一覧と実ファイルの一致を確かめる単体テストを別に置く | 0だが、テストを走らせ忘れる余地が残る | テスト実行分 |
| 4 実行順を実測コスト昇順に | 上表の順に並べ替える | 変わらない | 0 |

|---|---|---|---|---|
| いま漏れているゲート数 | 2 | **0** | 0 | 2 |

| 実装量 | – | 8行 | 30行+実行導線 | 1行 |

### 決定

**案2 + 案4 を採る(変更)。**

- `COMMON` の固定リストを廃し、`glob("production/check_*.py")` で列挙する。
- 除外は `EXCLUDE = {"all"}` と、**理由つきの `DEFERRED`**(いまは `yougo`)だけ。
- **`DEFERRED` のゲートは走らせるが落とさない(WARN)**。理由は下の「較正」。
- `align` は即 GATES 入り。**30/30 で合格することを確認済み**(`python3 production/check_align.py` を全本に実行、NG 0件)。
- 並びは実測コスト昇順(`toi, hold, teinei, flow, ikko, ryakugo, bunsho, yokkyu, yougo, goi, yomi, align, video, figure, overlap, long`)。

**`yougo` を即座に落とすゲートにしない根拠(測定)**: 全30本に走らせると **16本が不合格・26語**。
中身を見ると「レシート」「カード」「日用品」「自治体」「ボーナス」「タンス」のような
説明の要らない普通語が多い。`production/yougo_easy.txt` は27語しか登録がなく、**較正が終わっていない**。
較正前に落とすゲートに昇格させると、`check_ikko.py` のときと同じ「人の合否と一致しない機械判定」になる。

### 根拠

- 実測: 16ゲート中2本が `check_all` の外にいる。うち1本は HEAD のコミットで新設されたもの。
- 実測: `check_align.py` は30/30合格 → 入れても誰も落ちない。
- 実測: `check_yougo.py` は16/30不合格 → 入れると半分が落ちる。較正が先。
- 実測: ゲート費用の77%が上位4本 → 順序変更だけで不合格の返りが4倍速くなる。

### 確度

**A**(全部このコンテナでの実行結果。再現コマンドは各項に記載)。
