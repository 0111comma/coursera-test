# 00 完成度の批評 — 71小分類 × elements/ の突き合わせ(2026-08-21)

**結論を先に**: 「全部を1つずつ deep research しろ」という要求に対して、
**この調査は「71項目のうち約半分」しか deep research していない。**
残りの半分は (a) 1行で流された、(b) 外部根拠がゼロ、(c) そもそも分類表に項目が無い、のどれかである。

さらに構造的な問題が3つある。

1. **分類表の数が合っていない。** 見出しは「71小分類」だが、表を数えると **A61 + B15 + D8 = 84**、
   C は中分類7のまま小分類ゼロ。`script.md` はその C を独断で **38小分類**に割ったので、
   実際に調査された小分類は **122**。**分類表と調査結果が別物になっている。**
2. **調査対象が L001 という横型1本だけ。** 公開済みは**ショート31本 + 長尺2本**。
   `bg.md` / `layout.md` / `tachie.md` は「ショート」「縦型」という語が**1度も出てこない**。
   33本中31本を占める形式の値(SUB_WRAP・セーフエリア・立ち絵サイズ・BGM音量差)は**未調査**。
3. **ユーザーが最も強く指摘してきた領域に、分類そのものが無い。**
   `check_yokkyu`(欲求)・`check_toi`(冒頭の問い)・`check_goi`(語の省略)・`check_ryakugo`・
   `check_teinei`(端折り)・`check_flow`(文脈の断絶)・`check_align`(字幕とシーンのズレ)——
   この7ゲートは **71分類のどこにも属さず、elements/ の11ファイルのどれにも1行も無い。**
   CLAUDE.md の冒頭が「いちばん大事な順序 — 欲求 → 場面 → 決定 → 数字」と書いている当のものが、
   要素分解の対象外になっている。

## §5 確度Aを名乗るのに一次資料が無いもの

このリポジトリの定義では A = 一次資料**または**自前の実測。
自前実測のAは正当なので問題は無い。問題は**外部主張にAを付けたもの**で、
検証で以下が撤回・降格された。**撤回が分類表に反映されていない**のは §1-3 のとおり。

| 項目 | Aの根拠として書かれていたもの | 検証後 |
|---|---|---|
| A5-1 「3種以上でマンネリ回避(実測A)」 | 自チャンネルの実測 | **そのデータは存在しない**。撤回 |
| A5-6 「図が無い時間を作らない(実測A)」 | 同上 | 外部は5〜10秒〜60〜90秒までばらけ、一次資料無し。25秒に根拠無し |
| A4-5 「人間の瞬目頻度準拠(A)」 | 医学文献 | **1本も開けていない** → C |
| A7-2 「転換の間(実測A)」 | 自チャンネル | 「2〜3秒」はパブリックスピーキングの定石で動画の根拠ではない |
| A8-3 「15秒/20秒(実測A)」 | 自チャンネル | 「**この2つの数字は定石ではない**」と cover.md が明記 |
| D3 チャプター仕様(A) | `10-ending.md` | **その文書に書かれていない**。公式本文は fetch 不可 → B |
| D1 タイトル28字(A) | チェックリスト | **Shorts用**の値の長尺への外挿 → C |
| D6 締めの問いの効果(実測B) | 参照元 | 参照元が「**効果はこれから測る**」と書いている → C |
| C(script.md)の「実測」全般 | check_long の出力 | **署名バグで字数推定値だった**。総尺419.2s→実測400.7s(-18.5s) |

**最後の1件は影響が大きい。** `check_long.durations()` が `bands` を署名に渡しておらず、
**BANDS を使う長尺は永久に署名が一致しない** = **check_long は長尺の秒を一度も実測していない**。
推定は約5%長い側にずれ、**下限ゲート(章≥60秒・話速≥290字/分)を実際より安全に見せる**。
L001 の ch3 は実測 60.2秒で、**不合格ラインまで0.2秒**だった。

## §6 そもそも分類が粗い箇所(さらに小さく割るべき)

### 6-1 A5 図解 — 型ごとに条件が違うのに、7項目を全型に一律で当てている

`figure.md` 自身が型ごとのバラつきを実測している:

| 型 | 数値ラベル | 字幕40ptとの比 |
|---|---|---|
| barsN | 30pt | **0.75倍** |
| table | 34 / 30pt | 0.85 / 0.75倍 |
| timeline | 36pt | 0.90倍 |
| curve | 27pt | **0.67倍** |

**バラついていること自体が「型ごとの小分類が要る」という証拠。**
A5-3(マーク仕様)・A5-4(数値ラベル)・A5-5(登場アニメ)は、
棒グラフと表と折れ線で**守るべきものが違う**のに1つの決定で済ませている。

割るべき単位(型 × 条件):

- **barsN**: 軸の原点(0起点か)/ 棒の本数上限 / 最小可読高(figure.md が10pxのWARNを提案済み)/
  並び順(値順か時系列か)/ ハイライトの数
- **compare2**: 左右の意味の固定(左=悪/右=良 か)/ 差分の見せ方 / L001 で**24ユニット(21%)**も
  使われている偏りの是非
- **curve**: 軸ラベル / 線の太さ / 凡例の位置 / マークのサイズ(現状 0.67倍で最小)
- **timeline**: 向き(左→右)/ 刻みの粒度 / 年またぎの表現
- **table**: 行数上限 / 列数上限 / 罫線の有無 / ハイライト行
- **band / checklist**: checklist は figure.md が「図から外す」と決定済み = **分類の再編が確定している**
- **waterfall**(新設決定済み・未実装): 増減の色 / 合計の見せ方

### 6-2 A3 字幕 — 形式・話者・内容で条件が違う

- **縦型/横型**: `SUB_WRAP` は横型26字。縦型の値と根拠が項目に無い(§2-3)
- **話者別**: A3-12 は色分けだけ。**字数の上限を話者で変える**決定(C3-4/C4-1 の「聞き手16字以下」)が
  A3 側に反映されていない。台本側とテロップ側で同じ制約を二重管理している
- **内容別**: 数値を含む字幕・専門語を含む字幕・リアクションの短い字幕で、
  サイズも改行位置も本来違う。今は一律

### 6-3 B3 効果音 — 4種を1つの項目群で扱っている

`impact` は **2.2秒鳴る**(audio.md)。`pop` は短い。
**長さが1桁違う音を「B3-3 音量」「B3-4 同期」で同じ扱いにしている。**
audio.md 自身が「impact は2.2秒鳴るので、この比較に含めても意味が出ない」と書いており、
**型ごとに割らないと A/B の設計すらできない**ことを認めている。
割るべき: 種類ごとに(用途 / 長さ / 音量 / 同期点 / 1本あたりの許容回数)。

### 6-4 A7 場面転換 — 「章の変わり目」しか見ていない

A7-1〜A7-4 は全部「章札」まわり。抜けているのは:

- 冒頭ブロック → 第1章 の転換(43.2秒地点。章札の型と同じでよいのか)
- 第4章 → 締め の転換
- **章の中の転換**(60〜90秒の拍。C2-6 が台本側で扱うが、映像側の項目が無い)
- 転換の映像表現そのもの(カット / クロスフェード / ワイプ)。
  **現状カット固定だが、選択肢として比較された形跡が無い**

### 6-5 A4 立ち絵 — 「立ち絵を消す判断」が項目になっていない

L001 は **113ユニット中72(63.7%)が `chara="none"`**。
**立ち絵に関する最大の決定は「出すか消すか」なのに、12小分類のどれもそれを扱っていない**
(A4-10 は非話者の減光、A4-2 は位置)。
CLAUDE.md は「図が主役のユニットは立ち絵を消す」と書いているが、
**「図が主役」の判定基準が定義されていない**。割るべき小分類。

### 6-6 D — 長尺とショートで別物なのに1つの表

D1(タイトル字数)・D2(概要欄)・D5(投稿時刻)・D7(終了画面)・D8(字幕)は
