前版 `00-gaps.md` は第1ラウンドだけを見て「71項目のうち約半分しか調べていない」と書いた。

## 数えないと決めたもの

- **「外部の一次資料が読めない」は穴に数えない。** support.google.com / w3.org / nhk.or.jp /
  springer / frontiersin / mdpi / plos / note.com はすべて 403 か EGRESS_BLOCKED で、
  WebFetch も curl も通らない。これは**環境の制約であって調査の不備ではない**。
  第2ラウンドの10ファイルはこれを正しく扱った(「一次資料を読んだ」と書いた箇所は1つも無い)。
- ただし**「読めないものを根拠に行動を変えた」場合は穴に数える**(下の §1-3)。

## 数える穴

1. 決定が曖昧なまま2つ以上の文書に割れているもの(**裁定が要る**)
2. 測れるのに測っていないもの
3. 選択肢を出していないもの(「維持」としか書いていない)

### 1-1【最重要】第1ラウンドの確度C 33件は「実装しない」のか「実装する」のか
