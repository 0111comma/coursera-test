# チャンネルの器 — 調査(第3ラウンド)

対象: 再生リスト / シリーズ設定 / インフォカード / 公開設定・予約・プレミア /
カテゴリ・言語・字幕言語 / 年齢制限・子ども向け / チャンネル説明 / ハンドル・名前・キーワード。

第1〜2ラウンドで **21ファイル中0ヒット**、つまり誰も一度も見ていない領域。
「動画の中身」ではなく「動画を並べる棚」と「アップロード画面の設定欄」を扱う。

## この調査で使った測定手段

| 手段 | 何を測ったか |
|---|---|
| `ast.literal_eval` で `production/make_upload_kit.py` の辞書を全数展開 | 再生リストの本数・所属数・予約時刻・関連動画リンクの向き |
| `grep -l` で `uploads/*_投稿キット.txt` 30本の全数走査 | 各設定項目がキットに「有るか無いか」 |
| `ffprobe -show_entries format=duration` | mp4 29本の実尺 |
| `unicodedata.east_asian_width` | チャンネル説明・バナー文言・キーワードの全角幅 |
| `python3 production/make_upload_kit.py` の実行 | 生成ゲートが今どうなっているか |
| WebSearch のスニペット | 外部仕様(カード・公式シリーズ・ハンドル・子ども向け・年齢制限) |

**外部サイトは本文を読んでいない**(403で遮断)。外部由来の記述はすべて
検索スニペットのみを根拠とし、独立3ドメイン以上一致したものだけBとした。
