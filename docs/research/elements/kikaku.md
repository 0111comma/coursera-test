### 群ごとの分離力(AUC。1.0=完全分離、0.5=コイン投げ)

| 分け方 | AUC | 平均差 | n |
|---|---|---|---|
| **損得が全員に起きるか / 条件つきか** | **1.000** | **+27.6pt** | 8/6 |
| 題材型(制度 / 計算) | 0.571 | +3.5pt | 7/5 |
| 欲求型(損失回避A・C / その他) | 0.521 | +1.9pt | 6/8 |

再現:
```
python3 - <<'EOF'
def auc(g1,g0):
    return (sum(1 for a in g1 for b in g0 if a>b)+0.5*sum(1 for a in g1 for b in g0 if a==b))/(len(g1)*len(g0))
print(auc([94.6,81.0,79.2,78.9,77.8,71.2,64.1,59.2],[54.9,52.9,48.8,47.9,44.2,40.0]))  # 1.0

EOF
```

### この表からしか言えないこと(3つ)

1. **欲求の型(A〜D)は、実測視聴率をまったく説明していない。** AUC 0.521 はコイン投げと同じ。
   A型の内訳は 94.6 / 59.2 / 48.8 / 44.2 で**群内の幅が50.4ポイント**あり、群間差1.9ポイントを
   完全に飲み込んでいる。**A〜Dの強さの順序(yokkyu-map §6 で確度Cと自認)は、
   14本の実測でも支持されなかった。**
2. **説明しているのは「損得が視聴者のほぼ全員にいま起きているか」だけ**で、これは
   重なりゼロ(全員群の最小59.2% > 条件つき群の最大54.9%)。**14本のどの1本を
   分類し直しても差は18.3ポイント以上残る**(全本を1本ずつ反転させて確認済み)。
3. **「答えは視聴者が自分では出さない計算の結果であること」は、実測では逆向きだった。**
   AUC 0.364。制度の読み上げに分類した3本(旧S012 79.2 / S008 71.2 / S009 54.9)の
   平均は自前計算11本より5.8ポイント**高い**。
   `verify.py` の算術演算数と視聴率の相関は **r = −0.034(スピアマンρ = 0.022, n=13)**。
   **計算の重さは視聴率と無関係である。**

### 正直に言う限界

- **分類は私がやった。しかも視聴率を見たあとに分類した。** 循環の危険がある。
  だから §E1-5 に**事前登録(未測定17本の予測)**を置いた。これが外れたら本節は捨てる。
- 「給料から引かれる保険料、実は半分」の企画書は**リポジトリに残っていない**
  (`videos/_rejected/S012-shaho-roushi-zatsugaku/` にあるのは v2「会社は460万円」)。
  タイトルから v1(ユーザーが「面白くない」と却下した雑学版)と推定しているが、
  **リポジトリでは裏が取れない**。視聴率79.2%という数値そのものは
  `demand-2026-08.md` に記録された実測(確度B)、**それが却下版だという同定は確度C**。
- 公開順・サムネ・投稿時刻・季節を分離できていない。**因果ではなく相関である。**

  ものを機械化するだけで、新しい主張を足していない。
  外部方針の解釈(inauthentic の対象)は確度Bだが、**それに基づいて閾値を作ってはいない。**

- **確度**: 現状の測定 **A** / YouTube の方針内容 **B**(スニペット4件一致・原文未読)/
  「独自性要素が収益化の可否をどれだけ左右するか」は **測れていない(確度なし)**。

## AB-0 このチャンネルで A/B テストが成立する最小の差

以降のA/Bテストの本数は、すべてこの計算から出している。

実測14本の視聴率から群内の標準偏差をプールすると **SD = 8.41ポイント**
(全員群 SD 10.24 / 条件つき群 SD 5.01)。両側 α=.05・検出力80% の目安 n = 16σ²/Δ² より:

| 検出したい差 Δ | 各群に必要な本数 | 合計 |
|---|---|---|
| 5pt | 46本 | **92本** |
| 10pt | 12本 | 24本 |
| **15pt** | **6本** | **12本** |
| 20pt | 3本 | 6本 |

**含意: このチャンネルの本数では「15ポイント以上動く変更」しか検証できない。**
冒頭の言い回し・語彙・色といった細部は、**原理的に自チャンネルでは判定できない**。
そこに本数を使うより、該当率のような大きい軸に使うほうが得である。

(確度**A**。自前計算。ただし n=16σ²/Δ² は正規近似の目安であり、
 視聴率が上限100%に張り付く分布であることは考慮していない — 実際にはもう少し要る)
