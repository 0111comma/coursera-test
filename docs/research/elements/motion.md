  「スマホ内蔵スピーカーがそういう再生系である」は検索スニペット3件一致(B)。
  案Bの改善量 -39.2→-16.5dB も**自前測定(A)**。ピークを揃えるので、
  今の再生環境で聞こえ方が大きく変わることはない(加算後に正規化して確認済み)。

## A7-5 冒頭ブロック→第1章 の転換(43.2秒地点)

- **現状(測定値)**:

  - **画面変化量 MAD = 0.1100**、20%超変化した画素 24.9%。
    これは112境界中の**最大値ではない**(最大は unit43 の 0.1177)。
    しかも直前の unit11(t=38.80s、通常のカット)が **0.1054** で、
    **章の転換とほぼ同じ大きさの画面変化が2連続で起きている**。

## 測れなかったこと(正直に)

1. **impact の 2.2秒が長すぎるか。** 尾は発話より +3dB 出ているが、
   中心40Hzで声の帯域とほぼ重ならない。マスキングとして害があるかは判定できない。
2. **視聴者の再生環境の内訳。** 「スマホ内蔵スピーカーは低域が出ない」は
   検索スニペット3件で一致したが(B)、**このチャンネルの視聴者の何割が
   内蔵スピーカーで見ているかは分からない**。YouTube Studio のデータが無い。
3. **注視の奪い合い。** 「立ち絵は図への注視を奪う」は測れない。
   代わりに測れたのは遮蔽率だけで、これは注視の一部でしかない。
4. **転換の映像表現が視聴維持に効くか。** 画面変化量は測れたが、
   その大小が離脱率にどう効くかは、公開後のデータでしか分からない。
5. **puchun を長尺で使わなかった理由。** コードにもドキュメントにも残っていない。
   意図的なのか書き忘れなのか、この環境からは判別できない。

## A/Bテストの設計について(このチャンネルの現実に合わせる)

長尺は **L001 の1本しか公開していない**。動画を単位にした A/B は
片群8本×2群=16本が要り、月2本のペースでは8か月かかる。現実的でない。

そこで **1本の中の複数の継ぎ目を使った被験者内比較**にする。
YouTube Studio の視聴維持グラフは秒単位で読めるので、
**同じ動画の中で「印を付けた継ぎ目」と「付けない継ぎ目」の落ち込みを比べる**。
L001 は継ぎ目が5つ(43.2 / 149.7 / 224.0 / 284.2 / 384.5 秒)あるので、
1本で 2群×2〜3箇所が取れる。判定に必要な視聴回数は下の表に書いた。
