    **新しく出た内容への注視が「短く・少なく・遅く」なる**というアイトラッキングの報告。
    `longform-design.md` の「図が主役のユニットは立ち絵を消す」はこれと一致しており、維持でよい。
    https://www.sciencedirect.com/science/article/pii/S0959475224000057 /
    https://www.pnas.org/doi/10.1073/pnas.2309054121
  - 1スライド1メッセージ: 1枚に2つ以上の主張があると認知が分散してどちらも伝わらない、
    という日本語の実務側の一致。図の文字要素3つまでの上限はここから。
    https://webtan.impress.co.jp/e/2019/08/07/32999 /
    https://diamond.jp/articles/-/209182 /
    https://www.tridge.work/2018/07/08/contents-volume/
  - **正直に書く**: 「1画面の要素は何個まで」という数値の定石は
    動画の分野では**見つからなかった**。スライドの世界の「1スライド1メッセージ」は
    メッセージの数の話であって、視覚要素の個数の話ではない。
    だから個数そのものには上限を設けず、
    「内容に関係しない要素を1つ減らす(フッター)」と
    「図の中の文字を3つまで」の2点だけを決めた。

- **⚠検証(効果量の扱い)**: coherence の「23/23・中央値 0.86」と signaling の「d=.38」は、
  引用先(`ctl.risepoint.com` / `link.springer.com` / `sciencedirect.com`)が
  **すべて egress 遮断で開けず、本検証では確認できなかった**。
  数字の桁感としては Mayer 系のレビューで見る値と矛盾しないが、
  **裏が取れていない以上、これらを単独で行動の根拠にしない**。
  幸い A2-4 の決定はどれも「装飾を1つ減らす / 図の文字を3つに抑える」という
  低リスク側なので、確度が下がっても害は小さい。

- **確度**: **B → C**(検証後。
  「フッターが下部UIで隠れる」は **A ではなく検証不能**(調査員は確度C の1系統ソースを
  A と書き換えていた)。一貫性・合図の効果量も本検証では未確認。
  したがって A2-4 の決定は **どれも A/B 待ちの仮説**として扱う。
  ただし決定3(章チップとバッジは維持)は現状維持なので、そのまま据え置いてよい)
