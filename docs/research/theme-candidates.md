# テーマ選定調査(2026-08)

教育系YouTubeチャンネルのテーマをゼロから選定するための市場調査と候補評価。

## 前提条件(調査で判明した重要な制約)

### 1. YouTubeの「量産型コンテンツ」規制が最大のリスク

- 2025年7月のYouTubeパートナープログラム(YPP)改定で、ポリシー名称が「繰り返しの多いコンテンツ」から**「量産型のコンテンツ(inauthentic content)」**に変更され、AIによる大量生成が明確に規制対象になった
- 2026年に入り、AI動画の収益化停止が大量発生している。停止パターンの典型:
  - 他人の動画の内容をAI音声・AI画像で差し替えただけの動画
  - **雑学系のAI量産動画**(独自性がないと判定される)
  - テンプレートで作られ大量生産された印象を与えるAI生成コンテンツ
- 一方、**AIを補助ツールとして使い、独自の洞察・視点があるコンテンツは収益化可能**

**→ 企画の生命線は「Claude Codeで作った」ことではなく「独自の価値(一次情報・実演・独自の切り口)を毎回入れられる仕組み」。テーマ選定の最重要評価軸とする。**

### 2. 収益化条件(2026年時点)

| ルート | 条件 |
|---|---|
| 長尺動画(広告収益) | 登録者1,000人 + 総再生4,000時間(直近12ヶ月) |
| ショート動画(広告収益) | 登録者1,000人 + **直近90日でショート視聴1,000万回** |
| 一部機能のみ | 登録者500人〜 |

**→ Shortsだけでの収益化はハードルが極めて高い(1,000万回/90日)。現実的な収益化ルートは「Shortsで認知・登録者獲得 → 週1解説動画(5〜15分)で再生時間を稼ぐ」導線。ユーザーの想定ペース(毎日ショート+週1解説)はこの構造に合致する。**

### 3. 高RPMジャンル(2026年、faceless系実測データ)

- 金融・投資: $15〜30+(最高水準だが競合最激戦)
- AIツール・自動化: $10〜25
- ビジネス・B2Bソフトウェア: $14〜38
- 英語学習: 約$12(競合1万chと手薄、成長21倍という報告も)
- ビジネスドキュメンタリー: $8〜18

## 各候補の詳細

### 1. AIツール活用術(ChatGPT/Claude/Gemini等の使い方・仕事術)【推薦】

- **独自性(A)が構造的に強い**: 実際にツールを操作した画面録画・実測結果・プロンプト実例が毎回の一次情報になる。「AIで作った動画」ではなく「AIを検証した動画」なので量産型判定への耐性が最も高い
- **正確性(B)**: Claude Code自身がツールを実際に実行して検証できる唯一のジャンル。制作パイプラインと検証が一体化する
- **継続性(C)**: 各社が毎週新機能をリリースするためネタが自動供給される。ニュース性でShortsも回る
- **競合(D)**: 日本語圏は伸びているが、体系的な初心者向け・非エンジニア向けはまだ層が薄い。最大手でも登録者数万人規模で参入余地あり
- **収益性(E)**: $10〜25と高RPM。視聴者層(仕事効率化に関心があるビジネスパーソン)の広告価値が高い
- **リスク**: ツールのUI変更で動画が陳腐化しやすい → Shorts中心の高回転と相性が良い(むしろ追い風)

### 2. ITスキル・プログラミング入門

- コード実行で正確性を完全担保できる。Claude Codeとの相性は最良
- ただし初心者向けプログラミング教育は無料教材が飽和しており、視聴動機の設計が難しい。AIツール活用術に内包する形(「AIで学ぶ/AIにやらせる」)が現実的

### 3. お金・金融リテラシー

- RPM最高水準だが、リベ大(両学長)・中田大学など巨大チャンネルが君臨する最激戦区
- YMYL(お金・健康)領域は誤情報リスクが高く、AI生成との組み合わせは炎上・規制リスクが大きい。金融商品への言及は法規制(金商法)の考慮も必要

### 4. 英語学習

- Shorts適性とネタ継続性は最強クラスだが、「AI音声でフレーズ読み上げ」型はAI量産チャンネルが既に大量参入しており、量産型判定の高リスク帯。差別化の仕組みを作りにくい

### 5. 雑学・科学解説 / 6. 歴史解説

- 2026年の収益化停止事例の筆頭ジャンル。「独自の洞察なしのAI雑学動画」とみなされやすく、収益化目的なら避けるべき

## 推薦

**候補1「AIツール活用術」を推薦する。**

理由の要約:
1. 量産型規制への耐性が構造的に最も高い(実演=一次情報を毎回含められる)
2. Claude Codeが「制作」と「検証」を同時にできる唯一のテーマで、企画→制作→投稿の全自動化構想と噛み合う
3. 高RPM × ネタ自動供給 × Shorts適性の三拍子
4. 「自分たちもAIで作っている」というメタ構造自体をチャンネルの独自性・売りにできる

対抗案は候補2だが、単独ジャンルとしてより「候補1の中のシリーズ」として扱うのが良い。
