# 競合が強い領域で、どう立ち回るか(2026-08-17)

ユーザー指示:
> NISAの動画って世に溢れかえってるでしょ? その中でもどうやって選んでもらえるか考えよう。
> 競合が強い時、どういった立ち回り方をすべきなのかもうちょっと仕組み化して調べてから
> プロットの作成とか計画に入って欲しい。
> そもそもどういった思考で動画作成の計画をすべきなのか、YouTubeに限らずリサーチして欲しい。

調べた結果を、**このチャンネルで判定できる形**に落とした。survey ではなく基準として使う。

---

## 1. 結論を先に

**後発が勝てるのは「大手が言えないことを言うとき」だけ。**

チャレンジャー戦略の研究で一貫しているのは、後発が勝つのは
**「リーダーにはできない選択をする意思がある」**ときだという点である。
より良く作る、より多く出す、では追いつかない(資本と時間で負ける)。
必要なのは**非対称性**であり、その最も確実な源泉が
「**リーダーが構造的に言えないこと**」である。

このチャンネルにとってそれは何か。**大手のマネー系チャンネルの多くは
証券会社・銀行・保険の広告主やアフィリエイトと繋がっている。**
だから彼らは構造的に次を言えない:

| 大手が言いにくいこと | このチャンネルは言える |
|---|---|
| 「その商品を持たないほうがいい場合がある」 | 言える(何も売っていない) |
| 「NISAが不利になる場面がある」(損益通算できない等) | 言える |
| 「手数料の話」「乗り換えても大した差にならない」 | 言える |
| 「制度を使わないという選択」 | 言える |
| 数字が地味でも、正確な額 | 言える(煽る必要がない) |

**これがこのチャンネルの非対称性であり、企画の出発点にすべきもの。**
「NISAを分かりやすく解説」は、リーダーと同じ土俵で資本負けするだけ。

---

## 2. 企画の思考順序(YouTubeに限らない一般形)

コンテンツ企画の枠組みとして実務で最も汎用性があるのは
**Jobs To Be Done (JTBD)** である。要点:

> 人は製品を買うのではなく、**ある状況で前に進むために製品を雇う**。
> だから企画は「トピック」ではなく「**その人が置かれた状況と、片づけたい用事**」から立てる。

トピック起点(「NISAについて解説する」)と、JTBD起点
(「NISAを始めたが、**下がっているのを見て売るべきか迷っている人**が、
判断できるようになる」)では、出来上がる動画がまったく違う。

### このチャンネルでの企画順序(この順で書く)

0. **状況を書く**。「誰が、どんな場面で、何に詰まっているか」を1文で。
   トピック名(NISA・住宅ローン)ではなく**場面**を書くこと
1. **その人の用事を書く**。「この動画を見終わったとき、何ができるようになるか」
2. **大手が言えないことか確認する**(セクション1)。言えることなら、なぜ後発の自分が作るのか
3. **1つの問い**に絞る(プレイブック L1)
4. **答えを数字で出す**。自前計算できるか。できないなら企画を捨てる
5. あとは既存の8行(基準作S011の照合表)へ

## 3. 「NISA動画が溢れている」への具体的な答え

### やってはいけない企画(全部リーダーと同じ土俵)

- NISA完全ガイド / 新NISAとは / 始め方 / おすすめの銘柄
- 「積立と成長投資枠のちがい」のような**制度の目次**
- 「〇〇万円積み立てたらいくら」のシミュレーション(無数にある)

### 勝てる可能性がある企画の型

**型A: 大手が言えない不利な話**
- NISAで損したとき、**課税口座より不利になる**(損益通算も繰越控除もできない)
- 売っても枠が戻るのは**翌年**。しかも**買った時の値段(簿価)**でしか戻らない
- 「非課税」は**利益にかかる話**。入れた金額が非課税になるわけではない

**型B: 数字で殴る誤解訂正**
- 「NISAは1円も増やさない。増やすのは運用。NISAがするのは税金を取らないことだけ」
- その「税金を取らない」がいくらの得なのかを、**自分の積立額で**出す

**型C: 制度の外側**
- NISA以外に非課税の箱があること(宝くじ・iDeCo・…)を比べる
  ※ S017 でこれをやろうとして「根本的すぎて面白くない」と却下された。
  **比較の軸が教科書的だと死ぬ**。軸は「同じ額を稼いだのに手取りが違う」など
  視聴者の体感に寄せる

### 判定に使う質問(企画時に必ず答える)

1. **これは大手が言えることか?** 言えるなら、なぜ自分が作るのか
2. **検索したら同じ動画が10本出てくるか?** 出てくるなら、自分の版の何が違うか
3. **答えを自前計算で出せるか?** 出せないなら、それは意見であって数字ではない

## 4. 長尺(8分超)への適用

長尺は**選ばれて見られる**(ショートは押し付けられる)。
だから入口に専門語を使ってよく、むしろタイトルで**争点**を明示すべき。

「NISA完全ガイド」ではなく、
**「NISAで損したらどうなるのか」**のように**大手が避ける問い**をタイトルに置く。

これは検索需要とも噛み合う。「NISA 損」「NISA デメリット」で検索する人は、
**すでに口座を持っていて不安になっている人**で、
JTBDでいえば「売るべきか判断したい」という明確な用事を持っている。

## 5. 確度と限界(research-standards.md に従う)

| 主張 | 確度 | 根拠 |
|---|---|---|
| 後発は「リーダーが言えないこと」で戦う | **B** | チャレンジャー戦略の実務通説として複数ソースで一貫。ただし実証データではない |
| 企画はトピックではなく状況・用事から立てる | **B** | JTBDは実務で広く使われる枠組み。コンテンツ企画への適用例も多数 |
| このチャンネルの非対称性は「何も売っていないこと」 | **C** | 上の2つからの推論。**自チャンネルのアナリティクスで検証する仮説**として扱う |
| 「NISA デメリット」系が伸びる | **C** | 検索需要の推測。実際に出して確かめる |

確度Cで行動を変えない、が原則だが、
**企画の優先順位を決めるだけならCでも使ってよい**(何を先に試すかの順序付け)。
「これが正しい」と断定して他を捨てるのは、Bが揃ってから。
