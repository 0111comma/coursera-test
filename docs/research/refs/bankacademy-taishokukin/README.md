| 6.7% | 上部タイトル帯が出て本編開始。老人が小判を持つ絵 | 退職金をもらったら… |

## 1本目と共通していたこと(=チャンネルの型)

- **カバーの作り**が同じ: 黄色の放射状背景・段組みで積むタイトル・下にマスコット
- **カバーの尺**も同じ: 1本目は0.6〜3.7%、2本目は〜4.1%。本編開始は5.6% / 6.7%
  → **カバーは全体の4〜6%(60秒なら2.5〜3.5秒)**
- 本編に入ると**上部にタイトル帯が固定**され、そこにタイトルが縮小して残る
- 本編の背景はクリーム色 + ドット
- マスコット(ペンギン)がカバーにも本編にも出る

## タイトルの言い方

1本目「9割はこれでOK!」/ 2本目「**まずこれやれ!**」
どちらも**最後の1行が命令形・断定形**で、ピンク帯に白抜き。
上の行(何の話か)と下の行(だから何をしろ)が**色と装飾で明確に分かれている**。

- 1行目「50代・60代」= 誰向けか(青縁・白抜き)
- 2〜3行目「退職金を受け取ったら」= いつの話か(黄+白、ピンク縁)
- 4行目「まずこれやれ!」= 何をしろ(ピンク帯・白抜き)

## 本編の入り方

「退職金をもらったら…」と**三点リーダで止めて引っ張る**。
1本目の入り「50代・60代の新NISAは」も同じく、**言い切らずに次のカットへ渡す**型。

## 1本目と決定的に違うところ: 結論の位置

| | 結論が出る位置 |
|---|---|
| 1本目(新NISA) | **73.2%**「思い立ったら始めましょう!」 |
| 2本目(退職金) | **8.7%**「最初の半年は何もしないで下さい」 |

**同じチャンネルが、動画によって型を変えている。**

2本目はタイトルが「まずこれやれ!」= 命令なので、**命令をすぐ出して、
そのあと理由と具体例(NG行動)を並べる**構成。
1本目はタイトルが「9割はこれでOK」= 安心の約束なので、
**状況と感情を積んでから答えに着地**する構成。

→ **タイトルの型が、本編の構成を決めている。**
   「◯◯しろ」なら結論を先に、「◯◯でOK」なら最後に。

## 1枚の絵で2〜3文を持たせている

札束の絵は 11.7%〜17.7%(**6%ぶん**)続き、そのあいだにテロップが2回変わる。
老人+小判も 6.7%〜8.7% で2文。

つまり **「1文につき1枚」ではない**。1本目で見えていた「毎カット別の絵」は
そういう区間もあった、というだけで、**絵を据え置いて文だけ変える区間もある**。
ただし据え置きは **6%(60秒なら3.6秒)まで**で、うちの9〜17秒とは桁が違う。

## 素材はチャンネル横断で使い回している

20.6% の老夫婦スマホは、**1本目の31.9%・60.8%と同じ絵**。
→ 素材ライブラリは動画ごとではなく**チャンネル全体で共有**されている。
   1本作るたびに25点用意するのではなく、**積み上がった資産から選んでいる**。

## 逆説型のフックを本編で使っている

「退職金をもらったら…」→「**最初の半年は何もしないで下さい**」
お金を受け取った人に「何もするな」と言う。**予想を裏切る指示**をいちばん最初に置いている。

### ここが一番の発見

**表を出して、話が進むにつれて行を赤枠で順に光らせている。**

これは今日 L002 で実装した `sl.table(..., highlight=n)` と**同じ考え方**。
つまり「同じ図を出したまま、注目する場所を動かす」やり方は
**このジャンルでも実際に使われている**。うちの道具はすでにこれができる。

違うのは:

- 向こうは **金額 + 絵文字/アイコン + 説明** の3列構成で、行そのものが意味を持つ
- 赤い太枠で囲む(うちは行の背景色を変える)
- **表が出るのは33%以降**。それまでは絵とテロップだけ
- 表を出しているあいだも**テロップは変わり続ける**(2文で2回)

### 数字の出し方

- 26.3%「月5万」← 最初の数字
- 33.2%「2,000万」← 前提の金額
- 36.5%「600万」← 表の1行目

**数字は必ず「その語だけ」黄色**にしている(月**5万**、**2,000万**、生活防衛資金**600万**)。
うちも `【】` で強調できるので、ここは今のままで足りる。

| 進捗 | 画面 | テロップ |
|---|---|---|
| 33.2% | 表(枠なし) | 仮に退職金が **2,000万**なら |
| 36.5% | 表 + **1行目**赤枠 | 生活防衛資金**600万** |
| 39.6% | 表 + **2行目**赤枠 | 個人向け国債**500万** |
| 42.2% | 表 + **3行目**赤枠 | 新NISA**600万** |
| 45.0% | 表 + **4行目**赤枠 | 高配当株・ゴールド**300万** |
| 47.3% | 笑う高齢女性(絵に戻る) | 国債(年1.8%)に / **500万**と |
| 49.7% | 同じ絵 | 高配当株(年3%)に / **300万**あれば |

**表は 33.2%〜45.0%、つまり 11.8% のあいだ画面に居る。**
60秒なら約7秒、90秒なら約10.6秒。

そのあいだに **5回テロップが変わり、赤枠が4回動く**。
つまり **1つの図で7秒持たせるが、その7秒のあいだに画面は5回変化している**。

### うちとの比較(ここが結論)

| | 図の滞在 | そのあいだの画面の変化 |
|---|---|---|
| @bankacademy の表 | 11.8%(60秒なら**7秒**) | **5回**(テロップ5回・赤枠4回) |
| うちのショート(S016以降) | **9〜17秒** | **0回**(字幕だけ変わる) |

**滞在時間はそこまで違わない。違うのは「そのあいだ画面が変わるかどうか」。**
今日測った「静止0.00%」の問題そのもので、
向こうは同じ図を出しながら**赤枠を動かして変化を作っている**。

`sl.table(..., highlight=n)` は既にあるので、
**新しい機能は要らない。使い方を変えるだけ。**

### 数字の出し方(この動画)

26.3% 月5万 → 33.2% 2,000万 → 36.5% 600万 → 39.6% 500万 →
42.2% 600万 → 45.0% 300万 → 47.3% 500万(年1.8%) → 49.7% 300万(年3%)

**表の行を1つずつ読み上げて、そのあと利回りを付けて再登場させている。**
同じ数字を2回使い、2回目に意味を足す(500万 → 国債(年1.8%)に500万)。
