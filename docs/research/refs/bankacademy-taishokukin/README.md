## 1本目と共通していたこと(=チャンネルの型)

- **カバーの作り**が同じ: 黄色の放射状背景・段組みで積むタイトル・下にマスコット
- **カバーの尺**も同じ: 1本目は0.6〜3.7%、2本目は〜4.1%。本編開始は5.6% / 6.7%
  → **カバーは全体の4〜6%(60秒なら2.5〜3.5秒)**
- 本編に入ると**上部にタイトル帯が固定**され、そこにタイトルが縮小して残る
- 本編の背景はクリーム色 + ドット
- マスコット(ペンギン)がカバーにも本編にも出る

## タイトルの言い方

1本目「9割はこれでOK!」/ 2本目「**まずこれやれ!**」
どちらも**最後の1行が命令形・断定形**で、ピンク帯に白抜き。
上の行(何の話か)と下の行(だから何をしろ)が**色と装飾で明確に分かれている**。

- 1行目「50代・60代」= 誰向けか(青縁・白抜き)
- 2〜3行目「退職金を受け取ったら」= いつの話か(黄+白、ピンク縁)
- 4行目「まずこれやれ!」= 何をしろ(ピンク帯・白抜き)

## 本編の入り方

「退職金をもらったら…」と**三点リーダで止めて引っ張る**。
1本目の入り「50代・60代の新NISAは」も同じく、**言い切らずに次のカットへ渡す**型。

## 1本目と決定的に違うところ: 結論の位置

| | 結論が出る位置 |
|---|---|
| 1本目(新NISA) | **73.2%**「思い立ったら始めましょう!」 |
| 2本目(退職金) | **8.7%**「最初の半年は何もしないで下さい」 |

**同じチャンネルが、動画によって型を変えている。**

2本目はタイトルが「まずこれやれ!」= 命令なので、**命令をすぐ出して、
そのあと理由と具体例(NG行動)を並べる**構成。
1本目はタイトルが「9割はこれでOK」= 安心の約束なので、
**状況と感情を積んでから答えに着地**する構成。

→ **タイトルの型が、本編の構成を決めている。**
   「◯◯しろ」なら結論を先に、「◯◯でOK」なら最後に。

## 1枚の絵で2〜3文を持たせている

札束の絵は 11.7%〜17.7%(**6%ぶん**)続き、そのあいだにテロップが2回変わる。
老人+小判も 6.7%〜8.7% で2文。

つまり **「1文につき1枚」ではない**。1本目で見えていた「毎カット別の絵」は
そういう区間もあった、というだけで、**絵を据え置いて文だけ変える区間もある**。
ただし据え置きは **6%(60秒なら3.6秒)まで**で、うちの9〜17秒とは桁が違う。

## 素材はチャンネル横断で使い回している

20.6% の老夫婦スマホは、**1本目の31.9%・60.8%と同じ絵**。
→ 素材ライブラリは動画ごとではなく**チャンネル全体で共有**されている。
   1本作るたびに25点用意するのではなく、**積み上がった資産から選んでいる**。

## 逆説型のフックを本編で使っている

「退職金をもらったら…」→「**最初の半年は何もしないで下さい**」
お金を受け取った人に「何もするな」と言う。**予想を裏切る指示**をいちばん最初に置いている。
