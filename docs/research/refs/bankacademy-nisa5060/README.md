## 訂正(2026-08-23)

9枚の時点で「**9枚を通じてグラフ・表が1つも出ていない**」と書いたが、**誤りだった**。

正しくはこう:

  (13で「月3万円の積立で年利5%なら」、14で「65歳時点で資産は802万となり」)
- そのグラフは**自作ではなく「引用:金融庁」と明記されたスクリーンショット**

**うちは冒頭から数字を出して、自作の図に載せる設計。ここが真逆だった。**

## 追記(19枚時点)

### 絵は使い回している

- 60.8% の老夫婦スマホは **31.9% と同じ絵**
- 70.8% の困る高齢女性は **10.0% と同じ絵**(ただし**吹き出しを追加**して別物にしている)

つまり **33カットぶんの絵を用意しているわけではない**。
素材は20点程度あれば足りて、**同じ絵を文脈を変えて再登場させている**。
うちが「毎カット新しい図を描く」と考えると死ぬが、そうしなくてよい。

### 新しく見えた技法2つ

1. **吹き出しで視聴者の心の声を代弁**(70.8%)
   困る高齢女性の絵に「年齢的に無理かなぁ...」という吹き出しを足し、
   テロップは「年齢的に遅いと諦めず」。**視聴者の内心を先に言葉にしてから否定する**。
   絵の再利用と組み合わせているのが上手い。

2. **アイコン付きの箇条書き**(57.1%)
   「債券 / 高配当株 / 金」を、それぞれの絵と一緒に縦に3つ並べる。
   グラフではないが、**うちの checklist に近い型**。ここは今の道具でそのまま作れる。

### 構成の流れ(見えている範囲)

| 区間 | やっていること |
|---|---|
| 0〜4% | タイトルを段階的に積む(静止では始まらない) |
| 5〜24% | **状況と感情**。老夫婦・困り顔・仙人。数字は出ない |
| 25〜32% | 前提の提示(新NISAで、じっくり、たとえば50〜65歳で) |

**数字が出るのは全体の1/3を過ぎてから。**
それまでは「あなたの状況はこうですよね」と共感を積んでいる。
うちは冒頭15秒以内に数値を出すゲート(`check_long` の「冒頭の数値」)まで作っていた。
ショートでも同じ思想で、**1本目の図が3秒以内**に出る。ここは設計思想がはっきり違う。

## 絵の素材数(見積り)

22コマ中、目視で確認できた再利用が3組:

- 31.9% の老夫婦スマホ ≡ 60.8%
- 10.0% の困る高齢女性 ≡ 70.8%(吹き出しを追加)
- 28.9% のペンギン(お金袋) ≡ 77.9%

→ 22コマで**約19種類**。全体33カットに引き伸ばすと **素材はおよそ25点**。

**1本作るのに25点の絵が要る**が、**毎回描き下ろす必要はない**。
ペンギン(マスコット)は表情・ポーズ違いで何度も出るので、
マスコットの差分を10種類ほど持てば、そのうち半分近くが埋まる。

**結論(73.2%)のあと、10%以上を使って5カット連続のCTA**を打っている。
しかも文は1つながりの定型文になっている:

> バンクアカデミーでは今後も、50代・60代向けの、やさしい資産運用をシェアしますので、
> ぜひチャンネル登録・フォローをお願いします!

- **登録ボタンそのものを絵で見せる**(82.9%)。言葉だけで言わない
- ロゴを1カット丸ごと使う(75.8%)
- **チャンネルが誰に何を届けるかを、毎回同じ文で言う**(=定型の自己紹介)

うちの締めは「次に見るものを名指しする」1〜2ユニット(約7秒)。
**導線の作り込みが桁で違う。**ただしこれは維持率とは逆に働きうる
(最後まで見る人が減る)ので、**登録率と維持率のどちらを取るかの設計判断**。
向こうは明確に登録を取りに行っている。
