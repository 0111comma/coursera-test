## 深掘りループ② 音声の調声

実施: 2026-08-12。調査3件+全ユニットのカナ(読み)全数検証。

### 調査で得た基準(A1〜A7)

| # | 基準 | 根拠 |
|---|---|---|
| A1 | 読み間違いゼロ(公開前にカナを全数照合) | 誤読は信頼を一撃で壊す(戦略§6の正確性と同根) |
| A2 | フレーズごとの緩急。重要文は遅く、つなぎは速く(一律速度の禁止) | [テックジム: VOICEVOX上級テク](https://techgym.jp/column/voicevox/), [プロ直伝ナレーションのコツ](https://sho-in.ed.jp/column/926/)(読みの印象は「スピード・語尾・メリハリ」) |
| A3 | 抑揚は一律にせず文脈で1.05〜1.3(単調=機械っぽさの主因) | 同上+[ヨミアゲAI: イントネーション調整](https://ai-yomiage.com/blog/voicevox2026-63UGjr) |
| A4 | ナレーション基調はピッチ低め(-0.03〜-0.08)、ピーク・驚きで持ち上げ | ナレーション用途は-0.05〜-0.10が効果的([テックジム](https://techgym.jp/column/voicevox/)) |
| A5 | オチ・ピークの直前に「間」(pauseLengthScale 1.4〜1.7でタメ) | 間=沈黙が機械っぽさを消す。感情表現の基本は速度変化(興奮=速、落ち着き=遅) |
| A6 | 疑問文は語尾上げ(エンジン自動)。抑揚の上げすぎ注意 | 上げすぎは不自然([Genussmittel](https://genussmittel.biz/voicevox-control-voice-change)) |
| A7 | 感情の方向付け: 損失は低く遅く/発見・爆発は高く速く | プロは喜怒哀楽で声色と抑揚を使い分ける([VOICE MART](https://www.voice-mart.jp/magazine/4654/)) |

### 検証結果と改善

- **A1**: 全15ユニットのカナを`audio_query`で全数取得して照合 → **「+256万円」が「タス256万円」と誤読されているのを発見(不合格)** → ナレーションを「プラス256万円」に読み指定(字幕は+のまま)。他14ユニットは正読(1日=イチニチ、積立額=ツミタテガク、早見表=ハヤミヒョウ等を確認)
- **A2〜A7**: **全ユニット一律1.2速・抑揚ほぼ一律で不合格** → ユニット別の音声演出を設計・実装:
  - 冒頭宣言「411万円。」= 1.05速・抑揚1.2(タメて張る)
  - オチ「まだ155万円」= 1.1速・ピッチ-0.06・間1.4倍(落とす)
  - 爆発「プラス256万円」= 1.25速・抑揚1.3(興奮)
  - 損失「増える分はゼロ」= 1.1速・抑揚1.05・ピッチ-0.08(重み)
  - ピーク「…、1233万円」= 間1.7倍でタメ→抑揚1.3(最高潮)
  - 基調ピッチ-0.03・句読点の間1.1倍(AIの早口感を消す)
- shortlibのUnitに `speed / pitch / pause_scale` を追加し、`audio_query`の`pitchScale`/`pauseLengthScale`を制御

### 再検証

修正後ナレーションのカナ再取得で「プラス256万円」「…、(間)1233万円」を確認(A1合格)。
再レンダリング: 53.7秒(緩急・タメで+2.8秒、55秒以内を維持)。自動チェック**ALL PASS**。
→ **A1〜A7全合格。ループ②完了**

| # | 基準 | 根拠 |

| S2 | lo-fiの質感: 7th/9thボイシング・スウィングハット(60〜74%)・ビニールノイズ・ローパス | [lofi hip hopの作り方](https://khufrudamonotes.com/how-to-make-lofi-hip-hop), [TRIVISION STUDIO](https://trivisionstudio.com/howtomake-lofi-hiphop/) |
| S3 | 定番の入手先はDOVA-SYNDROME/甘茶の音楽工房/効果音ラボ | ゆっくり/ずんだもん系の定番([Yukkurigen](https://yukkurigen.com/blog/yukkuri-bgm-free-guide)) |

| S5 | SEは強調箇所のみ・表示の頭に同期(ループ6を継承) | — |

### 検証結果と改善

- **S3**: DOVA-SYNDROME・甘茶の音楽工房・効果音ラボはいずれも本環境から到達不可(接続テスト済み)→ **自作合成の質を定石に寄せる方針で確定**し、`production/assets/bgm.wav` を置けば実BGMに差し替わる仕組みを追加(S6対応。ローカル工程でDOVA等の楽曲に差し替え可)
- **S1 不合格(ダッキングなし)** → ffmpegの`sidechaincompress`で発話中BGM自動減衰を実装(ratio=6, attack=8ms, release=300ms)。フィルタグラフはasplitでナレーションを分岐(検証済み)
- **S2 不合格(スウィングなし・ノイズなし・9thなし)** → synth_bgm v2: Am9/Fmaj9/Cadd9/G9ボイシング、ハット66%スウィング、ビニールノイズ(ヒス+クラックル)、倍音を絞りナレーション帯域を確保、キック柔らかめ
- **S5 合格**(ループ6の実装を維持)

### 再検証

再レンダリング(53.7秒)+自動チェック**ALL PASS**(平均-16.4dB)。
→ **S1〜S6全対応。ループ③完了**(S3の実音源はローカル工程で差し替え可能な構造で担保)

## 深掘りループ④ 冒頭0.5秒の絵力

実施: 2026-08-12。調査2件(編集定石+注意科学の学術研究)。

### 調査で得た基準(H1〜H4)

| # | 基準 | 根拠 |
|---|---|---|
| H1 | 冒頭0.5秒に「突発的な出現(abrupt onset)」を置く。フェード・滑らかな成長で始めない | 注意研究: 突発的出現と「動きの開始」は注意を捕捉するが、滑らかな動きは捕捉しない([Abrams & Christ 2003](https://journals.sagepub.com/doi/abs/10.1111/1467-9280.01458), [Attention, Perception & Psychophysics](https://link.springer.com/article/10.3758/s13414-018-1548-1)) |
| H2 | 完成形(結論画)を最初に見せる | 編集定石([電通PRC](https://prx.dentsuprc.co.jp/blog/c86), [アビリブ](https://www.ab-net.co.jp/abilivepromotion/news/247/)) |
| H3 | 冒頭0〜5秒は約1秒刻みの短カットで詰める | [課題解決PF: 構成テンプレ](https://0120.co.jp/blog/video-13/) |
| H4 | 動きにジャーク(弾み・オーバーシュート)を入れる。等速・滑らかすぎは注意を引かない | H1と同根(スムーズな運動は捕捉しない) |

### 検証結果と改善

- **H1/H4 不合格**: 現冒頭は滑らかなカウントアップ(ease-out)のみ → **スケールパンチ実装**: 数字が25%サイズから`easeOutBack`(オーバーシュート約9%)で0.3秒で叩き込まれ、同時にカウントアップ。突発的出現+ジャークの両方を満たす
- **H2 合格**(カバーフレーム=完成形の先出しは実装済み)
- **H3 合格**(カバー0.07秒→パンチ0.3秒→カウント1.2秒→次カット2.5秒)
- shortlibに`ease_out_back`と、SEを着地に同期させる`se_at`オフセットを追加

### 再検証

再レンダリング(53.7秒)+自動チェック**ALL PASS**。パンチ途中フレーム(t≈0.17で既に等倍近く+オーバーシュート)を目視確認。
→ **H1〜H4全合格。ループ④完了**

再レンダリング+自動チェック**ALL PASS**。360px幅の再実測で潰れ・にじみなし、可読性維持を確認。

## 深掘りループ⑦ 終わり方(即切りループ)とテンポ配分

実施: 2026-08-12。調査1件+全15ユニットの実測秒数分析。

### 調査で得た基準(E1〜E3)

| # | 基準 | 根拠 |
|---|---|---|
| E1 | ショートに余韻は不要。**プツッと即切りして冒頭に戻る**リズムが中毒性を生む | [日経クロストレンド: NGコンテンツ7つの原則](https://xtrend.nikkei.com/atcl/contents/18/00898/00001/), [MarkeZine](https://markezine.jp/article/detail/44587) |
| E2 | ラストのセリフが冒頭のセリフへのフリになっている(2周目に気づかず突入) | [hiroboonext: ループ再生の作り方](https://hiroboonext.net/youtube-shorts-hook-loop-structure/) |
| E3 | テンポの山谷は意図して設計する(タメ=演出、末尾の無音=事故) | 調声ループ(A5)との整合判断 |

### 検証結果と改善

- **実測**: 全ユニット秒数 = フック1.96秒 → 中盤3.2〜4.2秒(オチ・爆発ゾーンは調声のタメで意図的に遅い) → ピーク4.77秒(間1.7倍) → 締め2.7〜3.0秒。山谷は調声設計と整合しており合格
- **E1 不合格**: 最終ユニット後に**1.0秒の無音(余韻)** → 即切り(0.15秒)に修正
- **E2 合格**: 「あなたなら月いくら?→コメントで」→(ループ)→「411万円。」= 質問がフリ、冒頭が答えの再提示
- **E3 判断記録**: ユニット間の0.15〜0.35秒はナレーションの息継ぎとして維持(「間ゼロ」定石はお笑い・喋り主導型の話で、調声定石(A5)と衝突するため、ナレーション型は最小限の間を残す判断)

### 再検証

即切り修正はループ⑧のレンダリングに統合して反映(v4で pad 0.15 を確認)。→ **E1〜E3合格。ループ⑦完了**
