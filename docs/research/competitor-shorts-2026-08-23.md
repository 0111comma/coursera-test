# 競合ショートを調べてわかったこと(2026-08-23)

ユーザー指摘:「出した結論がカメラワークを足すだけ? 競合チャンネルのショート動画で
バズっているものを勉強してこい」。

**この調査の限界を先に書く。** この環境では動画を再生できない(YouTubeの視聴・
ページ取得は塞がれている)。だから「実際に見て分解した」ではなく、
**検索で読める分析記事・制作解説をつき合わせた結果**である。
個別の動画の再生数や画面構成を確かめてはいない。そこは確度Cとして扱う。

---

## 1. いちばん大きい発見: 我々はジャンルの作法から外れている

複数の記事が一致して書いている「ずんだもん解説の王道」は、

> **ずんだもん(聞き手・初心者役)と四国めたん(解説役)の掛け合い形式**

つまり**会話劇**である。そして「スライド形式の一方通行の説明と異なり、
掛け合いによるエンターテイメント性で視聴者を引き付ける」と説明されている。

**我々のショート30本は、全部ずんだもんの単独ナレーション + スライドである。**

ジャンルの標準的な作りとして挙げられているのは:

| 要素 | ジャンルの作法 | 我々のショート |
|---|---|---|
| 話し手 | **2人の掛け合い**(聞き手役 + 解説役) | ずんだもん1人 |
| 画面 | 明るくにぎやか・テンポ重視 | 暗く抑えた配色(#1a1a19) |
| 効果音 | 頻繁(ピロリン/ドンッ/ズン) | 1本あたり数個 |
| 見せ方 | 会話劇 | スライド(図の提示) |
| 制作ツール | YMM4 が事実上の標準 | 自作(matplotlib + ffmpeg) |

**ここが本題**: 我々の画作りは dataviz の作法(抑えた配色・グリッドは控えめ・
合図は1点)から積み上げてきた。**図として正しくする方向に最適化して、
このジャンルの視聴者が期待する方向から離れていた。**
ゲートをいくら磨いても「地味」が消えなかったのは、磨いている軸が違ったから。

しかも**ユーザーは長尺のときにすでにこれを指摘していた**
(「よくあるずんだもんともう1人の寸劇系にして」)。
長尺には入れたが、**ショートには一度も入れていない。**

## 2. 冒頭3秒(複数ソースで一致・確度B)

- **冒頭3秒での離脱率が65%を超えると、レコメンド表示が大幅に制限される**
- 冒頭3秒を直すだけで平均再生数が3〜5倍になった事例が複数
- フックの型: **逆説型 / 数値型 / 問いかけ型 / Before-After型**
- 「小さな裏切り」(視聴者が予測した瞬間に違う展開を見せる)が効く
- **静止画・ロゴから始まると3秒以内に90%がスワイプ**

我々の冒頭は「問い(1行) + カバー」で、型としては問いかけ型。
ただし**画としては静止**なので、最後の項目に抵触している。

## 3. ショートと長尺の役割(確度B)

2026年のYouTubeは**両方を投稿するチャンネルを優遇**する傾向で、
**Shorts=認知獲得、長尺=ファン化・収益化**の2段構えが主流。

→ 長尺をやめるのではなく、**順番の問題**。
   いまショートに戻るのは、この型に沿っている。

## 4. わかっていないこと(正直に)

- 個別のバズ動画の再生数・画面構成を確かめていない
- 「鮮やかな緑背景」「効果音の頻度」はnote記事1本ベース。**確度C**
- 金融ジャンルのショートで、キャラ解説と顔出し実写のどちらが強いかは不明
- 我々のチャンネルの実データ(維持率・離脱位置)がまだ無い

**これを埋める一番早い方法**: ユーザーが「これは良い」と思うショートを2〜3本
挙げてもらい、その構成を分解する。検索より確実で速い。

## 5. 出せる提案

優先順にすると、前回出した「カメラワーク」は**3番目**になる。

1. **ショートを掛け合いにする**(ずんだもん=聞き手 / めたん=解説役)。
   長尺用に作った `use_duo()` がそのまま使える。**ジャンルの作法に戻る**のがいちばん大きい
2. **冒頭3秒を作り直す**。静止で始めない。数値型・逆説型のフックを型として持つ
3. **カメラを動かす**(実測済み: 静止0.00% → 2.11%、+20秒/本)
4. 効果音を増やす・テンポを上げる
5. 配色を明るい方向に振るか検討(ただし**確度Cなので、まず1本で試す**)
