## 重要な制約 — この環境から一次資料が開けない

`.go.jp` も企業サイトも、**すべて egress proxy にブロックされている**(2026-08-24確認)。

```
www.jasso.go.jp:443    gateway answered 403 to CONNECT
www.mhlw.go.jp:443     gateway answered 403 to CONNECT
help.netflix.com       EGRESS_BLOCKED
www.amazon.co.jp       EGRESS_BLOCKED
```

WebSearch は通るが、返ってくるのは**スニペット**。公式の料金ページを開いて
確かめることはできない。よって以下の料金はすべて **確度B(二次情報)**。

**焼く前にユーザーの環境で確認すること。**

## 3. 30代男性の典型的な組み合わせ

LINEリサーチで**動画配信が30代の46.2%**、次いで音楽配信。
Amazonプライムは物販とセットなので保有率が高い。この3つを置く:

| サービス | 月額 |
|---|---|
| Netflix スタンダード | 1,590円 |
| Spotify Premium | 1,080円 |
| Amazonプライム(年5,900円 ÷ 12) | 492円 |
| **合計** | **3,162円** |

**分布(3,000円未満が6割台半ば = 境界がここ)と、実サービスの積み上げが、
両方とも3,000円台に着地した。**独立した2つの見方が一致したので、
この額は企画の前提として使える。

### 30年ぶんに直すと(35歳→65歳、360か月)

| | 額 |
|---|---|
| 1日あたり | **105円** |
| 出したお金の合計 | **113万8320円** |
| ただ貯めるだけ | 113万8320円 |
| 年3%で運用(仮定) | 184万2614円 |
| 年5%で運用(仮定) | **263万1602円** |

**1つ(Spotify 1,080円)だけ止めた場合**: 出したお金 38万8800円 /
年5%と仮定して 89万8839円。

## 4. 名指ししてよいことにした(strategy.md §6.2)

それまで `docs/strategy.md` は「個別商品・銘柄には一切言及しない」と書いていた。
**これはユーザーの指示ではなく、Claude が最初のコミット(`b3f956a`)で
独断で入れたもの**だった。2026-08-24にユーザーから

> 「これを私から禁止した覚えは一度もないけど。あなたが勝手に禁止したんでしょ?
>   これも名指しOKだから」

と指摘され、撤回した。

**金融商品を含めて、名指しは可。**金商法が規制しているのは投資助言業であって、
商品名を出すことではない。禁じるべきだったのは名指しではなく**推奨**だった。

言うのは**金額と、それが何年でいくらになるか**だけ。推奨も否定もしない。
