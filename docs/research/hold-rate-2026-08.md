# 視聴維持率のプログラム(ループ71)

ユーザー指示「棒グラフの色とかどうでもいい。抜本的に視聴維持率を上げる施策が必要」。

## 1. 自チャンネルの実測が指すボトルネック(確度A)

| 事実 | 数字 | 出どころ |
|---|---|---|
| Stayed to watch | 平均 **28.9%** | Studio実測(S011時点) |
| 平均視聴率 | 59.2%(79.2%〜39.8%) | Studio実測7本 |
| 上位と下位の分かれ目 | 「いまやっていること」かどうかで40pt | demand-2026-08.md |

**7割は最初の1〜2秒で消えている。** ここが最大の穴で、色や図の種類の問題ではない。

## 2. 現行の型の構造欠陥(自己診断)

1. **1フレーム目のカバーに答えの数字を出していた。** フィードでは1フレーム目=本編。
   サムネのつもりで置いた「95万円」「78歳」が、冒頭ネタバレになっていた
2. **答えが動画の6割地点で出て、残り4割が補足と説教。** 支払いが終わった観客は帰る
3. **締めが「〜してほしいのだ」の助言。** 冒頭に戻る仕掛けがなく、2周目が出ない

## 3. 施策 — 維持の型(このリポジトリの新しい標準)

外部の一致点(オープンループ / 冒頭1秒 / ループ構成。複数の独立解説で一致=確度B)を、
うちの1問い1計算の形式に翻訳したもの。

```
0-2秒   問い+当事者化。カバーの答えは「??歳」のようにマスク(H1)
〜40%   前提を最短で渡す。「聞いたことがあるはず/でも誰も計算しない」でギャップ宣言
40-80%  数字を段階的に積む。途中で一度「待つほど得に見える」→「でも」の反転を置く
80-90%  中盤に「あなたは何歳だと思う?」の参加(ask)を挟んだうえで、答えを最後に出す(H2)
ラスト   冒頭の問いの語に戻る1文で締める(H3)。助言の説教で終わらない
```

## 4. 機械ゲート(check_hold.py 新設。check_all に組み込み済み)

- **H1 ネタバレ**: カバーの主役に数字を出すなら「?」を含める
- **H2 終盤の新情報**: 金額・歳・%の「最後の初出」が全ユニットの60%以降
- **H3 ループ**: 最終ユニットが冒頭の問いの内容語を受ける

既存の全ショートがH1〜H3に不合格だった(=今までの型と明確に違う)。

## 5. 計測(ここからが本体。確度は今はB、実測でAにする)

この型は仮説である。次をユーザーのStudioから貰い、判定する:

1. **Stayed to watch**(新型 vs 旧型の平均) — H1の効果
2. **維持率カーブの後半の傾き**(50%→100%地点) — H2の効果
3. **平均視聴率が100%を超えるか** — H3(2周目)の効果

パイロットは S027(年金繰下げ)。旧型のまま出る直近本(S018〜S022)が対照群になる。
3本ずつ溜まったら平均で比較し、効かなければこの型を捨てる(記録は残す)。

## 6. やらないこと

- 色・フォント・立ち絵などの見た目だけの変更を「維持率施策」と呼ばない
- 釣りタイトル(本編が答えない問い)。問いには必ず本編で答える
