## 1. 表の読み方

- **決定**: 変更 / 維持 / A/B送り / 未調査 のいずれか。「変更」は実装対象。
- **確度**: この環境の定義に厳密に従う。
  **A = 自分でこのリポジトリを測って再現した** / **B = WebSearch のスニペットが独立3件以上一致**
  / **C = スニペット1〜2件または推測。確度Cで現状を変えてはいけない**(CLAUDE.md)。
- **根拠の種類**: `測` = このコンテナでの自前測定(コード実行・ffmpeg・PIL・VOICEVOX・ゲート実行) /
  `索` = WebSearch のスニペット / `実` = ユーザー提供の YouTube Studio 実測 / `無` = 根拠なし。
- **外部の一次資料は2ラウンドを通して1本も読めていない。** support.google.com / w3.org /
  nhk.or.jp / springer / frontiersin / mdpi / plos / note.com はすべて 403 か EGRESS_BLOCKED。
  したがって**確度Bと書かれているものは「検索結果が3件一致した」以上の意味を持たない。**
  `索` だけを根拠に「変更」と決めた行は、下の表では**確度をBに留め、実装順を後ろに置いている。**
