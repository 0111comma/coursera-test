# 横型長尺の寸劇形式(ずんだもん×四国めたん)調査 — 2026-08-20

ユーザー指示「横動画はよくあるずんだもんともう1人の寸劇系にして」を受けた調査。
確度ラベルは research-standards.md 準拠(A=一次資料 / B=独立複数ソース一致 / C=単一ソース・仮説)。

## 1. 相方と役割分担

- **相方は四国めたん一択**(確度B)。ずんだもん解説の「王道パターン」として
  複数の制作ガイドが名指しで挙げるのがこのペア。VOICEVOX 同梱で追加コスト無し。
  - VOICEVOX 話者ID: **四国めたん ノーマル = 2**(手元のエンジンで確認済み。確度A)
- **役割は ずんだもん=聞き手(初心者・視聴者の代弁)、めたん=解説役**(確度B)。
  制作ガイド複数が一致。給与明細クラスタの視聴者(自分の数字を知らない人)と
  ずんだもんの視点が重なるので、当チャンネルの欲求設計とも整合する。
- 口調: ずんだもん「〜なのだ」(継続)。めたんは「〜よ/〜ね/〜かしら」の落ち着いた解説口調。
  断定・命令はさせない(戦略§6は話者が増えても適用)。

## 2. 台本の型(検索の一致点 × 既存 longform-design.md の統合)

- **解説しっぱなしにしない。掛け合いで余白を作る**(確度B)。
  聞き役の質問を起点に解説役が答える形が、会話の流れを止めない安全な型。
- 1文20〜30字(確度B)— 既存ゲート(ユニット文長)と同じ基準なので変更不要。
- **義務教育で習わない語には説明を添える**(確度B)— 既存の check_goi と同思想。
  寸劇では「ずんだもんが聞き返す」形で説明を台詞化できる(説明が長台詞にならない)。
- 章構成・冒頭40秒で答え・章の出口の判定・図が主役 — **longform-design.md の型は維持**。
  寸劇はナレーションの器が変わるだけで、構造の型は変えない(確度C: 自チャンネルで検証)。
- 掛け合いのリズム(自チャンネルの規則として設定。確度C・実測で検証):
  - **めたんの連続台詞は3ユニットまで**。4つ目までにずんだもんの反応・質問を挟む
  - 章の出口の問いは**ずんだもんが言う**(視聴者の代弁)。判定は**めたんが言う**
  - リビール(数字の初出)の直後は**ずんだもんのリアクション**(surprised/troubled)

## 3. 画面(レイアウトの慣行)

- **向かい合わせ配置**: ずんだもん左下(反転して内側を向く)、めたん右下(確度B)。
- **字幕は話者で見分けられるようにする**(色分け+名札。確度B)。
  ずんだもん=緑系、めたん=ピンク系(髪色由来の慣行)。
- 話していない側は目立たせない(減光)。話者側はボブ(小さな上下)で「喋っている」を出す。
- 図が主役のユニットは立ち絵を消す(`chara="none"`)— 既存規則を両者に適用。

## 4. 素材とライセンス

- **音声**: 「VOICEVOX:四国めたん」のクレジット記載で商用利用可
  (一次資料: zunko.jp/con_ongen_kiyaku.html。voicevox_resource 内 policy.md でも確認。確度A)
- **立ち絵**: VOICEVOX公式リソース(GitHub VOICEVOX/voicevox_resource)の
  portrait.png(300×500・透過)を使用。ずんだもんで前例のある入手経路
  (assets/zunda README の「旧: VOICEVOX公式ポートレート」)。キャラクター利用は
  東北ずん子ガイドライン準拠(確度A)。
- **改善余地**: 坂本アヒル様「四国めたん立ち絵素材」(ニコニコ静画 im10791276)は
  パーツ分割PSDで口パク・表情差分が可能(ずんだもんと同作者・同ライセンス)。
  ニコニコ静画はログインが要るため**ユーザーのローカルDL→アップロードが必要**。
  もらえたら gen_zunda_parts.py と同じ方式で表情パーツ化する(確度A: ずんだもんで実績)。
  それまで めたんは公式ポートレート+トークボブで運用する。

## 5. ゲートへの影響

- 台本ゲート(bunsho/goi/flow/teinei)は字幕文で走るので**そのまま適用**。
  Q→Aの隣接ペアは話題語を自然に共有するため flow の鎖とも相性がよい。
- check_yomi: 読みの照合は話者2でも同じ辞書系なので現行(話者3のquery)で足りる。
- render_signature に **unit.speaker を含める**(混在レンダリングの再開事故防止)。
- クレジットゲート(VOICEVOXクレジット): 「VOICEVOX:四国めたん」を
  script.md / 投稿キットの両方に追加する。
