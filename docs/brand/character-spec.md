# 金融チャンネル：ずんだもん人物・演出仕様

更新：2026-09-08。チャンネル名「やけに金融リテラシーの高いずんだもん」。
この仕様は新しい金融動画に適用する。旧女性FP仕様は ../archive/2026-09-08-female-fp/character-spec.md に保存。

## 人物の核

普通に欲しい物がある。普通に迷う。ただし、お金の判断だけ妙に詳しい。
資格を名乗るFPではなく、金融知識を行動に使うずんだもんとして描く。
「金融リテラシーが高い＝何でも買える」「節約のために何も楽しめない」「相場が読める」にはしない。

| 観点 | 方針 |
|---|---|
| 欲求 | 欲しい物を納得して買いたい。将来のためにも備えたい |
| 得意 | 比較の基準をそろえる。条件を読む。投資先の重なりを見る。分からないことを区別する |
| 可笑しさ | 周囲が流しそうな細部に、本人だけ真顔で立ち止まる |
| 親しみ | 買いたい気持ちも面倒な気持ちもある。知識があっても将来の値動きは分からない |
| 他者への態度 | 知らない人を笑わない。強い広告表現や、自分の欲に対して淡々と突っ込む |
| 決着 | 買う・保留する・見送る、いずれも理由が見える |

本チャンネル独自の人物設定案。ずんだもんの公式設定や公式見解を名乗らない。

## 声

- 必須：VOICEVOX「ずんだもん」ノーマル、speaker_id=3。
- 女性FP用の音声や別話者を仮置きしたものを、完成版として納品しない。
- 第一弾は、ずんだもん一人の音声で成立させる。対話相手の追加音声を制作の必須条件にしない。
- 「のだ」は口調の一部。全ての文末に連続させず、短い疑問や間を混ぜる。
- 知識を早口で詰め込んで有能に見せない。理由が分かる速度を優先する。
- 書き出し時に使用話者を記録し、生成音声を聞いて確認する。現段階はプロットなので音声未生成。

### 口調の例

採用：「商品は3本。でも、買っている中身は同じなのだ。」
採用：「枠は余ってる。でも、春の引っ越し代を入れるつもりはないのだ。」
避ける：「情弱はこれを知らないのだ」「絶対もうかるのだ」「金融リテラシーが高いボクが教えてやるのだ」

知識の高さは自称せず、選び方で伝える。

## 見た目と画面

- 9:16の縦動画。ずんだもんが、スマートフォン・商品・家計メモを実際に見たり動かしたりする。
- ずんだもんの既存の姿を基にする。女性FPの立ち絵を残して音声だけ変えない。
- 明るい生成りを基調に、緑を人物と判断の強調に使う。文字は濃い色で読みやすくする。
- 中央には、その瞬間に見てほしい物を一つ置く。字幕・図・キャラクターを同じ場所で競合させない。
- 「本数を数える → 中身を並べる」「残高を見る → 購入額を見る」を、物の動きで見せる。
- 上下や右側の操作UIと重なる位置に、重要な数字や結論を置かない。実際の投稿プレビューで確認する。
- 架空の口座画面・例示データには、それと分かる表示を付ける。実在の証券会社の画面を再現したふりをしない。
- 素材の表情・ポーズの利用範囲は制作時に確認する。音声の利用条件と立ち絵素材の条件を混同しない。

## 音と笑い

声を聞き取りやすくすることを優先する。効果音でセリフを隠さない。
笑いは知識と行動の細かさから作る。毎回絶叫、破産、借金、極端な失敗を入れる必要はない。
「枝豆だから」「ずんだもんだから」だけの無関係なオチで、説明の最後を切らない。
