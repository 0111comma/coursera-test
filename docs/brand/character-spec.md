### 規約について(確認済み)

YouTube の広告掲載ガイドラインで制限されるのは
「性行為・成人向け玩具・性的満足を目的とした画像」および
「性的なものを**強く**連想させるタイトルやサムネイル」。
**大人っぽくスタイリッシュな女性キャラはここに当たらない。**

ただし **サムネイルは本編より厳しく判定される**ので、
サムネに使うカットだけは表情・ポーズを抑えめにしておく。
(出典: [広告掲載に適したコンテンツのガイドライン](https://support.google.com/youtube/answer/6162278?hl=ja) /
[サムネイルに関するポリシー](https://support.google.com/youtube/answer/9229980?hl=ja))

### 生成が断られたときは

画像生成は露骨な指示を断る。断られたら**「セクシー」という語を使わず**、
「大人っぽい」「上品」「落ち着いた」「スタイリッシュ」に言い換える。
上のプロンプトはその形で書いてある。

# 実物での検証(2026-08-23)— 1枚目

`assets/character/01_base.jpg`(1024×1024)を受け取って検証した。

## 使える。ただし2点、次から直したい

| 項目 | 結果 |
|---|---|
| 大きさ | 1024×1024 ✓ |
| 背景の白さ | 245以上と235以上がほぼ同数(56.5% / 56.6%)= **圧縮ノイズが少ないきれいな純白** ✓ |
| 背景抜き | `production/cutout.py` で成功。白いVネックも残った ✓ |
| 被写体の位置 | x 0.146〜0.841 / **y 0.033〜0.999 = 上下が切れている** ✗ |

### 直したいこと1: 下に余白がない

被写体が y=0.999 まで届いていて、**下端で平らに切れている**。
動画に置くと直線の切り口が見える。次からは

> **バストアップ、下に少し余白**

と入れる。上下に余白があると、置き場所を自由に決められる。

### 直したいこと2: 囲まれた白の扱い

髪と肩のあいだ、腕と身頃のあいだに**白い隙間**ができ、
外周から塗りつぶしが届かず白いまま残った。動画の実寸ではっきり見えた。

対処は `cutout.py` に入れた(**囲まれた白は大きいものだけ服として残す**。
実測でインナー1.13%・隙間0.59%だったので1%で切っている)。
ただしポーズによっては隙間のほうが大きくなりうるので、
**1枚ごとに抜いた結果を目で確認する**。

## 画風について

指定は「5〜6頭身のデフォルメ」だったが、出てきたのは**7〜8頭身のアニメ調**。
ユーザーが「いい感じ」と判断したので**これを基準にする**。

→ **残り19枚は、この絵を毎回添付して「この人物と同一人物で」と指示する。**
   文字のプロンプトだけでは、この頭身と画風には戻らない。

# 背景抜きは「位置で分ける」で解決した(2026-08-23)

**結論: 背景は白のままでよい。緑にする必要はなかった。**

囲まれた白をどう扱うかで往復したが、答えは単純だった。
**目とインナーは中央にあり、髪のあいだ・腕と腰のあいだは左右の端にある。**
横方向の位置で分ければ済む。

`production/cutout.py`:

1. 外周から繋がった白を塗りつぶしで消す
2. 残った「囲まれた白」は、**重心の x が 0.42〜0.68 の中にあるものだけ残す**
   (= 服と目)。帯の外にあるものは背景の隙間として消す

実測(1枚目):

| 領域 | 重心のx | 判定 | 残存 |
|---|---|---|---|
| 目(左) | 0.50 | 残す | 100% |
| 目(右) | 0.61 | 残す | 100% |
| インナー | 0.56 | 残す | 100% |
| 髪のあいだ(左) | 0.29 | 消す | 抜けた |
| 髪のあいだ(右) | 0.70 | 消す | 抜けた |
| 腕と腰のあいだ | 0.33 | 消す | 抜けた(残り13%は輪郭線) |

帯の範囲は `KEEP_X0 / KEEP_X1` の定数。ポーズによって合わなければそこを調整する。
**1枚ごとにマゼンタ地に置いて目で確かめる**(抜け残りは一目で分かる)。

## 試して駄目だった規則(記録)

- **面積で切る**: 目(181px)より髪のあいだ(357px)が大きく、**目が先に消えた**
- **外の背景からの距離で切る**: 髪のあいだ(15px)は消せたが、
  腕と腰(141px)とインナー(134px)が同じくらいで**区別できなかった**

汎用の規則を探しにいったのが遠回りだった。**位置という一番素直な手掛かりで足りた。**
