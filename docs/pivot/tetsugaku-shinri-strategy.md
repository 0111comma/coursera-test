# チャンネル企画書: 哲学・心理学への転換(v1 / 2026-09-02)

**ユーザーの決定(2026-09-02)**:

> 「これ金融系やってたけど、もう思いっきり舵を変えて哲学と心理学にしたい」

この文書は、金融チャンネルを**哲学・心理学のチャンネルに作り替えるための企画書**。
既存の `docs/strategy.md`(金融)は履歴として残し、この文書が通ったら
CLAUDE.md・yokkyu-map・ゲートを順に書き換える(§10)。

確度ラベルは `docs/research/research-standards.md` に従う(A=一次資料で確認 /
B=独立した複数の二次資料が一致 / C=推定・仮説。**Cで行動を変えない**)。

## 0. 結論(先に言う)

1. **チャンネルは作り直さず、いまのチャンネルで転換する。**視聴者の実測(男性83.7%・
   45歳未満54%)と登録者は、題材が変わっても資産。哲学・心理学のショートで
   落ちるのは「アルゴリズムが覚えた視聴者像」であって、人ではない
2. **主ペルソナ P-M(35歳・男性・会社員)は変えない。**変えるのは題材で、人ではない。
   S034 で「ネタに合わせてペルソナを動かす」失敗をしたばかり(persona.md)
3. **芯は「今日の場面で、自分の判断を1つ決められる哲学・心理学」。**
   名言集・本の要約・「へえ」で終わる心理トリビアは作らない。
   金融時代の最重要ルール **「欲求 → 場面 → 決定 → 根拠」の順序はそのまま使う**
4. **差別化は「根拠を見せる」に置く。**心理学は**再現された実験だけ**を、
   哲学は**原典の該当箇所**を画面に出す。これが量産型規制への防御でもある
   (雑学系のAI量産動画は2026年に収益化停止が続出。§6)
5. 最初の4週間は**橋渡し(お金の不安の心理学)**で、金融の視聴者を連れて渡る。
   5週目から全面転換

## 1. なぜ同じチャンネルで転換するか(確度B)

| | 同じチャンネルで転換 | 新チャンネル |
|---|---|---|
| 登録者・視聴者像 | 残る。橋渡しの動画で連れていける | ゼロから |
| アルゴリズムの再学習 | 2〜6週間の落ち込みを覚悟する(確度B。複数のリブランド解説が一致) | 最初から新題材で学習 |
| 収益化の条件 | 長尺の再生時間・登録者を引き継ぐ | 登録者1,000人・4,000時間をやり直す |
| 過去動画 | チャンネルページに金融動画が並び、新規訪問者が混乱する | 混乱なし |

**判断**: 同じチャンネル。過去の金融動画は消さず、転換が定着した時点(8週目の判定。§9)で
**限定公開に落とすかを決める**(視聴時間の履歴は残る)。

**橋渡し**(1〜4週目): お金の話の**中の心理学**を4〜6本。
「損失回避(取られる痛みは得る喜びの2倍)」「サンクコスト(積み立てた投信をやめられない)」
「現状維持バイアス(保険を見直さない理由)」「社会的比較(同期の年収が気になる)」。
これらは金融の視聴者がそのまま見られて、しかも心理学の入口になる。

## 2. コンセプト

**「35歳が、今日の場面で自分の判断を1つ決められる哲学・心理学」**

競合の型(確度B。yutura・YouTube検索の上位から):

| 型 | 例 | 弱点 |
|---|---|---|
| 名言集・偉人紹介 | ニーチェ名言集、「小学生でもわかる◯◯」 | 偽名言が多い。見ても何も決まらない |
| 本の要約 | 「嫌われる勇気」「ストア派に学ぶ」要約 | 本1冊ぶんを詰めるので、場面が無い |
| 心理トリビア | 「確証バイアスって何?」 | 名前を覚えて終わる。**雑学=量産型判定の本丸** |
| ゆっくり解説(思考実験) | トロッコ問題・パラドックス | 面白いが、視聴者の生活に戻ってこない |

このチャンネルは真逆で、**場面 → 判定 → 根拠**の順に置く。
「金曜の夜、上司の一言が頭から離れない」から入り、「考える対象から外していい」で終わり、
その根拠(エピクテトス『提要』第1章 / あるいは再現された実験)を画面に出す。

金融時代からそのまま持ってくる型:

- **1動画=1つの判定**(金融の「1動画=1つの数字」を置き換える)
- 冒頭で場面を名指しし、20秒以内に判定を出し、残りで根拠と例外を見せる
- **正直の幕**を必ず置く(「全員に当てはまるわけではない」の例外を1つ言う)
- 視聴後に**決められること**が動作で書けない企画は捨てる(check_yokkyu)

## 4. 欲求マップ(哲学・心理学版)

金融の A〜D を、同じ強さの順で置き換える。**「欲求 → 場面 → 決定 → 根拠」の順序は同じ。**

| | 欲求 | 場面 | 決められること | 根拠の型 |
|---|---|---|---|---|
| **A** | **自分の判断を疑いたくない・騙されたくない** | 決めたあと・失敗のあと・誰かの話を信じたあと | 決める前に何を1つ確かめるか | バイアスの実験(再現済みのみ) |
| **B** | **大きな選択を間違えたくない** | 転職・辞める・買う・引っ越す | どちらを選ぶかの判定基準 | 意思決定の実験 / 哲学の判断枠(中庸・二分法) |
| **C** | **時間と努力を無駄にしたくない** | 続けるか・やめるか・積み上げたものを捨てるか | やめる条件を1つ決める | サンクコスト / セネカ『人生の短さについて』 |
| **D** | **先の不安を減らしたい** | 老い・死・意味・「このままでいいのか」 | 考える対象と、考えなくていい対象を分ける | 哲学の本丸(ストア派・エピクロス・実存) + 幸福研究の数字 |
| **E** | **人間関係で消耗したくない**(新設) | 上司・同僚・SNS・比較 | 反応するかしないか、何を気にしないか | エピクテトス / 社会心理学(再現済みのみ) |

**単独で使わない欲求(金融と同じ)**: F 賢く見られたい・人に言いたい(雑学欲)。
名言・トリビア・「◯◯効果って知ってる?」はここに落ちる。**視聴後に決められることが
「知った」だけなら捨てる**(yokkyu-map §5 の判定法をそのまま使う)。

**落ちているかどうかの一文**: この動画を見た人は、月曜の朝に何をしなくなるか / 何をするか。

## 5. 根拠のルール(金融の check_zentei の置き換え)

金融時代の最重要ゲートは「説明していない数字を出さない」だった。
哲学・心理学では、数字の代わりに**主張の出どころ**がゲートになる。

### 5.1 心理学: 再現された実験だけを言う

心理学の有名な実験は、2010年代の再現プロジェクトで**半分近くが再現に失敗した**
(確度B。Open Science Collaboration 2015 など複数の独立した報告が一致。
企画時に原論文と再現研究をWebSearchで確認し、URLと確認日を plan.md に書く)。

YouTubeの心理学動画は、その再現失敗した実験を今も語っている。
**ここが差別化になる。**このチャンネルは、動画に出す実験ごとに再現性ラベルを付ける:

| ラベル | 意味 | 扱い |
|---|---|---|
| **再現済み** | 独立した追試・メタ分析で効果が確認されている | 動画で言ってよい |
| **未再現・縮小** | 追試で効果が出ない、または大幅に小さい | **動画で「効く」と言わない。**言うなら「再現されなかった」として言う |
| **撤回・論争中** | 論文の撤回、データ不正、解釈の論争 | 出さない |

未再現の代表(確度B。企画時に個別に確認する): 自我消耗(意志力は消耗する)・
パワーポーズ・マシュマロ実験(家庭環境で説明される)・プライミング(高齢語で歩みが遅くなる)・
ジャム実験(選択肢が多いと買わない)・ダニング=クルーガー(統計的な見かけという指摘)。

**「再現されなかった心理学」自体が企画になる。**「意志が弱いから続かない、は
実験で否定された」は、P-M の自責を減らす(欲求A・D)。

### 5.2 哲学: 原典の該当箇所を画面に出す

- 引用は**原典の書名・章(節)**を画面に出す。「ニーチェはこう言った」だけは禁止
- **偽名言を出さない。**ネットで流通するニーチェ・アインシュタイン・ブッダの名言の多くは
  出典が無い(確度B)。原典で該当箇所が見つからないものは使わない
- 訳文は青空文庫・パブリックドメインの訳、または自前の要約。著作権のある訳文を
  そのまま字幕にしない
- 解釈が割れる箇所は「解釈の1つ」と言う

### 5.3 数字は今までどおり

幸福研究・時間・年齢の数字(幸福のU字カーブの底が40代後半、など)は
**今までどおり verify.py と plan.md の前提表**で扱う。check_zentei はそのまま生きる。

## 6. コンプライアンス(YMYL・量産型規制)

### 6.1 心理学はYMYL(健康)に触れる

- **診断しない。病名を当てない。治療を勧めない。**「あなたは◯◯障害かも」は作らない
- うつ・不安・自殺に触れる題材は**作らない**(相談窓口の案内が要る領域は、
  この形式(60秒・AI音声)でやるべきでない)
- 「認知行動療法」など治療法の名前は出さない。認知の癖の話は「考え方の癖」までにする
- 概要欄に「本動画は心理学の研究の紹介であり、医療・カウンセリングの代わりではありません」
- 東北きりたんは「一緒に考える案内役」。心理士・専門家を装わない

### 6.2 量産型コンテンツ規制(2026年の収益化停止の本丸)

2026年に入り、**雑学系・心理学系のAI量産動画の収益化停止が続出**している
(確度B。note・ウォーカープラス等の複数の独立した報告が一致)。
金融より哲学・心理学のほうが**この規制に近い**。金融は「独自計算」で守れたが、
哲学・心理学は「どこかで見た話をAI音声で読む」に最も落ちやすい。

全動画に**次のうち2つ以上**を入れる(戦略§8 の置き換え):

- [ ] 原典の該当箇所を**自前で訳し、図にした**もの(要約サイトの引き写しでない)
- [ ] 実験の**数値**(効果量・人数・再現研究の結果)を自前の図にしたもの
- [ ] **自分の場面に当てはめる判定表**(P-M の場面 × 判定。他所に無い)
- [ ] 複数パターンの比較(35歳/45歳、続ける/やめる、反応する/しない)
- [ ] 再現性ラベル(§5.1)そのものが独自の要素

**名言集・本の要約・「◯◯効果10選」は作らない。**量産型判定の典型で、しかも
視聴後に何も決まらない。

### 6.3 引用・著作権

- 書籍の訳文を字幕に長く使わない(引用の要件: 主従・必要最小限・出典明記)
- 実験の図表は元論文を貼らず、数値から自前で描く(金融と同じ)

## 7. フォーマット(制作パイプラインは変えない)

`production/` の描画・TTS・ゲートはそのまま使う。変わるのは中身:

| | 金融 | 哲学・心理学 |
|---|---|---|
| 1動画の芯 | 1つの数字 | **1つの判定**(二択で答えが出る形) |
| 冒頭 | 数字のカウントアップ | **場面の名指し**(「上司の一言が、頭から離れない?」) |
| 図の主役 | 棒・曲線・式 | **分岐(反応する/しない)・対比・判定表**。数字がある回は今までどおり |
| 正直の幕 | 「全員が得するわけではない」 | 「当てはまらない場面」を1つ言う |
| 締め | 「自分の数字で足す」 | 「月曜の朝に、これを1つやらない/やる」 |
| 出典 | 官公庁・verify.py | 原典の章節・論文・再現研究 + verify.py |

長尺(横型)は、ショートで維持率の高かった判定を**4章(場面4つ)**に広げる。
`longform-design.md` の型はそのまま。

## 9. KPIと転換のスケジュール

最重要KGIは金融時代と同じ **視聴維持率**。転換の成否も維持率で判定する。

|---|---|---|
| 1〜4 | 橋渡し5本(§8 #1〜5)を投稿。チャンネル名・概要を「哲学と心理学で、今日の判断を1つ決める」に変える | 橋渡しの維持率が金融の直近10本の中央値を下回らない |
