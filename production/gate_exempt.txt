# ■ 問い・式・換算を2カットに割っている箇所(溜めて出すショートの基本の型)。
#   ゲートは「問いと答え」「式と答え」「換算の入力と出力」が繋がっていることを
#   文字の一致では見られない。
S033:flow:2   # 「サブスクに払う114万円、どれを止める?」→「月1590円、1080円、492円。」。
              # **問いと、それに答えるための内訳の提示**。114万円がどこから来たのかを
              # 分解して見せる材料なので、語ではなく数の系列で繋がっている
S033:flow:3   # 「月1590円、1080円、492円。」→「合わせて、月3162円。」。
              # **足し算の入力と出力**。割ると足し算そのものが消える
S033:flow:14  # 「同じ額なのに、263万円。」→「あなたが決めるのは、3162円の行き先だけ。」。
              # 開示した263万円を「毎月の3162円の行き先」の側から言い換える
              # **意味づけの一文**(図は前カットと同じ2本の棒。積む側=263万円)
S033:flow:7   # 「105円のために、解約画面は開かない。」→「あなたが35歳なら、65歳まで
              # あと30年。」。単価の小ささから期間の長さへ移る**設計上の転換点**
              # (小ささ×長さ=114万の仕込み)
S033:flow:8   # 「あなたが35歳なら、65歳まであと30年。」→「360回はらうと、合計いくら?」。
              # 期間(30年)と**回数への換算**(30年=毎月1回×360回)。
              # ゲートは数値どうしの換算関係を見られない
S033:flow:9   # 「360回はらうと、合計いくら?」→「止めなければ、114万円。」。
              # **問いとその答え**(3162円 × 360回)
S033:flow:11  # 「114万円を、気づかないまま払いますか?」→「同じ3162円を、毎月あなたが
              # 積み立てたら?」。痛みから反転へ移る**設計上の転換点**。
              # ここで前の語を引き継ぐと、痛みを引きずったまま反転に入ることになる
S033:flow:13  # 「増える率は、年5%と仮定します。」→「同じ3162円なのに、263万円。」。
              # **計算の前提の宣言と、その結果の開示**
S033:flow:15  # 「あなたが決めるのは、毎月3162円の行き先だけ。」→「263万円は、3つ全部を
              # 止めた話。」。**2つ前(#13)で出した263万円の条件を明示する文**で、
              # 直前ではなく1つ飛ばして受けている(撤回の入口)
S033:flow:19  # 「それを積めば、年5%と仮定して約90万円。」→「止める1つの月額に、
              # 360か月をかける。」。例(1つ止めた場合)から**視聴者自身の式への
              # 一般化**(持ち帰りの転換点)

# ■ 1文に数字が複数出るが、**1つの事実の入力と出力**になっている箇所。
S033:teinei:2 # 「月1590円、1080円、492円。」。**3つを並べて足す文**なので、
              # 数字が3つ出るのはこの文の用件そのもの。割ると足し算が消える
S033:teinei:5 # 「これを30日で割ると、1日105円。」。**換算の入力(30日)と
