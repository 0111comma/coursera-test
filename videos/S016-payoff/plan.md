# 企画書: 銀行が潰れたら貯金はどうなる?(ペイオフ)

- **ID**: S016 / **形式**: ショート / **ピラー**: 貯金と暮らし(バックログ#19)
- **構成テンプレ**: T2誤解訂正型 / **再生リスト**: 1分でわかるお金の数字 / 貯金と暮らしの数字
- **投稿枠**: 8/21(金) 8:30 / **ステータス**: 制作済み
- **投稿タイトル**: 銀行が潰れたら貯金はどうなる?【上限1000万】(23字)

## 狙い

- 誤解: 「銀行が潰れたら貯金は全部消える」→ 訂正: 1,000万円+利息までは預金保険で保護
- 視聴後: 「1銀行1人あたり元本1,000万+利息まで保護。決済用は全額。外貨は対象外。2010年に実際に発動した」と言える
- 反直感: ①実際に発動したことがある(日本振興銀行・2010) ②利息ゼロの決済用口座なら全額保護 ③同じ銀行内の複数口座は合算(名寄せ)
- ユーモア: 「ボクの貯金は、余裕でセーフなのだ」(H5財布自虐)

## フック: 「1000万円」
