//
//	animation0	目 - 待機中

//
//	animation5	口 - 待機中
//	animation6	口 - 口パク
//

//	animation10	前髪もみあげ
//	animation11	記号など
//
//	目と口の表情は平時もアニメーションとして定義する。
//	理由：「start,ID」「stop,ID」メゾットで他のアニメーション停止する（パーツを外す）ことができるため。
//	そうしないとパーツが重なって表示される
//	トリッキーな方法ではあるが要はPSDToolkitっぽく使う方法である。
//
//	これ以外は必要に応じて各サーフェスごとに定義する。
//
//******************************************************************************
//surface100番台について
//
//	各animation定義から呼び出せるようにsurface100番台に表情パーツを割り当てておく。
//
//******************************************************************************
