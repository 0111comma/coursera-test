//	そうしないとパーツが重なって表示される
//	トリッキーな方法ではあるが要はPSDToolkitっぽく使う方法である。
//
//	これ以外は必要に応じて各サーフェスごとに定義する。
//
//******************************************************************************
//surface200番台について
//
//	各animation定義から呼び出せるようにsurface200番台に表情パーツを割り当てておく。
//
//******************************************************************************
