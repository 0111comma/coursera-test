# 企画書: 1000万円を月5万ずつ取り崩すと、何歳で尽きるのか(S032)

- **公開予定**: 未定(新デザイン1本目)
- **形式**: 縦型 1080×1920 / 新デザイン(自前キャラ・明るい背景・冥鳴ひまり)

## 最初の一言(問い)

**貯金1000万円。毎月5万円で何歳まで?**

## この人の欲求

**老後にいくら使っていいのか分からなくて、使えない。**(yokkyu-map D: 損を避けたい)

貯めるまでの話は山ほどあるのに、**取り崩す側の話が薄い**。
「2000万円必要」までは言われるが、**それを月いくらずつ使えるのか**を誰も言わない。
だから使えずに抱えたまま歳を取る。

## 想定視聴者

**P-B: 50代後半〜60代。退職金や貯金がまとまった額あるが、使い方が決まっていない人。**

具体的な状況: 退職金を受け取った、あるいは受け取る目前。
銀行から運用の案内が来る。でも「いくらまで使っていいのか」を誰も教えてくれない。
だから使えずに置いたままにしている。

## 指を止める理由

**「貯金1000万円。毎月5万円で何歳まで?」** — 金額も期間も自分の頭にある数字なので、
答えを知らないことに気づいてしまう。**割り算1回で出るのに、やったことがない。**

## 視聴後に得るもの

**「月5万」のつもりが、実際は月2万7000円だと分かる。**
そのうえで、自分の額を出す式(貯金 ÷ 年数 ÷ 12)を持ち帰る。

## 視聴後に決められること

**自分の取り崩し額を、その場で決める。**

式(貯金 ÷ 年数 ÷ 12)を1枚で出すので、自分の貯金額と持たせたい年数を入れて
「月いくらまで使う」をその場で決められる。表を探しに戻る必要がない。

## なぜこの企画か

2026-08-23 に競合(@bankacademy)のショートを分解したときに見つけた穴。
向こうは「毎月5万を年金にプラスできます!」で終わっていて、
**それが何歳まで続くのかを言っていない**(competitor-shorts-teardown-2026-08-23.md)。

**うちは年数で答えられる。**しかも算数なので制度改正で腐らない。

- **この動画の結論**: 「月5万ずつ取り崩すと82歳で尽きる。95歳まで生きたら**13年足りない**。
  95歳まで持たせるなら、使えるのは**月2万7000円** — **つもりの半分ちょっと**」。
  「月5万くらいなら使える」という予想と食い違う(ネタ選定ゲートF1)。

- **プロットの作り直し(2026-08-23)**: 最初の台本は「割り算1回で200か月」を
  4ユニットかけて声に出すだけで、**驚きが1つも無かった**。1000÷5=200は誰でも暗算できる。
  ユーザー指摘「プロットマジでこれでいいと思ってんの?」。
  芯を「割り算の実演」から「**5万のつもりが2万7000円**」に移した。
  競合が『毎月5万を年金にプラスできます』で止めている穴は、
  **その5万が17年で終わること**であって、割り算の手順ではない。

## 数値(verify.py で検証済み)

元手1000万円・毎月5万円ずつ取り崩し・65歳開始:

| | 尽きるまで | 何歳で |
|---|---|---|
| 運用しない | 200か月 = 16.7年 | **82歳** |
| 年3%で運用 | 278か月 = 23.2年 | 88歳 |
| 年5%で運用 | 431か月 = 35.9年 | 101歳 |

95歳(30年)まで持たせるなら、毎月いくらまでか:

| | 毎月 |
|---|---|
| 運用しない | 2万7000円 |
| 年3%で運用 | 4万2000円 |
| 年5%で運用 | 5万3000円 |

**利回りはすべて仮定。**元本保証ではないことを台本で明示する。

## コンプライアンス(戦略§6)

1. 投資助言をしない。個別商品・業者を出さない ✓
2. 断定を避ける。利回りは「仮定」と明示 ✓
3. 算数のみ。制度の数値を使わないので出典は不要だが、**仮定であることは毎回言う** ✓
4. verify.py で再計算 ✓
5. 制度に依存しないが、利回りを扱うので**耳にも時点が届くように**
   「ただし、いま確実な方法はありません。」と言う(バッジだけに頼らない) ✓
6. 独自性: 独自計算 + 独自グラフ(年齢の帯・つもりと実際の比較)+ 持ち帰る式(3つ) ✓
