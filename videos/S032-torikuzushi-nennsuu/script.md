## この動画に出る数の出どころ

**画面に出る数は、導出値か前提値のどちらかしかない。**(`production/check_zentei.py`)

| 数 | 種類 | 出どころ |
|---|---|---|
| 65歳 | 前提 | 年金が始まる年齢(日本年金機構)。台本#2で「年金が始まる」と言ってから出す |
| 90歳 | 前提 | 90歳まで生きる人は男性の4人に1人(厚労省 令和7年簡易生命表)。台本#5で根拠ごと出す |
| 5万円 | 前提 | 仮定。動画の問いそのもの |
| 81歳 | 導出 | 1000万 ÷ 5万 = 200か月 = 16年8か月。65 + 16年8か月 = 81歳8か月 |
| 8年 | 導出 | 90歳 − 81歳8か月 = 8年4か月 |
| 300か月 | 導出 | 90 − 65 = 25年 = 300か月 |
| 3万3000円 | 導出 | 1000万 ÷ 300か月 = 3万3333円 → 1000円単位で3万3000円 |

**81歳は切り上げていない。**200か月は16年8か月なので、尽きるのは82歳ではなく81歳8か月。

## 概要欄テキスト

老後資金の1000万円を、毎月5万円ずつ取り崩すと何歳で尽きるのか。
運用しない場合・年3%・年5%の3つで計算しました。

■ 65歳から毎月5万円ずつ取り崩した場合(元手1000万円)
運用しない → 200か月(16年8か月)で、81歳8か月
年3%で運用 → 278か月(23年2か月)で、88歳2か月
年5%で運用 → 431か月(35年11か月)で、100歳11か月

■ なぜ90歳まで考えるのか
90歳まで生きる人は、男性で26.7%、女性で50.8%。
男性でも4人に1人、女性なら2人に1人が届く年齢です。
(厚生労働省「令和7年(2025)簡易生命表の概況」)
平均寿命(男81.09年・女87.13年)は「0歳の人の平均余命」なので、
65歳まで生きた人の目安には使っていません。

■ 90歳まで持たせるなら、毎月いくらまでか(元手1000万円)
運用しない → 毎月3万3000円まで(「月5万」のつもりより1万7000円少ない)
年3%で運用 → 毎月4万7000円まで
年5%で運用 → 毎月5万8000円まで

■ 持ち帰る式
貯金額 ÷ 持たせたい月数 = 毎月使っていい額

貯金額が違う場合(90歳まで・運用しない)
500万円 → 毎月1万6000円まで
2000万円 → 毎月6万6000円まで
3000万円 → 毎月10万円まで

## 固定コメント(投稿直後に設置)

あなたは毎月いくら必要ですか?
「貯金額 ÷ 持たせたい月数」で、毎月使っていい額が出ます。
65歳から90歳までなら300か月。1000万円なら毎月3万3000円です。
金額から決めると、いつ尽きるかが分かりません。
