# 企画書: 4月から6月の残業は、9月から1年ぶん引かれる(S012)

## この人の欲求

**残業代で手取りを増やしたい。でも、知らないうちに引かれるのは嫌だ。**

トピック(社会保険料)ではなく、**残業して手取りを増やそうとしている人**に向ける。

## 視聴後に決められること

**残業を4〜6月に寄せるか、7月以降に寄せるかを選べる。**
(選べない職場もある。その場合でも「9月から手取りが減る理由」が分かって身構えられる)

## この動画が答える問い(1つだけ)

**4月から6月に残業すると、手取りはいくら減るのか。それは取り返せるのか。**

答え: **年6万8112円ひかれて、増える年金は年2631円。取り返すのに26年、つまり91歳。**

## なぜ前の企画を捨てたか(ループ67)

前の S012 は「社会保険料は会社も同じ額を払っている」で、
ユーザー判定は「面白くない」。オチを「会社が出した460万円のうち、手取りは315万円」に
作り直したが、判定は変わらなかった。

> 「S12も、会社が出してるから何なの?っていう。ただの雑学ですか?っていう。
>   会社が払ってくれてんだね、ありがとうで終わる動画をわざわざ見続けようと思わなくない?」

診断は**視聴者の身に何も起きないこと**だった。会社の財布がいくらでも、見た人は何もしない。
オチを鋭くする方向で2回直したが、**直す方向がそもそも間違っていた**。

同じ社会保険料でも、この企画なら:

| | 前の企画 | この企画 |
|---|---|---|
| 誰の話か | 会社の財布 | **自分の手取り** |
| 身に起きること | 無い | **9月から1年、毎月5676円ひかれる** |
| 決められること | 無い | **残業を寄せる月** |

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-0。投資に興味は無いが、**残業代は気にしている**会社員。
  給与明細の控除欄が9月から増えていることに、気づいていない
- **指を止める理由**: 「4月から6月に残業すると、手取りが減る」。
  残業したら増えるはずのものが減る、という逆。しかも**時期が名指しされている**
- **視聴後に得るもの**: 自分の残業をいつに寄せるかの判断材料。
  および、9月から手取りが減っていた理由
- **視聴者の予想**: 「残業した月の分が引かれるだけでしょ」
- **この動画の結論**: 「4〜6月の残業で決まった保険料が、**9月から1年間**ひかれる。
  1年で**6万8112円**。増える年金は年2631円なので、取り返すのに**26年**」

## 鎖(L1: 1本 = 1つの鎖)

```
34万円 → 38万円(4〜6月の残業)→ 差 4万円
4万円 × 9.15%  = 3,660円/月(厚生年金)
4万円 × 4.925% = 1,970円/月(健康保険)
        合計    5,676円/月 ×12ヶ月 = 68,112円
4万円 × 5.481/1000 × 12ヶ月 = 2,631円/年(増える厚生年金)
68,112 ÷ 2,631 = 25.9年 → 65歳 + 26年 = 91歳
```

種になる数字は **34万円と38万円** の2つ。あとは全部そこから導かれる(S011と同じ形)。

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| いつ決まって、いつ効くか | **時間の対応** | 固有シーン `koyomi()`: 12ヶ月の帯。4〜6月を光らせ、9月からの1年を別の帯で示す |
| 34万 → 38万 | AとBの量が違う | 共通の底からの棒2本 + 差の帯 |
| 引かれる額 | 積み上がる | 棒2本(厚生年金・健康保険) |
| 何歳で取り返すか | **1本の数直線上の点** | 固有シーン `nenrei()`: 65歳から伸びる帯に、81歳(平均寿命)と91歳(取り返す)を打つ |

`nenrei()` は S011(年金)で合格をいただいた「75歳」の図と同じ型。
**損得が自分の寿命の上で決まる**ことを、位置で見せる。

## 数値の根拠

verify.py 参照。2026年度の料率・東京都・40歳未満(介護保険料なし)。

- 定時決定: 4月・5月・6月に支払われた報酬の平均で標準報酬月額が決まり、
  **その年の9月から翌年8月まで**適用される
- 標準報酬月額は等級表で決まる。ここでは等級表に実在する 34万円 → 38万円 を例にとる
- 本人負担: 厚生年金 9.15% / 健康保険(協会けんぽ東京都)4.925% /
  子ども・子育て支援金 0.115%
- 増える厚生年金 = 標準報酬月額の差 × 5.481/1000 × 12ヶ月(報酬比例部分・総報酬制)
- 平均寿命81歳は S011 と同じ値を使う

## コンプライアンス(戦略§6)

- **「残業するな」とは言わない。** 出すのは「いつ決まって、いくら引かれ、いつ取り返せるか」だけ
- **一方的に損とは言わない。** 増える年金(年2631円・終身)を必ず出す。
  さらに**傷病手当金・出産手当金も標準報酬月額で決まる**ため増える旨を入れる
- 標準報酬月額は等級表で決まるため、この額は概算である旨をバッジに出す
- 「2026年度の料率です」の時点表記をナレーションに入れる
- 40歳以上は介護保険料が加わるため条件が違う旨を概要欄に記載
- 4〜6月に固定的賃金が変わった場合は随時改定になる旨を概要欄に記載

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 引かれる額(68,112円)と増える年金(2,631円)、
   そこから取り返す年数(26年)を verify.py で再計算
2. **独自グラフ**: 12ヶ月の暦の上に「決まる期間」と「効く期間」を並べた図
3. **複数パターン比較**: 引かれた全額で見た場合(91歳)と、
   厚生年金の保険料ぶんだけで見た場合(82歳)の2通り
