# 企画書(長尺): NISAで損したらどうなるのか(L001)

- **公開予定**: 2026-08-21(金)
- **形式**: 横型 1920×1080 / 6分47秒(実測)
- **設計の根拠**: `docs/research/longform-design.md`(長尺の型)、
  `docs/research/competitive-positioning.md`(後発の立ち回り)

## この人の欲求

**NISAがマイナス。この損を、せめて税金の足しにしたい。無駄にしたくない。**

トピック(NISAの制度)ではなく、**含み損を抱えて何かできないか探している人**に向ける。
「NISAを解説する」ではなく、「その人の損が使えるのかどうか」に答える。

## 尺の見込み

**約6.7分(107ユニット)。** 章1つで1つの「引けない場面」を扱い、場面が4つ
(同じ年 / 翌年以降 / 額がちがう場合 / 利益が無い年)あるため。
内訳: 冒頭40秒 + 4章 × 約85秒 + 締め30秒。

**当初は「約8分」と書いていたが、6.7分になった。** 理由は2つ。

1. **寄り道の章を削った。** 旧第1章「NISAは増やす仕組みか」は本題ではなく、
   しかも離脱の山(53秒)に置いていた(`01-length.md` / `02-opening.md`)
2. **継ぎ目の重複を消した。** 6つの継ぎ目のうち5つで、前章の出口と章札が
   同じ問いを2回言っていた。合計28.5秒(`03-structure.md`)

**尺のために場面を増やさない。** 8分に届かないのでミッドロール広告の条件は満たさないが、
**8分は広告の条件で、視聴者のための数字ではない**(`01-length.md` 確度A)。
薄めて8分にするより、6.7分で言い切る。

## 視聴後に決められること

**NISAの含み損を売るかどうかを、税金とは切り離して決められる。**
(NISAで売っても税の計算は動かないので、売却の判断から税を外してよい)
**課税口座に損がある年は、確定申告して相殺するかを決められる。**

## この動画が答える問い(1つだけ)

**NISAで損したとき、課税口座で損したときより不利になるのか。いくら不利なのか。**

- **視聴者の予想**: 「NISAは非課税なんだから、損しても特に何もないでしょ」
- **この動画の結論**: 「NISAの損は税金の計算では**無かったこと**になる。
  同じ年に課税口座で利益があると、**小さいほうの額の20.315%**を余分に払う。
  例(NISAで20万円の損・課税口座で20万円の利益)なら **40,630円**」

## なぜこの企画か(competitive-positioning.md の3つの質問)

**Q1. これは大手が言えることか?**

半分だけ言える。**証券会社のFAQには書いてある**(損益通算・繰越控除の不可は
各社が明記している)。ただし**見出しにしているところは、ほぼ無い。**
広告主・アフィリエイトが証券会社である以上、
「NISAが課税口座に負ける場面」をタイトルに置く動機が構造的に無い。

**だからこのチャンネルの非対称性は「言えること」ではなく「見出しにできること」。**
ここは正直に書いておく。「誰も言っていない」は嘘になる。

**Q2. 検索したら同じ動画が10本出てくるか?**

「NISA デメリット」では出てくる。ただしその大半は
**制度の目次(項目を並べるだけ)**で、**いくら損するのかを金額で出していない。**
こちらは金額と、**相殺できるのは小さいほうまで**という公式まで出す。ここが違い。

**Q3. 答えを自前計算で出せるか?**

出せる。`verify.py` で全額を再計算している。税率20.315%と四則演算だけ。

## 想定視聴者(JTBD: 状況と用事)

- **状況**: NISA口座を持っていて、**評価額がマイナスになっている**。
  同じ年に、課税口座(特定口座)でも売買をしている。
- **用事**: 「この損は、税金の面で何か意味があるのか」を判断できるようになりたい。
- **指を止める理由**: タイトルで争点を名指しする(longform-design §0)。
  「NISAで損したらどうなるのか」。制度解説ではなく**争点**。
- **視聴後に得るもの**: 自分の場合にいくら差が出るかを、その場で計算できる。

## 構成(longform-design §3 の型)

**ループ71のフェーズ12で組み替えた。** 章は4つ。根拠は
`docs/research/longform-loop-2026-08/03-structure.md`(9分なら4〜5章 / 1章100〜130秒 /
章札は前章の問いを繰り返さず**答えの側**を予告する)。

| # | 章 | 尺 | 章の問い | 章の出口(判定) |
|---|---|---|---|---|
| 0 | 冒頭 | 40s | NISAで損したらどうなるのか | **引けない損の値段が40,630円** |
| 1 | 引けない損 | 100s | NISAの損は、利益から引けるのか | **引けなかった損の値段が40,630円** |
| 2 | 来年の利益 | 90s | 来年の利益からは、引けるのか | **2年つづくと差は2倍(81,260円)** |
| 3 | 効く範囲 | 80s | この不利は、いくらまで効くのか | **余分に払うのは小さいほうの2割** |
| 4 | 自分の場合 + 締め | 90s | 自分の場合は、どう出すのか | **得も損も同じ40,630円。売却の判断に税は不要** |

**冒頭40秒で答えを出し切る。** 最初の数値は約7秒、最初の図も約7秒。
**章の切れ目を45〜75秒に置かない**(60秒で55%以上が離脱するため。`01-length.md`)。
旧構成では53.0秒に寄り道の章を置いていた。

各章の出口に**損得の判定**を置き、その**直前に0.6秒の止め**を入れる
(BGMもそこで切れる。`04-rhythm.md` / `08-audio.md`)。
**問いは判定ではない**(`07-progress.md`)。

## 鎖(L1: 章 = 1つの鎖)

```
章1  20万円 × 20.315% = 40,630円
章2  (20万 − 20万) × 20.315% = 0円  ⇔  20万 × 20.315% = 40,630円  → 差 40,630円
章3  40万 × 20.315% = 81,260円(2年またぎ)
章4  30万と10万 → 小さいほうの10万 × 20.315% = 20,315円
     利益0円 → 差 0円
締め −40,630 / 0 / +40,630 の3行
```

種になる数字は **20.315%** ひとつ。全章がそこから導かれる。

## コンプライアンス(戦略§6)

- **「NISAをやめたほうがいい」とは言わない。** 言うのは
  「損が出た年に、課税口座に利益があると、この差が出る」という**条件つきの事実**だけ
- 個別の銘柄・投資信託・証券会社を出さない
- 「必ず」「儲かる」を使わない。例に使う金額はすべて**仮定**と明示
- **「2026年8月時点の制度です」**を冒頭テロップと締めの両方に入れる
- 税制は改正される。復興特別所得税は2037年分までである旨を締めに入れる
- 確定申告の要否は個人の事情で変わるため、**手続きの一般論に留め、個別判断はしない**

## 独自性要素(戦略§8 — 2つ以上必要。ここでは4つ)

1. **独自計算**: 差額をすべて verify.py で再計算(40,630 / 81,260 / 20,315)
2. **独自の公式**: 「不利になる額 = 小さいほう × 20.315%」という形にまとめたもの
3. **複数パターン比較**: 損と利益の大小4パターン + 3ケースの一覧表
4. **独自グラフ**: 横並び4本の比較と、年をまたぐ繰越の図
