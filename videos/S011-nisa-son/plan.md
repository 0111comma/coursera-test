# 企画書: NISAで損すると、その損はなかったことになる(S011 v2)

## 旧S011(債券)却下の理由

ユーザー判定:「債券のやつ、純粋におもんないので却下」

- オチが「途中で売らなければ元に戻る」= **安心で終わっていた**(プレイブックF3)。
  見終わったあとに何も引っかからない
- 債券はP-Aが単体で持っていないので、「自分の資産の話」になりきらなかった
- F1(予想と食い違う)は満たしていた。**食い違った結果、視聴者に何が起きるか**を
  ゲートに入れていなかったのが企画側の欠陥

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-A。28〜40歳の会社員。NISAでインデックス投信を積立中。
  最近は特定口座でも少し買っている。NISA=税金ゼロで得、としか思っていない。
- **指を止める理由**: 「NISAで損すると、その損はなかったことになる」。
  得なはずの口座で、損が「なかったこと」にされる、という不穏さ。
- **視聴後に得るもの**: NISAと普通の口座を**両方持っている年に、損が出たとき**
  何が起きるかが分かる。損益通算という言葉の意味も分かる。
- **視聴者の予想**: 「NISAは税金がゼロだから、どう転んでも得では?」
- **この動画の結論**: 「損した年は、普通の口座より税金が**約10万円多くなる**ことがある」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 利益と損 | 二者が非対称・打ち消し合う | 固有シーン sousai(): ゼロの線を挟んで上下に棒 |
| NISAの場合 | 片方が消える | 同じ図で損の棒だけを薄くする(**形の欠落**で見せる) |
| 最後の比較 | AとBの量が違う | 共通の底からの棒2本(ゼロ と 10万円) |

## 数値の根拠

verify.py 参照。すべて仮の数字。

- 普通の口座で利益50万円 → 税金は 50万 × 20.315% = **101,575円**(画面は約10万円)
- 同じ年に別の株で50万円損 → 両方が普通の口座なら差し引きゼロ → **税金ゼロ**
- 損のほうがNISAだと、その損は計算に入らない → 利益50万円にそのまま課税 → **約10万円**
- 差は 101,575円

## コンプライアンス(戦略§6)

- 「NISAを使うな」「損切りしろ」とは言わない。**損が出た年の扱い**の説明に留める
- 利益が出た年はNISAのほうが有利であることも画面と概要欄で明示し、
  片側だけを見せない
- 税率は2026年8月時点。制度は変わりうる旨を概要欄に記載
