# 企画書: 住民税は、去年の給料で決まっている(S015)

## この人の欲求

**辞めたあとに払えなくなるのが怖い。備えておきたい。**

## 視聴後に決められること

**辞める前に、来年ぶんの住民税を残しておくと決められる。**

基準作 S011「年金は何歳で元が取れるのか」の8行(プレイブック末尾)を埋めてから作った。

## 基準作S011との照合(8行すべて埋まること)

| 要素 | S016での中身 |
|---|---|
| 入口(F5) | 「給料から引かれる住民税」= 明細を見たことがあれば必ず載っている。専門語ではない |
| 予想との食い違い(F1) | 「住民税は今の給料にかかっている」→ 去年の給料で決まっている |
| オチ(F3) | 実害(辞めた翌年、収入ゼロでも17万円の請求)+ 見方の変更(去年の請求書) |
| 主語(F4) | 自分の給与明細と、自分がこれから受け取る納付書 |
| 丁寧さ(G1〜G4) | 18ユニット・推定52秒。1文につき新しい数字は1つ。図は1箱ずつ足す |
| 図 | 横位置=時間。左に去年の年収、右に今年の住民税。矢印で結ぶ |
| 数字 | 給与所得控除〜均等割まで verify.py で自前計算(控除額は検索で確認) |
| 締め | 「辞めるな」「節税しろ」に振らず、見方の変更に着地(戦略§6) |

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-0。この動画を選んでいない。お金の勉強に興味がない。
  ただし**給与明細の「住民税」の行**は全員が持っている。金額は見たことがあるが、
  それがどの年の所得で決まっているかは知らない。
- **指を止める理由**: 「給料から引かれる住民税は、去年の分なのだ」。
  毎月見ている数字が、実は今の自分の話ではない、という食い違いが1文目で成立する。
- **視聴後に得るもの**: 自分の住民税がどう計算されているかと、
  **収入が変わった翌年に何が起きるか**が、金額と時間軸で分かる。
- **視聴者の予想**: 「住民税は、今の給料にかかっているんでしょ」
- **この動画の結論**: 「**去年の所得で決まっている**。だから会社を辞めて収入がゼロでも、
  翌年に約17万円の請求が来る。給料が下がった年も、税額は去年のまま」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 年収と住民税 | AとBの量が違う | 共通の底からの棒2本(400万円 と 17万円) |
| 去年と今年 | 時間のずれ | 固有シーン okure(): 横位置=時間。左=去年の年収、右=今年の住民税。矢印で結ぶ |
| 辞めた場合 | 片方だけ消える | 同じ okure() で右の年の収入をゼロにしても、税の箱は残る |
| 分割払い | 数えられる回数 | 同じ大きさのブロック4個(1個=1回) |

## 数値の根拠

verify.py 参照。年収400万円・独身・扶養なし・東京都・40歳未満(介護保険なし)の概算。

| 段階 | 計算 | 額 |
|---|---|---|
| 給与所得控除 | 4,000,000 × 20% + 440,000 | 1,240,000円 |
| 給与所得 | 4,000,000 − 1,240,000 | 2,760,000円 |
| 社会保険料控除 | 4,000,000 × 14.69%(概算) | 587,600円 |
| 基礎控除(住民税) | 令和8年度も据え置き | 430,000円 |
| 課税所得 | 2,760,000 − 587,600 − 430,000(千円未満切捨) | 1,742,000円 |
| 所得割 | 1,742,000 × 10% − 調整控除2,500 | 171,700円 |
| 均等割 | 市町村3,000 + 道府県1,000 + 森林環境税1,000 | 5,000円 |
| **合計** | | **176,700円**(画面は約17万円) |
| 毎月の天引き | 176,700 ÷ 12 | 14,725円(画面は約1万4700円) |
| 自分で払う場合 | 176,700 ÷ 4期 | 44,175円/回(画面はおよそ4万4千円) |

年収に対する割合は4.4%。市販のシミュレーターの「年収400万で約17.8万円」とも整合する。

## 出典

- 住民税の基礎控除は令和8年度(2026年度)も43万円で据え置き
  (2025年の改正で引き上げられたのは所得税側。給与所得控除の最低保障額の引き上げも
  年収190万円以下が対象で、年収400万円の計算には影響しない)
- 均等割5,000円(2024年度から森林環境税1,000円を含む)
- 所得割は市町村民税6%+道府県民税4%=10%
- 住民税は前年1月〜12月の所得で計算し、翌年6月から翌々年5月に納める後払い方式
- 確認日 2026-08-16
- 注記: 官公庁サイトはこの環境のネットワークポリシーで遮断されているため、
  控除額・税率の確認は検索索引経由。**税額の計算はすべて verify.py の自前計算**。

## コンプライアンス(戦略§6)

- 節税の指南をしない。「こうすれば安くなる」は言わない
- 「辞めるな」「辞める前に貯めろ」と行動を指示しない。事実と時間のずれだけを示す
- 社会保険料は健保組合・自治体・年齢で変わるため「概算」とバッジで明示
- 扶養・各種控除がある人は税額が変わる旨を概要欄に記載
- 退職の時期(1〜5月/6月以降)で徴収方法が変わることは概要欄に記載
