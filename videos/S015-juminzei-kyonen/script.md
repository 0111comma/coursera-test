# 台本(ショート): 住民税は、去年の給料で決まっている

- **ID**: S015 / **テンプレ**: 仕組み解説型 / **想定尺**: 約52秒
- **投稿タイトル**: 住民税17万円は去年の給料で決まる(17字)
- **調声・構成**: render.pyが正(共通シーンはproduction/scenes_common.py)

## ネタ選定ゲート(プレイブックF1)

- **視聴者の予想**: 「住民税は、今の給料にかかっているんでしょ」
- **この動画の結論**: 「**去年の所得で決まる**。辞めて収入ゼロでも、翌年に約17万円の請求が来る」

## 構成の意図

- 入口は「給料から引かれる住民税」。明細を見たことがあれば必ず載っている行なので、お金の勉強に興味がない人でも他人事にならない(persona.md P-0 / プレイブックF5)
- 主役は「去年の年収」と「今年払う税」が別の年にあること。横位置を時間にして、左に去年・右に今年を置き、矢印で結ぶ。辞めた場合は右の年の収入をゼロにしても税の箱が残る形にして、時間のずれを位置だけで見せる
- 1文につき新しい数字は1つ。400万円 → 17万円 → 1万4700円 → 6月 → 4回 → 4万4千円 と1段ずつ積む
- 節税の指南はしない。締めは「住民税は去年の請求書」という見方の変更に着地させる

## ナレーション全文

給料から引かれる住民税は、去年の分なのだ。
まず、年収400万円の人で見るのだ。
その人がはらう住民税は、年17万円。
つまり毎月の給料からは、約1万4700円。
その額は、去年の年収で決まるのだ。
その住民税とは、住む街に払う税金。
その計算は6月に決まり、6月から引かれる。
つまり、いつも1年おくれなのだ。
では、会社を辞めた年はどうなる?
その年の収入がゼロでも、請求は来る。
その額が、さっきの17万円なのだ。
しかも6月から、4回に分けて届くのだ。
つまり1回あたり、およそ4万4千円。
その17万円を、収入がない年にはらう。
でもこれは、辞めた人だけの話ではない。
たとえば給料が下がっても、同じなのだ。
その年の税金は、去年のままだから。
住民税は、去年の請求書なのだ。

(18ユニット)

## 概要欄テキスト

給与明細の「住民税」が、どの年の所得で決まっているかを金額で確かめました。
・前提は年収400万円・独身・扶養なし・東京都・40歳未満(介護保険料なし)の概算です
・給与所得控除 4,000,000 × 20% + 440,000 = 1,240,000円 → 給与所得 2,760,000円
・社会保険料(概算14.69%)587,600円と、住民税の基礎控除430,000円を引いて課税所得 1,742,000円
・所得割 1,742,000 × 10% − 調整控除2,500 = 171,700円
・均等割 5,000円(2024年度から森林環境税1,000円を含む)
・合計 **176,700円**。毎月の天引きは約14,700円です
・この税額は「前の年の1月〜12月の所得」で計算され、翌年6月から翌々年5月にかけて納めます。つまり1年おくれの後払いです
・そのため、会社を辞めて収入がゼロになった年でも、翌年には前年分の請求が来ます。自分で払う場合は6月から4期に分かれ、1回あたり約44,000円です
・辞めた人だけの話ではありません。給料が下がった年も、その年の税額は去年の所得のままです
・住民税の基礎控除は2026年度(令和8年度)も43万円で据え置きです(引き上げられたのは所得税側)
・扶養や各種控除がある方、健保組合や自治体が異なる方は税額が変わります
・退職した月(1〜5月/6月以降)で徴収方法が変わります
・動画内の数値はすべて verify.py で再計算しています
