# 台本: スマホを置くと、なんで落ち着かないのか(Z003)

チャンネル「ヤケに心理学に詳しいずんだもん」の3本目。企画書は plan.md。
RocknRoll One / **ずんだもん(VOICEVOX speaker=3)** / 語ごとのポップ。縦1080×1920。

## この本の型(docs/channel-zunda/strategy.md §8 #17。問い型)

- 1コマ目 = **場面の問い**(昨日の脱衣所を思い出させる)
- 判定は5秒以内(落ち着かないのはスマホのせいではなく、何もしない時間のせい)
- 締めは**手が動く動作**(今夜、風呂の前にスマホを脱衣所の棚に置く。1回だけ)

## メッセージは1つ

**「スマホは原因じゃない。人はもともと何もしない時間に耐えられない。だから今夜、棚に置く」**の1つ。
学びの3問(誰が言った/なぜ残った/誰がどう評価した)は、**この1つを深くするためだけ**に置いた。
plan.md §1.7 にカット数の上限(8/4/3)を先に書いてある。

## 責める語を1つも置かない

視聴者は**自分を責めている側**なので、「依存」「中毒」「意志が弱い」を1回も使わない
(strategy §14「励まさない」と同じ側の禁止)。
この動画がやるのは、責める対象を**スマホから「何もしない時間」に移す**ことだけ。

## 正直の幕(strategy §5.2)

パスカルの結論は「神のいない人間は悲惨だ」まで行く。**この動画はそこまで行かない**と、
動画の中で言う(#32〜#35)。借りているのは見方の部分だけ。

**Wilson et al. 2014(Science, n=42。ひとりで座るより電気ショックを選んだ実験)は出さない。**
独立した大規模追試を確認できていないため(strategy §8 #17 の指定)。

## 概要欄

スマホを置くと落ち着かないのは、スマホのせいじゃないかもしれないのだ。
人が何もしない時間に耐えられないことは、スマホの350年前の本にもう書いてあるのだ。

## この台本で守ったこと(工程の記録)

- **工程A(鎖)**: 風呂の前に一瞬まよう → 落ち着かないのはスマホのせいだと思っている →
  じつは何もしない時間のせい → それを1670年の本が書いている → 書いたのはパスカル →
  39歳で死んで、本にならず紙片のままだった → その紙片に「気晴らし」の話がある →
  狩りと賭け事の場所に、いまはスマホが入る → 「部屋にじっとしていられない」 →
  スマホは逃げ先で、原因じゃない → その紙片が読めるのは、死後に他人が編んだから →
  噛みついたヴォルテールのおかげで読み継がれた → パスカルの結論はこの先にあるが、
  借りるのは見方だけ → 今夜、棚に置く、の1本
- **経験的な主張をしない**(strategy §5.2): 「置くと集中できる」「眠りが良くなる」は言わない
- **責める語を置かない**(plan §11)。「依存」「意志が弱い」を1回も使わない
- **正直の幕**(#32〜#35)。パスカルの結論まで行かないと自分で言う
- **締めは動作**(今夜、脱衣所の棚に置く。何分がまんするかは決めない)
