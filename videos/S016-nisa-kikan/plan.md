# 企画書: NISAの証券会社は、年に1回しか変えられない(S016)

## この人の欲求

**証券会社を変えたい。でも手続きを間違えて、1年待たされるのは嫌だ。**

欲求マップの **B(選択を間違えたくない)**。
「NISAとは」ではなく、**すでにNISAを始めていて、別の会社に移りたい人**に向ける。

## 視聴後に決められること

**今年のうちに変えるのか、来年にするのかを決められる。**
**今年変えるなら、9月末までに手続きを終わらせると決められる。**

## この動画が答える問い(1つだけ)

**NISAの証券会社は、いつでも変えられるのか。**

答え: **変えられない。年に1回だけで、しかもその年に1度でも買っていると変えられない。**
**受付は前年10月1日から、その年の9月30日まで。**

- **ID**: S016
- **形式**: ショート(〜60秒)
- **コンテンツピラー**: 制度解説
- **ステータス**: 企画中
- **作成日**: 2026-08-18

## 場面(いつ、この人はこれに出会うか)

「手数料の安い会社に移りたい」「アプリが使いにくい」と思ったとき。
そして**積立を止め忘れたまま**、今年ぶんを1回買ってしまっている。

## 既公開との重なり(ユーザー指摘への対応)

S002は「NISAと税金」、S003は「枠1800万」、L001は「NISAの損」。
**この動画は税金も枠も損も扱わない。手続きと期限の話**なので重ならない。

## 鎖(1本だけ)

```
NISAの金融機関の変更
  → 変えられるのは 年1回だけ
  → 受付は 前年10月1日 〜 その年の9月30日
  → ただし その年に1度でも買っていたら、その年は変えられない
      → 積立を止め忘れて1月に1回買った → 次に変えられるのは翌年 = 最大1年待ち
```

種になる数字は **年1回** ひとつ。

## 独自性要素(戦略§8 — 2つ以上)

1. **独自の図**: 1年のカレンダーの上に「変えられる期間」と「買った瞬間に閉じる」を重ねる
2. **複数パターン比較**: 今年まだ買っていない人 / 1月に1回買った人 の2通り
3. **手順**: 変更前の会社に申し出る → 勘定廃止通知書を受け取る → 変更先に出す、の3ステップ

## コンプライアンス(戦略§6)

- **特定の証券会社を勧めない・けなさない。** 「手数料が安い会社」など一般化する
- 「変えろ」とも「変えるな」とも言わない。**期限と条件だけを渡す**
- 変更しても**それまでに買った分は元の会社に残る**(移管されない)ことを明示する
- 手続きには書類のやりとりがあり、**日数がかかる**ので9月末ぎりぎりは避ける旨を注記
- 「2026年8月時点の制度です」を入れる
