# 企画書: 年金を1年待つと、何歳で得になるのか(S027)

- **公開予定**: 2026-09-18(金)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

年金、1年待つと何歳で得になる?

## この人の欲求

**もらい方で損をしたくない。いつから受け取るかを選び間違えたくない。**

欲求マップの **A(取られたくない)** と **B(大きな選択を間違えたくない)**。
B の note のとおり判定を1つの数字に落とす。ここでは **78歳**。

## 場面

**S011(年金、何歳まで生きたら元が取れる?)を見た人の、次の疑問。**
「繰り下げると増える」とは聞いたことがあるが、
増える率(8.4%)ともらい損ね(192万円)を並べて計算したことはない。

## 視聴後に決められること

**自分の健康と家系の見立てで、待つかどうかを決められる。**
78歳という損益分岐が1つ出るので、そこに自分の見立てを当てるだけになる。

## この動画が答える問い(1つだけ)

**1年繰り下げたら、何歳で「待たない場合」に追いつくのか。**

- **視聴者の予想**: 「8.4%も増えるなら、待ったほうが得でしょ」
- **この動画の結論**: 「**追いつくのは78歳。** 待った1年は年金が入らず、
  もらい損ねる **192万円** を、増えた **月1万3440円** で取り返すのに143ヶ月かかる。
  78歳より長生きするなら待つほど得、その前に亡くなると待った分だけ損」

## 鎖(1本だけ)

```
月16万円(仮定)
  ひと月遅らせるごとに +0.7% → 1年で +8.4% → 月 +13,440円(一生つづく)
  待った1年のもらい損ね = 16万 × 12 = 192万円
  192万 ÷ 13,440 = 143ヶ月 ≒ 12年 → 66歳開始なら 78歳で追いつく
  (5年待って70歳開始でも、追いつくのは同じ143ヶ月後 = 約82歳)
```

種になる数字は **0.7%/月** ひとつ。

## 想定視聴者(JTBD: 状況と用事)

- **P-A(親の年金、または自分の年金の受け取り方を考え始めた人)**。
  「繰り下げ」の語は知っているが、損益分岐は計算していない。
- **用事**: 待つかどうかを、自分の寿命の見立てで判断できるようになりたい。

## 指を止める理由

**「何歳で得になる?」**という、S011(何歳まで生きたら元が取れる?)と同じ型の問い。
S011 は公開2時間で通常の1.9倍の再生。答えが **78歳** の1つの数字。

## 視聴後に得るもの

「増える率」だけ見ていたのが、**もらい損ねる192万円**とセットで見られるようになる。
増えた分は一生つづくが、追いつくまで12年かかる、という時間の感覚が入る。

## コンプライアンス(戦略§6)

- 「待つべき」「待つな」とは言わない。判定の分岐(78歳)だけを渡し、選択は視聴者に残す
- 月16万円は**仮定**とバッジで明示。年金額は人により違う
- 税・社会保険料は計算に入れていないことを概要欄に書く(増えると税も増え得る)
- 「2026年8月時点」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 13,440円・192万円・143ヶ月・78歳を verify.py で再計算
2. **独自の言い切り**: 何年待っても「追いつくまで143ヶ月」は同じ、という一般化
3. **S011との連続性**: 「元が取れる年齢」の次に「待つと得になる年齢」を置く回遊設計

## 出典

- 損益分岐が受給開始から約12年後になるのは 0.7%/月 からの計算(自前)
