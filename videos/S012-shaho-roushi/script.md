## ネタ選定ゲート(プレイブックF1)

- **視聴者の予想**: 「引かれてるのは、明細に書いてある額だけでしょ」
- **この動画の結論**: 「同じ額をもう一人分、会社が払っている。年収400万円の人に、会社は**460万円**出している」

## 構成の意図

- 入口は「給料」。全員が明細を持っているので、投資に興味がない人でも他人事にならない
- 主役は「見えている負担」と「見えていない負担」の対称。同じ幅の帯を上下に置き、
  下(会社の負担)を後から出すことで「もう半分あった」を形で見せる
- 1文につき新しい数字は1つ。59万 → 9.15% → 36万6千 → 60万 → 119万 → 460万 と1段ずつ積む
- 「保険料が高い」という評価はしない。事実の提示と、見方の変更に留める

## ナレーション全文

給料から引かれる保険料は、半分だけなのだ。
まず、年収400万円の人で見るのだ。
その人が引かれる保険料は、年59万円。
その中身は、年金と健康保険なのだ。
その中でいちばん大きいのが、厚生年金。
その料率は、給料の9.15%なのだ。
つまり年に、36万6千円が引かれる。
その保険料、誰が払っているのだと思う?
その厚生年金、会社も9.15%出している。
健康保険も、会社が同じだけ出すのだ。
だから会社の負担も、年60万円ある。
合わせると、年119万円が払われている。
つまり年収400万円の人に、460万円。
明細の保険料は、半分しか見えていないのだ。

(14ユニット)

## 概要欄テキスト

給与明細から引かれている社会保険料が、実は半分だけだという話です。
・厚生年金・健康保険・子ども子育て支援金は、会社と本人が半分ずつ負担します(労使折半)
・例: 年収400万円・東京都・介護保険なしの概算
・本人の負担は 厚生年金9.15% + 健康保険4.925% + 支援金0.115% + 雇用保険0.5% = 14.69% → 約59万円
・会社の負担は 同じ3つ + 雇用保険0.85% = 15.04% → 約60万円
・合わせると年約119万円が、あなたのために払われている計算になります
・会社から見た費用は 400万円 + 60万円 = 約460万円。年収400万円の人に、会社は460万円出しています
・実際の保険料は標準報酬月額の等級表で決まるため、これは年収に料率を掛けた概算です
・健康保険料率は都道府県で異なり、40歳以上は介護保険料が加わります
・動画内の数値はすべて verify.py で再計算しています
あなたの給与明細、社会保険料はいくらでしたか?
