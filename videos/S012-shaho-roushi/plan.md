# 企画書: 会社が出した460万円のうち、手元に残るのは69%(S012)

基準作 S011(年金)の8行を埋めてから制作した(プレイブック ループ57)。
**ループ66で作り直した。** 旧版の結論は「社会保険料は会社も同じ額を払っている」で、
ユーザー判定は「面白くない」。事実として正しいが**豆知識**であり、
見た人の判断も行動も変わらない(実害がない)。
同じ計算から実害のある問いが1つ取れたので、そちらに寄せた。

## この動画が答える問い(1つだけ)

**会社があなたに出している額のうち、手元に残るのはいくらか。** → 69%(差は145万円)

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-0。この動画を選んでいない。投資にもお金の勉強にも興味がない。
  ただし**給与明細は全員が持っている**ので、他人事にならない。
- **指を止める理由**: 「会社はあなたに460万円。でも手取りは315万円」。
  自分の年収でも手取りでもない数字が2つ並ぶ違和感。
- **視聴後に得るもの**: 会社が自分に払っている総額(460万円)と、
  実際に手元に残る額(315万円)の差が**145万円**だと分かる。
- **視聴者の予想**: 「会社が出しているのは年収の400万円でしょ」
- **この動画の結論**: 「会社が出した460万円のうち、手元に残るのは315万円。
  **69%**しか残らない」

## 鎖(プレイブック L1: 1本 = 1つの鎖)

```
400万円 − 59万円 − 26万円 = 315万円(手取り)
400万円 + 60万円          = 460万円(会社の支出)
460万円 − 315万円         = 145万円 → 315 ÷ 460 = 69%
```

種になる数字は年収400万円ひとつ。あとは全部そこから導かれる。
`check_ikko.py` 判定は**鎖1本**。

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 年収と社会保険料 | AとBの量が違う | 共通の底からの棒2本(400万 と 59万) |
| あなたと会社の負担 | 二者がほぼ同じ量 | 棒2本(59万 と 60万) |
| 会社から見た費用 | 前→後で変わった | 棒2本 + 差の帯(400万 → 460万) |
| 460万のうち残るぶん | **全体と部分** | 固有シーン nokoru(): 帯1本を塗り分ける |

最後を棒2本にしなかった理由: 460万円と315万円を並べると「別々の2つの額」に見える。
見せたいのは**同じ1つの額の内訳**なので、帯を1本にして中を塗り分け、
**塗られていない部分の長さ**がそのまま145万円になるようにした。

## 数値の根拠

verify.py 参照。年収400万円・東京都・40歳未満(介護保険なし)・独身・扶養なしの概算。
実際は標準報酬月額の等級表で決まるため、年収に料率を掛けた概算とする(バッジで明示)。

- 本人負担率 = 厚生年金9.15% + 健康保険4.925% + 子育て支援金0.115% + 雇用保険0.5%
  = 14.69% → **587,600円**(画面は約59万円)
- 会社負担率 = 同じ3つ + 雇用保険0.85% = 15.04% → **601,600円**(画面は約60万円)
- 給与所得 = 400万 −(400万×20% + 44万)= **2,760,000円**
- 所得税 =(給与所得 − 社会保険料 − 基礎控除58万)× 5% × 1.021 = **81,271円**
- 住民税 =(給与所得 − 社会保険料 − 基礎控除43万)× 10% − 調整控除2,500 + 均等割5,000
  = **176,700円**(S015 と同じ計算・同じ額)
- 手取り = 400万 − 58.76万 − 8.13万 − 17.67万 = **3,154,429円**(画面は315万円)
- 会社の支出 = 400万 + 60.16万 = **4,601,600円**(画面は460万円)
- **差 = 1,447,171円**(画面は145万円)/ **手取り ÷ 会社の支出 = 69%**

## コンプライアンス(戦略§6)

- 「会社が損している」「保険料や税金が高すぎる」といった評価はしない。事実の提示に留める
