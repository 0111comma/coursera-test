# 企画書: 給料から引かれる保険料は、半分だけ(S012)

基準作 S011(年金)の8行を埋めてから制作した(プレイブック ループ57)。

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-0。この動画を選んでいない。投資にもお金の勉強にも興味がない。
  ただし**給与明細は全員が持っている**ので、他人事にならない。
- **指を止める理由**: 「給料から引かれる保険料は、半分だけ」。
  毎月見ている数字が「半分」だと言われる違和感。
- **視聴後に得るもの**: 自分の social 保険料が、明細の額の倍あることが分かる。
  そして**会社から見た自分の値段**(460万円)が分かる。
- **視聴者の予想**: 「引かれてるのは、明細に書いてある額だけでしょ」
- **この動画の結論**: 「同じ額をもう一人分、会社が払っている。
  年収400万円の人に、会社は**460万円**出している」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 年収と保険料 | AとBの量が違う | 共通の底からの棒2本(400万 と 59万) |
| 見える負担/見えない負担 | 二者が対称・片方が隠れている | 固有シーン meisai(): 同じ幅の帯を上下に。下(会社)を後から出す |
| 会社から見た費用 | 前→後で変わった | 棒2本 + 差の帯(400万 → 460万) |

## 数値の根拠

verify.py 参照。年収400万円・東京都・介護保険なしの概算。
実際は標準報酬月額の等級表で決まるため、年収に料率を掛けた概算とする(バッジで明示)。

- 本人負担率 = 厚生年金9.15% + 健康保険4.925% + 子育て支援金0.115% + 雇用保険0.5%
  = 14.69% → **587,600円**(画面は約59万円)
- 会社負担率 = 同じ3つ + 雇用保険0.85% = 15.04% → **601,600円**(画面は約60万円)
- 厚生年金の本人分 = 400万 × 9.15% = **366,000円**
- 合計 = **1,189,200円**(画面は約119万円)
- 会社から見た費用 = 400万 + 60万 = **4,601,600円**(画面は約460万円)

## 出典

- 日本年金機構「厚生年金保険料額表」(保険料率18.3%・労使折半)
- 全国健康保険協会「令和8年度 保険料額表」(東京都 9.85%・労使折半)
- 厚生労働省「令和8年度の雇用保険料率」(一般の事業 本人0.5%・事業主0.85%)
- こども家庭庁「子ども・子育て支援金」(0.23%・労使折半)

## コンプライアンス(戦略§6)

- 「会社が損している」「保険料が高すぎる」といった評価はしない。事実の提示に留める
- 料率は毎年改定され、健康保険料率は都道府県で異なる旨をバッジと概要欄に明示
- 40歳以上は介護保険料が加わるため、この計算とは条件が違う旨を概要欄に記載
