# 企画書: 宝くじの1億円は税金ゼロ。株の1億円は2割とられる(S017)

基準作 S011「年金は何歳で元が取れるのか」の8行(プレイブック末尾)を埋めてから作った。

## 基準作S011との照合(8行すべて埋まること)

| 要素 | S017での中身 |
|---|---|
| 入口(F5) | 「宝くじ」= 買ったことがなくても知っている。**NISAでは始めない** |
| 予想との食い違い(F1) | 「1億円当たったら半分は税金でしょ」→ ゼロ。逆に株のもうけは2割 |
| オチ(F3) | 実害(1億円で約2031万円、10万円でも2万315円)+ 行動(NISAという箱) |
| 主語(F4) | 自分がこれから作れる口座。10万円のもうけという、実際に動かす額でも見せる |
| 丁寧さ(G1〜G4) | 18ユニット・推定54秒。1文につき新しい数字は1つ。灰色は1段ずつ出す |
| 図 | 同じ1億円を2本並べ、右の上だけを灰色にする。NISAの段でその灰色が消える |
| 数字 | 税率と非課税の根拠のみ検索で確認 → 金額は verify.py で自前計算 |
| 締め | 「NISAをやれ」ではなく「同じもうけでも置く場所でちがう」に着地(戦略§6) |

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-0。この動画を選んでいない。投資に興味がない。
  ただし**宝くじ**は誰でも知っている。「1億円当たったら」の話には全員が乗れる。
  NISAを入口にすると興味のない人の指が動くので、**答えとして中で出す**(F5)。
- **指を止める理由**: 「宝くじで1億円当たっても、税金はゼロなのだ」。
  「大金には税金がかかる」という常識と正面から食い違う。
- **視聴後に得るもの**: もうけにかかる税金は**置く場所で変わる**という見方。
  そしてNISAが「税金がかからない箱」であること、その上限が1800万円/年360万円であること。
- **視聴者の予想**: 「1億円当たったら、半分くらいは税金で持っていかれるでしょ」
- **この動画の結論**: 「宝くじは**ゼロ**。法律でそう決まっている。
  でも株のもうけ1億円には**20.315%**がかかり、およそ**2000万円**引かれる。
  その税金がかからない箱が**NISA**」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 宝くじと株 | 同じ量なのに片方だけ削られる | 固有シーン hako(): 同じ縮尺の棒2本。右の上だけ灰色にする |
| NISA | 削られたものが戻る | 同じ hako() で灰色を消す。面積が元に戻るのが答え |
| NISAの枠 | AとBの量が違う | 共通の底からの棒2本(1800万円 と 360万円) |

## 数値の根拠

verify.py 参照。

| 項目 | 計算 | 額 |
|---|---|---|
| 宝くじ 1億円の税金 | 当せん金付証票法 第13条により所得税なし。所得ではないので住民税もなし | **0円** |
| 株 1億円のもうけの税金 | 100,000,000 × 20.315% | 20,315,000円(画面はおよそ2000万円) |
| 手元に残る額 | 100,000,000 − 20,315,000 | 79,685,000円(画面はおよそ8000万円) |
| 10万円のもうけの税金 | 100,000 × 20.315% | **20,315円**(画面は2万315円) |
| NISAの生涯上限 | 簿価残高 | 18,000,000円 |
| NISAの年間上限 | つみたて枠120万+成長投資枠240万 | 3,600,000円 |

画面と台本では1億円の例だけ「およそ2000万円/およそ8000万円」と丸めて言う。
1000万円の位で丸めても内訳の合計が1億円のままであることを verify.py で確認している。
身近な額(10万円のもうけ→2万315円)は端数まで出す。

## 出典

- 当せん金付証票法 第13条「当せん金付証票の当せん金品については、所得税を課さない」
  (国内で正規に販売された宝くじ。海外の宝くじは一時所得として課税対象)
- 株式・投資信託の譲渡益と配当の税率: 所得税15.315%(復興特別所得税を含む)+住民税5%
- NISAの上限: 生涯1,800万円(簿価残高)、年間360万円
- 確認日 2026-08-16
- 注記: 官公庁サイトはこの環境のネットワークポリシーで遮断されているため、
  条文・税率の確認は検索索引経由。**金額の計算はすべて verify.py の自前計算**。

## コンプライアンス(戦略§6)

- **投資助言をしない**。「NISAを始めよう」「株を買おう」とは言わない。
  税金のかかり方が置く場所で違う、という事実だけを示す
- 特定の証券会社・商品・銘柄を出さない(「証券会社などで作る口座の種類」まで)
- 宝くじを買うことをすすめない。当せん金が非課税である事実の説明にとどめる
- NISAには元本保証がなく、損失は損益通算できないなど不利な点もあることを概要欄に記載
- 高額当せん金を家族に分けると贈与税がかかる場合があることを概要欄に記載
- 税率・上限は改定される。「2026年8月時点」を概要欄に明示
