# 企画書: 変動はどこまで上がったら、固定に負けるのか(S013)

基準作 S011「年金は何歳で元が取れるのか」の8行(プレイブック末尾)を埋めてから作った。

## 基準作S011との照合(8行すべて埋まること)

| 要素 | S013での中身 |
|---|---|
| 入口(F5) | 「家」= 買う予定がなくても値段を知っている物。専門語ではない |
| 予想との食い違い(F1) | 「どっちでも似たようなものでしょ」→ 1377万円ちがう。しかも過去と今で答えが変わる |
| オチ(F3) | 実害(1%上がると毎月1万4728円)+ 見方の変更(変動は今の安さ、固定は先の安心を買っている) |
| 主語(F4) | 自分がこれから借りる額。毎月8万5036円は自分の口座から出ていく |
| 丁寧さ(G1〜G4) | 21ユニット・推定54秒。1文につき新しい数字は1つ。棒は1本ずつ足す |
| 図 | 借りた3000万円の上に利息を積む。2つの金利を**同じ縮尺**で並べる |
| 数字 | 元利均等の式で自前計算 → verify.py で再計算(金利のみ検索で確認) |
| 締め | 「借りるな」「変動にしろ」に振らず、見方の変更に着地(戦略§6) |

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-0。この動画を選んでいない。投資にもお金の勉強にも興味がない。
  ただし**家の値段は誰でも知っている**ので、3000万円という数字で他人事にならない。
  中身を書くときの想定読者はP-A/P-Bだが、題材とフックを決めるのはP-0(F5)。
- **指を止める理由**: 「3000万円の家。金利で1377万円ちがう」。
  同じ家なのに1000万円単位で変わる、という矛盾が1文目で成立している。
- **視聴後に得るもの**: **どっちが得だったのかの答え**と、その理由。
  そして自分が判断するための2つの数字(1%上がると毎月いくら / どこで並ぶか)。
- **この動画が答える問い(1つだけ)**: 「変動はどこまで上がったら、固定のほうが得になるのか」
- **視聴者の予想**: 「変動と固定、どっちでも似たようなものでしょ」
- **この動画の結論**: 「同じ3000万円の家で**1377万円**ちがう。
  **過去は変動が正解だった**(金利がずっと下がってきたから。1991年は8.5%)。
  だからいまも**75%が変動**を選んでいる。**でも2024年から上がりはじめた**。
  1%上がるだけで毎月**1万4728円**ふえ、5年後に**3.83%**まで上がってそのままなら、
  固定と総額が並ぶ」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 変動と固定のちがい | 動くか、動かないか | 同じ軸に2本の折れ線。変動=上下に振れる線、固定=一直線。**縦軸に目盛りを置かない**(将来の金利を予想する図ではないため) |
| 何回はらうか | 積み上がっている | 同じ大きさのブロック35個(1個=1年=12回) |
| 借りた額と利息 | 一方が他方に乗る | 固有シーン kaeshi(): 下に3000万円、上に利息を積む積み上げ棒 |
| 金利のちがい | 二者の量が違う | 同じ kaeshi() に2本目を足す。**同じ縮尺**なので高さの差=金額の差 |
| 毎月の返済 | AとBの量が違う | 共通の底からの棒2本(8万5036円 と 11万7812円) |

## 数値の根拠

verify.py 参照。元利均等返済の式 `m = P·i / (1 − (1+i)^−n)` で自前計算。
借入3000万円・35年(420回)・ボーナス払いなし。

| 金利 | 毎月 | 総返済 | うち利息 |
|---|---|---|---|
| 年1.025%(変動) | 85,036円 | 35,714,990円(3571万円) | 5,714,990円(571万円) |
| 年3.140%(全期間固定) | 117,812円 | 49,480,933円(4948万円) | 19,480,933円(1948万円) |
| 差 | 32,776円 | 13,765,943円(**1377万円**) | 同左 |

「どっちが得か」に答えるための数字(すべて verify.py で計算):

| 問い | 計算 | 答え |
|---|---|---|
| 変動が1%上がると毎月いくら増える? | 1.025% → 2.025% の毎月返済の差 | 85,036 → 99,764円(**+14,728円**) |
| 変動はどこで固定に並ぶ? | 5年間1.025%、その後 X% が35年目まで続く場合の総額 = 固定の総額 | **X = 3.83%** |

分岐点が固定金利(3.14%)より高いのは、変動が最初の5年ぶんを安い金利で返しているため。
「固定と同じ率まで上がっただけでは、固定に追いつかない」ことを意味する。
なお金利0.01%は総額およそ54,000円に相当するので、小数2桁の表示では
固定との差が約26,000円残る(verify.py で許容幅として明示)。

## コンプライアンス(戦略§6)

- 変動と固定のどちらが得かは**言わない**。金利が違うと総額が変わる事実だけを示す
- 金利の動き方を見せる折れ線は**模式図**。縦軸に目盛りを置かず、値も画面に出さない。
  変動の線は固定の線を何度も横切らせ、**変動が固定より高くなることも低くなることもある**
  形にする(どちらかの側に寄せると「変動のほうが得」という主張になってしまうため)
- 特定の金融機関・商品名を出さない(「大手行の変動金利」「フラット35の最頻金利」まで)
- 金利は毎月変わる。「2026年8月時点」「2026年7月時点」を画面と概要欄に明示
- 変動金利は将来上がる可能性がある。この計算は**その金利がずっと続いた場合**の単純計算
  である旨をバッジと概要欄に明示する(「変動なら得」と読ませない)
- 「借りるな」「今が買い時」とは言わない。締めは「家の値段は金利でも決まる」に着地

## 修正履歴

### ループ60: 「変わらない金利もある」が何の話か分からない(ユーザー指摘)

初心者向けにと考えて「変動金利」「固定金利」という語を**わざと使わなかった**結果、
1.025%が「あとで変わる金利」だと一度も言わないまま
「でも、変わらない金利もあるのだ」に入っていた。**何との対比なのかが成立していない。**

対処(用語を削るのではなく、名指しして、その場で意味を言う):

1. 金利を定義した直後に「2種類ある」と宣言する専用ユニットを置いた
2. **変動金利・固定金利を名前で呼び、動き方のちがいを折れ線で見せる**ユニットを2つ足した
3. 1.025%は「その変動金利は」、3.14%は「その固定金利は」と、毎回どちらの話か明示した
4. 積み上げ棒の足元ラベルも「年1.025%」→「変動 1.025%」に変えた

再発防止として持ち帰る一般則(プレイブック W7 に追加):
**専門語は「使わない」ではなく「使う前に言い換える」。**
語を消すと、その語が指していた区別まで消える。区別が消えると、
あとで出てくる対比(「変わらない金利もある」)が宙に浮く。

### ループ62: 「で、どっちが得なの?」に答えていなかった(ユーザー指摘)

指摘:「プロットの流れは改善してきていると思う。ただ、結局人が気にしたいのって、
どっちが得して、どっちが損でっていう話じゃん。過去、変動金利で損した人はこれぐらい、
逆に変動の方が過去を見ると得しますよ、そういう話まで落とし込みたい。」

そのとおりで、旧版は「差は1377万円」で止まり、締めが「家の値段は金利で決まる」という
**当たり障りのない一般論**だった。判断の材料をひとつも渡していない。

作り直した構成(**事実 → いま → 分岐点**の3段。どれも助言ではない):

1. **過去の事実**: 金利はずっと下がってきた(1991年の変動は8.5%、いまは1.025%)。
   だから変動で借りた人は、その都度安くなった。いまも**75%が変動**を選んでいる
2. **いま起きていること**: 2024年の日銀マイナス金利解除から、変動は上がりはじめた
3. **分岐点**: 変動が1%上がると毎月**1万4728円**ふえる。
   5年後に**3.83%**まで上がってそのまま続けば、全期間固定と総額が並ぶ

締めは「変動は今の安さ、固定は先の安心」。どちらを勧めるでもなく、
**何を買っているのかの言い換え**に着地させた(戦略§6)。

なお「変動のほうが得」「固定のほうが安全」とは一度も言っていない。
過去はこうだった/いまこう動いている/この線を越えたら逆転する、という事実だけを並べ、
判断は視聴者に残している。

### ループ64: 足しすぎて鎖が4本になっていた(プロット改善プログラム フェーズ3)

ユーザー指摘:「金利の話のやつ、もっと意味わかんなくなってる、プロットが」

機械で測ると原因が出た(`production/check_ikko.py`):

```
[NG] 鎖4本 / 宙に浮いた数字5個
       鎖1: 1377万円 → 3571万円 → 4948万円
       鎖2: 2 → 1 → 5年
       鎖3: 8万5036円 → 9万9764円 → 1万4728円
       鎖4: 3.14% → 3.83%
       単発: 3000万円、1.025%、35年、75%、8.5%
```

**3つの鎖と3つの単発。** 視聴者は鎖1を組み立て終わった所で鎖のない事実を3つ投げられ、
また別の鎖を2本組まされる。5回リセットされていた。

原因は、ループ60とループ62の指摘に応えるとき**足すだけで引かなかった**こと。
どちらの指摘も正しく、足した内容も正しい。間違っていたのは、尺が変わらないのに
話だけ増やしたこと。

**1つの問いに絞り直した**: 「変動はどこまで上がったら、固定に負けるのか」。
答えは 3.83%。冒頭から結末まで1本の鎖になる。

削ったもの(どれも事実だが、この問いの答えに寄与しない):

| 削った内容 | どうするか |
|---|---|
| 75%が変動を選んでいる | 別の動画のネタ(「みんなが選んでいるほうが正解とは限らない」) |
| 1991年の変動は8.5%だった | 同上(「金利は昔いくらだったのか」) |
| 2024年から上がりはじめた | 同上 |
| 毎月8万5036円 → 9万9764円 の内訳 | 差の1万4728円だけ言う。内訳は概要欄に |

結果: 鎖4本 → **2本**(1377万円→3571万円→4948万円 / 3.14%→3.83%)。
残った2本は「総額の差」と「それが並ぶ金利」で、**同じ問いの表と裏**である。
