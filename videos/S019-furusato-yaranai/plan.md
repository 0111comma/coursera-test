# 企画書: ふるさと納税、やらないと年いくら損しているのか(S017)

- **公開予定**: 2026-08-25(月)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

ふるさと納税、やらないと年いくら損?

## この人の欲求

**面倒でやっていない。でも、やらないことの値段は知っておきたい。損はしたくない。**

欲求マップの **A(取られたくない)** と **C(無駄にしたくない)** の重なり。

## 場面

**「ふるさと納税、やったほうがいいらしい」とは聞いている。でも一度もやっていない。**
手続きが面倒そうで、しかも「どうせ大した額じゃない」と思っている。
やっていない人がいちばん母数が大きい。

## 視聴後に決められること

**今年ぶんをやるかどうかを決められる。**
やらない場合に消える額が年1万6千円という1つの数字で出るので、
手間と釣り合うかをその場で比べられる。

## この動画が答える問い(1つだけ)

**やっていない人は、1年でいくらぶんを取り逃がしているのか。**

- **視聴者の予想**: 「税金がちょっと安くなるだけでしょ」
- **この動画の結論**: 「**税金は1円も安くなっていない。** 減るのではなく、
  **払う先が変わるだけ**。変わったお礼に返礼品が届くので、
  年収500万円・独身の目安で **年1万6千円ぶん**。10年やらなければ **16万円**」

## 鎖(1本だけ)

```
年収500万円・独身の目安 = 6万円まで出せる
  6万円を出す → 5万8千円が税から引かれる → 持ち出しは2千円
  返礼品は寄付額の3割まで → 6万円 × 3割 = 1万8千円ぶん
  差し引き = 1万8千円 − 2千円 = 1万6千円
  10年 = 16万円 / 月あたり 1333円
  ただし払う税金の総額は変わらない。変わるのは払う先だけ
```

種になる数字は **6万円** ひとつ。

## 想定視聴者(JTBD: 状況と用事)

- **P-B(制度は聞いたことがあるが、一度もやっていない人)**。
  手続きが面倒そうで後回しにしている。上限の計算も自分ではしていない。
- **用事**: やる価値があるのかを、手間と釣り合う金額で判断したい。

## 指を止める理由

**「やらないと年いくら損?」**という、やっていない自分に直接向いた問い。
答えが **1万6千円** という1つの数字なので、手間と比べられる。

## 視聴後に得るもの

**税金そのものは減っていない**と分かる。
減税だと思っていたものが「払う先を変えるとお礼がつく」仕組みだと分かるので、
損得の見当がその場でつく。

## S005 との違い

S005(公開済み・視聴率79.2%)は「**なぜ実質2000円なのか**」という**仕組み**の話。
この動画は「**やらない人が1年でいくら取り逃がしているか**」という**金額**の話。
S005 はすでにやる気のある人に上限を教える動画で、
こちらは**一度もやっていない人**に、やらない側の値段を出す動画。

## コンプライアンス(戦略§6)

- 「必ず得をする」とは言わない。**上限は年収・家族構成・他の控除で変わる**と本編で言う
- 特定の自治体・返礼品・仲介サイトを出さない
- 6万円はあくまで**目安**とバッジとナレーションの両方で言う
- 「2026年8月時点の制度です」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 5万8千円・2千円・1万8千円・1万6千円・16万円・1333円を verify.py で再計算
2. **独自の言い切り**: 「税金は減っていない。払う先が変わるだけ」という整理
3. **独自の早見表**: 1年・10年・月あたりに割った、やらない側の値段

## 出典

- ふるさと納税は、上限までの寄付なら自己負担2000円を除いて所得税・住民税から控除される
- 年収500万円・独身(給与所得者)の控除上限の目安は約6万円
  — 複数の仲介・解説サイトで一致(確認日 2026-08-18)
- 返礼品は寄付額の3割まで(総務省の3割基準。2026年8月時点で維持)
- 注記: 官公庁サイトはこの環境のネットワークポリシーで遮断されているため、
  内容の確認は検索索引と仲介大手の公表資料経由。**金額はすべて verify.py の自前計算**
- 確度: 控除の仕組みと3割基準は **A**。年収500万円独身の上限6万円は **B**
  (複数の民間シミュレーターで一致。個人の控除で上下する目安)
