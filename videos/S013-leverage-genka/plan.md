# 企画書: 2倍の商品は、元に戻っても減っている(S013)

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-A。28〜40歳の会社員。NISAでインデックス投信を積立中。
  SNSで「レバナス」「2倍」といった言葉を見かけるが、何が2倍なのかは知らない。
  「指数が戻れば自分も戻る」と素朴に思っている。
- **指を止める理由**: 「元の値段に戻ったのに、減っている商品がある」。
  戻ったのに減る、という矛盾が名詞を知らなくても立つ。
- **視聴後に得るもの**: 「日々の値動きの2倍」が何を意味するかが分かる。
  上下をくり返す相場では、指数が戻っても自分は戻らないと分かる。
- **視聴者の予想**: 「2倍の商品なら、指数が戻れば自分も戻るのでは?」
- **この動画の結論**: 「約束しているのは**1日ぶん**の2倍。毎日リセットされるので、
  上下をくり返すと元の水準に戻らない」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 1日目の値動き | AとBの量が違う | 共通の底からの棒2本(10% と 20%) |
| 毎日リセット | 積み上がっている/前→後 | その日の始まりの残高を棒で(100 → 80) |
| 2日後の水準 | 時間で変わる・2つが離れる | 同じ軸に2本の折れ線 + 右端に直接ラベル |
| 最後の差 | 前→後で変わった | 棒2本 + 差の帯(100 と 97.8、差2.2) |

## 数値の根拠

verify.py 参照。100から始めた場合(すべて仮の数字)。

- 1日目: 指数 −10% → 100が90。2倍型 −20% → 100が80
- 2日目: 指数が100に戻る上げ幅は **+11.1%**(100 ÷ 90 − 1)
- 2倍型は 80 × (1 + 11.1% × 2) = **97.8**。指数は100なのに2.2少ない
- 先に上がって後で下がった場合は **98.2**。順番を変えても元には戻らない

  (原指標の上昇と下落がくり返される相場では、複利効果によりパフォーマンスが逓減する)

## コンプライアンス(戦略§6)

- 特定の商品名・銘柄コード・運用会社を挙げない。「2倍の値動きを目指す商品」と一般化する
- 「買うな」「売れ」とは言わない。**仕組み上こうなる**という事実の提示に留める
- 上げ相場が続けば逆に増えることもあるため、「必ず減る」とは言わない
  (動画では「上下をくり返すほど目減りする」と条件を明示)
