# 台本(ショート): 2倍の商品は、元に戻っても減っている

- **ID**: S013 / **テンプレ**: 仕組み解説型 / **想定尺**: 約55秒
- **投稿タイトル**: 元に戻ったのに減る「2倍の商品」の話(18字)
- **調声・構成**: render.pyが正(共通シーンはproduction/scenes_common.py)

## ネタ選定ゲート(プレイブックF1)

- **視聴者の予想**: 「2倍の商品なら、指数が戻れば自分も戻るのでは?」
- **この動画の結論**: 「約束しているのは**1日ぶん**の2倍。毎日リセットされるので、上下をくり返すと元の水準に戻らない」

## 構成の意図

- フックは「元の値段に戻ったのに、減っている商品がある」。名詞を知らなくても矛盾が立つ
- 主役は「指数は戻ったのに、2倍型は戻らない」という2本の線の離れ方 → 同じ軸に2本の折れ線
- 各日の値動きは棒2本(10%と20%)。長さで倍率が見える
- 「毎日リセットされる」を固有シーンで、その日の始まりの残高(100 → 80)として位置で見せる
- 特定の商品名は挙げない。「必ず減る」とも言わず、上下をくり返す場合という条件を明示する

## ナレーション全文

元の値段に戻ったのに、減っている商品。
まず指数とは、株全体の平均のこと。
その平均の2倍だけ動く商品があるのだ。
その商品を、100だけ買ったとする。
ただし約束は、その日1日ぶんだけ。
たとえば平均が10%下がったとする。
その商品は2倍なので、20%下がるのだ。
つまり手元は、80まで減るのだ。
では次の日、平均が元に戻るとする。
そのとき必要な上げ幅は、11.1%。
でも80から増やすので、追いつかない。
その結果は97.8。平均は100なのに。
その差2.2は、80から増やしたからだ。
逆に上げ続ける時は、大きく増える。
上下をくり返すほど、この目減りは積もる。

(15ユニット)

## 概要欄テキスト

「レバレッジ型」と呼ばれる、日々の値動きの2倍を目指す商品の仕組みを図で解説しました。
・約束しているのは「その日1日」の値動きの2倍。毎日リセットされます
・例: 1日目に指数が10%下がると、2倍型は20%下がる(100 → 90 / 100 → 80)
・2日目に指数が元の100に戻る上げ幅は +11.1%(100 ÷ 90 − 1)
・2倍型は 80 ×(1 + 11.1% × 2)= 97.8。指数は100に戻っているのに、2.2 少ない計算になります
・先に上がって後で下がった場合も 98.2 で、順番を変えても元には戻りません
・上げ相場が続く局面では逆に大きく増えることもあります。「上下をくり返すほど目減りする」という性質の話です
・動画内の数値はすべて verify.py で再計算しています(すべて仮の数字です)
