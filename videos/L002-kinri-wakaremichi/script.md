# 台本(長尺・横型): 変動金利は、いつ・何%まで上がったら固定金利に負けるのか

- **ID**: L002 / **テンプレ**: 仕組み解説型 / **想定尺**: 約8.5分
- **投稿タイトル**: 変動金利は何%で固定金利に負けるのか(18字)
- **調声・構成**: render.pyが正(共通シーンはproduction/scenes_common.py)

## ネタ選定ゲート(プレイブックF1)

- **視聴者の予想**: 「変動が上がったら怖い、としか言われないから判断できない」
- **この動画の結論**: 「1つの数字では答えられない。5年後なら3.83%、10年後なら4.96%、15年後なら6.94%。**変動金利が負けるには、早く上がる必要がある**」

## 構成の意図

- この人の欲求: 家を買いたい。でも、金利で損はしたくない
- 分かれ目の数字を出すこと自体は目的ではない。**自分の場合を判定できること**が目的
- 締めの3ステップが着地: ①返し終える年数を決める ②その行の金利を見る ③そこまで上がると思うか考える
- 章 = ショート1本。章の出口に必ず損得の判定を置く
- 「変動を選べ」「固定を選べ」とは言わない。出すのは分かれ目の数字と前提だけ

## 概要欄テキスト

住宅ローンの変動金利は、いつ・何%まで上がったら固定金利に負けるのか。分かれ目を自分で計算しました。

■ 答え(3000万円・35年で借りた場合)
借りた直後に上がる → 3.14%
5年後に上がる → 3.83%
10年後に上がる → 4.96%
15年後に上がる → 6.94%
20年後に上がる → 11.04%
25年後に上がる → 21.90%

■ 結論
変動金利が固定金利に負けるには、早く上がる必要があります。上がるのが遅いほど、そのときに残っている借金が小さいので、同じ1%でも効き方が違います。

■ 自分の場合の読み方(3ステップ)
1. 何年で返し終える見込みかを決める
2. その年数の行の金利を見る
3. そこまで上がると思うかを考える

■ 内容
・変動金利 年1.025% / 全期間固定 年3.140%(2026年8月時点の水準)
・上がらなかった場合、総返済額は 3571万円 と 4948万円 で、差は1377万円。利息だけで比べると3.4倍
・元利均等返済は最初ほど利息が多く、1回目は利息25,625円+元金59,411円。最終回は利息73円
・変動が1%上がると毎月+14,728円(年+176,736円)
・5年ルール・125%ルールは毎月の額の変わり方を抑えるだけで、総返済額は変わりません(減らなかった分は未払利息として残ります)
・遅く上がるほど耐える理由は残高。5年後2634万円 → 15年後1845万円(借りた額の61%)
・5年目に300万円を繰り上げ返済(返済額軽減)すると、分かれ目は3.83%→4.26%に上がります
・すでに変動金利で借りている人は、上がる時期を「残り年数」に置き換えて読めます。ただし借り換え費用は別途かかります

■ 前提
・2026年8月時点の金利水準です。団信・手数料・保証料は含んでいません
・「そこまで上がって、そのまま最後まで続く」という仮定での計算です。実際の金利は上下するので、この表は判断の目安であって予測ではありません
・固定金利はフラット35の水準です。銀行の全期間固定はまた別の水準になります
・動画内の数値はすべて verify.py で再計算しています
