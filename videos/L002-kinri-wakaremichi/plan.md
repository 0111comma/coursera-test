# 企画書(長尺): 変動金利は、いつ・何%まで上がったら固定金利に負けるのか(L002)

- **公開予定**: 2026-08-23(日)
- **形式**: 横型 1920×1080 / 約9〜10分
- **設計の根拠**: `docs/research/longform-design.md`

## この動画が答える問い(1つだけ)

**変動金利は、いつ・何%まで上がったら、固定金利に負けるのか。**

答え(自前計算):

| 上がる時期 | 分かれ目の金利 |
|---|---|
| 借りた直後 | **3.14%**(= 固定金利そのもの) |
| 5年後 | **3.83%** |
| 10年後 | **4.96%** |
| 15年後 | **6.94%** |
| 20年後 | **11.04%** |
| 25年後 | **21.90%** |

**結論の1文: 変動金利が負けるには、早く上がる必要がある。**
15年逃げ切れば、7%まで上がっても固定金利には負けない。

## なぜこの企画か(competitive-positioning.md の3つの質問)

**Q1. これは大手が言えることか?**
言えるが、**やっていない**。住宅ローン系の情報は銀行・比較サイトが出し手なので、
「変動か固定か」は**シミュレーターに入力させる**形になり、
**分かれ目そのものを1本の曲線で見せる**動画は見当たらない。
入力させる側は「答えを1つ出す」動機が無い(入力してもらうのが目的だから)。

**Q2. 検索したら同じ動画が10本出てくるか?**
「変動 固定 どっち」は無数に出る。ただし**大半が「金利が上がったら怖い」で終わる**。
**何%で・いつ上がったら負けるのかを数字で出しているものは、ほぼ無い。**

**Q3. 答えを自前計算で出せるか?**
出せる。元利均等返済の式と二分法だけ。`verify.py` で全数値を再計算している。

## 想定視聴者(JTBD: 状況と用事)

- **状況**: 住宅ローンをこれから組む、または変動金利で借りていて、
  ニュースで「金利上昇」を見て**固定金利に借り換えるべきか迷っている**。
- **用事**: 「自分は逃げ切れるのか」を判断できるようになりたい。
- **指を止める理由**: 争点を数字にしたタイトル。「変動金利は何%で固定金利に負けるのか」
- **視聴後に得るもの**: **上がる時期で分かれ目が変わる**という見方と、
  自分の残り年数に対応する数字。

## 構成(longform-design §2 の型)

| # | 章 | 尺 | 章の問い | 章の出口(判定) |
|---|---|---|---|---|
| 0 | 冒頭 | 60s | 変動金利は何%で固定金利に負けるのか | **1つの数字では答えられない。いつ上がるかで変わる** |
| 1 | 上がらなかったら | 110s | そもそも今の金利でいくら違うのか | **変動金利が1377万円安い** |
| 2 | 上がったら | 130s | 1%上がると何が起きるのか | **毎月1万4728円、年17万6736円ふえる** |
| 3 | 分かれ目 | 160s | では何%まで上がったら並ぶのか | **5年後なら3.83%。10年後なら4.96%** |
| 4 | 逃げ切り | 140s | 遅く上がるとどうなるのか | **15年逃げ切れば6.94%まで耐える** |
| 5 | 繰上返済 | 120s | 繰り上げて返すと分かれ目は動くのか | **5年で300万円返すと3.83%→4.26%に上がる** |
| 6 | 締め | 50s | — | 曲線1枚 + 時点表記 + 免責 |

**冒頭で答えを出し切る**(longform-design §1)。
ただしこの動画の答えは**表**なので、冒頭では「5年後なら3.83%」だけを出し、
「では10年後なら?」で残りを引っ張る。

## 鎖(L1: 章 = 1つの鎖)

```
章1  3000万円 / 35年 → 変動1.025% = 毎月85,036円 → 総額3571万円
                      固定3.140% = 毎月117,812円 → 総額4948万円 → 差1377万円
章2  変動が1%上がる → 毎月 85,036 → 99,764円 = +14,728円 → ×12 = 年176,736円
章3  総額が4948万円に並ぶ金利を探す(二分法)→ 5年後なら3.83%
章4  同じ探し方で 10年→4.96% / 15年→6.94% / 20年→11.04% / 25年→21.90%
章5  5年で300万円繰上返済 → 分かれ目 3.83% → 4.26%
```

種になるのは **3000万円・35年・1.025%・3.140%** の4つ。あとは全部そこから導かれる。

## 図(横型の見せ場 — longform-design §4b)

| 章 | 図 |

| 1 | 積み上げ棒2本(元金3000万 + 利息571万 / 利息1948万)。S013 の kaeshi() を横型に |
| 2 | 毎月の額の折れ線。横幅があるので35年ぶんの目盛りが打てる |

章4の曲線は縦型では絶対に描けなかった図で、**この企画を長尺でやる理由そのもの**。

## コンプライアンス(戦略§6)

- **「変動金利を選べ」「固定金利を選べ」とは言わない。** 出すのは分かれ目の数字だけ
- 特定の銀行・商品・比較サイトを出さない。金利は「2026年8月時点の実勢の水準」とする
- **「そこまで上がって、そのまま最後まで続く」という仮定**であることを毎回明示する。
  実際の金利は上下するので、この表は**判断の目安であって予測ではない**
- 5年ルール・125%ルールは毎月の額の変わり方を抑えるだけで、
  **総額は変えない**(未払利息の扱いは金融機関により異なる)旨を注記
- 団信・手数料・保証料は含めない概算である旨をバッジに出す
- 「2026年8月時点の金利です」を冒頭テロップと締めの両方に

## 独自性要素(戦略§8 — 2つ以上必要。ここでは4つ)

1. **独自計算**: 分かれ目の金利を二分法で6点求めている(verify.py)
2. **独自グラフ**: 「上がる時期 × 分かれ目の金利」の曲線。既存の解説に見当たらない形
3. **複数パターン比較**: 6つの時期 + 繰上返済あり/なし
4. **原文ベース**: 元利均等返済の式そのものから計算しており、
   シミュレーターの出力を引用していない

## 出典

- 変動金利 年1.025%(2026年8月・大手行の引き下げ後の水準)
- 全期間固定 年3.140%(2026年7月のフラット35最頻金利。借入21〜35年・融資率9割以下・団信付き)
- 確認日 2026-08-16。官公庁・住宅金融支援機構のサイトはこの環境のネットワークポリシーで
  遮断されているため、金利水準の確認は検索索引経由。**計算はすべて verify.py の自前計算**
- 確度: 計算は**A**(自分で再現できる)。金利水準は**B**(実勢の代表値。個別条件で変わる)

## S013(ショート)との関係

S013 は同じ計算の**5年後の1点だけ**を使っている。長尺は**時期を動かす**ので重複しない。
ショートを見た人が「では10年後は?」と思ったときの受け皿になる。
S013 の概要欄からこの動画へ誘導する。
