# 企画書: 銀行の100万円、置き場所でいくら変わるのか(S030)

- **公開予定**: 2026-08-26(水)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

貯金100万円、置き場所でいくら変わる?

## この人の欲求

**給料の口座に置きっぱなしのお金を、無駄にしたくない。**

欲求マップの **C(無駄にしたくない)**。
リスクを取る話ではない。同じ預金のまま、置き場所だけで差が出ることを知らずに
損している状態を「無駄」として突く。

## 場面

**給料の口座に、使う予定のないお金が100万円たまっている人。**
預け先を「給料が振り込まれるから」という理由だけで決めていて、
金利で比べたことが一度もない。ニュースで「金利が上がった」とは聞いたが、
自分の口座で何円変わるのかは計算していない。

## 視聴後に決められること

**いま100万円を置いている口座に置き続けるか、定期預金に移すかを決められる。**
判定の数字は「年7172円(税引き後)」1つ。移すだけで、元本が減る心配はない。
ただし急に使うぶんは普通預金に残す、という線引きも一緒に渡す。

## この動画が答える問い(1つだけ)

**同じ100万円を1年置いたとき、普通預金と高い定期預金でいくら変わるのか。**

- **視聴者の予想**: 「利息なんてどうせ数百円でしょ」
- **この動画の結論**: 「**税引き後で年7172円の差。** 普通預金0.4%は税引き後3187円、
  高いネット銀行の定期1.3%は税引き後1万359円。10年で7万1720円」

## 鎖(1本だけ)

```
100万円
  普通預金 0.4% → 利息 4,000円 → 税(20.315%)を引いて 3,187円
  定期預金 1.3% → 利息 13,000円 → 税を引いて 10,359円
  差 = 10,359 − 3,187 = 7,172円/年 → 10年で 71,720円
```

種になる数字は **金利2つ(0.4% / 1.3%)** だけ。あとは全部計算で出す。

## 想定視聴者(JTBD: 状況と用事)

- **P-B(貯金はあるが運用はこわい人)**。投資の動画は素通りするが、
  「預金のまま損しない」話なら自分ごとになる。
- **用事**: リスクを取らずに、いま持っているお金の置き方だけ直したい。

## 指を止める理由

カバーが「**??円**」。金額を隠した状態で「移すだけ。減る心配はない」と添える。
投資をすすめる動画ではないと1枚目で分かるので、P-Bが離脱しない。

## 視聴後に得るもの

「金利0.4%と1.3%」という抽象的な差が、「自分の100万円なら年7172円」という
具体的な円の差に変わる。預け先を金利で比べるという発想が入る。

## 維持の型(hold-rate-2026-08.md)

- カバーは「??円」で答えを隠す
- 3187円→1万359円→差7172円と段階でリビール、10年の7万1720円は84%地点
- 直後に「ただし引き出しにくい」の反転を置く
- 締めは「100万円の置き場所、今日決めてみるのだ」で最初の問いに戻す

## 図

| ユニット | 図 |
|---|---|
| 問い | カード「いくら変わる?」 |
| 金利 | 棒2本(普通0.4% と 定期1.3%) |
| 利息 | 棒2本(税引き後 3187円 と 1万359円) |
| 差 | カード「年7172円」 |
| まとめ | 早見表(普通/定期/1年の差/10年の差) |
| 締め | チップ(預け先はどうやって選んだ?) |

## コンプライアンス(戦略§6)

- 特定の銀行名・商品名を出さない。「高いネット銀行では」までにとどめる
- 「移すべき」とは言わない。差の数字を渡し、締めは「今日決めてみるのだ」で選択を残す
- 金利は「2026年8月の水準。銀行と時期で変わります」とバッジ・注記で明示
- 利息の税(20.315%)を引いた後の数字で言う。税引き前だけで大きく見せない
- 定期預金の欠点(引き出しにくい)を本編で言う

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 3187円・1万359円・7172円・7万1720円を verify.py で再計算
2. **税引き後で統一**: 金利比較の動画は税引き前が多い。本作は全部税引き後
3. **反転の設計**: 得の直後に「引き出しにくい」を置き、普通預金に残す線引きまで渡す

## 出典

- 普通預金 年0.4%・ネット銀行の1年定期 年1.3% は 2026年8月時点の代表的な水準
  — 確認日 2026-08-20(銀行と時期で変わるため「水準」として提示)
- 利息への税率 20.315%(所得税15% + 復興特別所得税0.315% + 住民税5%)
- 金額はすべて verify.py の自前計算
- 確度: 税率は **A**。金利水準は **B**(複数行の公表金利の範囲。個別行は名指ししない)
