# 企画書: 毎月5000円の固定費。65歳までにいくら払うのか(S033)

- **公開予定**: 未定(新ペルソナ P-M の1本目)
- **形式**: 縦型 1080×1920 / RocknRoll One / 東北きりたん / 語ごとのポップ

> **2026-08-24。ペルソナを35歳男性会社員(P-M)に変えて最初の企画。**
> S032 は「65歳から貯金を取り崩す」話で、主に刺さるのは視聴者の 24.4%(55歳以上)だった。
> この動画は**まだ積む側にいる人**に向ける。

---

## 1. この人の欲求

**知らないうちに、毎月勝手に引かれているものを止めたい。**

`docs/research/yokkyu-map.md` の **A(取られたくない)**。いちばん強い欲求。
「自分の財布から、自分の知らないうちに出ている」が核。

**煽らない。**「あなたは損している」ではなく、**止めたときに何が返ってくるか**を出す。

## 2. 場面

**口座やカードの明細を見て、「これ何だっけ」が1行ある。**

- 使っていないサブスクが落ち続けている
- 前に入った保険や会費を、金額を確かめずに払っている
- スマホ代を「そんなものか」と思って何年も同じ

## 3. 想定視聴者

**P-M: 35歳・男性・普通の会社員。手取り25〜35万円。**

この人は「毎月5000円」を**小さいと思っている**。だから止めていない。
月5000円は**1日167円**。缶コーヒー1本ぶんで、意識に上がらない額。

## 4. 最初の一言(問い)

**毎月5000円のサブスク。65歳までに、いくら払う?**

## 5. 指を止める理由

「5000円」も「サブスク」も自分の明細にある言葉なので、**自分の話だと分かる**。
そして**答えを知らない**。掛け算1回で出るのに、やったことがない。

## 6. 視聴後に得るもの

**「たった5000円」の正体が、自分の数字で分かる。**
35歳から65歳までの30年で、出ていくお金は **180万円**。
止めて同じ額を積んだ場合、年5%と仮定すると **416万円**。

## 7. 視聴後に決められること

**今日、明細を開いて1つ止める。**

「止めるかどうか」ではなく **「1つ」** と数を決めているので、その場で動ける。
金額は視聴者それぞれなので、**式(月額 × 360か月)を1枚で出す**。
自分の額を入れれば、自分の数字が出る。

「◯◯を知った」で終わらない。

## 8. 感情の設計 — どこで刺し、どこで返すか

| # | 何を起こすか | 台詞の役 |
|---|---|---|
| 序盤 | **自分ごと化** | 「1日にすると167円」。小さいと思っていた理由を言葉にする |
| 中盤 | **痛み** | 「180万円。使った覚えがないまま出ていく」 |
| 後半 | **反転** | 同じ額を積んだら416万円。**同じお金が、逆側に立つ** |
| 締め | **行動** | 「今日、明細を開いて1つ止める」 |

**この動画の肝は「反転」。**同じ5000円が、出ていく側と入ってくる側の
両方に立つことを、同じ画面で見せる。恐怖で終わらせない(yokkyu-map A の注記)。

## 9. この動画の結論(ネタ選定ゲート F1)

**「1日167円が、30年で180万円。止めて積めば、年5%と仮定して416万円。」**

「たった5000円」という予想と食い違う。**額の小ささと、結果の大きさの落差**が中身。

---

## 10. 前提と根拠

**この動画には、外から持ってくる数値が1つも無い。**

理由: この実行環境からは官公庁のサイト(`.go.jp`)が**すべてブロックされて**いて、
一次資料を開いて確かめられない(2026-08-24に確認。`mhlw` `nenkin` `nta` `jasso` すべて403)。
**確かめられない数字を画面に出さない**という CLAUDE.md の最優先ゲートに従い、
前提はすべて**明示した仮定**にした。

| 値 | 根拠 | 出典(確認日 2026-08-24) |
|---|---|---|
| 5000円 | 止める固定費の例。視聴者が自分の額に置き換える | (仮定。動画の1文目がこの額) |
| 35歳 | この動画の対象。P-M の年齢 | (仮定。docs/persona.md の主ペルソナ) |
| 65歳 | 積むのをやめる年齢として置いた | (仮定。制度の数値ではない) |
| 年5% | 積んだ場合の利回り | (仮定。元本保証ではなく、減る年もある) |

**利回りは仮定なので、0%(ただ貯めるだけ)を必ず並べて出す。**
増える前提だけを見せない(戦略§6-2)。

---

## 11. 数値(verify.py で検証済み)

```
毎月5000円 ÷ 30日     = 1日167円
5000円 × 360か月       = 180万円(35歳→65歳の30年で出ていく額)
ただ貯めるだけ          = 180万円
年3%で運用(仮定)      = 291万円
年5%で運用(仮定)      = 416万円
416万円 − 180万円      = 236万円(増えた分)
```

## 13. コンプライアンス(戦略§6)

1. 投資助言をしない。**個別のサブスク名・保険会社名・証券会社名を一切出さない** ✓
2. 断定を避ける。利回りは「仮定」と明示し、0%の場合も並べる ✓
3. 前提の数値には根拠を付ける(§10。**すべて仮定であることを明示**)✓
4. verify.py で再計算 ✓
5. 時点表記: **制度の数値を使っていない**ので、制度の時点表記は不要。
   利回りの仮定であることをバッジで明示する ✓
6. 独自性: 独自計算 + 独自グラフ(出ていく側と入ってくる側の対比)
   + 持ち帰る式(月額 × 360か月)✓
