# 企画書: 電波が心配で乗り換えない人へ。同じ回線のまま月1883円(S034)

**この動画は S033 の型を意図的に外している。**
S033(サブスク)は「止める → 差額を30年積む → 263万円」だった。
同じ骨で2本続けると、視聴者には同じ動画に見える(ループ71のユーザー指摘
「画面構成飽きてきた」と同じことが、構成でも起きる)。

だからこの動画は:

- **差額を30年積まない。**出すのは月の差と1年の差まで
- 欲求を **A(取られたくない)から B(選択を間違えたくない)へ移す**
- 逆転は金額ではなく**前提の否定**に置く
  (「乗り換えない最大の理由」が、この選択肢には当てはまらない)

---

## 1. この人の欲求

**スマホ代は高いと思っているが、選択を間違えたくない。**

`docs/research/yokkyu-map.md` の **B(大きな選択を間違えたくない)**。
直近3本(S030=C / S031=A / S033=A)が A・C に寄っていたので、ここで B を入れる。

この人は「格安は安いが、何かを失う」と思っている。失うものが何なのかを
はっきり言えないまま、**判断を保留している**。保留のコストが月1883円。

**煽らない。**「損している」ではなく、**何を失って何を失わないのか**を並べる。
失うもの(店舗サポート・かけ放題の別料金)も同じ画面で正直に出す。

## 2. 場面

**大手キャリアのままで、料金プランを3年以上見直していない人。**

きっかけは「請求額を見た」「家族に格安を勧められた」「機種変更の案内が来た」。
乗り換えを考えたことはあるが、**電波が悪くなるのが不安**で止まっている。
この不安は本物で、MVNO(格安SIM)では実際に混雑時間帯の速度が落ちる。

**そこがこの動画の入口になる。**その不安が当てはまらない選択肢がある。

## 3. 想定視聴者

P-M(35歳・男性・会社員)。docs/persona.md。
大手キャリアを10年以上使っていて、プランは自分で選んだ記憶がない。
「格安SIM」という言葉は知っているが、大手が出しているオンライン専用プランと
MVNOの区別がついていない。**この区別が動画の中身そのもの。**

## 4. 最初の一言(問い)

> 「格安にすると、電波が悪くなると思ってませんか?」

数字ではなく**前提の確認**から入る。この動画が否定するのはこの前提であって、
視聴者の判断力ではない。

## 5. 指を止める理由

- **自分が言われたことのある文句がそのまま出る。**「電波が悪くなる」は
  乗り換えない理由の定番で、視聴者は自分の言い分が画面に出たと感じる
- カバーで **4,853円 と 2,970円** を並べる。どちらも実在の値で、差が一目で出る
- **答えを伏せる。**「同じ回線のまま」という語をカバーに置かない
  (S033 の反省: パッケージが転回を先に殺していた。kotoba-rules K1)

## 6. 視聴後に得るもの

大手キャリアには「同じ回線を使うオンライン専用プラン」があり、
MVNO(格安SIM)とは別物であること。速度の不安はMVNOの話であって、
オンライン専用プランには当てはまらないこと。そのかわり店舗では手続きできず、
24時間かけ放題は別料金になること。

## 7. 視聴後に決められること

**今のプランを続けるか、同じ回線のオンライン専用プランに変えるかを決められる。**

判断の材料も決まっている: **今月の請求額と、使ったギガ数の2つを見る。**

「知る」で終わらせない。**見るものが決まっていて(請求額と使用ギガ)、
選ぶ先が2つに絞られている**状態にして終わる。

## 8. 感情の設計

1. **是認**(電波の不安は当たっている。MVNOでは実際に落ちる)
2. **区別**(だがそれはMVNOの話。大手のオンライン専用は同じ回線)
3. **金額**(その差、月1883円)
4. **正直**(ただし店舗は使えない。かけ放題は別料金)
5. **それでも残る差**(かけ放題を足しても月783円)
6. **行動**(請求額と使ったギガを見る)

**4を飛ばさない。**デメリットを自分から出すことが、この動画の信用の全部。

## 9. この動画の結論(ネタ選定ゲート F1)

> **「格安にすると電波が悪くなる」は正しい。ただしそれはMVNOの話で、
> 大手が出すオンライン専用プランは同じ回線をそのまま使う。**

予想と食い違う点: 視聴者は「安い = 何かを犠牲にする」と思っている。
犠牲になるのは**回線品質ではなく、店舗サポートとかけ放題**だと分かる。
犠牲の中身が入れ替わる。

## 10. 前提と根拠

**料金は調べた値。ahamo の料金だけ確度A、平均額は確度B。**

この実行環境は egress proxy が報道各社と MM総研を遮断していて
(2026-08-30確認。m2ri.jp / itmedia.co.jp / k-tai.watch.impress.co.jp が
いずれも EGRESS_BLOCKED)、一次資料のPDFを開いて確かめられない。
**複数の独立した報道の検索スニペットが一致すること**までを確認した。

**焼く前・投稿前にユーザーの環境で料金を確認すること。**

| 値 | 根拠 | 出典(確認日 2026-08-30) |
|---|---|---|
| 4,853円 | MNO4ブランドの月額平均。MM総研 2026年7月調査 | ケータイWatch / ITmedia / マイナビ の報道が一致(確度B) |
| 4,198円 | 利用者全体の月額平均。同調査 | 同上(確度B) |
| 3,296円 | サブブランドの月額平均。同調査 | 同上(確度B) |
| 1,979円 | MVNOの月額平均。同調査 | 同上(確度B) |
| 2,970円 | ahamo。30GB + 5分かけ放題 | https://ahamo.com/special/lp/001.html (2026-08-30確認・**確度A**) |
| 1,100円 | ahamo の24時間かけ放題オプション | ahamo公式(2026-08-30確認・**確度A**) |
| 混雑時間帯にMVNOの速度が落ちる | 通信の仕組み(MVNOは帯域を借りる)。**動画では「速度が落ちることがある」と幅で言う** | (通信事業の構造。特定業者の品質評価はしない) |

**この動画は運用利回りを使わない。**したがって「年5%と仮定」の免責は不要。
そのかわり **「料金は2026年8月時点」の時点表記を必ず入れる**(戦略§6-5)。

## 11. 数値(verify.py で検証済み)

```
大手4ブランドの平均        = 4,853円/月   (MM総研 2026年7月)
オンライン専用(ahamo)     = 2,970円/月   (30GB + 5分かけ放題)
差                        = 1,883円/月
1年ぶん  1,883 × 12        = 22,596円
24時間かけ放題を足しても
  4,853 −(2,970 + 1,100) =   783円/月  → 1年 9,396円
(参考)大手 − サブブランド =  1,557円/月
```

**30年に伸ばさない。**伸ばせば大きな数字は作れるが、それは S033 と同じ動画になる。
この動画の判定は「今のプランを続けるか」なので、1年で足りる。

## 13. コンプライアンス(戦略§6)

1. **特定業者を推奨しない。**ahamo は「大手のオンライン専用プランの例」として
   名指しするが(§6.2 で名指しは禁じていない)、「乗り換えるべき」とは言わない。
   決定は視聴者に渡す(「今のままにするか、移すかを決められる」)
2. **他社の品質を貶めない。**MVNOについては「混雑する時間帯に速度が落ちることがある」
   という構造の説明までにとどめ、特定事業者の品質評価はしない
3. **断定を避ける。**「安くなる」ではなく「差はいくら」。使用状況で結果は変わる
4. 数値はすべて verify.py で再計算し、assert で固定した
5. **「2026年8月時点の料金です」の時点表記を入れる**
6. 独自性要素: (a) 大手平均とオンライン専用の自前差分計算、
   (b) かけ放題を足した場合の再計算(「安いのは条件を削っているから」への答え)、
   (c) MVNO / サブブランド / オンライン専用の3階層の整理 — 3つで基準を満たす
