## 直すときに1つだけ守ってほしいこと

**合計320〜345字。** 1字が約0.14秒なので、これを外れると尺が合いません。
1ユニットは10〜20字。20字を超えると字幕が画面からはみ出します。

## 出せる数字(これ以外は出さないでください)

すべて計算・検証済みです。

| 数 | 意味 |
|---|---|
| 4356円 | スマホ代の平均(MM総研 2025年1月調査) |
| 5025円 | 大手4ブランドの平均 |
| 2970円 | ahamo(30GB + 5分かけ放題) |
| 1961円 | MVNOの平均 |
| 2055円 | 5025 − 2970 |
| 2万4660円 | 2055 × 12 |
| 35歳 / 65歳 / 360か月 | 積む期間(仮定) |
| 74万円 | 2055 × 360 = 739,800円 |
| 年5% | **仮定**。必ず「仮定」と言う |
| 171万円 | 2055円を年5%で360か月積んだ場合 = 1,710,291円 |

## 言ってはいけないこと

- 「儲かる」「必ず」「〜すべき」の断定
- 「ahamoにしろ」「乗り換えるべき」などの**推奨**(**名前を出すのは可**)
- 特定の会社を名指しで「高い」「損」と言うこと
  (言うのは**実額と、その差がいくらになるか**だけ)
- 利回りを断定すること(必ず「仮定」と添える)

- **誰に**: 35歳・男性・普通の会社員
