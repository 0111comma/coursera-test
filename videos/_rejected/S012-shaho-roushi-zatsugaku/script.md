# 台本(ショート): 会社が出した460万円、手元に残るのは69%

- **ID**: S012 / **テンプレ**: 仕組み解説型 / **想定尺**: 約51秒
- **投稿タイトル**: 会社は460万円、手取りは315万円(18字)
- **調声・構成**: render.pyが正(共通シーンはproduction/scenes_common.py)

## ネタ選定ゲート(プレイブックF1)

- **視聴者の予想**: 「会社が出しているのは、年収の400万円でしょ」
- **この動画の結論**: 「会社が出した460万円のうち、手元に残るのは315万円。**69%**しか残らない」

## 構成の意図

- 入口は「給料」。全員が明細を持っているので、投資に興味がない人でも他人事にならない
- 答える問いは1つだけ:「会社が出した額のうち、手元に残るのはいくらか」
- 鎖は1本。400万 −59万 −26万 = 315万 / 400万 +60万 = 460万 / 460万 −315万 = 145万 → 69%
- 最後は棒2本にせず、460万円という帯1本を塗り分ける。塗られていない部分の長さが145万円になる
- 「保険料や税金が高い」という評価はしない。事実の提示と、見方の変更に留める

## ナレーション全文

会社はあなたに460万円。でも手取りは315万円。
まず、年収400万円の人で見るのだ。
これは2026年度の料率で計算した。
その人の給料から、社会保険料が引かれる。
その社会保険料は、年59万円。
さらに所得税と住民税で、年26万円。
だから手取りは、さっきの315万円。
つまりここまでは、明細で分かるのだ。
では、会社はいくら出しているのか。
実は社会保険料を、会社も払っている。
これを労使折半、半分ずつというのだ。
その会社の負担も、年60万円ある。
つまり年収400万円の人に、460万円。
その460万円のうち、手取りは315万円。
差の145万円は、税と社会保険料なのだ。
会社が出した額の、69%しか残らない。
明細に見えるのは、その一部なのだ。

## 概要欄テキスト

会社があなたに払っている総額と、実際に手元に残る額の差を計算しました。
・例: 年収400万円・東京都・40歳未満(介護保険なし)・独身・扶養なしの概算
・社会保険料(本人分)は 厚生年金9.15% + 健康保険4.925% + 子ども子育て支援金0.115% + 雇用保険0.5% = 14.69% → 約59万円
・所得税 約8万1千円 + 住民税 約17万7千円 = 約26万円
・したがって手取りは 400万 − 59万 − 26万 = 約315万円
・一方、社会保険料は会社も負担しています(労使折半)。会社の負担は 同じ3つ + 雇用保険0.85% = 15.04% → 約60万円
・会社から見た費用は 400万円 + 60万円 = 約460万円
・つまり会社が出した約460万円に対して、手元に残るのは約315万円。差は約145万円で、残るのは69%という計算になります
・実際の保険料は標準報酬月額の等級表で決まるため、これは年収に料率を掛けた概算です
・料率と控除額は2026年度のものです。健康保険料率は都道府県で異なり、40歳以上は介護保険料が加わります
・動画内の数値はすべて verify.py で再計算しています
あなたの給与明細、手取りはいくらでしたか?
