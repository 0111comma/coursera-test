# 企画書: 実家のタンス預金は、相続のときに調べられる(S018)

## 最初の一言(問い)

親の家、相続税はいくらからかかる?

**1ユニット目でこれを声に出す**(ループ71のユーザー指摘)。

### 前の版をなぜ捨てたか

前の版は「実家を片づけていたら、現金が出てきたとする」から入り、
そこから基礎控除 → 税務調査 → 加算税へ**話が3つに割れていた**。

> 「2つ目の動画、相続税の動画。これマジゴミだと思う。マジで何の話してるかわかんないし、
>   読み間違いもあるし、これなんでこんなん出してきたの?」

背骨を1本にした。**いくらから税金がかかるのか** → その線に何が入るのか →
家の現金も入る → それは調べられる → 書かないといくら増えるか → だから数える。

読み間違いは「相続人」を **ソオゾクジン** と読んでいたもの(正しくは そうぞくにん)。
`production/check_yomi.py` を作り直して機械で落とすようにし、言い方も変えた。

## この人の欲求

**うちは相続税がかかるのか。かかるなら、あとから余計に取られたくない。**

欲求マップの **A(取られたくない)**。
「タンス預金とは」ではなく、**家に現金がある人・親の家に現金がある人**に向ける。

## 視聴後に決められること

**家にある現金を、相続財産として申告するかどうかを決められる。**
(いくら余計に取られるのかが分かるため)

## この動画が答える問い(1つだけ)

**家に置いた現金を申告しなかったら、いくら余計に取られるのか。**

答え: **本来の税額に、最大40%が上乗せされる。**
本来100万円なら、140万円。さらに延滞税が別でつく。

## 企画の4行(docs/persona.md)

- **想定視聴者**: 実家に現金があると知っている人、または自分が現金を家に置いている人。
  P-B(まだ何もしていないが、いつか向き合うと分かっている人)
- **指を止める理由**: 「黙っていたらどうなる?」という**自分の家で起きうる**話。
  「1.4倍」という数字で、いくら余計に取られるのかが即座に分かる
- **視聴後に得るもの**: そもそも申告が要る家かどうかの線引きと、隠した場合の上乗せが分かる
- **この動画の結論**: 「多くの家は**4200万円まで無税**で関係ない。
  ただし超えていて隠すと、本来の税額に**最大40%**が上乗せされる」

## 場面(いつ、この人はこれに出会うか)

親の家を片づけていて、現金が出てきたとき。
あるいは自分が「銀行より家のほうが安心」と現金を置いているとき。

## 鎖(1本だけ)

```
家にある現金 1000万円 → 相続財産に入る(申告が必要)
申告しないと → 税務署は 過去10年ぶんの出金記録 をたどれる
バレると    → 本来の税額 + 加算税 + 延滞税
              悪質だと判断されると 重加算税 最大40%
本来100万円の税額 → 140万円 になる(差 40万円)
```

種になる数字は **40%** ひとつ。

## 独自性要素(戦略§8 — 2つ以上)

1. **独自計算**: 本来の税額100万円に対する加算税の上乗せを verify.py で再計算
2. **複数パターン比較**: 無申告加算税(15/20/30%)と重加算税(最大40%)の段階を並べる
3. **仕組みの説明**: なぜバレるのか(出金記録をたどれる)を、隠す/隠さないの対比で出す

## コンプライアンス(戦略§6)

- **脱税の方法を教える動画にしない。** 「バレない方法」は一切扱わない
- 税理士・税務署・特定のサービスを推奨しない
- **相続税は基礎控除(3000万円 + 600万円 × 法定相続人の数)があり、
  そもそも申告が要らない人が多い**ことを明示する。ここを省くと不安を煽るだけになる
- 加算税の率は**税額に対するもの**であり、財産額に対するものではないことを明示する
- 個別の判断は税務署・税理士に、と明示する(手続きの一般論に留める)
- 「2026年8月時点の制度です」を入れる

## 出典

- 無申告加算税: 50万円までの部分15%、50万円超300万円までの部分20%、300万円超の部分30%
- 重加算税: 悪質と判断された場合、最大40%
- 加算税とは別に延滞税がかかる
- 税務署は被相続人の口座の出金記録をたどることができ、まとまった出金は注目される
- 相続税の税務調査は申告から1〜2年後、調査割合は全体の約20%
  — ランドマーク税理士法人 / 税理士法人チェスター / 相続ステーション ほか
  (確認日 2026-08-18)
- 確度: 加算税の率は**A**(複数の税理士法人の解説で一致)。
  調査割合20%は**B**(出典が民間の集計)。
  官公庁サイト(国税庁)はこの環境のネットワークポリシーで遮断のため検索索引経由
