# 企画書: 金利が上がると、債券が下がる(S011)

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-A。28〜40歳の会社員。NISAでインデックス投信を積立中。
  「バランス型」や「4資産」に入っている債券の意味は知らない。
  ニュースの「金利上昇」は聞くが、自分の資産とどうつながるか説明できない。
- **指を止める理由**: 「金利が上がって、損した人がいる」。
  金利が上がる＝利息が増えて嬉しい、という直感と真逆なので、なぜ、が立つ。
- **視聴後に得るもの**: ニュースの「金利上昇で債券安」の意味が分かる。
  そして**自分の投信の債券部分が下がっても、満期まで持つ設計なら何が起きているか**が分かる。
- **視聴者の予想**: 「金利が上がったら、もらえる利息が増えるだけでは?」
- **この動画の結論**: 「利息は固定なので、**値段のほうが下がって帳尻を合わせる**。
  下がって困るのは、途中で売る人だけ」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 利息の比較 | AとBの量が違う | 共通の底からの棒2本(長さ=毎年の利息) |
| 値段の調整 | 前→後で変わった | 棒2本 + 差の帯(100万 → 91万、差9万) |
| 満期まで持つ | 時間で変わる | 折れ線(91万から100万へ戻る) |

## 数値の根拠

verify.py 参照。額面100万円・表面利率1%(毎年1万円)・残存10年の債券を、
市場の利回りが2%になった時点で評価する(将来の利息と元本を2%で割り引く)。

- 価格 = Σ(1万円 ÷ 1.02^t, t=1..10) + 100万円 ÷ 1.02^10 = **910,174円** ≈ 91万円
- 途中で売ると出る損 = 100万円 − 91万円 = **約9万円**
- 満期まで持てば額面100万円が戻る(発行体が破綻しない場合)

- 財務省「国債金利情報」(利回りの用語)

  ネットワークポリシーで遮断されているため、内容確認は検索索引経由。
  **動画内の数値はすべて verify.py の自前計算**で、外部の数値を引用していない。

## コンプライアンス(戦略§6)

- 特定の債券・投信・証券会社を挙げない。金利の先行きを予想しない
- 「満期まで持てば戻る」は**発行体が破綻しない場合**である旨を画面に注記する
- 実際の債券価格は信用力や需給でも動く旨を概要欄に記載する
