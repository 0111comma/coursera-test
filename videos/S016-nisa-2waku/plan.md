# 企画書: つみたて投資枠と成長投資枠、どっちで積み立てる?(S016)

- **公開予定**: 2026-08-21(金)
- **形式**: 縦型 1080×1920 / 60秒未満

## この人の欲求

**積立を増やしたい。でも設定を選び間違えたくない。**

欲求マップの **B(大きな選択を間違えたくない)**。
場面は「口座や商品を選ぶ」。B の note のとおり、**判定を1つの数字に落とす**。
ここでは **月10万円**。S013 の「3.83%」と同じ役割の数字。

### 前の版をなぜ捨てたか(ループ71のユーザー指摘)

前の版は「NISAで売ったら、投資枠はいくら戻るか(簿価・翌年)」だった。

> 「だから何って思う。これは**どの欲求に訴求している動画なの?**」

企画書には C(無駄にしたくない)と書いてあったが、**実際には誰の欲求でもなかった**。

1. **損得が発生するのが、生涯投資枠1800万円を使い切りそうな人だけ。**
   埋めている途中の人にとっては、簿価で戻ろうが戻るまいが何も変わらない
2. **視聴者は売っていない。** 積み立てている最中で、
   `demand-2026-08.md` 自身が書いた分かれ目「視聴者がいま実際にやっていること」を外していた
3. 出発点が仕組み(簿価・翌年復活)で、視聴者を後から貼りつけた。
   CLAUDE.md にある旧 S012 の失敗と同じ形

**私が見ていたのは S003(64.1%)との「話題の近さ」であって「場面の近さ」ではなかった。**
話題は同じ NISA の投資枠だが、場面は「売る」で、視聴者がいまやっていないことそのもの。

## 場面

証券会社の画面に「つみたて投資枠」と「成長投資枠」の2つがあり、
**毎月の積立額を増やそうとして、どちらで設定するのかで手が止まっている。**
S003(NISA枠1800万、何年で埋まる?・視聴率64.1%)の直接の続きで、
しかも**いま実際にやっている操作**。

## 視聴後に決められること

**毎月の積立を、どちらの投資枠で設定するかを決められる。**
月10万円までなら、つみたて投資枠だけでいい。超えたい月だけ成長投資枠を足す。

## 想定視聴者(JTBD: 状況と用事)

- **P-A(すでに積み立てている人)**。月1〜5万円をつみたて投資枠で積み立てていて、
  **ボーナスや昇給で積立額を増やそうとしている**。
  証券会社の画面に「つみたて投資枠」と「成長投資枠」が並んでいて、
  成長投資枠のほうは「個別株の人向けだろう」と思って触っていない。
- **用事**: 積立額を増やすとき、どちらの投資枠で設定すればいいのかを決めたい。

## 指を止める理由

**「つみたて投資枠は、月いくらで止まる?」**という、自分の設定画面にある言葉での問い。
月10万円という**1つの数字**が答えなので、自分の積立額とその場で比べられる。

## 視聴後に得るもの

自分の積立額が月10万円の上下どちらにあるかで、
**設定を変える必要があるかどうかがその場で分かる**。
そして成長投資枠だけに寄せると1200万円で止まることも分かる。

## この動画が答える問い(1つだけ)

**つみたて投資枠は、月いくらで止まるのか。超えたいときはどうするのか。**

- **視聴者の予想**: 「成長投資枠は個別株を買う人のもので、自分には関係ない」
- **この動画の結論**: 「**成長投資枠でも同じ商品を積み立てられる。**
  つみたて投資枠は月10万円で止まるので、それを超えたい月だけ成長投資枠を使う。
  ただし成長投資枠は一生で1200万円までなので、
  **成長投資枠だけでは1800万円は埋まらない**(残り600万円はつみたて投資枠の分)」

## 鎖(1本だけ)

```
つみたて投資枠 年120万円 ÷ 12 = 月10万円   ← 分かれ目の数字
  → 超えたい分は成長投資枠 年240万円(月20万円)
  → 合わせて 年360万円 = 月30万円
  → ただし一生ぶん1800万円のうち成長投資枠は1200万円まで
  → 残り600万円は、つみたて投資枠でしか埋まらない
```

種になる数字は **年120万円** ひとつ。全部そこから割り算で出る。

## コンプライアンス(戦略§6)

- 「どちらが得か」は言わない。言うのは**上限がいくらで、どこで切り替わるか**だけ
- 個別の銘柄・投資信託・証券会社を出さない
- 「必ず」「儲かる」を使わない。金額はすべて**仮定**と明示
- 「2026年8月時点の制度です」をバッジとナレーションの両方に入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 月10万円・月30万円・600万円・5年・15年をすべて verify.py で再計算
2. **複数パターン比較**: 2つの投資枠を、年額・月額・一生ぶんの3つの軸で並べる
3. **独自の早見表**: 「いくら積み立てるか → どちらで設定するか」の判定表

- 成長投資枠でも投資信託の積立設定ができる(つみたて投資枠と同じ商品を選べる)
