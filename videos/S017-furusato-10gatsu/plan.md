# 企画書: ふるさと納税、10月から返礼品のルールが変わる(S017)

## この人の欲求

**欲しい返礼品を、もらい損ねたくない。**

欲求マップの **C(無駄にしたくない)**。
「ふるさと納税とは」ではなく、**まだ今年ぶんをやっていない人**に向ける。

## 視聴後に決められること

**欲しい返礼品があるなら、9月中に寄付するかを決められる。**
**急がないなら、10月以降のルールで選び直すと決められる。**

## この動画が答える問い(1つだけ)

**いま見ている返礼品は、10月以降も同じように選べるのか。**

答え: **選べなくなるものがある。2026年10月から、加工品は「その地域で過半の付加価値が
生まれたこと」を証明できないと返礼品にできない。**

- **ID**: S017
- **形式**: ショート(〜60秒)
- **コンテンツピラー**: 制度改正ニュース
- **ステータス**: 企画中
- **作成日**: 2026-08-18

## 企画の4行(docs/persona.md)

- **想定視聴者**: ふるさと納税を毎年やっているが、**今年ぶんはまだ手をつけていない人**。
  「年末にまとめてやればいい」と思っている。P-A(すでにやっていて、やり方で迷う人)
- **指を止める理由**: 「10月に何が変わる?」という**期限**の話。
  年末だと思っていたものに、実は9月末の区切りがあると知らされる
- **視聴後に得るもの**: 欲しい返礼品があるなら9月中に動くべきか判断できる
- **この動画の結論**: 「10月から**選べる返礼品が入れ替わる**。
  ただし3割・5割ルールと実質2000円は変わらない。変わるのは品のほうだけ」

## 場面(いつ、この人はこれに出会うか)

夏。「ふるさと納税は年末にやればいい」と思っている。
実は**欲しかった加工品が、10月にはもう無いかもしれない**。

## S005 との重なり(ユーザー指摘への対応)

S005 は「**いくらまで**(上限)」の話。この動画は「**いつまでに**(期限)」の話。
金額の計算は一切しないので重ならない。

## 鎖(1本だけ)

```
2026年10月1日 から、返礼品の基準が厳しくなる
  → 加工品は「区域内で過半の付加価値」を証明できないと出せない
  → ロゴを付けただけの品は「1年以内の販売実績」が必要で、その数量が上限
  → だから 9月30日まで と 10月1日から で、選べる返礼品が変わる
残り時間: 8月18日から9月30日まで = 43日
```

種になる数字は **10月1日** ひとつ。

## 3段階の改正(この動画では10月だけを扱い、残りは触れるだけ)

| 時期 | 何が変わるか |
|---|---|
| 2025年10月(実施済み) | 仲介サイトのポイント付与が全面禁止 |
| **2026年10月** | **地場産品基準の厳格化 ← この動画** |
| 2027年1月 | 特例控除に上限(予定) |

## 独自性要素(戦略§8 — 2つ以上)

1. **独自の図**: カレンダーの上に「9月30日まで」と「10月1日から」の境目を引く
2. **原文ベース**: 令和7年総務省告示第220号の内容(過半の付加価値・販売実績)から起こす
3. **複数パターン比較**: 変わらないもの(3割・5割ルール)と変わるもの(地場産品基準)の対比

## コンプライアンス(戦略§6)

- **特定の自治体・返礼品・仲介サイトを出さない**
- 「今のうちに寄付しろ」と煽らない。**期限と、何が変わるかだけ**を渡す
- **どの返礼品が対象外になるかは自治体の判断**であり、確定情報ではない旨を明示する
- 3割ルール(調達費)・5割ルール(募集経費)は**変わらない**ことを明示する
- 上限額の話はしない(S005に譲る)
- 「2026年8月時点の情報です」を入れる

## 出典

- 2026年10月1日からの指定対象期間で地場産品基準が厳格化(令和7年総務省告示第220号)。
  加工品は区域内で過半の付加価値が生じたことの証明、一般販売価格の記載、
  100万円以上の支払先の公表などが求められる
- ロゴ等を付しただけの商品は1年以内の販売・配布実績が必要で、その数量が上限
- 3割基準(調達費)・5割基準(募集経費)は引き続き維持
  — ふるさとチョイス公式の告知 / 実務解説複数(確認日 2026-08-18)
- 確度: 改正の内容は**B**(仲介大手の公式告知と実務解説で一致。告示原文は未確認)。
  **どの返礼品が消えるかは確度C**なので、断定せず「変わる可能性がある」に留める
