# 企画書: 昇給1万円、手取りはいくら増えるのか(S018)

- **公開予定**: 2026-08-28(金)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

昇給1万円、手取りはいくら増える?

## この人の欲求

**上がったぶんを、知らないうちに持っていかれるのが嫌だ。**

欲求マップの **A(取られたくない)**。いちばん強い欲求で、
場面も「給与明細を見た」でそのまま当てはまる。

## 場面

**昇給の内示が出た、あるいは4月の給与明細を見たところ。**
「1万円上がった」と聞いて喜んだが、振り込まれた額を見て思ったより増えていない。
なぜ減っているのかを、金額で知りたい。

## 視聴後に決められること

**提示された昇給額に0.68をかけて、手取りでいくら増えるかをその場で出す。**
転職や残業の条件も、額面ではなく手取りに直してから比べる。
1万円あたり約3割が消えると分かるので、
「月2万円アップ」の提示がいくらの手取りになるかを自分で出せる。

## この動画が答える問い(1つだけ)

**月給が1万円上がったとき、手元に増えるのはいくらか。**

- **視聴者の予想**: 「税金でちょっと減るくらいでしょ」
- **この動画の結論**: 「**増えるのは6807円。3193円が消える。**
  しかも先に引かれるのは税ではなく**社会保険料の1469円**で、
  税がかかるのは**その残りの8531円**」

## 鎖(1本だけ)

```
月給 +1万円
  → 社会保険料 14.69% = 1469円 が先に引かれる
  → 残り 8531円 に税がかかる
      所得税 10.21% = 871円
      住民税 10%    = 853円
  → 手元に増えるのは 10000 − 1469 − 871 − 853 = 6807円
  → 消えるのは 3193円(およそ3割)
```

種になる数字は **1万円** ひとつ。あとは率をかけるだけ。

## 想定視聴者(JTBD: 状況と用事)

- **P-A(会社員で、昇給または転職を目の前にしている人)**。
  額面の金額で条件を比べている。手取りへの変換をしたことがない。
- **用事**: 提示された額面が、実際にいくら手元に増えるのかを知りたい。

## 指を止める理由

**「昇給1万円、手取りはいくら増える?」**は、
上がったと聞いた瞬間に誰もが一度は思い、そして計算しない問い。
答えが **6807円** という1つの数字なので、その場で自分の昇給に当てはめられる。

## 視聴後に得るもの

**引かれる順番**が分かる。税が先だと思っていたものが、
実際は社会保険料が先で、税はその残りにかかる。
だから「社会保険料は税より重い」ことが金額で分かる。

## S004 との違い

S004(公開済み・視聴率59.7%)は「**年収400万円の手取りはいくらか**」という**総額**の話。
この動画は「**上がった1万円のうち、いくら残るか**」という**増えた分**の話。
総額の手取り率は約8割だが、**増えた分の手取り率は約68%**で、そこが違う。

## コンプライアンス(戦略§6)

- 率は**2026年度・東京・40歳未満**の前提で、年収や自治体で変わることを本編で言う
- 「必ずこうなる」とは言わない。バッジとナレーションの両方で前提を出す
- 介護保険料(40歳以上)は前提から外していることを企画書に明記する
- 「2026年度の率です」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 1469円・8531円・871円・853円・6807円・3193円を verify.py で再計算
2. **独自の分解**: 「社会保険料が先、税はその残りに」という引かれる順番の見せ方
3. **独自の早見表**: 1万円の行き先を4つに割った表
