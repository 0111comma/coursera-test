# 企画書: ボーナス50万円、手取りはいくらか(S028)

- **公開予定**: 2026-09-22(火)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

ボーナス50万、手取りはいくら?

## この人の欲求

**ボーナスの額面で予定を立てて、あとでがっかりしたくない。取られたくない。**

欲求マップの **A(取られたくない)**。場面は「支給の内示・明細を見た」。

## 場面

**ボーナスの支給額を聞いて、使い道を考え始めたところ。**
振り込みの当日に「思ったより少ない」となるのが毎回だが、
いくら引かれるのかを事前に計算したことはない。

## 視聴後に決められること

**支給額に0.78をかけて手取りを出し、その額で使い道の予算を決める。**
50万円と聞いたら39万円で計画を立てる。

## この動画が答える問い(1つだけ)

**ボーナス50万円のうち、手元に来るのはいくらか。**

- **視聴者の予想**: 「税金で1割くらい減るんでしょ」
- **この動画の結論**: 「手取りは **39万1709円**。**10万8291円** が消える。
  先に引かれるのは税ではなく**社会保険料の7万3450円**。
  ただし**住民税はボーナスからは引かれない**(毎月の給料から引かれている)」

## 鎖(1本だけ)

```
ボーナス50万円
  社会保険料 14.69% = 73,450円 が先に引かれる
  残り 426,550円 に所得税(この例では8.168%)= 34,841円
  手取り = 500,000 − 73,450 − 34,841 = 391,709円
  消えるのは 108,291円(約2割)
  住民税はここからは引かれない(前年分を毎月の給料から払っている)
```

種になる数字は **50万円** ひとつ。

## 想定視聴者(JTBD: 状況と用事)

- **P-A(ボーナスのある会社員)**。支給額は知らされたが、手取りを計算していない。
- **用事**: 使える額を確定させて、買い物・旅行・返済の予算を立てたい。

## 指を止める理由

**「手取りはいくら?」**は、支給日が近い人がまさに知りたい問い。
答えが **39万1709円** の1つの数字で、自分の額面にもだいたい0.78をかければ移せる。

## 視聴後に得るもの

**住民税がボーナスから引かれない**ことが分かる。
「ボーナスは税金が重い」という思い込みが、内訳つきで置き換わる。

## S018(昇給1万円)との違い

S018 は「**毎月の昇給**の増えた分がいくら残るか」。
この動画は「**年2回のボーナス**が一度にいくら引かれるか」と「住民税は引かれない」。
額の大きさと、住民税の有無が違う。

## コンプライアンス(戦略§6)

- 率は**2026年度・東京・40歳未満**の前提。所得税率は前月給与で変わることを本編で言う
- 「必ずこうなる」とは言わない
- 「2026年度」を音声でも言う(いま14.69%)
- 介護保険料(40歳以上)は前提から外していることを概要欄に書く

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 73,450円・426,550円・34,841円・391,709円・108,291円を verify.py で再計算
2. **独自の指摘**: 住民税はボーナスから引かれない、という誤解の置き換え
3. **独自の早見表**: 50万円の行き先4行(住民税の行に「0円(給料の側)」を置く)

## 出典

- 賞与の社会保険料率(2026年度・東京・協会けんぽ・40歳未満):
  健康保険4.925% + 子ども子育て支援金0.115% + 厚生年金9.15% + 雇用保険0.5% = 14.69%
- 賞与の所得税は「前月の社会保険料控除後の給与」で税率が決まる。この例では8.168%と仮定
- 住民税は前年所得に対する税で、毎月の給与から特別徴収される(賞与からは引かれない)
  — 社会保険労務士事務所・会計ソフト各社の公表資料で一致(確認日 2026-08-19)
- 確度: 社会保険料率は **A**。所得税率8.168%は **B**(前月給与によって変わる仮定)
