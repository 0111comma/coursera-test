# 台本(ショート): 年金は、何歳まで生きたら元が取れるのか

- **調声・構成**: render.pyが正(共通シーンはproduction/scenes_common.py)

## ネタ選定ゲート(プレイブックF1)

- **視聴者の予想**: 「払った分ぐらいは返ってくるでしょ」
- **この動画の結論**: 「**75歳まで生きないと払い損**。年金は積み立てではなく、長生きしすぎた時のための保険」

## 構成の意図

- 入口は「年金」。全員が払っている物なので、投資に興味がない人でも他人事にならない(persona.md P-0 / プレイブックF5)
- 主役は「払った山」と「もらった山」がどこで並ぶか。左右の棒を**同じ縮尺**で並べ、
  右が伸びて左に届く瞬間を「ここで追いついた」と示す
- 1文につき新しい数字は1つ。1万7920円 → 40年 → 860万円 → 7万608円 → 85万円 → 10年 → 75歳 と1段ずつ積む
- 「払うな」とは言わない。締めは「年金は貯金ではなく保険」という見方の変更に着地させる

## ナレーション全文

年金って、払った分は返ってくるのか。
その年金には、2つの種類があるのだ。
まずは自分で払う、国民年金で見るのだ。
その保険料は、いま月1万7920円。
これを20歳から、60歳になるまで払う。
つまり40年間、払い続けることになる。
その40年ぶんの合計は、860万円。
では65歳から、いくらもらえるのか。
その額は、多い人で月7万608円。
ただしこれは、1度も抜けずに払った人の額。
その額を年に直すと、およそ85万円。
860万円を85万円で割ると、10年。
つまり75歳で、払った分に届く。
その75歳より長生きすると、どうなる?
その場合、男性の平均寿命は81歳。
そこまで生きれば、525万円の得。
でも早く亡くなれば、払い損なのだ。
だから年金は、貯金ではないのだ。
長生きしすぎた時の、保険なのだ。

(19ユニット)

## 概要欄テキスト

「年金は払った分だけ返ってくるのか」を、実際の金額で計算しました。
・自分で払う人(国民年金)の保険料は、2026年度で月17,920円
・20歳から60歳までの40年間で、合計8,601,600円(約860万円)
・65歳から受け取る老齢基礎年金は、満額で月70,608円。1年で847,296円(約85万円)
・8,601,600 ÷ 847,296 = 10.15年。つまり65歳+約10年2ヶ月=**75歳ごろ**で払った分に届きます
・男性の平均寿命81.35歳まで生きると、そこから6.2年ぶんで約525万円のプラス
・女性の平均寿命87.33歳なら、約1030万円のプラスになります
・逆に早く亡くなれば、払った額を下回ります。年金は積み立てではなく、長生きした場合に備える保険の仕組みです
・保険料も年金額も毎年改定されます。この計算は2026年度の金額がずっと続いた場合の単純計算です
・会社員(厚生年金)は保険料の半分を会社が払うため、条件が異なります
・老齢年金のほかに障害年金・遺族年金もあり、これらは損得の計算には入っていません
・動画内の数値はすべて verify.py で再計算しています
あなたは何歳まで生きるつもりですか?コメントで教えてください。
