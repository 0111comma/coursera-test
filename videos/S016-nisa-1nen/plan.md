# 企画書: 積立を1年おくらせると、いくら損するのか(S016)

- **公開予定**: 2026-08-21(金)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

積立、1年おくらせるといくら損する?

## この人の欲求

**先延ばしで損をしたくない。「来年でいいや」がいくらの値段なのかを知りたい。**

欲求マップの **A(取られたくない)** と **C(無駄にしたくない)** の重なり。
失っているのは財布の中身ではなく、**増えるはずだった分**。

### 作り直しの経緯(ループ71のユーザー指摘)

前の版は「つみたて投資枠は月10万円が上限」だった。

> 「意味わからん。こんなものを作れと言った覚えはない。全部作り直して」

**診断: 答えを制度から借りていた。**
月10万円も年360万円も、公式サイトに書いてある数値を読み上げているだけで、
視聴者が自分では出さない数字ではなかった。問いの形だけ整えても、
答えが「調べれば出てくる事実」なら「だから何」で終わる。

実測の上位はすべて**計算しないと出ない数字**が答えだった。

| 上位 | 答えの正体 |
|---|---|
| S005 79.2% | なぜ実質2000円 — 仕組みを金額に変換した結果 |
| S001 77.8% | 月1万円の積立は意味ない? — 20年後の金額 |
| S003 64.1% | 1800万は何年で埋まる? — 割り算の結果 |
| S011(ユーザー評価) | 年金は何歳で元が取れる? — 割り算の結果 |

**この動画から、企画の条件に一行足す。**
> 答えは、視聴者が自分では出さない計算の結果であること。
> 制度に書いてある数値をそのまま答えにしない。

## 場面

**「積立、そのうち始めよう」と思ったまま何ヶ月か経っている。**
証券口座は作ったが、積立の設定をしていない。
あるいは設定はしたが、増額をずっと先延ばしにしている。

## 視聴後に決められること

**今月ぶんから始めるか、来年からにするかを決められる。**
先延ばし1年ぶんの値段が95万円という1つの数字で出るので、その場で比べられる。

## この動画が答える問い(1つだけ)

**1年おくらせると、20年後の金額はいくら変わるのか。**

- **視聴者の予想**: 「1年ぶんだから、積み立てた36万円ぶん少ないだけでしょ」
- **この動画の結論**: 「**差は95万円。** 出したお金の差は36万円だけで、
  **残りの59万円は増えるはずだった分**。待っただけで消える。
  しかもNISAならその差に税金がかからないので、ふつうの口座より差が大きい」

## 鎖(1本だけ)

```
毎月3万円 / 年5%と仮定
  20年つづける → 1233万円
  1年おくらせて19年 → 1138万円
  差 95万円
    うち 出したお金の差 36万円(= 3万円 × 12ヶ月)
       増えるはずだった分 59万円
  毎月1万円の人なら、差はおよそ32万円
```

種になる数字は **月3万円と年5%** の2つだけ。あとは全部そこから出る。

## 想定視聴者(JTBD: 状況と用事)

- **P-A(積立を始めようとして止まっている人)**。口座はある。設定をしていない。
  「もう少し勉強してから」「ボーナスが出てから」と思っている。
- **用事**: 先延ばしの値段を知って、今月から出すかどうかを決めたい。

## 指を止める理由

**「1年おくらせるといくら損する?」**は、いま自分がやっている先延ばしそのものへの問い。
答えが **95万円** という1つの数字なので、その場で自分の判断に使える。

## 視聴後に得るもの

差の**6割が「増えるはずだった分」**だと分かる。
つまり失っているのは積立額ではなく時間だと分かるので、
「まとめて後から入れれば取り戻せる」という思い込みが崩れる。

## コンプライアンス(戦略§6)

- **年5%は仮定**とバッジ・ナレーション・早見表の3か所で明示する。増える保証はない
- 「必ず増える」「儲かる」を使わない。言うのは**仮定のとおりなら差はこうなる**という計算だけ
- 個別の銘柄・投資信託・証券会社を出さない
- 「2026年8月時点」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 1233万・1138万・95万・36万・59万・32万をすべて verify.py で再計算
2. **独自の分解**: 差を「出したお金の差」と「増えるはずだった分」に割る見せ方
3. **複数パターン比較**: 月3万円の人と月1万円の人

## 出典

- 積立の計算は毎月末払いの年金終価の式。利回りは年5%と仮定(自前計算)
- NISA口座の運用益は非課税。課税口座の税率は20.315%
  (所得税15% + 復興特別所得税0.315% + 住民税5%)。2026年8月時点
- 注記: 官公庁サイトはこの環境のネットワークポリシーで遮断されているため、
  制度の確認は検索索引と金融機関の公表資料経由。**金額はすべて verify.py の自前計算**
- 確度: 計算そのものは **A**(自前計算・再現可能)。年5%という仮定は **C**(あくまで仮定)
