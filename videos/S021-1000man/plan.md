# 企画書: 貯金1000万円、月いくらで届くのか(S021)

- **公開予定**: 2026-09-08(火)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

貯金1000万円、月いくらで届く?

## この人の欲求

**1000万円は貯めたい。でも毎月いくら出せばいいのかが分からない。選び方を間違えたくない。**

欲求マップの **B(大きな選択を間違えたくない)**。
B の note のとおり、**判定を1つの数字に落とす**。ここでは月4万円と月2万4300円。

## 場面

**「1000万円貯めたい」と思ったが、毎月の金額に落としたことがない。**
給与振込の口座にそのまま置いていて、金利を見たこともない。
目標額だけがあって、逆算ができていない。

## 視聴後に決められること

**毎月出せる額から、預金だけで届くのか、増やす前提が要るのかを決められる。**
月4万円が出せるなら預金だけで届く。出せないなら、その差を埋める方法を考える必要がある。

## この動画が答える問い(1つだけ)

**1000万円を20年で貯めるには、毎月いくら要るのか。**

- **視聴者の予想**: 「1000万円 ÷ 240ヶ月 = 月4万2000円くらいでしょ」
- **この動画の結論**: 「**預金だけなら月4万円。** 年5%と仮定して増やすなら **月2万4300円**。
  差は **月1万5700円**、20年で **377万円**。
  受け取る額はどちらも1000万円だが、**出すお金が961万円と584万円**で違う」

## 鎖(1本だけ)

```
目標 1000万円 / 20年(240ヶ月)
  預金 年0.4%と仮定 → 毎月 40,029円 ≒ 月4万円 → 20年で出すお金 961万円
  運用 年5%と仮定   → 毎月 24,329円 ≒ 月2万4300円 → 20年で出すお金 584万円
  毎月の差 15,700円 / 20年ぶんの差 377万円
  受け取る額は、どちらも1000万円
```

種になる数字は **1000万円と20年** の2つだけ。

## 想定視聴者(JTBD: 状況と用事)

- **P-B(貯金はしているが、目標を毎月の金額に落としていない人)**。
  ボーナスで貯める・余ったら貯める、というやり方をしている。
- **用事**: 毎月いくら出せば目標に届くのかを知りたい。

## 指を止める理由

**「月いくらで届く?」**という、目標を毎月の金額に翻訳する問い。
答えが **月4万円** という1つの数字なので、自分に出せるかどうかがその場で分かる。

## 視聴後に得るもの

**同じ1000万円でも、出すお金が961万円と584万円で違う**と分かる。
つまり足りないのは金額ではなく、増える力だと分かる。

## コンプライアンス(戦略§6)

- **年5%は仮定**とバッジ・ナレーション・早見表の3か所で明示する。増える保証はない
- **「預金なら減らない」ことも本編で言う。** 片側だけを良く見せない
- 個別の銘柄・投資信託・証券会社・銀行を出さない
- 「必ず増える」「儲かる」を使わない
- 「2026年8月時点」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 月4万円・月2万4300円・月1万5700円・377万円・961万円・584万円を verify.py で再計算
2. **独自の逆算**: 目標額から毎月の金額を出す向き(ふつうは積立額から将来額を出す)
3. **独自の早見表**: 出すお金の総額を並べて、受け取る額が同じことを見せる

## S001・S016 との違い

- S001(公開済み・77.8%)は「月1万円を積み立てたら20年後いくら」= **積立額 → 将来額**
- S016 は「1年おくらせるといくら損する」= **時間の値段**
- この動画は「1000万円に届くには月いくら」= **将来額 → 積立額**。向きが逆

## 出典

- 計算は毎月末払いの年金終価の式を、目標額から逆算したもの(自前計算)
- 預金の金利 年0.4% は 2026年8月時点のネット銀行の水準を仮定として置いた
- 確度: 計算そのものは **A**(自前計算・再現可能)。年5%と年0.4%はいずれも **C**(仮定)
