# 企画書: ふるさと納税の2000円は何回払うのか(S020)

- **公開予定**: 2026-09-04(金)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

ふるさと納税の2000円、何回払うの?

## この人の欲求

**せっかくやるなら、いちばん得な使い方をしたい。無駄にしたくない。**

欲求マップの **C(無駄にしたくない)**。すでにやっている人が対象。

## 場面

**ふるさと納税をやろうとして、寄付先を選んでいる。**
「2000円は寄付するたびにかかるはずだから、1か所にまとめよう」と思っている。
返礼品を複数選ぶと自己負担が増えると誤解している。

## 視聴後に決められること

**寄付先を1か所にまとめるか、上限まで複数に分けるかを決められる。**
自己負担が年1回だけと分かるので、分ける手間と得の大きさを比べられる。

## この動画が答える問い(1つだけ)

**自己負担2000円は、寄付するたびに払うのか。**

- **視聴者の予想**: 「寄付するたびに2000円かかるでしょ」
- **この動画の結論**: 「**年に1回だけ。** 自治体の数は関係ない。
  1か所に1万円だと残るのは1000円ぶんだが、10か所に1万円ずつなら **2万8000円ぶん**。
  1万円あたりの負担は **2000円から200円** まで下がる」

## 鎖(1本だけ)

```
1か所に1万円 → 返礼品3000円ぶん − 自己負担2000円 = 残るのは1000円ぶん
10か所に1万円ずつ(合計10万円) → 返礼品3万円ぶん − 自己負担2000円 = 残るのは2万8000円ぶん
  自己負担は年に1回だけなので、1万円あたりの負担は 2000円 → 200円
  ただし上限を超えた分は税から引かれず、まるごと自腹になる
```

種になる数字は **自己負担2000円** ひとつ。

## 想定視聴者(JTBD: 状況と用事)

- **P-A(ふるさと納税を1回はやったことがある人)**。
  自己負担が寄付ごとにかかると思っていて、1か所にまとめている。
- **用事**: 寄付先を分けるべきかどうかを決めたい。

## 指を止める理由

**「2000円、何回払うの?」**は、やったことがある人ほど確かめたくなる問い。
答えが **年1回** という一言で、しかも金額の差が2万7000円ぶん出る。

## 視聴後に得るもの

自己負担が**寄付の回数ではなく年単位**だと分かる。
だから「まとめたほうが安い」という思い込みが消える。

## コンプライアンス(戦略§6)

- **上限を超えた分は自腹**になることを本編で必ず言う
- 特定の自治体・返礼品・仲介サイトを出さない
- 上限は年収・家族構成・他の控除で変わることを早見表の注記に入れる
- 「2026年8月時点の制度です」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 3000円・1000円・3万円・2万8000円・200円をすべて verify.py で再計算
2. **独自の見せ方**: 1万円あたりの自己負担が 2000円 → 200円 に薄まる形にした
3. **独自の早見表**: 1か所/10か所/自分で払う額/上限超過の4行

## S005・S017 との違い

- S005(公開済み・79.2%)は「**なぜ実質2000円なのか**」= 仕組み
- S017 は「**やらない人が1年でいくら取り逃がすか**」= やらない側の値段
- この動画は「**2000円は何回かかるのか**」= やる人の**分け方**の話。3本とも payload が違う

## 出典

- 自己負担2000円は寄付する自治体の数や返礼品の数によらず一律(年間の合計にかかる)
  — 仲介大手および金融機関の公表資料で一致(確認日 2026-08-18)
- 返礼品は寄付額の3割まで(総務省の3割基準。2026年8月時点で維持)
- ワンストップ特例は年5自治体まで(6か所以上なら確定申告が要る)
- 注記: 官公庁サイトはこの環境のネットワークポリシーで遮断されているため、
  内容の確認は検索索引と民間の公表資料経由。**金額はすべて verify.py の自前計算**
- 確度: 自己負担の一律性と3割基準は **A**(複数の独立資料で一致)
