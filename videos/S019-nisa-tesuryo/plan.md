# 企画書: 積立の手数料、20年でいくら取られるのか(S019)

- **公開予定**: 2026-09-01(月)
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

積立の手数料、20年でいくら取られる?

## この人の欲求

**知らないうちに引かれるのが嫌だ。手数料で取られたくない。**

欲求マップの **A(取られたくない)**。
明細に出てこないぶん、住民税や社会保険料よりも気づきにくい。

## 場面

**積立の商品を選んでいる、あるいはもう積み立てている。**
商品一覧に「手数料 年0.1%」「年1.0%」と並んでいるが、
どちらも小さい数字に見えるので、そこで比べたことがない。

## 視聴後に決められること

**いま持っている商品の手数料を確かめ、1%を超えていたら乗り換えるか決められる。**
0.9%の差が20年で119万円になると分かるので、手間と釣り合うかを比べられる。

## この動画が答える問い(1つだけ)

**手数料が年0.1%と年1.0%で、20年後にいくら違うのか。**

- **視聴者の予想**: 「1%くらい、大した差じゃないでしょ」
- **この動画の結論**: 「**差は119万円。** しかも**1年目の差はたった1522円**なので、
  途中では気づかない。出したお金はどちらも720万円で同じ」

## 鎖(1本だけ)

```
毎月3万円 / 20年 / 年5%と仮定
  手数料 年0.1% → 実際に増えるのは 4.9% → 1219万円
  手数料 年1.0% → 実際に増えるのは 4.0% → 1100万円
  差 119万円(出したお金はどちらも720万円)
  1年目だけの差 = 1522円 ← 気づかない理由
```

種になる数字は **手数料の差 0.9%** ひとつ。

## 想定視聴者(JTBD: 状況と用事)

- **P-A(すでに積み立てている人、または商品を選んでいる人)**。
  商品の一覧を見ているが、手数料の欄を判断に使ったことがない。
- **用事**: 手数料の差が判断に値するのかを、金額で知りたい。

## 指を止める理由

**「20年でいくら取られる?」**という、取られる側からの問い。
答えが **119万円** という1つの数字で、しかも
**1年目は1522円しか違わない**という落差が意外性になる。

## 視聴後に得るもの

**気づけない理由**が分かる。手数料は明細に出ず、1年目の差は1522円しかない。
だから「小さいから無視してよい」ではなく「小さいから確かめないと分からない」に変わる。

## コンプライアンス(戦略§6)

- **特定の投資信託・運用会社・証券会社を出さない。** 0.1%と1.0%は水準の例
- 年5%は仮定とバッジ・ナレーション・早見表の3か所で明示する
- 「安いほうが必ず得」とは言わない。言うのは**同じ増え方なら差はこうなる**という計算だけ
- 「2026年8月時点」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 1219万・1100万・119万・720万・1522円をすべて verify.py で再計算
2. **独自の対比**: 20年の差(119万円)と1年目の差(1522円)を並べて、気づけない理由を出す
3. **独自の早見表**: 手数料の差・1年目・20年後・出したお金の4行

## 出典

- 積立の計算は毎月末払いの年金終価の式。増える率は年5%と仮定(自前計算)
- 手数料(信託報酬)は残高から日々差し引かれるため、実際に増える率は「利回り − 手数料」になる
- 注記: 特定の商品を指すものではない。0.1%・1.0%はいずれも実在する水準の例として置いた
- 確度: 計算そのものは **A**(自前計算・再現可能)。年5%という仮定は **C**
