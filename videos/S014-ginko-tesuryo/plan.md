# 企画書: 100万円の利息より、ATM手数料のほうが多い(S014)

基準作 S011「年金は何歳で元が取れるのか」の8行(プレイブック末尾)を埋めてから作った。

## 基準作S011との照合(8行すべて埋まること)

| 要素 | S014での中身 |
|---|---|
| 入口(F5) | 「銀行」= 口座を持っていない人がいない。専門語ではない |
| 予想との食い違い(F1) | 「金利が34年ぶりに上がったなら増えるでしょ」→ 手数料のほうが多い(逆転) |
| オチ(F3) | 実害(1年で773円のマイナス)+ 見方の変更(金利は選べないが手数料は選べる) |
| 主語(F4) | 自分の普通預金と、自分が押しているATMのボタン |
| 丁寧さ(G1〜G4) | 18ユニット・推定55秒。1文につき新しい数字は1つ。棒は1本ずつ足す |
| 図 | 利息の棒と手数料の棒を**同じ縮尺**で並べ、手取りの高さに引いた線を越えさせる |
| 数字 | 金利・手数料の水準のみ検索で確認 → 金額は verify.py で自前計算 |
| 締め | 特定の銀行をすすめない。「無料の回数を見る」という行動に着地 |

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-0。この動画を選んでいない。投資にもお金の勉強にも興味がない。
  ただし**銀行口座とATM**は全員が持っている。「金利が上がった」というニュースは
  聞いたことがあるが、自分の口座でいくらになるのかは知らない。
- **指を止める理由**: 「銀行に100万円。1年でつく利息は3187円」。
  100万円という大きな額と、3187円という小さな額の落差が1文目で成立している。
- **視聴後に得るもの**: 自分の預金にいくら利息がつくのか、そこから税金がいくら引かれるのか、
  そして**同じ1年でATM手数料をいくら払っているのか**が、金額で比べられるようになる。
- **視聴者の予想**: 「金利が34年ぶりに上がったんだから、置いておけば増えるでしょ」
- **この動画の結論**: 「1年の利息は税引き後で**3187円**。一方、時間外のコンビニATMを
  月1回使うだけで年**3960円**。**手数料のほうが多い**。
  金利は自分で選べないが、手数料の無料回数は自分で選べる」

## 図の型(figure-forms.md)

| ビート | メッセージの型 | 図の型 |
|---|---|---|
| 利息と税金 | 全体の一部が引かれる | 固有シーン zandaka(): 4000円の棒を、税金813円と手取り3187円に分ける |
| 使う回数 | 積み上がっている | 同じ大きさのブロック12個(1個=1回) |
| 利息と手数料 | 二者の量が違う | 同じ zandaka() に2本目を足す。手取りの高さの線を越えるかで見せる |

## 数値の根拠

verify.py 参照。

| 項目 | 計算 | 額 |
|---|---|---|
| 1年の利息(税引前) | 1,000,000 × 0.4% | 4,000円 |
| 税金 | 4,000 × 20.315%(所得税15.315%+住民税5%) | 813円 |
| 手取り | 4,000 − 813 | **3,187円** |
| ATM手数料 | 330円 × 12回(月1回) | **3,960円** |
| 差 | 3,960 − 3,187 | 773円 手数料のほうが多い |

参考: 月2回なら7,920円。金利が0.001%だった頃の利息は税引前で年10円。

## 出典

- 普通預金金利: 3メガバンクが2026年8月3日から年0.4%(6月16日発表。旧行時代の
  1992年8月以来およそ34年ぶりの水準)
- コンビニATM手数料: 大手行の時間外(平日夜・土日祝)で1回330円の水準
- 利息の源泉徴収税率: 所得税15.315%+住民税5%=20.315%
- 確認日 2026-08-16
- 注記: 官公庁・金融機関サイトはこの環境のネットワークポリシーで遮断されているため、
  金利・手数料の水準確認は検索索引経由。**金額の計算はすべて verify.py の自前計算**。

## コンプライアンス(戦略§6)

- 特定の銀行名を出さない・すすめない(「大手3行」「大手行の時間外の水準」まで)
- ネット銀行への乗り換えをすすめない。「無料の回数は銀行ごとに違うので自分の口座を見る」まで
- 金利も手数料も改定される。「2026年8月時点」をバッジと概要欄に明示
- 「預金するな」「投資しろ」とは言わない。締めは「増やす前に、減らすのを止める」に着地
- 利息は年2回に分けて支払われ、そのつど1円未満を切り捨てるため、実際の年間税額は
  この単純計算と1円ほどずれることがある旨を概要欄に記載
