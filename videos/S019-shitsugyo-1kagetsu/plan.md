# 企画書: 会社を辞めてから、失業手当が出るまでの空白が短くなった(S019)

## この人の欲求

**辞めたい。でも、収入が無い期間が怖い。その不安を減らしたい。**

欲求マップの **D(不安を減らしたい)**。
「雇用保険とは」ではなく、**辞めるかどうか迷っている人**に向ける。

## 視聴後に決められること

**辞めたあと収入が無い期間が何ヶ月かを出して、辞める時期を決められる。**

## この動画が答える問い(1つだけ)

**自己都合で辞めたら、失業手当が出るまで何ヶ月空くのか。**

答え: **2025年4月から、給付制限が2ヶ月 → 1ヶ月に短くなった。**
待期7日 + 給付制限1ヶ月。空白がひと月ぶん縮んだ。

- **ID**: S019
- **形式**: ショート(〜60秒)
- **コンテンツピラー**: 制度改正ニュース
- **ステータス**: 企画中
- **作成日**: 2026-08-18

## 場面(いつ、この人はこれに出会うか)

辞めようか迷っているとき。
「自己都合だと3ヶ月出ない」と昔の知識で思い込んで、動けないでいる。

## 既公開との重なり

雇用保険・失業手当はこれまで1本も作っていない。**完全に新しい領域**。
S018(傷病手当金)とは「働けないときの収入」で隣接するが、
**病気で休む**話と**辞める**話で場面が違う。

## 鎖(1本だけ)

```
自己都合で退職
  → 待期 7日        (これは誰でも同じ)
  → 給付制限 1ヶ月   (2025年3月までは2ヶ月だった)
  → 合計 約1ヶ月と7日 で受給が始まる
ただし 初回の振込までは、手続きから おおむね1ヶ月半〜2ヶ月
```

種になる数字は **1ヶ月** ひとつ。

## 独自性要素(戦略§8 — 2つ以上)

1. **独自の図**: 退職日を起点にした時間の帯。旧ルール(2ヶ月)と新ルール(1ヶ月)を上下で比較
2. **複数パターン比較**: 自己都合(待期7日+1ヶ月)と会社都合(待期7日のみ)の対比
3. **例外まで出す**: 5年以内に3回以上の自己都合退職は3ヶ月に戻る

## コンプライアンス(戦略§6)

- **「辞めろ」とも「辞めるな」とも言わない。** 期間の事実だけを渡す
- 転職エージェント・退職代行など特定のサービスを出さない
- **給付制限と、実際の初回振込までの日数は別**であることを明示する
  (手続き・認定日があるので、1ヶ月経った翌日に振り込まれるわけではない)
- 受給には**被保険者期間の要件**(自己都合は原則、離職前2年間に12ヶ月以上)があることを注記
- 5年以内に3回以上の自己都合退職は3ヶ月になる例外を明示する
- 「2026年8月時点の制度です」を入れる

## 出典

- 2025年4月1日以降の離職から、自己都合退職の給付制限が原則2ヶ月 → 1ヶ月に短縮
- 待期期間7日はそのまま
- 5年以内に3回以上の自己都合退職は給付制限3ヶ月
- 離職期間中などに教育訓練を受けた場合は給付制限が解除される
- 手続きから初回振込までは、おおむね1ヶ月半〜2ヶ月
  — 社労士事務所の解説複数 / 就職支援サイトで一致(確認日 2026-08-18)
- 確度: 制度の内容は**A**(改正の施行日と期間が複数の独立ソースで一致)。
  初回振込までの日数は**B**(実務の目安で、地域と認定日で変わる)
