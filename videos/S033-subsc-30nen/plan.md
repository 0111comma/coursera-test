## 1. この人の欲求

**知らないうちに、毎月勝手に引かれているものを止めたい。**

`docs/research/yokkyu-map.md` の **A(取られたくない)**。いちばん強い欲求。

**煽らない。**「あなたは損している」ではなく、**止めたときに何が返ってくるか**を出す。

## 2. 場面

**カードの明細に、契約した覚えが薄いサブスクが並んでいる。**

- 動画配信は30代の46.2%が使っている(LINEリサーチ 2025年10月)
- 一つひとつは千円台なので、**合計を見たことがない**

## 3. 想定視聴者

**P-M: 35歳・男性・普通の会社員。手取り25〜35万円。**

この人は**3つとも契約している可能性が高い**。そして合計額を知らない。

## 4. 最初の一言(問い)

**サブスク3つで、月いくら?**

## 5. 指を止める理由

**カバー(1フレーム目)にサービス名(Netflix・Spotify・プライム)が出る。**
自分の明細にある名前なので、「114万円」が他人事の概算ではなく
**自分の3つを足して掛けた数字**だと分かる。そして自分は合計を見たことがない。
(2026-08-29: カバーは「名指し3チップ+あなたも30年払う?+114万円」の損失枠に統一。
サービス名は72pxタイルでも読めるよう下帯の白チップ3枚で出す。
263万円・90万円はカバーに出さず、動画内の転回に取っておく)

## 6. 視聴後に得るもの

**「千円ちょっと」を3つ持つと、30年でいくらになるかが分かる。**
1日あたり105円。35歳から65歳までの30年で **114万円**。
同じ額を積んだ場合、年5%と仮定すると **263万円**。

## 7. 視聴後に決められること

**今日、明細を開いて、使っていないものを1つ止める。**

「全部やめろ」ではない。**1つ**と数を決めているので、その場で動ける。
金額は人それぞれなので、**式(月額 × 360か月)を1枚で出す**。

**1つ(1080円)止めるだけでも、出したお金は約39万円、年5%と仮定して約90万円。**

「千円ちょっとを3つ」という感覚と食い違う。

## 10. 前提と根拠

**料金は調べた値。ただし確度Bで、一次資料を開けていない。**

この実行環境は egress proxy が**全ドメインを遮断**していて(2026-08-24確認。
`.go.jp` も `help.netflix.com` も `www.amazon.co.jp` も403)、
公式の料金ページを開いて確かめられない。検索スニペットの突き合わせまで。

**焼く前にユーザーの環境で料金を確認すること。**

| 値 | 根拠 | 出典(確認日 2026-08-24) |
|---|---|---|
| 1590円 | Netflix スタンダード。2026年5月時点で変更なし | https://www.pricey.jp/web/articles/4050 (2026-08-24確認・確度B) |
| 1080円 | Spotify Premium。**980円説もあり割れている。要確認** | https://musicfab.dvdfab.org/general/spotify-vs-youtube-music.htm (2026-08-24確認・確度B) |
| 492円 | Amazonプライム 年5900円 ÷ 12。2023年8月改定 | https://tmubl.jp/column/amazon-prime-price/ (2026-08-24確認・確度B) |
| 3000円未満が6割台半ば | LINEリサーチ 2025年10月・15〜69歳・n=3148。この分布と積み上げ3162円が一致 | https://prtimes.jp/main/html/rd/p/000001498.000129774.html (2026-08-24確認・確度B) |
| 35歳・65歳 | 35歳が対象で、65歳まで積むと**仮定**した | (仮定。docs/persona.md の P-M。制度の数値ではない) |
| 年5% | 積んだ場合の利回り。**仮定**であって約束ではない | (仮定。元本保証ではなく、減る年もある) |

**利回りは仮定なので、0%(ただ貯めるだけ=114万円)を必ず並べて出す。**

## 11. 数値(verify.py で検証済み)

```
1590 + 1080 + 492      = 3162円/月
3162 ÷ 30日            = 1日105円
月1回 × 360か月         = 360回(35歳→65歳に払う回数)
3162 × 360か月(30年)  = 113万8320円 → 「114万円」
ただ貯めるだけ           = 114万円
年3%で運用(仮定)       = 184万円
年5%で運用(仮定)       = 263万円
1つ(1080円)だけ止める = 出したお金 約39万円 / 年5%仮定で 約90万円
```
