## 2026-08-30 厳格審査(craft / consistency / retention / artdirection /
## thumbnail / kousei / nihongo / copy)での全面改稿

**動画の問いを「合計はいくらか(既知)」から「どれを止めるか(未知・行動)」へ移した。**
カバーが0秒目に114万円を出しているのに、旧 unit1 は「サブスク3つで、月いくら?」と
別の問いから始まっていた。視聴者は答えを知った状態で、10ユニット(推定24秒)かけて
その答えに追いつかされ、第1幕の全部がサムネの答え合わせになっていた。

**表を4カット連続で出すのをやめた**(旧 01〜04 は同一グリッド・同一値で12.8秒。
カット境界の図の変化画素が 4.21%/6.02%/3.93% で、視聴者には1カットだった)。
いまは 表 → hero(合計)→ 表 と**1カットおきに構図が変わる**。
合計3,162円は3ユニット目(推定6秒)で出る。

**缶コーヒーとの比較カットを削除した。**「105円 < 缶コーヒー1本」は
「缶コーヒー1本は105円より高い」という価格の主張だが、plan §10 の前提表にも
verify.py にも缶コーヒーの値が無かった。記号で言い換えても
CLAUDE.md の最優先ゲート(説明していない数字を出さない)の違反は消えない。
代わりに「なぜ30年止めなかったのか」を**行動**で言う(「105円では、わざわざ解約しない。」)。
視聴者の内心を断定で代弁しない。

**「止めるだけで確定する額」を声に出した。**この動画が求める行動は「止める」だけで、
「積む」は求めていない。行動と直結する唯一の額(1つ止めれば出ていかない約39万円)が
言葉になっておらず、行動の見返りが全部「仮定つきの90万円」に寄っていた。

**263万円の条件を回収した。**旧稿は「とはいっても、全部は止められない」で前提を
崩すだけで、263万円が「3つ全部を止めた場合の話」であることを一度も言わなかった。

**決定に判定基準を入れた。**「使っていない1つ」は、どれが使っていないかを
視聴者が既に知っている前提の書き方だった。「先月ひらかなかった1つ」なら、
視聴中にその場で対象を特定できる。

**特定サービスの単独強調をやめた**(plan §13.3)。旧 hyo_1 は「使っていない1つ」の
見出しの下で Spotify 行だけを緑リングで強調していて、声が選択権を視聴者に
渡しているのに絵が断定していた。

**カバーを2ブロックにした。**下段のチップ3枚・ティーザー・免責は、72pxタイルに
換算した実測 ink 高が 2.6〜3.9px(トップの下限は8px)で、画面高の32%を使いながら
「開く理由」を運んでいなかった。いまは 赤=114万円(既知)/ 緑=2??万円(未知)の
非対称だけを置く。立ち絵は 04_surprised(困り顔では赤い114万円の振幅に届かない)。

**字幕を墨プレートの上の白文字にした。**白 #ffffff とクリーム地 #f3e7d3 の
コントラスト比は 1.22:1 で、字形を作っていたのは7pxの茶縁だけだった。
画数の多い字(開・細・積)は内白が縁に食われて塊になっていた。
プレートなら地とのCRが12:1になり、縁も疑似影も要らない。
**強調は色ではなく役割色の下線**にした(#7ac043 はパレット中で唯一の
高彩度ライムで、1カットにしか出ない第4の色だった)。

## 概要欄テキスト

Netflix・Spotify・Amazonプライムの3つを持つと、月3162円。
35歳から65歳までの30年で、いくらになるのかを計算しました。

■ 内訳(2026年8月時点)
Netflix スタンダード  1,590円/月
Spotify Premium      1,080円/月
Amazonプライム        年5,900円(月あたり492円)
合計                 3,162円/月 = 1日あたり105円

■ 35歳から65歳まで(360か月)
出ていくお金          1,138,320円
同じ額を積んだ場合(いずれも仮定):
  運用しない          1,138,320円
  年3%で運用          1,842,614円
  年5%で運用          2,631,602円

■ 1つ(1,080円)だけ止めた場合
出したお金            388,800円(約39万円)
年5%で運用(仮定)    898,839円(約90万円)

■ 持ち帰る式
月額 × 360か月 = 30年で出ていく額

## サムネAB(投稿後に検証する項目)

現行(B案): 墨帯フック「止めない3つ / 30年で?」+ 赤「止めなければ 114万円」
+ 緑「積んでいたら 2??万円」+ 04_surprised(下端までブリード)。

- **伏せ方**: 現行「2??万円」(桁だけ見せる) vs 「?万円」(完全に伏せる) vs
  「+149万円」(差だけ見せる)。**114万円は既知・もう片方が未知**という非対称が
  作れているかで比べる。どの案でも数字は verify.py 由来のものだけにする
  (114万円=PRINCIPAL / 263万円=FV5 / 差=149万円)
- **フックの文言**: 現行「止めない3つ / 30年で?」(指示語なし・中核動詞あり) vs
  「サブスク3つ / 30年で?」(対象を名指す)。前者は本編の決定語と一致し、
  後者はカテゴリが一目で分かる
- **立ち絵**: 04_surprised(現行) vs 03_troubled。赤い114万円が要求する
  衝撃の振幅に困り顔が届くかを見る
- A案(数字だけの1文)は check_hold の H1(カバーの主役テキストに数字を出すなら
  「?」を含める)に掛かるので採らない
