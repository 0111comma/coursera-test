## 直すときに1つだけ守ってほしいこと

**合計320〜340字。** 1字が約0.165秒なので、これを外れると尺が合いません。
1ユニットは10〜20字。20字を超えると字幕が画面からはみ出します。

## 出せる数字(これ以外は出さないでください)

すべて計算・検証済みです。

| 数 | 意味 |
|---|---|
| 1590円 / 1080円 / 492円 | Netflix / Spotify / Amazonプライム(年5900円÷12)の月額 |
| 3162円 | 3つの合計 |
| 105円 | 3162 ÷ 30日 |
| 35歳 / 65歳 / 30年 / 360か月 | 積む期間 |
| 114万円 | 3162 × 360 = 1,138,320円 |
| 年5% | **仮定**。必ず「仮定」と言う |
| 263万円 | 3162円を年5%で360か月積んだ場合 = 2,631,602円 |
| 約39万円 / 約90万円 | 1080円の場合(388,800円 / 898,839円) |

## 言ってはいけないこと

- 「儲かる」「必ず」「〜すべき」の断定
- 「買うべき」「おすすめ」などの推奨(**名前を出すのは可**)
- 特定のサービスを名指しで「無駄」と言うこと
- 利回りを断定すること(必ず「仮定」と添える)

## この動画のねらい

- **誰に**: 35歳・男性・普通の会社員
- **どの欲求に**: 知らないうちに毎月引かれているものを止めたい
- **見た人に何をしてほしいか**: 明細を開いて、使っていないものを1つ止める
- **オチ**: 同じお金が、出ていく側と入ってくる側の両方に立つ
