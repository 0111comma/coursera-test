# S033 プロット — 編集用(Gemini へ)

この表の「台詞」の列だけを書き直してください。
書き直したものを、同じ表の形で返してもらえれば、そのまま動画にします。

- **ユニット数は増やしても減らしてもかまいません。**
- 「場面」は各行で映る絵の名前です。台詞を足したときは、
  どの絵に載せたいかを書いてください(既存の名前でも、新しい説明でも可)。

---

## 守ってほしい条件(これだけは物理的な制約です)

| 項目 | 値 | 理由 |
|---|---|---|
| 合計の字数 | **300〜330字** | 1字≒0.165秒。50〜55秒に収まる範囲 |
| ユニット数 | **20以上** | 画面が変わる回数。競合は60秒で34〜37回 |
| 1ユニットの字数 | **10〜20字** | これを超えると字幕が4行になり画面からはみ出す |
| 1行あたり | 句読点で区切って**11字前後** | 字幕の折り返し幅 |

## 出せる数字(これ以外の数字は出さないでください)

すべて `verify.py` で計算・検証済みです。

| 数 | 意味 |
|---|---|
| 1590円 | Netflix スタンダードの月額 |
| 1080円 | Spotify Premium の月額 ※980円説もあり要確認 |
| 492円 | Amazonプライム(年5900円 ÷ 12) |
| **3162円** | 3つの合計(月額) |
| 105円 | 3162円 ÷ 30日 = 1日あたり |
| 35歳 / 65歳 | 対象年齢と、積むのをやめる年齢(どちらも仮定) |
| **360か月** | 35歳→65歳の30年 |
| **114万円** | 3162円 × 360か月 = 1,138,320円 |
| 年5% | 運用の利回り(**仮定**。必ず「仮定」と言う) |
| **263万円** | 3162円を年5%で360か月積んだ場合 = 2,631,602円 |
| 約39万円 | 1080円 × 360か月 = 388,800円 |
| **約90万円** | 1080円を年5%で360か月積んだ場合 = 898,839円 |

## 言ってはいけないこと

1. 「儲かる」「必ず」「〜すべき」などの断定
2. 「この商品を買うべき」のような**推奨**
   (Netflix等の**名前を出すのは可**。禁止なのは推奨と、名指しで「無駄」と言うこと)
3. 利回りを断定すること(必ず「仮定」と添える)

## この動画で伝えたいこと

- **誰に**: 35歳・男性・普通の会社員
- **どの欲求に**: 知らないうちに毎月引かれているものを止めたい
- **見た人に何を決めてほしいか**: 今日、明細を開いて、使っていないものを**1つ**止める
- **オチ**: 1日105円が30年で114万円。止めて積めば、年5%と仮定して263万円。
  **同じお金が、出ていく側と入ってくる側の両方に立つ**
