# 企画書: NISAは売っても、枠がその年には戻らない(S016)

## この人の欲求

**NISAの枠を無駄にしたくない。売ったせいで枠が減るなら、売り方を考えたい。**

欲求マップの **C(無駄にしたくない)**。
「NISAとは」ではなく、**もう積み立てていて、一部を売ろうか迷っている人**に向ける。

## 視聴後に決められること

**売るのを今年にするか、来年にするかを決められる。**
(売る前に、翌年いくら枠が戻るかを自分で出せるようになるため)

## この動画が答える問い(1つだけ)

**NISAで売ったら、枠はいつ、いくら戻るのか。**

答え: **その年には戻らない。翌年に、買った値段のぶんだけ戻る。**
100万円で買って150万円で売っても、戻るのは **100万円ぶん**。

## 場面(いつ、この人はこれに出会うか)

含み益が出ていて、一部を利益確定しようか迷っているとき。
「売ってもまた買い直せばいい」と思っている。

## 鎖(1本だけ)

```
100万円で買った投資信託が、150万円になった
  → 売る                   → 手元に150万円(利益50万円は非課税)
  → 今年の枠は?             → **戻らない**
  → 翌年の枠は?             → **100万円ぶんだけ戻る**(買った値段 = 簿価)
  → 150万円ぶんは戻らない    → 差 50万円ぶんの枠が消える
```

種になる数字は **買った値段** ひとつ。

## L001(長尺)との関係

L001 は「NISAの損」が主題で、枠の話は手順の4つめとして**10秒ほど触れているだけ**。
この動画は**枠だけを60秒で扱う**ので重ならない。L001 からの導線にもなる。

## 独自性要素(戦略§8 — 2つ以上)

1. **独自計算**: 買値100万・売値150万での「戻る枠」と「消える枠」を verify.py で再計算
2. **独自の図**: 生涯投資枠1800万円の帯の上で、売った後に戻る部分を色分けする
3. **複数パターン比較**: 値上がりして売った場合 / 値下がりして売った場合(損なら簿価まるごと戻る)

## コンプライアンス(戦略§6)

- **「売るな」「売れ」とは言わない。** 戻る枠の出し方だけを渡す
- 個別の銘柄・投資信託・証券会社を出さない
- 例に使う金額はすべて**仮定**と明示する
- **年間の投資枠(360万円)には別の上限がある**ことを注記する
- 枠が戻るのは翌年で、**その年の非課税保有限度額の範囲内**であることを明示
- 「2026年8月時点の制度です」を入れる

## 出典

- NISAの非課税保有限度額(生涯投資枠)は1800万円。年間投資枠は360万円
- 売却した場合、その分の枠が再利用できるのは**翌年**
- 再利用できる額は**簿価(取得価額)ベース**であり、売却額ではない
  — 金融機関各社の公表資料で一致(確認日 2026-08-18)
- 確度: 制度の内容は**A**(複数の金融機関の公表資料で一致)。

  **金額はすべて verify.py の自前計算**
