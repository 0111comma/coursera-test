# 企画書: 空売り(S022 v2)

## 企画の4行(docs/persona.md)

- **想定視聴者**: P-A。28〜40歳の会社員。NISAでインデックス投信を月1〜3万円積立中。
  個別株も信用取引もやっていない。「空売り」という言葉はニュースやSNSで見たことがあるが、
  意味を人に説明できない。
- **指を止める理由**: 「株が下がると、もうかる人がいる」という、名詞を知らなくても分かる矛盾。
  自分の投信は下がると損なのに、得をする人がいるのはなぜか、が直ちに立つ。
- **視聴後に得るもの**: ニュースの「空売り」の意味が分かる。そして**自分はやらない理由**が分かる。
- **視聴者の予想**: 「持っていない株を売る?意味がわからない」「損しても出した額まででしょ」
- **この動画の結論**: 「借りて売って買い戻すだけ。ただし**損に上限がない**」

## v1(却下)の失敗

ユーザー指摘:「なぜこのプロットでGOが出ると思ったの?」「最初の『100万円の空売りで〜』
これなんで入れたの?その次の繋がりは?」「空売りの解説動画だってならなくない?」

1. **数字フックの誤用**: 1文目を「100万円の空売りで、損が200万円」にした。
   このペルソナは空売りを知らず、ポジションも持っていない。**知らない名詞の金額は他人事**であり、
   「何の動画か」も伝わらない。数字フックは既知の名詞にしか効かない(年金・学費・宝くじは効いた)。
2. **1→2の断絶**: 損の金額を出したあと、2文目で定義に戻った。話が前に進んでいない。
3. **企画書を書かずに render.py を書いた**。だから「誰が、なぜ止まるのか」が一度も定義されなかった。

## v2の設計

**フックは名詞なしで分かる現象にする。名詞は2文目で与える。**

| # | ビート | 役割 |
|---|---|---|
| 1 | 株が下がると、もうかる人がいるのだ | 矛盾。名詞を知らなくても分かる。「どうやって?」が立つ |
| 2 | その方法が【空売り】。やることは3つだけ | 名詞を与える + 「3つだけ」で難易度の不安を下げる |
| 3〜5 | 借りる → 売る → 買い戻して返す | 3ステップの図を1行ずつ積み上げる |
| 6 | たとえば100万で売り、80万で買い戻せば20万 | **ここで初めて数字**。名詞を理解した後だから意味が乗る |
| 7 | これが、下がると得をする仕組み | 冒頭の矛盾を回収 |
| 8 | では、上がってしまったら? | 反転の起点 |
| 9〜10 | 高い値段で買うことになる → 3倍なら損200万円 | ピーク |
| 11〜12 | 買いは100万で止まる / 空売りは上限がない | 非対称(この動画の核心) |
| 13 | これで、ニュースの空売りが分かる | ペイオフの明示。やり方は勧めない |

## 数値の根拠

verify.py 参照。100万円分を空売りした場合:
- 2割下がって80万円で買い戻す → もうけ20万円
- 株価が3倍 → 買い戻しに300万円 → 損200万円(出した100万円を超える)
- 普通に買った場合の最大損失は、株価が0でも投資額の100万円

## コンプライアンス(戦略§6)

- 仕組みとリスクの解説に限る。**やり方の推奨・煽りはしない**
- 「損に上限がない」は事実の提示。実務上は追証・強制決済で止められる旨を注記する
- 締めは「ニュースが分かるようになる」であって「やってみよう」ではない
