# FZ002 改訂制作設計

ユーザーの2026-09-08の指摘 U23〜U25を適用。同じ1本を修正する。

## 一つの学び

「商品数」では分散を判定できない。オルカンにS&P500連動商品とQQQを買い足す場面で、共通する実在企業を見せる。買い足しの目的が、投資先を広げることなのか、既に持つ米国大型株を厚く持つことなのかで判断が変わる。

## 展開

1. オルカンにS&P500とQQQも追加、これで分散？
2. 3商品の投資対象を簡潔に並べる。
3. エヌビディア・アップル・マイクロソフトが3商品に入っている表。
4. 3商品からエヌビディアへ「投資額の一部が」向かう図。
5. 全銘柄が同じではなく、企業ごとの配分も異なると補足。
6. 広げるか、厚く持つか。投資先と割合を見て決める。

X/Y各50%の架空例は採用しない。根拠は sources.json と script.md。資料日付が違うため厳密な重複率は算出しない。重ね買いを常に悪いとも、QQQをS&P500の完全な部分集合とも説明しない。

## 画面

- 1080×1920、24fps。右側専用の予約領域は0px。
- カードはx=32〜1048の左右対称。字幕帯とチャンネル帯は幅1080px全体を使う。
- 下側360px（y=1560〜1919）は背景色だけ。タイトル・チャンネル登録欄用。360pxは今回の制作上の設定値であり、ユーザーが過去に指定した数値とは主張しない。
- 字幕・図・立ち絵・音声クレジットは全てy<1560に収める。
- VOICEVOXの実際の話者一覧でずんだもんノーマル・speaker_id=3を照合。

## 検証

render.py が各カットの出現中・静止中の文字境界を検査。全描画フレームで下360pxの背景色と、右端まで続く字幕帯を検査。完成MP4を全デコードし、解像度、音声ストリーム、60秒未満を確認。出力render-report.jsonに生成元コミット、SHA256、検証値を記録する。
