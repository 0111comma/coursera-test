# FZ002｜主題を維持した具体例の差し替え（U27）

主題：商品を3本買っても、それだけで分散したとは限らない。見るべきは中身と割合。

元の構成「投資信託3本で分散？ → 投資信託の中身 → 3商品の例 → 同じ企業への投資が重なる → 月次レポートの投資先・割合を見る → 袋が3つでも中身は別物にならない」を復元する。

変更するのは架空のX/Y各50%を、実在するオルカン・S&P500連動商品・QQQと実在企業の例へ置き換える部分。米国大型株を厚く持つかどうか、買い足しの目的の二択、各商品の詳しい紹介へ主題を変えない。

実商品の保有内容は完全一致しないため、旧架空例の「合算しても割合が同じ」という数値の結論は転用しない。商品数だけでは分散の程度を判断できないという元のメッセージを守る。

画面と音声は既定を維持：1080×1920・24fps、下360px予約、右専用余白0px、左右内側32px、VOICEVOXずんだもん3。納品には必ず独立したMP4リンクを添付。
