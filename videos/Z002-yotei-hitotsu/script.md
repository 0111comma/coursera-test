## この本の型(docs/channel-zunda/strategy.md §8 #11)

- 1コマ目 = **場面の問い**(今週のカレンダーを思い出させる)
- 判定は5秒以内(足りてないのは時間ではなく予定のほう)
- 締めは**手が動く動作**(出なくていい1件を消す。消せないなら「欠席」の返信を1件)

## メッセージは1つ(2026-09-07 ユーザー指摘)

> 「このショート動画に込められるメッセージは一つだよ? なんでこんな詰め込もうとしてるの??」

この動画のメッセージは **「時間が足りないんじゃない。自分で予定に渡してる。今週1件消す」** の1つ。
学びの3問(誰が言った/なぜ残った/誰がどう評価した)は、**この1つを深くするためだけ**に置いた。
plan.md §1.7 にカット数の上限を先に書いてある。**この線に乗らないカットは、面白くても入れない。**

落としたネタ(次の1本になる): セネカの『倫理書簡集』第1書簡「時間を集めよ」、
アンブロシアヌス写本そのものの伝来史。

## 直したところ(冷読パネル。3周目 2026-09-08)

**前情報ゼロの読者4人に字幕だけを順に読ませ、「自分なら絶対に言わない文」を全カットで挙げさせた**
(`.claude/workflows/coldread.js`)。2人以上が「言わない」とした21文を、読者の言い方に置き換えた。
同じ日に走った日本語パネルの定訳直し(ストア派・食糧長官・政治顧問・随筆・写本・多忙な人)は残し、
**読者の言い方と定訳がぶつかるところは、定訳を残したまま語順だけ話し言葉に組み直した。**

- **書き言葉の名残を落とした**: 「役人あてに書いたのが」「その回らない職の人に」
  「浪費って、他人の用事で埋まった人生の一日のこと」「1件をどう選ぶかは〜にあるの」
- **迷子になったカットに橋を架けた**(読者4人が別々の場所で脱落していた):
  - #7 幕1から前置きなしに「ローマの役人あての本」へ跳んでいた → 「同じ悩みに答えた昔の本」
  - #14 芯が立った直後にセネカの経歴へ入れ替わっていた →
    「手放せって言うセネカは暇な人? 逆で、」と、**なぜ今この人の話をするか**を先に言う
  - #23 引用から書誌へ脈絡なく切り替わっていた → 「なんであなたに届いてるの?」と問いで繋ぐ
  - #24 写本・修道院が同時に出ていた → 「だって昔は印刷が無いから」と理由から入る
- **ゲートで書き言葉に戻さなかった**: 話し言葉に直した直後、check_flow が14件の断絶を出した。
  接続語を貼らず、**名詞をもう一度言うか、話し言葉の受け(で、/てか/だって/じゃあ)で繋いだ**。
  指示語が上限を超えたぶんは #4・#21・#30 を名詞に置き換えて減らした
- **ゲートを通すために足した語**(記録): #8「あなたより忙しい役人」(check_kotoba C1 の二人称)、
  #11「食糧長官は、街の食べ物をあずかる人のことね。」(check_yougo の語釈)。
  どちらも**説明のために足した文ではなく、視聴者の位置を示す文**として書いた

## 直したところ(パネルの指摘。2周目)

**日本語パネル(平均62.8・high 15件)と批評パネル(high 9件)で畳んだ。**
いちばん重かったのは、**学びの3幕が21カット(全40カットの53%)**まで膨らんで、
企画書 §1.7 が自分で置いた上限を破っていたこと。Z001 が学説史の年表になったのと同じ形。

- **原文に無い文言をカギカッコで「書いた」と断定していた**(「辞めなよ」「その仕事は辞めろ」)。
  本物の章節つき引用と同じカッコで出していたので、視聴者に区別がつかない。趣旨として言い直した
- **宛先が「ある役人」のまま**で、視聴者の最大の反論「自分がいないと回らない」への答えを捨てていた。
  パウリヌスはローマの食糧長官で、止まれば街が飢える職。そこに「手放せ」と書いてある
- **「なんで残った?」に how しか答えていなかった**(写本の経路)。why(修道院が写す本に選び続けた。
  異教徒なのに身内あつかいだった)に差し替え、11世紀の写本と100冊以上は次の1本に回した
- **100冊の写本のおかげでモンテーニュが読めた、は時代が合わない**(16世紀は活版印刷)
- **BADGE の「西暦49年ごろ」が執筆年の断定**になっていた(全カットに出続ける)。年を外した
- **締めの「時間が取り戻せる」は plan §11 で自分に禁じた効果の断定**。3.1 の枠内に戻した
- **本の出だしを取り違えていた**。1.1 は「人生は短い」と嘆く側から始まり、1.3 でセネカが返す

## 直したところ(1周目)

- **1.3 の定訳は「浪費」**(原語 perdere = 自分で使いつぶす)。「失う/取られる」に
  言い換えると、§9 の結論(自分で渡している)と逆を向く(日本語パネル)
- **西暦49年時点のネロはまだ皇帝でない**(即位は54年)。「のちの皇帝」と言う
- **国の財政を動かしたのはセネカではない**(a rationibus はパッラス)。「皇帝の右腕」にした
- **100冊以上は派生であって直接の写しではない**。「1冊から広がって」と言う
- **モンテーニュを様式史ではなく実例として置いた**。37歳で裁判所の職を手放した人=
  実際にカレンダーを消した人(批評パネル high)

時間が足りないんじゃなくて、予定に渡してるだけかもしれないのだ。
2000年近く前のローマで、皇帝の右腕をやっていた人が同じことを書いていたのだ。

## この台本で守ったこと(工程の記録)

- **工程A(鎖)**: 出なくていい会議が1件ある → 足りてないのは時間ではなく予定 →
  渡してるのは自分 → それを書いたのがセネカ → 皇帝の右腕という、いちばん忙しい側の人間 →
  忙しすぎる役人への手紙 → 「多くを浪費してるんだ」 → 浪費してるのは自分 →
  写本1冊で1000年残った → モンテーニュは37歳で職を手放した →
  財産は分けないのに時間は分け与える → 今週1件消す、の1本
- **経験的な主張をしない**(strategy §5.2): 「予定を消すと楽になる」「生産性が上がる」は言わない
- **会社・上司を悪者にしない**(plan §11)。会議に出るなとは言わない。判断は視聴者がする
- **励まさない**(§14)。「大丈夫」「気にしなくていい」は言わない
- **締めは動作**(1件消す/「欠席」と返信する)
