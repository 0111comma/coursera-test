# 企画書: 「老後2000万円」は月いくらで届くのか(S021)

- **公開予定**: 2026-08-22(土) 19:30
- **形式**: 縦型 1080×1920 / 60秒未満

## 最初の一言(問い)

老後の2000万円、月いくらで届く?

## この人の欲求

**「老後2000万円」と聞いて不安なだけで、何もできていない。
毎月の数字に直して、不安を手元の判断に変えたい。**

欲求マップの **D(先の不安を減らしたい)**。
D の note のとおり「数字を出すと不安はむしろ下がる」方向で作る。

### 作り直しの経緯(ループ71のユーザー指摘)

前の版は「貯金1000万円、月いくらで届く?」だった。

> 「S21はだれのどの欲求に向けた動画なの?」

答えられなかった。1000万円という目標も20年という期間も私が置いた仮定で、
**その数字を目指している実在の人がいない**。逆算という計算の型が先にあって、
視聴者を後から貼りつけていた(S012・旧S016と同じ失敗)。

**2000万円は違う。** 「老後2000万円問題」として誰もが聞かされた数字で、
不安だけ抱えて放置している人が実在する。チャンネルの実測でも
45〜54歳が総再生時間の半分を占め、S011(年金)がいちばん伸びた。

## 場面

**「老後2000万円」の話を何度も聞いて、不安なまま何もしていない。**
毎月いくら貯めれば届くのかを、一度も計算したことがない。

## 視聴後に決められること

**毎月の積立額を決める。** 出せる額が月5万円を超えるなら預金だけでいくと決められるし、
出せないなら、増やす前提(と、その分のリスク)を入れるかを決められる。

## この動画が答える問い(1つだけ)

**2000万円を30年でつくるには、毎月いくら要るのか。**

- **視聴者の予想**: 「2000万なんて、どうせ無理な額でしょ」
- **この動画の結論**: 「預金だけなら**月5万2300円**。年5%と仮定するなら**月2万4000円**。
  毎月の差は2万8300円、**30年で出すお金の差は1018万円**。
  受け取りはどちらも2000万円」

## 鎖(1本だけ)

```
2000万円 / 30年(360ヶ月)
  預金 年0.4%(2026年8月の水準) → 毎月 52,298円 ≒ 5万2300円
  運用 年5%と仮定             → 毎月 24,031円 ≒ 2万4000円
  毎月の差 28,300円 / 30年で出す額の差 1,018万円
```

種になる数字は **2000万円と30年** の2つだけ。

## 想定視聴者(JTBD: 状況と用事)

- **P-B(老後不安はあるが、具体的な行動をしていない人)**。
  2000万円という数字だけ知っていて、月割りにしたことがない。
- **用事**: 自分の家計で届く数字なのかを知って、不安を判断に変えたい。

## 指を止める理由

**「月いくらで届く?」**は、2000万円と聞かされた全員が一度は思って、計算しない問い。
誰もが知っている数字(2000万円)が入口なので、前提の説明が要らない。

## 視聴後に得るもの

2000万円が「無理な額」から「月5万2300円 or 月2万4000円」という
**比べられる数字**に変わる。不安の置き場所が決まる。

## コンプライアンス(戦略§6)

- **年5%は仮定**とバッジ・ナレーション・早見表で明示。増える保証はない
- **預金は減らない**ことも言う。片側だけを良く見せない
- 2000万円は「よく聞く数字」として扱い、「あなたに2000万円必要」とは言わない
  (足りない額は人によって違う、を図の注記に入れる)
- 個別の銘柄・投資信託・金融機関を出さない
- 「2026年8月時点」を入れる

## 独自性要素(戦略§8 — 2つ以上必要。ここでは3つ)

1. **独自計算**: 5万2300円・2万4000円・2万8300円・1018万円を verify.py で再計算
2. **独自の逆算**: 有名な2000万円を毎月の額に直す向き
3. **独自の対比**: 出すお金の差1018万円と、受け取りが同じ2000万円という並び

## 出典

- 「老後2000万円」は金融庁の市場ワーキング・グループ報告書(2019年)に由来する通称。
  不足額は前提により変わるため、動画では「よく聞く数字」として扱う
- 預金金利 年0.4%は2026年8月のメガバンク普通預金の水準
- 計算は毎月末払いの年金終価の式を目標額から逆算(自前計算)。確認日 2026-08-20
- 確度: 計算は **A**。年0.4%は **B**(銀行による)。年5%は **C**(仮定)
