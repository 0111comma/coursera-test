# 企画書: 2本持ちで分散したつもりが、米国80%になっている(S034)

**トピックの出どころ**: ユーザーが外部で集めた「いまYouTubeでホットな5案」の
NISA案(オルカンの次に買うべき銘柄)。

**元案のうち「メガバンク株・高配当株を2〜3銘柄ピックアップして紹介」は採用しない。**
個別銘柄の推奨は `docs/strategy.md` §6-1 の違反であり、
無登録の投資助言に当たりうる。ここは動かせない。

**そのかわり、元案がホットな理由のほうを取る。**
このネタが伸びるのは、視聴者が「**自分のNISAはこれで合っているのか**」と
思っているからで、銘柄を教えてほしいのはその不安の表れにすぎない。
不安そのものに、銘柄を1つも出さずに答える。

---

## 1. この人の欲求

**すでに積み立てている分を、間違った形のまま置いておきたくない。**

`docs/research/yokkyu-map.md` の **C(持っているものを無駄にしたくない)**が主、
**B(選択を間違えたくない)**が従。
直近は S030=C / S031=A / S033=A / (S034候補=B)。C を主に置くのは S030 以来。

この人は「1本だと不安だから」と2本目を買った。**分散を増やしたつもりでいる。**
実際に増えたのは分散ではなく、米国の比率だった。

## 2. 場面

**NISAで全世界株のインデックスを積み立てていて、
「これだけでいいのか」と思って2本目(米国株のインデックス)も買った人。**

きっかけは「銘柄の見直し」「積立設定を変えるとき」「他人のポートフォリオを見たとき」。
**「オルカンの次は何を買えばいい?」で検索した経験がある人**が中心。

## 3. 想定視聴者

P-M(35歳・男性・会社員)。docs/persona.md。
NISAのつみたて枠で全世界株を毎月積んでいる。
「分散」という言葉は知っているが、**自分が持っているものの中身は見たことがない**。
2本持ちが重複しているという発想がない。

## 4. 最初の一言(問い)

> 「全世界株と米国株、両方積み立てていませんか?」

銘柄名でも数字でもなく、**視聴者がやっている行動**から入る。
この動画が否定するのは行動の前提であって、視聴者の判断ではない。

## 5. 指を止める理由

- **自分がやったことがそのまま画面に出る。**「1本だと不安だから2本目を買う」は
  よくある行動で、視聴者は自分の話だと感じる
- **「分散」という言葉が裏返る。**増やしたのは分散ではなく偏り
- カバーに **60% → 80%** を並べる。何の比率かは伏せる
  (S033の反省: パッケージが転回を先に殺す。kotoba-rules K1)

## 6. 視聴後に得るもの

全世界株インデックスの中身は約6割が米国で、上位10銘柄だけで全体の約4分の1を
占めること(2026年8月時点)。そこに米国株インデックスを足すと、
足した分だけ米国比率が上がること。半々で持てば米国は約8割になること。

## 7. 視聴後に決められること

**2本の積立額の比率を、いまのままにするか変えるかを決められる。**

計算も決まっている: **全世界株の割合 × 0.6 + 米国株の割合。これが自分の米国比率。**

「知る」で終わらせない。**掛ける数が決まっていて、出る答えが1つ**の状態にして終わる。

## 8. 感情の設計

1. **是認**(2本目を買った動機は正しい。1本で不安になるのは自然)
2. **中身**(全世界株の6割は米国。約2500銘柄あるが上位10で4分の1)
3. **計算**(半々で持つと米国は8割)
4. **逆転**(増やしたのは分散ではなく偏りだった)
5. **正直**(米国に寄せること自体は間違いではない。**意図してやっているなら何も問題ない**)
6. **行動**(自分の比率を計算して、意図と合っているか確かめる)

**5を飛ばさない。**「2本持ちはダメ」と言うと、それは助言になる。
この動画が渡すのは**自分の比率を出す方法**であって、正解ではない。

## 9. この動画の結論(ネタ選定ゲート F1)

> **全世界株に米国株を足すと、分散は増えない。米国の比率が上がるだけ。
> 半々で持てば米国は約8割になる。**

予想と食い違う点: 視聴者は「本数を増やす = 分散が増える」と思っている。
中身が重なっている2本を足しても、**重なっている側が濃くなるだけ**だと分かる。
「分散」の意味が本数から中身に置き換わる。

## 10. 前提と根拠

**比率は毎月動く。だから幅で言い、時点表記を必ず入れる。**

この実行環境は egress proxy が運用会社のサイト(emaxis.am.mufg.jp)を遮断していて
(2026-08-30確認)、月次レポートを開いて確かめられない。
**複数の解説記事が「米国が約6割」「上位10銘柄で約4分の1」で一致すること**
までを確認した。

**焼く前・投稿前にユーザーの環境で、運用会社の月次レポートを確認すること。**

| 値 | 根拠 | 出典(確認日 2026-08-30) |
|---|---|---|
| 約60% | 全世界株インデックスの米国比率。世界の株式時価総額に占める米国の割合 | 複数の解説記事が一致(確度B)。**毎月動くので「約6割」と幅で言う** |
| 約25% | 上位10銘柄の合計比率。約2500銘柄のうち | 同上(確度B)。**「約4分の1」と言う** |
| 100% | 米国株インデックスの米国比率 | 定義そのもの(確度A) |
| 80% | 2本を半々で持ったときの米国比率 | **自前計算**(0.5 × 0.6 + 0.5 × 1.0)。verify.py で検証 |

**個別銘柄名は1つも出さない。**組入上位の企業名は「中身の説明」として出すことも
できるが(§6.2 で名指しは禁じていない)、この動画では出さない。
**「次に買うべき銘柄」を期待して来た視聴者に銘柄名を見せると、
出しただけで推奨と読まれる**からで、それはこの動画の設計と矛盾する。

## 11. 数値(verify.py で検証済み)

```
全世界株インデックスの米国比率   約60%      (2026年8月時点。毎月動く)
  中身は約2500銘柄。ただし上位10銘柄で約25%(4分の1)
米国株インデックスの米国比率     100%       (定義上)

2つをどの割合で持つと、米国は何%になるか
  全世界株100% : 米国株  0%  →  米国 60%
  全世界株 70% : 米国株 30%  →  米国 72%
  全世界株 50% : 米国株 50%  →  米国 80%   ← 半々
  全世界株 30% : 米国株 70%  →  米国 88%

100万円で言うと
  全世界株だけ  →  米国に 60万円
  半々で持つ    →  米国に 80万円
```

**自分の比率の出し方(これを動画の持ち帰りにする)**
> 全世界株の割合 × 0.6 + 米国株の割合 = 自分の米国比率

## 13. コンプライアンス(戦略§6)

1. **個別銘柄・特定商品を推奨しない。**出てくるのは「全世界株のインデックス」
   「米国株のインデックス」という**種類**だけ。商品名も組入銘柄名も出さない
2. **どちらが正しいと言わない。**米国に寄せること自体を否定しない。
   「意図してやっているなら問題ない」を必ず入れる。渡すのは**計算方法**であって正解ではない
3. **断定を避ける。**「分散できていない」ではなく「米国比率がいくつになるか」
4. 数値はすべて verify.py で再計算し、assert で固定した
5. **「2026年8月時点の比率です。毎月動きます」の時点表記を入れる**
6. 独自性要素: (a) 2本の保有比率ごとの米国比率の自前計算、
   (b) 100万円に置き換えた言い換え、(c) 持ち帰りの計算式(× 0.6 + 米国株の割合)
   — 3つで基準を満たす
