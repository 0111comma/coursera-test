# 企画書: 「老後は働けばいい」は成り立つか。働くと減る年金の線(S034)

**トピックの出どころ**: ユーザーが外部で集めた「いまYouTubeでホットな5案」の4番目
(2026年の年金新ルール)。ただし**元案の「申請しないと一生損する / 申請ハガキの
書き方」は事実誤認**だったので、制度の実態に合わせて作り直した。
在職老齢年金の基準額の見直しは**申請不要**で、日本年金機構が自動で計算し直す。

**2026-09-02 主対象を60代から P-M(35歳・男性・会社員)へ立て直した。**
前の4版は主対象を「60代で年金をもらいながら働く人」に置いていた。
`docs/persona.md` は「以後すべての企画は P-M から始める」と決めていて、
理解度テストの読者にも35歳男性を入れていなかった。ユーザーの指摘は一言だった。

> 「俺らのチャンネルのメインターゲットは35歳男性ね? これやるならなぜ35歳男性を入れない?」

S032 が落ちた理由(persona.md「30年先の話で、自分ごとにならない」)と同じ穴に、
ペルソナの側で落ちていた。**ネタに合わせて主対象を後から動かしていた。**

## 1. この人の欲求

**老後の不安を、自分の数字で減らしたい。「老後は働けばいい」が本当に逃げ道になるのか知りたい。**

`docs/research/yokkyu-map.md` の **D(先の不安を減らしたい)**が主、
**A(取られたくない)**が従。yokkyu-map の D は「数字を出すと不安はむしろ下がる」
方向で作ると決めている。この動画はその型で、**減る条件と減る量を数字で渡して、
逃げ道が成り立つかを本人が判定できる**状態にする。

P-M は「老後はやばいらしい」は知っているが、自分の数字で考えたことがない。
そしてたいてい**「まあ、65歳を過ぎても働けばいい」を逃げ道にしている**。
その逃げ道に「働くと年金が減る」という通説がぶつかると、逃げ道が消えたように感じる。
**実際には減るのは条件つきで、減っても超えた分の半分だけ。**それを知ると、
逃げ道は残る。

## 2. 場面

**35歳が老後の話を耳にして、「働けばいい」で逃げようとした瞬間。**

きっかけは「老後2000万円」の見出し・親の再雇用の話・会社の定年後再雇用の説明会・
同年代の「年金なんてあてにならない」という雑談。
そこで「働くと年金が減るらしい」と聞いて、逃げ道に穴が開いた気がしている。

この動画の損得が発生するのは、**65歳を過ぎて会社に雇われて働く人**。
P-M の大半は将来そこに入る(自営業・業務委託の収入では減らない。概要欄に置く)。
**親の再雇用の相談を受ける場面は副次。**persona.md「家族構成に依存する話は主題にしない」
に従い、親の話は概要欄と固定コメントに置く。

## 3. 想定視聴者

主対象は **P-M(35歳・男性・会社員)**。副対象は50〜60代(視聴者の24.4%)で、
この層は同じ仕組みを「いまの自分の話」として見る。台本は主対象に合わせて
「老後は働けばいい」から入り、60代を名指ししない。

この動画が扱う「在職老齢年金」は、名前を知らない人が多い。
**制度名は動画で言わない**(2026-08-30 素人3人テストで、3人全員が
「在職老齢年金という」の指示語「これ」で詰まった)。名前は行動を変えないので、
概要欄と固定コメントに置く。

**35歳が持ち帰るのは65万円という額ではなく、減り方の形**(足す → 線と比べる →
超えた分の半分)。額は毎年4月に見直されるので、35歳が65歳になるころには別の額になる。
動画の中でそう言う(§8 の 6)。言わないと、30年後に65万円だと信じたまま帰る。

## 4. 最初の一言(問い)

**「老後は働けばいい」と思ってる?**

制度名でも数字でもなく、**視聴者がいま持っている逃げ道**から入る。
2文目「でも年金をもらいながら働くと、年金が減る」で、逃げ道に穴が開く。
「もらいながら」の5文字で、**受け取っている年金が減る話**だと確定させる
(2026-08-31 知識ゼロ3人テスト。「厚生年金が減る」は、いまの振込額が減るのか、
給料から引かれる保険料が減るのか、将来の年金額が減るのかの3通りに読めていた)。

## 5. 指を止める理由

- **自分の逃げ道が1文目に出る。**「老後は働けばいい」は35歳が実際に口にする言葉で、
  そこに「減る」がぶつかる
- **通説がひっくり返る。**「働くと減る」は本当だが、**減るのは条件つきで、しかも半分だけ**
- カバーに **65万円** を置く。何の数字かは伏せる
  (S033の反省: パッケージが転回を先に殺す。kotoba-rules K1)

## 6. 視聴後に得るもの

**減るのは厚生年金だけ**であること。**仕組みの芯**——厚生年金と給料を足し、
その合計が**法律の決めた額**を超えた月だけ、**超えた分の半分だけ**厚生年金が減ること。
その額が**今年4月に51万円から65万円へ上がった**こと。
減っても半分なので、**働いて増える給料のほうが多い**こと。
そして**この額は毎年4月に見直されるので、35歳が覚えるのは額ではなく形**であること。

**捨てたもの**(60秒に全部は入らない):
旧基準51万円での例題(月2万円減っていた)・「あなたの厚生年金は振込通知書に載る」の
手順3カット(35歳の手元にはまだ無い書類。60代向けの手順だった)・
年24万円・申請不要・制度名。いずれも概要欄と固定コメントに置く。

## 7. 視聴後に決められること

**老後の備えの量を決めるとき、「65歳から働く分」を数えに入れるかどうかを決められる。**

「働くと年金が減るから、働いても意味がない」で逃げ道を消していた人は、
減る条件(合計65万円超)と減る量(超えた分の半分)を知って、
**働く分を老後の計画に戻す**。yokkyu-map D の「備えの量を決める」に当たる。

「知る」で終わらせない。**減る条件が1つ、減る量が1つ**に決まって、
「働けばいい」を老後の計画に入れていいかを本人が判定できる状態で終わる。

## 8. 感情の設計

0. **逃げ道**(「老後は働けばいい」と思ってる?)→ **穴**(もらいながら働くと減る)
1. **限定**(年金は2つ。減るのは会社で働いた厚生年金だけ)
2. **仕組み**(まず足す → 法律の65万円以下? → 超えた分の半分だけ減る)
3. **変化**(この65万円は今年4月に51万円から上がった)
4. **具体**(厚生年金10万+給料45万=55万 → 65万円より少ない → 0円)
5. **正直**(同じ人の給料が60万円なら合計70万円 → 5万円超え → 月2万5000円減る)
6. **判定**(減っても半分。増える給料のほうが多い → 「働けばいい」は成り立つ)
7. **形で持ち帰る**(65万円は毎年見直し → 覚えるのは超えた分の半分、という形)
8. **行動**(老後の備えを決めるとき、65歳から働く分を数えていい)

**0を飛ばさない。**逃げ道を先に口にさせてから穴を開ける。
穴が先だと「年金の話 = 減る・もらえない」の身構えで見る。

**2を厚くする。**前の版の理解度テストで0/3だったのはここ。仕組みの芯を渡さずに
数字だけ並べると、「そういうルールとして丸呑みした」で終わる。

**5を飛ばさない。**「全員減らない」にすると嘘になる。
その人に残る得を、数字ではなく規則で渡す(減るのは超えた分の半分だけ)。

**7を飛ばさない。**35歳向けにした以上、65万円が30年後も同じだと言うのは嘘になる。
額を捨てて形を持ち帰らせる。ここが前の60代向けの版との最大の差。

## 9. この動画の結論(ネタ選定ゲート F1)

> **「老後は働けばいい」は成り立つ。年金をもらいながら働くと厚生年金は減るが、
> 減るのは厚生年金と給料の合計が法律の額(2026年4月から月65万円)を超えた月だけで、
> 減るのは超えた分の半分だけ。働いて増える給料のほうが多い。
> 額は毎年見直されるので、覚えるのは形。老後の計画に「働く分」を数えていい。**

予想と食い違う点: 視聴者は「働くと年金が減る = 働くと損」と身構える。
この動画は**減っても半分で、しかも線が緩んだ側**の話。
「逃げ道が消えた」と身構えて見に来て、「逃げ道は残っている」で終わる。

## 11. 数値(verify.py で検証済み)

```
支給停止の基準額   51万円 → 65万円   (2026年4月1日。14万円の引き上げ)
計算式             (年金の月額 + 給与 − 基準額) ÷ 2

例(仮定): 年金の月額 10万円 + 給与 45万円 = 55万円
  2026年4月〜 55万円は65万円以下  → 減らない(0円)

70万円 = 厚生年金10万円 + 給料60万円(もう一人の例。給料は仮定)
  5万円 = 70万円 − 65万円(超えている分)
  2026年4月〜 5万円 ÷ 2 = 月2万5000円 減る
```

**全員が0円になるわけではない。**給料60万円の人は改正後も月2万5000円減る。
この行は台本に必ず入れる(嘘をつかないことが信用の全部)。

**台本の動詞は「減る」に統一する**(2026-08-30 第3ラウンドの素人審査)。
「止まる(支給停止)」は制度側の言い方で、丸ごとゼロに聞こえる。

## 13. コンプライアンス(戦略§6)

2. **断定を避ける。**「働けばいい」は「成り立つ」までで、「働けば足りる」とは言わない。
   給料が高い人は減ることを同じ動画で言う

4. 数値はすべて verify.py で再計算し、assert で固定した

   基準額は毎年4月に見直されるので、この表記は特に重要。**35歳向けなので声でも言う**

   制度を読み直す構成、(c) 元トピックの誤り(申請が要る)を正す —
