# 企画書: 「働くと年金が減る」から降りていい人がいる(S034)

**トピックの出どころ**: ユーザーが外部で集めた「いまYouTubeでホットな5案」の4番目
(2026年の年金新ルール)。ただし**元案の「申請しないと一生損する / 申請ハガキの
書き方」は事実誤認**だったので、制度の実態に合わせて作り直した。
在職老齢年金の基準額の見直しは**申請不要**で、日本年金機構が自動で計算し直す。

**この動画は「締切もの」ではなく「調整をやめていい人がいる」**という設計にする。

---

## 1. この人の欲求

**働いた分だけ受け取りたい。年金を減らされるのが嫌で、働き方を抑えるのはもっと嫌だ。**

`docs/research/yokkyu-map.md` の **B(大きな選択を間違えたくない)**が主、
**A(取られたくない)**が従。直近は S030=C / S031=A / S033=A と偏っていたので、
ここで B を主に置く。

この人は「働くと年金が減る」という**広く知られた通説**を信じて、
勤務日数・残業・役員報酬を自分から抑えている。**その調整が、
2026年4月から多くの人にとって不要になる。**

## 2. 場面

**60代(65歳以降も含む)で、老齢厚生年金を受け取りながら会社に雇われて働いている人。**
60代前半でこれに当てはまるのは特別支給または繰上げ受給の人に限られるので、
**サムネ・概要欄は「60代」で開く**(字幕も「60代」で名乗る)。
そして**その子ども世代**(親の働き方の相談を受ける30〜40代)。

**自営業・業務委託の収入では減らない**(厚生年金に入って働く場合の話)。
まだ受け取っていない人(繰下げ待ち)にも関係がない。この2つは概要欄に置く。

きっかけは「再雇用の条件を決める面談」「勤務日数を決める時期」
「年金の見込み額の通知が来た」。
**「年金が減るから、これ以上は働かない」と自分で決めた経験がある人**が中心。

## 3. 想定視聴者

主対象は60代前半の会社員・再雇用者。副対象は P-M(35歳)で、
**親の働き方の話として見る**。docs/persona.md の P-M は「親の年金」を
自分ごとの隣にある話として扱う。

この動画が扱う「在職老齢年金」は、名前を知らない人が多い。
**制度名は動画で言わない**(2026-08-30 素人3人テストで、3人全員が
「在職老齢年金という」の指示語「これ」で詰まった)。名前は行動を変えないので、
概要欄と固定コメントに置く。動画は「60代で働くと厚生年金が減る」から入る。

## 4. 最初の一言(問い)

**60代。もらってる年金、働くと減る?**

制度名でも数字でもなく、**視聴者がいま受け取っているもの**から入る。
「もらってる」の5文字で、**いま振り込まれている年金の話**だと1カット目で確定させる
(2026-08-31 知識ゼロ3人テスト。「厚生年金が減る」は、いまの振込額が減るのか、
給料から引かれる保険料が減るのか、将来の年金額が減るのかの3通りに読めていた)。

**行動(働く時間を抑えている)を条件にしない。**前の版は
「働く時間を抑えてる?」と条件を疑問形に埋め込んでいたため、
抑えていない人が自分を対象外だと読んだ(3人中2人)。

## 5. 指を止める理由

- **自分がやっている調整がそのまま画面に出る。**「働きすぎないようにしている」は
  60代の現場でよく聞く話で、視聴者は自分の話だと感じる
- **通説がひっくり返る。**「働くと減る」は今も正しいが、**減りはじめる合計が上がった**
- カバーに **51万円 → 65万円** を並べる。何の数字かは伏せる
  (S033の反省: パッケージが転回を先に殺す。kotoba-rules K1)

## 6. 視聴後に得るもの

**これは60代で年金をもらいながら働く人の話**であること。もらっている年金のうち
減るのは**厚生年金だけ**であること。**仕組みの芯**——厚生年金と給料を足し、
その合計が**国の決めた額**を超えた月だけ、**超えた分の半分だけ**厚生年金が減ること。
その額が**今年4月に法律が変わって 51万円から65万円へ上がり、もう65万円である**こと。
自分の位置は、**ねんきん定期便の厚生年金と、ボーナスを12で割って足した給料**を
足して65万円と比べれば出せること。

**捨てたもの**(2026-08-31 知識ゼロ3人テスト後の書き直し。60秒に全部は入らない):
「基礎年金は減らない」の1カット(3人全員がここで止まったので**画面だけに残した**)・
給料60万円の人の 9万5000円 → 2万5000円 の落差と月7万円(**規則を再適用して
見せる尺のない数字は出さない**)・「あなたは?」の呼びかけ2つ・
制度名「在職老齢年金」・比喩の「線」・年24万円・申請不要。
いずれも概要欄と固定コメントに置いた。

**足すのではなく捨てて厚くした。**理解度4.4/6.0の穴は情報の不足ではなく、
**仕組みの芯を渡さないまま数字の筋だけを並べたこと**だった。

## 7. 視聴後に決められること

**年金を減らされないために抑えていた勤務日数や報酬を、元に戻すかどうかを決められる。**

計算も決まっている: **年金の月額と、給与(賞与を12で割って足した額)を足して、65万円と比べる。**

「知る」で終わらせない。**足す数が2つに決まっていて、比べる相手が1つ**の状態にして終わる。

## 8. 感情の設計

0. **名指し**(60代。もらってる年金、働くと減る?)
1. **限定**(年金のうち減るのは厚生年金だけ)
2. **仕組み**(まず足す → 国の決めた月51万円を超える? → 超えた分の半分だけ減る)
3. **具体**(厚生年金10万+給料45万の人は、51万円を4万円超えて月2万円減っていた)
4. **変化**(今年4月に法律が変わり、51万円が**もう**65万円。この人は月2万円 → 0円)
5. **正直**(全員が0円ではない。給料60万円なら合計70万円で、4月からも月2万5000円減る)
6. **行動**(ねんきん定期便 → 給料を足す → ボーナスは12で割る → 65万円以下なら減らない)

**0を飛ばさない。**「もらってる」を1カット目に置く。
これが無いと、いまの振込額の話なのか、給料から引かれる保険料の話なのか、
将来の年金額の話なのかが決まらない(2026-08-31 知識ゼロ3人テスト)。

**2を厚くする。**理解度テストで0/3だったのはここ。仕組みの芯を渡さずに
数字だけ並べると、3人とも「そういうルールとして丸呑みした」で終わる。
**この動画でいちばん長い区間は2にする。**

**5を飛ばさない。**「全員得します」にすると嘘になる。
ただし**その人に残る得を、数字ではなく規則で渡す**(減るのは超えた分の半分だけ)。
9万5000円 → 2万5000円 の落差は、途中式を見せる尺が無いなら出さない。
出どころの分からない数字は、そこから先の理解を止める(読者2は#19で読むのをやめた)。

**6を判定で終わらせない。**「足して比べる」だけでは実行できない。
**足す数の在りか(ねんきん定期便)と、給料の中身(ボーナス÷12)を声で渡す。**

**手続きの安心(申請は要らない)は動画から外し、概要欄に置いた。**

## 9. この動画の結論(ネタ選定ゲート F1)

> **60代で厚生年金をもらいながら働くと、年金が減るのは今も正しい。
> ただし2026年4月に法律が変わり、減りはじめる合計が月51万円から65万円に上がった。
> 超えないために働き方を抑えていた人は、その調整をやめられる。**

予想と食い違う点: 視聴者は「年金の話 = 減る・もらえない」と身構える。
この動画は**制度が緩む側**の話であり、しかも**申請が要らない**。
「損しないための手続き」を身構えて見に来て、「やめていい我慢がある」で終わる。

## 10. 前提と根拠

**制度は2025年6月に成立済み。施行は2026年4月1日。確度B。**

この実行環境は egress proxy が mhlw.go.jp を遮断していて(2026-08-30確認)、
厚生労働省・日本年金機構の一次資料を開いて確かめられない。
**社会保険労務士事務所3件・給与計算ベンダー2件の独立した解説が、
基準額・計算式・施行日・根拠法のすべてで一致すること**までを確認した。

**焼く前・投稿前にユーザーの環境で、日本年金機構の資料を確認すること。**

## 11. 数値(verify.py で検証済み)

```
支給停止の基準額   51万円 → 65万円   (2026年4月1日。14万円の引き上げ)
計算式             (年金の月額 + 給与 − 基準額) ÷ 2

例(仮定): 年金の月額 10万円 + 給与 45万円 = 55万円
  2025年度   (55 − 51) ÷ 2 = 月2万円 止まる
  2026年4月〜 55万円は65万円以下  → 止まらない
  差         月2万円 / 年24万円

4万円 = 55万円 − 51万円(いままでの基準額を超えている分)
70万円 = 厚生年金10万円 + 給料60万円(もう一人の例。給料は仮定)

給料60万円の人: 月9万5000円 → 月2万5000円(差は月7万円)
  2025年度   (70万 − 51万)÷ 2 = 月9万5000円 減る
  2026年4月〜 (70万 − 65万)÷ 2 = 月2万5000円 減る
  **台本で声に出すのは「合計70万円」と「月2万5000円」だけ。**
  9万5000円と月7万円は、途中式(70万−51万=19万、その半分)を見せる尺が
  無いので出さない(2026-08-31。読者3人全員が「9万5000円がどこから出たか
  分からないまま書き取った」と書き、うち1人はここから先を読むのをやめた)。
  その人に残る得は、数字ではなく**規則**で渡す(減るのは超えた分の半分だけ)

「1円でも減りはじめる」給料の額(厚生年金10万円のとき)
  2025年度   給料 41万円 から
  2026年4月〜 給料 55万円 から
```

**全員が0円になるわけではない。**給料60万円の人は改正後も月2万5000円減る。
この行は台本に必ず入れる(嘘をつかないことが信用の全部)。

**台本の動詞は「減る」に統一する**(2026-08-30 第3ラウンドの素人審査)。
「止まる(支給停止)」は制度側の言い方で、丸ごとゼロに聞こえるのに
直後に「半分」が来るため、規則そのものが読めなくなっていた。

## 13. コンプライアンス(戦略§6)

1. **投資助言をしない。**この動画は制度の説明で、商品も銘柄も出てこない
2. **断定を避ける。**「得します」ではなく「基準額が上がった」。
   給料が高い人は改正後も減ることを同じ動画で言う
3. **不安を煽らない。**「申請しないと一生損する」は使わない(そもそも申請不要)。
   元のトピック案のこの部分は**事実誤認なので採用しない**
4. 数値はすべて verify.py で再計算し、assert で固定した
5. **「2026年4月時点の制度です」の時点表記を入れる。**
   基準額は毎年4月に見直されるので、この表記は特に重要
6. 独自性要素: (a) 給与別の早見を自前計算し、**動画の中で2人ぶん使う**
   (給料45万円と60万円。改正前後の停止額)、(b) 同じ人の改正前後を並べる
   (厚生年金10万+給料45万: 月2万円 → 0円)、(c) 元トピックの誤り
   (申請が要る)を正す — (a)(b) は動画の中、(c) は概要欄で満たす
