# 台本: 年金が減るから働かない、をやめていい人(S034)

主対象は60代前半で厚生年金をもらいながら働く人。副対象は P-M(35歳)で、
**親の働き方の話として見る**。RocknRoll One / 東北きりたん / 語ごとのポップ。

## 設計のねじ(plan §9)

**「働くと年金が減る」は否定しない。**否定するのは
「**だから働き方を抑えるしかない**」という結論のほう。
線そのものが2026年4月に動くので、抑える理由が消える人がいる。

**「全員が得します」にしない。**給料が高い人は改正後も減る。
これを同じ動画の中で、**その人を名指しして**言う(plan §8-5)。
給料60万円の人は、いま月9万5000円 → 4月からも月2万5000円が減る。
ここを飛ばすと嘘になる。

**元のトピック案にあった「申請しないと一生損する」は採用しない。**
この見直しに申請は要らない。日本年金機構が自動で計算し直す。
煽りとして機能する嘘を、こちらから足さない。

## 制度名の扱い(作文原則10)

「在職老齢年金」は正式な名前を**1回だけ**言い、その場で意味を渡す
(3「年金を減らす仕組みを、在職老齢年金という」)。
**動詞は最後まで「減る」で通す。**「止まる(支給停止)」は制度側の言い方で、
素人審査が「止まるなら全部ゼロに聞こえるのに、直後に半分と言われる」で
読めなくなった語。台本と図のラベルから外した。
「基本月額」「総報酬月額相当額」は**使わない**。耳で判別できないうえ、
視聴者が自分の数字を当てはめられない。
それぞれ「年金の月額」「給料(ボーナスを12で割って足した額)」と言う。

## プロット審査(2026-08-30。構成/日本語/コピー/素人目線の4人)

依頼主の「まだプロットがいけてない」を受けた審査。**尺を60秒に収めるために
文を削った結果、日本語が痩せて箇条書きの朗読に近づいていた**のが実態だった。
3ラウンドの書き直しで23カットに組み替え、さらに審査団が挙げた
構造の欠陥3件を直した:

1. **幕5(18〜21)だけ計算の工程が飛んでいた。** 幕3では
   「55万円 → 線を4万円超える → その半分、月2万円」と引き算を見せているのに、
   幕5は「合計70万円」からいきなり答えに飛び、**5万円(70万−65万)が
   声にも画面にも無かった**。「半分」という語だけが残り、何の半分かが宙に浮く。
   しかもここは「全員が得します」の嘘を避けるための最重要の幕で、
   **いちばん納得させたい相手にだけ工程を省いていた**。
   → 20「70万円は4月の線を5万円超える。」21「5万円の半分、2万5000円が減る。」
   図も hero(9万5000円)から formula(70万円 − 65万円 = 5万円)に変えて工程を通した

2. **「あなた」の指す人が幕3と幕5で入れ替わっていた。** 9〜16で給料45万の人を
   「あなた」に固定した直後、18で「給料60万円のあなた」と別人に付け替わり、
   0円と言い切った相手が2カット後にひっくり返って聞こえていた。
   → 18「ただし、給料が60万円の人は?」(三人称に切り替え)

3. **12→13 の因果が通っていなかった。**「毎年4月に動く」ことは
   「誰も自分の線を知らない」理由にならない(動く=毎年ニュースになる、とも読める)。
   → 13「4月に動くから、あなたの去年の額はもう違う。」(動く→知識が古びる、まで繋ぐ)

加えて日本語の誤読を1件つぶした。16「あなたの月2万円が0円になる。」は、
所有格が付いた瞬間に「あなたが受け取る2万円」に読みが移り、
**「あなたの2万円が消える」=損として成立してしまう**(画面は0円を得の色で
出しているので、絵と言葉が逆を向く)。減額のほうを主語に立て直して解消した。
→ 16「減っていた2万円が、【0円】に。」

## 概要欄テキスト

働きながら厚生年金をもらうと、年金と給料の合計が一定額を超えたぶんだけ
年金が減る仕組みがあります(在職老齢年金。制度上は「支給停止」といいます)。

その基準額が2026年4月1日から、月51万円→65万円に上がります。
根拠は令和7年法律第74号(2025年6月13日成立)です。

■ 動画で使った例(いずれも仮定の数字です)
・年金の月額10万円 + 給料45万円 = 合計55万円
  2025年度  (55万 − 51万)÷ 2 = 月2万円が減る
  2026年4月〜 55万円は65万円以下 → 減らない(年24万円の差)
・給料60万円 + 年金10万円 = 合計70万円の場合
  2025年度  (70万 − 51万)÷ 2 = 月9万5000円が減る
  2026年4月〜 (70万 − 65万)÷ 2 = 月2万5000円が減る(4月以降も減ります)

■ 自分の位置の出し方
年金の月額 + 給料(月給 + 直近1年の賞与 ÷ 12)を足して、65万円と比べるだけです。

■ 注意
・この見直しに申請は不要です。日本年金機構が自動で計算し直します
・減るのは老齢厚生年金だけで、老齢基礎年金は減りません
・基準額は毎年4月に見直されます。この動画は2026年8月時点の情報です
・法成立時点の試算は62万円でしたが、賃金の変動を反映して65万円になりました

■ 出典
・年金制度改正法(令和7年法律第74号。2025年6月13日成立)
・厚生労働省・日本年金機構の在職老齢年金の解説

## この台本で守ったこと(工程の記録)

- **工程A(鎖)**: 年金を減らす仕組み → 境目の線は51万円 → 線を超えた分の
  半分だけ年金が減る → 例で月2万円が減っている → 線は毎年4月に動く →
  だから誰も自分の線を知らない → 4月から65万円 → もう超えない →
  月2万円が0円 → 年間24万円 → ただし給料60万円なら4月からも2万5000円が減る →
  足して65万円と比べる、の1本

  幕2〜幕6は動詞ごと入れ替え(止まる→減る)、幕4は12〜13を新設して機構を入れ、
  幕5は4カットに割り直した
