## 概要欄テキスト

本チャンネルは非公式のファン制作です。

上司の一言が帰り道で消えない日に、考える対象を1つ取り替える話です。
その考え方を、誰が言って、なぜ1900年残って、いま誰がどう使っているかまで辿ります。

■ この動画の分け方(エピクテトスの言う「権内」)
・**権内にあるもの**(考える価値がある): 自分の言い方、明日いちばん最初に言う一文
・**権内にないもの**(考えても動かない): 上司の機嫌、その日の評価、他人の気分

「気にするな」ではありません。気にしないことはできないので、
**考える対象のほうを取り替える**という話です。

■ この動画で辿った鎖
1. **エピクテトス**(50頃–135頃)— ローマ帝国の元奴隷。主人はネロの秘書エパフロディトス。
   本人は1冊も書かず、弟子の**アッリアノス**が授業を記録した(『語録』、その要約が『提要』53章)
2. **マルクス・アウレリウス**(121–180)— 皇帝。『自省録』1巻で、若い頃の師から
   エピクテトスの覚え書きを借りたことに謝意を書いている。8巻47で「苦しめるのは出来事ではなく
   それについての判断だ」と、『提要』5とほぼ同じことを書いている
3. **修道院** — 『提要』はキリスト教向けに翻案されて写され続けた。
   変わったのは固有名(ソクラテス → 聖パウロ)がほとんどで、中身はほぼそのまま
4. **アルバート・エリス**(1913–2007)— 精神分析から離れ、1955年に論理療法を提唱。
   『提要』5を手本に挙げている。論理療法は認知行動療法の源流の一つ

## この台本で守ったこと(工程の記録)

- **工程A(鎖)**: 上司の一言が帰り道で消えない → ばつが付くのは「考える」 →
  1900年前の本に答えがある → 世の中は自分次第のものとそうでないものの2つ →
  自分次第なのは自分の言い方と出す物 → 上司の機嫌はそうでないほう →
  でも評価は上司が決める → そのとおりで、だから困る →
  それでも動かせるのは明日の一文だけ → その一文をメモに1行 →
  上司の機嫌を考える時間がそのぶん減る、の1本
- **人名・書名は声に出す**(3分版で60秒版の縛りを外した)。
  エピクテトス・アッリアノス・マルクス・アウレリウス・聖パウロ・アルバート・エリス、
  『語録』『提要』『自省録』。check_manabi が plan.md §1.7 の太字の名前を
  ナレーションに要求する
- **経験的な主張をしない**: 「反芻すると疲れる」「考えても無駄」のような
  測れる主張を原典で支えない(strategy §5.2)。言うのは分け方だけ
- **上司を悪者にしない**(strategy §1・§6)。7〜8文目で「評価は上司が決める」を認める
- **励まさない**(§14)。「大丈夫」「気にしなくていい」は言わない
- **締めは動作**(メモに1行)。「考えた時間を数える」型の締めは置かない(§0-4)
