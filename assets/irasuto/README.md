# いらすとや素材の置き場(Z001 用)

2026-09-05 ユーザー指示「いらすとやで必要な画像を指示して」。
**ここに下の名前で PNG を置くと、`production/scenes_zunda.py` が自動で使う**(無ければベクター図で描く)。

- 形式: いらすとやのダウンロードボタンの PNG そのまま(背景透過・800px 前後)。リサイズ不要
- **1本の動画で使うのは 20 点まで**(いらすとや規約: 21 点以上は有料)。Z001 は下の 17 点
- 素材の再配布は禁止なので、**このディレクトリの PNG はコミットしない**(.gitignore 済み)。各自ローカルに置く
- 概要欄にクレジット「イラスト: いらすとや」を入れる(必須ではないが慣行)
