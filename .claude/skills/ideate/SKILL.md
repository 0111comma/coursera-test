# ネタ出し(/ideate)

お金・金融リテラシーチャンネルの動画ネタを発案し、`ideas/backlog.md` に追記する。

## 手順

1. `docs/strategy.md` を読み、4つのコンテンツピラーとターゲット(20〜35歳のお金初心者)を確認する
2. `ideas/backlog.md` を読み、既存ネタとの重複を避ける
3. WebSearchで以下を確認し、時事性のあるネタを拾う:
   - 直近の税制・制度改正のニュース(NISA、iDeCo、社会保険、ふるさと納税など)
   - 官公庁の新しい統計・調査の発表(家計調査、金融リテラシー調査など)
4. ネタを発案する。引数で本数の指定があればその本数、なければショート10本+解説動画2本を目安とする
5. 各ネタが以下を満たすかチェックし、満たすものだけを backlog に追加する:
   - ターゲットの具体的な「知らない・不安」に答えている
   - ショートなら「1動画=1つの数字」に落とせる(フックの数字を必ず書く)
   - 独自性要素(独自計算・独自グラフ・原文解説・複数パターン比較)を2つ以上入れられる
   - 個別銘柄・特定商品の推奨にならない(戦略 §6)
6. `ideas/backlog.md` の表形式に従って追記し、追加したネタの一覧をユーザーに報告する

## ネタの質の基準

- ×「NISAとは」(漠然、競合と同じ) → ○「月1万円×20年、NISAあり/なしで手取りはいくら違う?」(数字で答えが出る)
- 視聴者が「自分の場合は?」と計算したくなる切り口を優先する
- 検索されるネタ(制度名)と、意外性で伸びるネタ(統計の驚き)をバランスよく混ぜる
