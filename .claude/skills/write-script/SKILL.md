# 台本作成(/write-script)

企画書を、合成音声ナレーション+画面指示の台本に落とし込む。

**最重要**: プロットは `docs/research/plot-playbook.md` の手順(パートC)で作り、
チェックリスト(パートD、D1〜D22)を全項目照合してから台本を確定する。
1つでも不合格なら書き直す。事実の羅列+小技はプロットではない(敵・賭け金・
フリオチ・感情アークのない台本はボツ)。参考実装: videos/S001-tsumitate-fukuri/script.md(v3)

## 手順

1. 対象の `videos/<ID>-<slug>/plan.md` を読む(引数でID指定。なければステータス「企画中」の最古のもの)
1b. **企画書の「この人の欲求」と「視聴後に決められること」を声に出して確認する**(ループ67)。
    台本の**冒頭はその欲求の場面から始め、終盤はその決定に着地させる**。
    分かれ目の数字を出して終わる台本は不合格(旧S013がそれだった)
2. `verify.py` があれば実行し、台本に書く数値がすべて検証済み出力と一致することを確認する
3. 形式に応じたテンプレート(`templates/script-short.md` / `templates/script-long.md`)を元に `script.md` を書く
4. 書き終えたらセルフチェックを行い、問題があれば直す(下記)
5. `plan.md` と `ideas/backlog.md` のステータスを「台本済み」に更新し、台本の全文をユーザーに報告する

## ナレーションの文体ルール(合成音声用)

- **ショートは docs/research/short-video-format.md のR1〜R14に必ず準拠する**(1ユニット=1文=1画面変化、冒頭1秒の動き、ループ+質問締め、字幕=読み上げ文)
- 話者はずんだもん(speaker=3)。語尾は「〜なのだ」を自然な範囲で(全文につけない)
- 話し言葉。一文は短く(ショートは25文字以内目安)。漢数字ではなく算用数字
- 読み間違えやすい語は言い回しを変える。専門用語は初出時に一言で言い換える(例: 「複利、つまり利息にも利息がつく仕組み」)
- 挨拶・自己紹介・「今日は〜について」は禁止。第一声で数字か結論を言い切る

## セルフチェック(投稿前の最終関門)

- [ ] 台本内のすべての数値が verify.py の出力と一致する
- [ ] 断定表現(「儲かる」「必ず」「〜すべき」)がない
- [ ] 個別銘柄・特定商品・特定業者への言及がない
- [ ] 利回り等の仮定に「仮定」の明示がある
- [ ] 時点表記(「2026年◯月時点」)がナレーションまたは画面にある
- [ ] 概要欄に免責文・出典リストがある
- [ ] 想定尺に収まる(ナレーション全文の文字数 ÷ 6.5文字/秒 で概算)
