# 企画書作成(/plan-video)

backlogのネタ1つを、制作可能な企画書に落とし込む。

## 手順

1. 対象ネタを決める(引数で指定があればそれ、なければ `ideas/backlog.md` のステータス「未着手」から優先度の高いものを1つ)
2. `docs/strategy.md` の §5(フォーマット定義)、§6(コンプライアンス)、§8(独自性要素)を確認する
3. **制度・数値の事実確認を必ず行う**: WebSearchで官公庁の一次資料(金融庁・国税庁・厚労省・総務省・日銀)を確認し、出典URLと確認日を記録する。学習時点の知識で制度の数値を書かない
4. 動画IDを採番する(`videos/` 内の既存IDの次番。ショート=S、解説=L)
5. `videos/<ID>-<slug>/` を作成し、`templates/plan.md` を元に企画書を書く:
   - フックの数字は仮置きせず、この段階で計算して確定させる
   - 計算を含む場合は `verify.py` をこの段階で書き、実行して数値を検証する
   - 独自性チェックリストとコンプライアンスチェックリストを実際に埋める(形骸化させない)
6. `ideas/backlog.md` の該当ネタのステータスを「企画済み(ID)」に更新する
7. 企画書の要点(フック、構成、検証済みの数字)をユーザーに報告する

## verify.py の書き方

- 動画に出すすべての数値を計算・出力するスクリプトにする(`python3 verify.py` で全数値が印字される)
- 前提(利回り、年収、期間など)は定数として冒頭にまとめ、仮定であることをコメントに書く
- 税額・社会保険料など制度依存の計算は、根拠(税率表の出典)をコメントに書く
